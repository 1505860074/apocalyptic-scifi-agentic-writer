# 网文生成工作台 · V5

这是一个「**通用写作引擎 + 多本小说**」的网文创作工作台。

**当前核心**：把"世界怎么演化"和"这一章怎么写"拆成独立的层（世界线→故事弧大纲→故事弧状态预算→章节状态分配），每层只吃"刚好够用"的输入，不靠一个agent通读全部前情；章节工坊在"焦点卡→正文生成"之间加了一道**场面调度**，先把每一拍展开成物理可演的动作/空间，再落笔，避免"大纲直接扩写、靠描写凑字数"。

| 版本 | 核心理念 |
|------|----------|
| V1 | 蓝图模式——先画完全书施工图再写 |
| V2 | 生长模式——播种子，大纲随写作演进 |
| V3 | 拆分+校验——写手不自查，每个关键节点有独立校验门 |
| V4 | 剧情演进分层——世界线/故事弧/状态预算/章节分配彼此独立，滑动窗口输入，省token防精度衰减 |
| V5 | **场面调度层——焦点卡与正文之间先把每拍展开成可演调度（站位/动作/对话/内心/感官），治"内容稀、靠描写凑"** |

完整说明见 `ENGINE/工作流总览.md`（唯一权威版本，本文件只是速览，如有冲突以总览为准）。

## 工作流全景

### 立项工坊（开新书第一步，一次性）
```
立项问答（逐维度选择题·定命题/风格/内容）→ 产出《立项书》 → ★ 立项自查（轻量校验门）
```
> 立项书是全书总纲，后面所有步骤动手前都先读它、受其约束。

### 架构工坊（一次性播种）
```
新建项目 建目录 → 世界观与金手指 → 人物种子 → 故事种子与世界基底（含世界线纪要起点） → ★ 架构一致性校验
```

### 故事弧工坊（每个故事弧一次，弧长由戏剧节拍决定）
```
世界线推演（每弧第一步·架构校验后即触发；够则轻过，不够则深推）
        ↓
故事弧大纲 → 故事弧状态预算（含一致性自查 + 支线预算 + 情绪蓄力卡）
```

### 章节工坊（每章循环）
```
章节状态分配 → 章纲节拍表 → 焦点卡 → ★ 焦点卡校验
        ↓
场面调度（每拍展开成可演调度卡）
        ↓
正文生成（只写不查） → ★ 独立正文自查 → 〔自查修正 仅必要时〕
        ↓
润色定稿（默认一道跑完） → 〔★ 最终交付检查 仅有实质改动时〕
```
> **独立正文自查 是全流程最重要的校验**：正文写完后独立agent全面自查，写手不自查。

### 人工反馈修复工坊（发布前/人工反馈后，随时触发）
```
复审修改（自动检索+连带修改） → ★ 回归校验
```

## 怎么用

**新书开始**：
- 「进入立项，书名《XXX》」→「跑立项自查」→「进入新建项目」→「进入世界观与金手指」→「进入人物种子」→「进入故事种子与世界基底」→「跑架构一致性校验」→「跑故事弧大纲，开第1弧」

**日常写作**：
- 「写第N章」→ 自动 章节状态分配→章纲节拍表→焦点卡→焦点卡校验→场面调度→正文生成→独立正文自查→〔自查修正按需〕→润色定稿→〔最终交付检查按需〕
- 一个故事弧写完了 → 判断世界线纪要余量，够就「跑故事弧大纲」开下一弧，不够先「跑世界线宏大推演」

**独立操作**：见 `ENGINE/工作流总览.md` 第六节完整话术表

**发布前人工复审**：
- 「修改第X章第Y段，问题：XXX」→ 自动触发 复审修改（自动检索上下文 + 连带修改）
