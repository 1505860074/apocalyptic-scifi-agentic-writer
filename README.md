# 网文生成工作台 · V3

这是一个「**通用写作引擎 + 多本小说**」的网文创作工作台。

**V3核心变化**：V2 引入"生长模式"（大纲随写作演进）。V3 在此基础上引入**"拆分+校验"**——每个步骤只做一件事、只产一种内容，关键衔接点有独立校验把关。杜绝"一个 agent 同时当写手和校对"带来的幻觉和杂糅。

| 版本 | 核心理念 |
|------|----------|
| V1 | 蓝图模式——先画完全书施工图再写 |
| V2 | 生长模式——播种子，大纲随写作演进 |
| V3 | **拆分+校验——写手不自查，每个关键节点有独立校验门** |

## 工作流全景（V3）

### 架构工坊（播种——3步 + 1验）
```
P1 世界观+金手指 → P2 人物种子 → P3 种子收束 → ★ V1 架构一致性校验
```
> P1-P3 和 V2 相同。V1 是新增——独立审查五个设定文件之间的逻辑矛盾。

### 写作工坊 · 演进（每3-5章——2步 + 1验）
```
P4a 态势分析+反向伏笔 → P4b 局部大纲+状态更新 → ★ V2 演进一致性校验
```
> P4 从一步拆为两步：先分析（P4a），再基于分析做规划（P4b）。V2 检查规划的合理性。

### 写作工坊 · 日更（每章——5步 + 3验）
```
P5a 章纲节拍 → P5b 焦点卡 → ★ V3 焦点卡校验
        ↓
P6 正文写作（只写不查） → ★ V4 独立自查 → P6fix 修正
        ↓
P7a 出戏+去味 → P7b 少年向+校验+标点 → ★ V5 最终交付检查
```
> **V4 是 V3 最重要的新增步骤**：正文写完后，由独立的 agent 做全面自查。写手不自查——这是防幻觉的核心设计。

### Review（人工反馈后——1步 + 1验）
```
P8 上下文手术修改 → ★ V6 回归校验
```
> V6 检查修改有没有破坏伏笔/衔接/数字一致性。

## 怎么用

**新书开始**：
- 「进入P1」→ 世界观+金手指
- 「进入P3」→ 点火的最后一步
- 「跑V1」→ 校验架构一致性

**日常写作**：
- 「写第N章」→ 自动 P5a→P5b→V3→P6→V4→P6fix→P7a→P7b→V5
- 「跑P4」→ 自动 P4a→P4b→V2（每3-5章跑一次）

**独立操作**（想单独跑某个子步骤）：
- 「只跑P5a，第N章」/「只跑P5b，第N章」
- 「跑V4，第N章」→ 独立自查（想追查质量时单独跑）
- 「只跑P7a，第N章」/「只跑P7b，第N章」
- 「跑V5，第N章」→ 最终交付检查

**人工 Review + 回归**：
- 「修改第X章第Y段，问题：XXX」→ P8
- 「跑V6，第X章」→ 检查修改是否引入了bug

**卡住了**：「卡住了，跑P4b」
