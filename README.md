# 网文生成工作台 · V2

这是一个「**通用写作引擎 + 多本小说**」的网文创作工作台。

**V2核心变化**：从"蓝图模式"（先画完全书施工图再写）→ **"生长模式"**（播种子，大纲随写作演进，故事自己长出来）。

## 核心理念

| 旧（V1） | 新（V2） |
|----------|----------|
| 架构工坊定死全书蓝图 | 架构工坊只播种底层规则 |
| 写作工坊按图施工 | 写作工坊跟着故事生长 |
| 全书事件线一次性写死 | 局部大纲每3-5章演进 |
| 伏笔全部预先设计 | 正向登记 + 写作中反向发现 |
| 教AI"写什么" | 教AI"用什么情绪嗓音写" |

## 8步工作流

### 架构工坊（播种，3步）
```
P1 世界观+金手指 → P2 人物种子 → P3 故事种子与世界基底
```
> 只定死物理规则和金手指机制，大秘密留白。

### 写作工坊（生长+Review，5步）
```
P4 演进大纲★ → P5 章纲+焦点卡 → P6 正文 → P7 润色 → P8 Review修改★
```
> ★ P4是生长核心：写完3-5章回看态势，生成接下来的局部大纲。
> ★ P8是人工Review：你说"第X章第Y段需要改"——自动拉通上下文、伏笔、人物状态，分析影响范围后再下刀，不是指哪改哪。

## V2核心创新
- **演进大纲**：大纲是活的，不是一次定死的
- **情绪温度**：文字的嗓音和角色的情绪同频——该慌时文字要慌
- **反向伏笔**：写作中随手写下的细节，回头可以做伏笔
- **表演式描写禁令**：禁止单字形容词断句、简单事件上的诗意化堆砌

## 怎么用
- 新书 → 「进入P1」从世界观和金手指开始
- 写正文 → 「写第N章」自动 P5→P6→P7
- 规划走向 → 「跑P4」基于已写内容生成接下来3-5章大纲
- 完整流程见 `ENGINE/00-工作流总览.md`

## 如何开始一本新书
1. 「进入P0，书名叫《XXX》」→ 自动创建目录结构和空模板
2. P1 → P2 → P3 依次填充世界观、人物、故事种子
3. P4 生成第一批局部章纲后，进入 P5→P6→P7 日更循环
4. 详见 `ENGINE/prompts/P0-新建项目.md`
