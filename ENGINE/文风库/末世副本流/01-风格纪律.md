# 末世副本流 · 风格纪律（抽象倾向）

> 只放这套声音的抽象倾向（换本同类末世副本流仍成立），不抄范文原句。通用手艺（落地/防AI味/句子呼吸）走通用引擎层，本包不重复。示例见 `02-范文例库/`。

## 核心倾向
1. **世俗滤镜消解恐怖**：用打工/还贷/上班/囤货的世俗类比翻译末世事件——既是笑点，也是贯穿全书的声音指纹。危险动作用庸常职场经验去丈量。
2. **系统UI＝双层文本**：面板/成就/道具名走"参数壳（品质/CD/数值的冷格式）+ 一句世俗梗核/冷吐槽备注"，机制信息走冷格式、调性笑点走那句备注。
3. **冷面吐槽缝进叙述**：主角吐槽不加引号直接缝进叙述句，配"面无表情/默默"的克制动作，用冷静反衬荒诞（比加引号喊出来更好笑）。
4. **恐怖靠听觉留白蓄力**：用一个"熟悉的日常声响"命名未知威胁，只写声音不写实体、把想象权交读者；正面血腥/怪物尸体延后揭示。
5. **激烈用生理信号写**：战斗高潮切短句，以身体反应（心跳/肾上腺素/闷响）替代心理描写，一个粗粝感官特写收尾。
6. **双轨情绪**：主角主线冷峻克制（队友死亡也只状态栏一行+沉默，留脑补）；悲剧NPC线可浓烈外放——冷热双轨维持整体冷调不腻。
7. **群体威胁整体喻+临时远景**：怪物潮用"液体/自然力"整体意象，危急顶点临时切一个远景航拍镜头把主角方缩成"弱小动物"压迫。

- 2026-08-22 · 末日ch18闭环第1轮 · 盲写与范文对差回填三条本流声音的抽象个性（校准第2条系统UI、补充节奏与听觉的本流基调）：
  14. **本流游戏UI写法（细化第2条）**：系统提示以**单行内嵌【】整块**呈现，句内带**施法者的玩家ID**作为系统腔的一层声音，笑点由**技能名/道具名本身**承担；**不拆成类型/效果/冷却/备注多字段**、不额外添加"备注"段子字段。叙述与系统提示始终**保持两条声部**，不合并、不表格化——这是本流双层文本的具体落法，区别于会把内联信息升级成分字段卡片的AI惯性。
  15. **本流节奏基调=连贯匀速的网文长流**：段落饱满、以中句为主，**不用单词/单字独句成段制造戏剧顿点**，**不使用 ＊＊＊ 一类场景分隔符**——场景切换靠自然承接完成，全篇一气呵成。（本流不走"极短句砸点+分隔符切镜"的顿挫路子，那会破坏这套匀速长流的呼吸。）
  16. **本流听觉处理=拟声与声音重复是签名留白**：原文里反复出现的拟声（同一串声音连写两次以上）是**刻意的节拍钉子**，改写时必须**原样保留其重复与节奏**，不得改写成无声的动作描述、也不得用别的声音替换。（呼应第4条"听觉留白蓄恐怖"：本流的恐怖/诡异常挂在一个被反复念的声音上。）
- 2026-08-22 · 末日ch18闭环第2轮 · 盲写与范文对差，进一步钉死系统UI这一层的原始质地（细化第2条＋第14条）：
  17. **系统UI文本要保留"双层"的原始排版，别做归一化处理**：本流游戏化反差幽默的固定笑点来源之一，就藏在系统框的原始细节里，改写/落地时四处不许动——① **玩家ID一律用玩家自取的沙雕网名**（"玩手机玩的""cos""带薪拉屎"这类）来显示技能来源/目标，**绝不换成角色本名**（换成真名＝抹掉游戏化反差）；② 【】内保留**"对你／对XX"的第二人称**指向，不改成第三人称转述；③ **[技能名] 的嵌套方括号原样保留**，不许把里层方括号拍平；④ 保留系统提示**独立成行的原始排版形态**。把 ID 换真名、把嵌套括号拍平、把第二人称改转述、把独立行揉进叙述段，任何一处都会抹掉这层双层游戏味——这是本流笑点的固定来源，属硬保真项。
- 2026-08-22 · 末日ch18闭环第3轮 · 盲写与范文对差，钉死系统UI的正式字段质地、两套数字体例、以及网文排版形态（细化第2/14/17条与第15条）：
  18. **系统UI＝对玩家说话的正式公文腔（再细化第2/14/17条）**：游戏系统通知保留**第二人称对玩家说话**（"您解锁""对你使用"），并保留**正式字段格式**（"持续时间：""冷却时间："等冒号字段、必要处用"15s"式英文缩写）；多条**独立弹窗**（如"技能触发"+"指定目标"是两条独立通知）要**分行呈现、不合并成一条**。UI 层这种冷／正式／公文的语气，与叙述层的吐槽语气之间的落差，正是本流双层文本的张力来源——把字段规整化、把缩写译成中文、把多条弹窗合并，都是在抹平这层张力。
  19. **数字体例＝正文中文数字、UI与数值阿拉伯数字，两套分工固定不混用**：正文行文用中文数字（"两点""五点""十分钟"），系统 UI 与伤害／掉血／积分／时长／冷却等数值用阿拉伯数字＋单位；两套体例分工固定、不互相串用。且一切**数值型机制一律显算化**——伤害/掉血/积分/时长/冷却写出具体数字，不模糊化（呼应第8条"精算决策显算化"，这里是它在体例层的落法）。
  20. **网文排版形态＝全角缩进＋密集分段＋一beat一短段，杜绝空行分隔的长essay段落**：采用一 beat 一短段、全角缩进、密集分段的网文排版，**杜绝用空行分隔的长段"网络文章体"**。这种摊开的短段节奏是本流声音指纹的重要构成，长段 run-on 会立刻读出 AI 味。★与第15条不矛盾、是分层的：第15条管的是**句层与顿挫层**（以中句为主、不用单字独句成段、不用场景分隔符、连贯匀速），本条管的是**排版与分段层**（缩进＋密集分段＋一段一beat）——匀速长流靠句子承接，不靠把多个 beat 塞进一个大段。
- 2026-08-22 · 末日ch18闭环第4轮 · 盲写与范文对差，钉死系统UI括号规则的"施放主体"细则、"冷面吐槽 vs UI块"的取舍优先级、以及本流声音的网感底色与吐槽节拍（细化第2/3/14/17/18条与第5条快嘴基调）：
  21. **系统UI回显纪律＝只有"名字"套方括号、施放主体裸写（再细化第14/17/18条）**：系统框里只有**技能名／道具名／成就名**这类"名字"才套方括号（`[带节奏]``[福报疗法]``[将队友护至身前]`），**施放主体（放技能的玩家名）一律裸写、不套方括号**（"玩家玩手机玩的使用技能[带节奏]"——"玩手机玩的"裸写）。且数值项必须给**确定数字**（15s／1小时／生命+26／两点伤害），**禁用"回满／大量／少许／若干"这类模糊量词**——UI 的性格就是冷冰冰的精确，一模糊就丢了这层机器腔。（★注意与"被作用目标"区分：目标玩家名有时随格式带方括号如"指定玩家：cos"／"玩家[白七]对你使用"，这里说的"裸写"专指句首那个**主动施放的主体**。）
  22. **"冷面吐槽缝叙述" vs "走UI块"的取舍优先级＝签名动作永远选前者**：遇到**关键的低数值或强反差**（打出个位数伤害、奖励小得离谱），优先把它**缝进叙述、用反讽词点破**（如"打出了高达两点的伤害"——用"高达"反讽），而**不是**丢进一个中性 UI 数值块了事。当"走 UI 块交代数值"和"走叙述反讽表态度"二选一时，本文风的**签名动作是后者**。分工：UI 块用于交代**机制**（有哪些技能、CD 多久），叙述反讽用于交代**态度**（这数值有多离谱）——关键反差归叙述，别让它冷冰冰躺在框里。
  23. **网感优先纪律＝能用圈层黑话就不换文学意象**：能用游戏／二次元圈层术语（结界／buff／仇恨／读条／奶量／CD／属性）时，就**保留黑话的贴地感**，不要换成诗化的文学比喻。把"给他加了 26 点血"写成"福报疗法"、把"仇恨"写成什么"命运的敌意"，会立刻掉出这个声音。本流的底色是**网感／贴地**，术语的圈层感本身就是人味和可信度，诗化一处就假一处。
  24. **快嘴吐槽压节拍纪律＝调侃句压到四字或短促短句，删稀释词**：吐槽／调侃句尽量压到**四字或短促短句**的节奏（"只打劫不干活"），删掉"那位""从不""负责""似乎""倒是"这类**稀释词**，让吐槽像脱口而出、而不是组织过的书面句。对照："那位只负责打劫，从不干活"——填充词一多，快嘴的节拍就被冲淡，脱口而出的锋利感全没了。（是第5条快嘴基调在"句子长度／填充词"层的落法。）
