# 系统流甜宠推理 · 文风配置

## 声音一句话
**自嘲型穿书女主的贴身限知声音**：推理段专业认真（法医/刑侦术语裹口语），撒糖/系统段插科打诨，靠"女主吐槽"一根轴在两种腔调间无缝切换；系统人格化当耍宝第二声部；甜里带谜、多线暧昧靠错位认知。

## 适配题材
系统流 / 推理悬疑 / 万人迷·多男主甜宠 / 穿书 / 现代架空刑侦 / 游戏世界。轻松网感向。**正剧、硬核纯推理（无甜无系统）、冷峻科幻不用本包**。
