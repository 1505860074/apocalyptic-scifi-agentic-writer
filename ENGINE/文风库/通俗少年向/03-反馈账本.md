# 通俗少年向 · 反馈账本（成长轨迹）

> 两条料的落脚处（见 `../_文风库总览.md` 第四节成长闭环）：
> - **用户意见**（作者对某书某段文风的评价）→ 记这里，抽象成倾向。
> - **用词优化跑档结论**（对比差距的抽象倾向）→ 也可汇总到这里做纵览。
>
> 攒够、稳定后，把可抽象的倾向提炼进 `01-风格纪律.md`（并注明来源）。**本账本记抽象反馈，不抄范文原句**（原句进 `02-范文例库/`）。

## 记录格式（按时间倒序追加）

```
### <日期> · 来源：<哪本书第几章 / 用词优化第几轮>
- **意见/差距**：<作者原话意见，或对比差距的一条抽象倾向>
- **抽象成倾向**：<换本同类书仍成立的说法>
- **拟怎么调**：<改01纪律的哪条 / 调00哪一维参数 / 加个范文例子>
- **状态**：待观察 / 已入01纪律 / 已调参数
```
