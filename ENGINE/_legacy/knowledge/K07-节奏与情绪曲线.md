# 节奏与情绪曲线

> 爽点/钩子管"点"，这份文件管"线"——整章、整卷、整本书的**情绪起伏**怎么排。
> 核心目标：**去平均化**。情绪像心电图，不能是一条直线。

---

## 一、为什么要管节奏

读者的爽，来自**情绪的落差和变化**，不是来自"一直很爽"。一直高潮 = 没有高潮；一直平淡 = 弃书。
好节奏 = **张弛有度**：紧张之后给喘息，喘息之后再拉紧；虐一下再爽，爽够了再抛悬念。

---

## 二、三个尺度的节奏

### 尺度 1：单章内的节奏（节拍 / beat）
一章 2000–3000 字，内部也要有波浪，别匀速。一个常用的单章节拍模板：

```
钩子回收/开场抓人（承接上章钩子，快速入戏）
   ↓
铺垫/推进（交代信息、人物互动，节奏放缓）
   ↓
小波折/升温（出现障碍或新情况，张力上升）
   ↓
本章高点（爽点 or 冲突爆发 or 关键转折）
   ↓
章末钩子（留悬念，逼下一章）
```

> 不是每章都严格按这个来，但每章都要有"**一个高点 + 一个钩子**"，且高点前有铺垫落差。

### 尺度 2：整卷的节奏（情绪曲线）
一卷 10–20 万字，是一条完整的情绪抛物线：

```
卷首：新目标/新危机登场（张力起）
  ↓  小高潮1（阶段爽点）
  ↓  低谷/挫折（虐一下、憋屈、失去，制造落差）  ← 这是很多新人漏掉的！
  ↓  蓄力/转机（主角想办法、金手指升级）
  ↓  卷末大高潮（大爽点：打脸/守护成功/基地升级）
卷尾：回收本卷钩子 + 抛出下一卷大钩子
```

**关键**：每卷中段要有一个**低谷**（负情绪），否则爽点没有落差、读者会疲。低谷不能太长太惨（免费读者会跑），点到即止。

### 尺度 3：全书的节奏（升级螺旋）
50–100 万字，靠"**目标升级 + 威胁升级**"的螺旋维持长线新鲜感：

```
自保 → 立足 → 建设 → 扩张 → 决战
每上一级：金手指升一级、避难所大一圈、敌人强一档、格局宽一层
```

每一卷都是这条螺旋的一圈，读者始终有"更大的目标在前面"。

## 三、情绪的调色板（别只会写"爽"）

一本耐读的书要调动多种情绪，轮换使用制造落差：

| 情绪 | 作用 | 用法 |
|---|---|---|
| 爽/燃 | 主基调，读者来这儿就为这个 | 爽点处（见爽点库） |
| 暖 | 情感锚点，让"守护"有分量 | 队友情、护老弱、避难所的烟火气 |
| 紧张/悬 | 抓注意力，维持追读 | 危机、倒计时、未知威胁 |
| 憋屈/虐 | 制造落差，爽点的燃料 | **少量、短暂**，虐完要快速反弹 |
| 悲壮 | 拔高格局，情感重锤 | 牺牲、告别、明知不可为而为之 |
| 恐惧 | 末世底色，氛围章专用 | 未知怪物、诡异场景、绝境 |
| 幽默/轻松 | 调剂，缓解疲劳 | 队友插科打诨、主角吐槽 |

> **去平均化的关键**：相邻章节的主导情绪要**有对比**。别连着五章都是同一个温度。紧张章后面接一个轻松的日常章，读者才不累。

## 四、特殊章节（打破匀速的工具）

按你的要求，在常规章节流中**穿插**这些特殊章节，制造质感变化：

### 弧光章
- **作用**：集中呈现某个人物的成长/转变（人物弧光的高光时刻），或主角价值观的关键抉择。
- **位置**：通常在卷中低谷后、或卷末高潮处。
- **写法**：慢下来，深入人物内心与选择，让读者对角色产生更深的情感联结。是"人味"最浓的一类章。

### 战斗章
- **作用**：动作高潮，释放紧张与爽感。
- **写法**：短句为主、节奏快、动作清晰（别让读者看不懂谁打谁）；配合金手指的降维打击爽点。

### 氛围章
- **作用**：营造末世的孤独、诡异、荒凉，给恐惧/悲凉情绪，也给读者从爽点里喘息。
- **写法**：慢节奏、长句、环境细节堆叠，五感描写，少对话。

### 特殊叙述章
- **作用**：打破常规叙述视角/形式，制造新鲜感。
- **写法举例**：切到反派/配角视角写一章；用日志/广播/系统面板/新闻播报的形式呈现；插叙灾变当天的回忆；多线并进的蒙太奇。**每卷用 1 次左右即可，用多了发腻。**

## 五、节奏自查（写卷纲/章纲时对照）

- [ ] 这一卷有没有"起—小高潮—低谷—蓄力—大高潮"的完整弧线？
- [ ] 中段有没有一个（短暂的）低谷制造落差？
- [ ] 相邻章节的主导情绪有没有对比，还是一个温度到底？
- [ ] 每 10–20 章有没有安排 1 个特殊章节（弧光/战斗/氛围/特殊叙述）换口味？
- [ ] 每章内部有没有"铺垫→高点→钩子"的波浪，而不是匀速平推？
- [ ] 负情绪（虐/憋屈）是不是控制在"短暂、点到即止"，没有拖沓劝退？
