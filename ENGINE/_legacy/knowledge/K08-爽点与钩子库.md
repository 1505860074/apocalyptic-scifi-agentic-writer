# 爽点与钩子库

> "爽点"让读者**这一章爽到**；"钩子"让读者**想看下一章**。
> 一部留得住人的书 = 密集的小爽点 + 阶段性的大爽点 + 永不断线的钩子。

---

## 一、爽点：让读者"爽到"的瞬间

### 爽点的底层逻辑
爽 = **落差的兑现**。先制造"缺"（危机、被轻视、资源匮乏），再给"补"（化解、打脸、暴富）。落差越大，爽感越强。**没有铺垫的爽是廉价的。**

### 男频末世常用爽点类型

| 爽点类型 | 说明 | 基建流适配示例 |
|---|---|---|
| **信息差碾压** | 主角先知/先备，别人还在懵 | 灾变前囤好物资，别人抢购时他已武装到牙齿 |
| **打脸** | 被轻视/被欺压后强势反转 | 被赶出聚居地→自建堡垒→当初赶他的人来求收留 |
| **扮猪吃虎** | 藏实力，关键时刻亮底牌 | 装普通幸存者，暴露基地一角吓退掠夺者 |
| **暴富/暴兵** | 资源/战力滚雪球 | 合成器量产装备，一夜武装一支队伍 |
| **建设成就** | 从无到有造出东西 | 废墟上竖起第一座穹顶，幸存者欢呼 |
| **收服/招募** | 强者/美人/专家投靠 | 收服前特种兵、女军医、天才工程师 |
| **守护** | 护住想护的人/城 | 挡下尸潮，避难所里的人一个没死 |
| **降维打击** | 用科技碾压低维对手 | 无人机群+自动炮塔清场，敌人还在拿冷兵器 |
| **打破规则** | 别人被规则困住，主角无视 | 别人被辐射区挡住，主角有防护科技长驱直入 |

### 用爽点的纪律
- **小爽点：几乎每章都要有**一个（哪怕小到"解决一个物资难题"）。
- **大爽点：每 5–10 章一次**，要有充分铺垫（先憋后放）。
- **爽点前必有"缺"**：先让读者跟着揪心/憋屈一下下（但别太久），再给糖。
- **别连续同类型**：打脸完接打脸会腻，要"打脸→建设→守护→暴兵"轮着来。

## 二、钩子：让读者"追下去"的诱饵

### 钩子的位置
1. **章末钩子**（最重要）：每章结尾留一个未解决的东西，逼读者点下一章。
2. **卷末钩子**：一卷结束时抛出通向下一卷的大悬念。
3. **全局钩子**：贯穿全书的核心谜（灾变真相、主角身世、金手指来历），是追读的总引擎。

### 章末钩子类型（每章挑一种收尾）

| 钩子类型 | 示例 |
|---|---|
| **危机逼近** | 雷达上，一个巨大的红点正朝避难所移动。 |
| **意外信息** | 那具尸体的军牌上，刻着他父亲的名字。 |
| **悬念提问** | 门是从**里面**锁上的。可这里，本该没有活人。 |
| **反转** | 他救下的女孩，抬头时瞳孔是竖的。 |
| **诱惑/机遇** | 图纸库亮起新词条：【解锁：反重力引擎——需前往军事禁区】。 |
| **倒计时** | 系统冷冰冰地播报：距离第二次尸潮进化，还有 72 小时。 |
| **人物危险** | 通讯里传来老周的声音，只有半句：「快跑，他们不是……」然后断了。 |

### 钩子的纪律
- **每章必留钩子**，别让读者读到一个"圆满结束"的章尾——那是让人放下书的信号。
- **钩子要兑现**：抛出的悬念要在合理范围内回收，别烂尾（用伏笔 DAG 管理）。
- **大钩子分层**：全局大谜 → 每卷中谜 → 每章小钩，层层嵌套，读者永远有"想知道"的东西。

## 三、爽点/钩子与情绪的关系

- 爽点负责"**正情绪**"（爽、燃、暖、扬眉吐气）。
- 钩子负责"**悬情绪**"（好奇、紧张、担忧）。
- 但一本书不能只有正和悬——还要有"**负情绪**"（虐、憋屈、悲壮、恐惧）来做落差。详见 `节奏与情绪曲线.md`。
- **口诀**：憋屈是为了更爽，虐一下是为了守护更动人。负情绪是爽点的燃料，但**别过量、别过久**（免费读者耐心低）。
