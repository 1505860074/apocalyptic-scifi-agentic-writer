# 末世基建题材设定库

> 这是"零件库"。在步骤01（世界观）、02（金手指）阶段，从这里取零件、做组合、再魔改，避免从空气里憋设定。
> **用法**：不要照抄，要"选 2–3 个零件 + 一个反常识扭转"，做出你自己的独特组合。

---

## 一、灾变类型（末世怎么来的）

选一个当主因，可叠加一个次因，制造复合末世。

| 类型 | 一句话 | 特点/爽点适配 |
|---|---|---|
| 病毒/丧尸 | 病毒爆发，人类变尸潮 | 最经典、门槛低、易代入；配基建流很稳 |
| 天灾降临 | 极寒/洪水/地壳剧变/陨石 | 生存压力强，囤货基建刚需 |
| 星球环境突变 | 辐射/大气/引力异变，地表不可居 | 硬科幻感强，适合"地下基地/穹顶城"基建 |
| AI/机械失控 | 智械叛乱，机器猎杀人类 | 科技对抗科技，主角金手指可"以子之矛" |
| 维度/异兽入侵 | 空间裂缝放出异兽/异族 | 战斗爽点足，适合"要塞防御战" |
| 数据/规则末世 | 世界被"系统化"，出现规则怪谈 | 脑洞流，难度高，新人慎选 |
| 复合末世 | 如"病毒+异变"：尸潮进化成变异体 | 阶段性升级危机，适合长线 |

> **番茄友好推荐**：病毒尸潮 或 天灾 打底（易代入），中期叠加"变异进化/外星黑手"抬格局。

## 二、科技金手指（基建避难所流核心）

金手指必须满足三性：**成长性**（能升级）、**掌控感**（主角说了算）、**建设感**（能滚雪球造避风港）。

| 金手指原型 | 机制 | 滚雪球路径 |
|---|---|---|
| 智能基地系统 | 一个能自主升级的 AI 基地核心，占地建设、自动防御、科技解锁 | 帐篷→小屋→堡垒→地下城→穹顶城 |
| 万物回收合成器 | 回收废料→合成物资/装备/图纸 | 捡破烂→造武器→造设备→造工厂 |
| 未来科技图纸库 | 逐步解锁未来科技蓝图（能源/医疗/武器/农业） | 解锁一项→建一类设施→形成产业链 |
| 空间避难所 | 随身携带的独立安全空间，可扩建、可种植、可庇护 | 一间房→一层楼→一座地下庄园 |
| 数据化建设面板 | 像玩策略游戏一样"框选建造"，资源→建筑→人口→科技 | 采集→建筑→科技树→文明升级 |
| 复制/量产能力 | 能复制物资/装备/兵种 | 一份→十份→武装一支队伍 |

> **组合示范**：「智能基地系统 + 数据化建设面板」= 主角像玩即时战略游戏一样，在末世里一点点造出人类最后的避风港。掌控感、建设感、成长性全齐。

## 三、势力生态（末世社会怎么运转）

一部末世长篇通常有这几类势力，供你排布冲突：

- **官方/军方残余**：国家统筹的象征（番茄读者吃这个），可为盟友或阶段性张力来源。
- **幸存者聚居地/据点**：主角基建流的"客户"和"人口来源"，也是内部矛盾场。
- **暴力团伙/掠夺者**：最直接的打脸对象，制造中低段爽点。
- **神秘组织/幕后黑手**：灾变真相的掌控者，长线大 boss，负责后期格局。
- **变异体/异兽阵营**：环境级威胁，随剧情进化，制造升级危机。
- **科技竞争者**：另一个也有金手指/黑科技的势力，主角的"科技对手"，制造高段博弈。

## 四、"基建流"的成长阶梯（对应分卷）

基建避难所流最爽的是"看着一片废墟变成钢铁堡垒"。建议把这条线做成全书主脊：

```
第1卷 求生    ：单人/小队自保，拿到金手指，建第一个安全屋
第2卷 立足    ：收第一批人，建据点，打退第一波掠夺者
第3卷 建设    ：据点升级成堡垒，形成产业链（水电食物医疗），名声传开
第4卷 扩张    ：吸纳幸存者聚居地，与官方/其他据点博弈，成一方势力
第5卷 决战    ：直面灾变真相/幕后黑手/终极威胁，避风港成人类希望
```

> 每一卷都是"避风港升一级 + 一个新的更大威胁"，这就是长线爽感的引擎。

## 五、常见硬伤自查（写设定时避坑）

- **物资守恒**：末世资源稀缺是紧张感来源。金手指别让主角"要什么有什么"，否则没了张力。给金手指**加限制**（能量上限、冷却、需要材料/前置科技）。
- **丧尸/异兽的智力与进化**要有内在逻辑，别忽强忽弱当工具。
- **社会不能真空**：有人的地方就有秩序、交易、背叛，别把末世写成只有主角和怪物。
- **科技别超纲**：基建速度要有代价（时间、材料、人力），一夜造出航母会让读者出戏。
