# 番茄男频规律与黄金三章

> 这份文件是"平台常识"。写总纲、黄金三章、每章正文时，都要拿它对照。

---

## 一、番茄是什么样的平台

- **免费阅读为主**，靠广告分成。读者划走的成本几乎为零 → **留存是第一生命线**。
- **移动端碎片阅读**：单章 2000–3000 字，读者常在通勤/睡前刷。段落要短、对话要多、爽点要密。
- **日更机制**：签约后要求日更（通常 2000 字/天起），全勤有奖。→ 决定了你要"可持续产出"，别把大纲设计得太烧脑写不动。
- **算法推荐**：前期靠"黄金三章"过机器/编辑初审拿到推荐位，靠"读者追读率、看完率"决定后续加不加推。

## 二、男频末世读者的情绪刚需（2025–2026 实测规律）

读者当下极度渴望 **精神解压 + 安全感**。他们厌倦"被动挨打 + 无限升级换地图"。愿意为这三样买单：

1. **主角绝对掌控全局** —— 不憋屈、少挨打，尽量"我早有准备"。
2. **无视规则发疯 / 降维打击** —— 用科技/信息差碾压，爽在"你们还在挣扎，我已经通关"。
3. **建设属于自己的避风港（基建流）** —— 囤货、造基地、收人、滚雪球，安全感拉满。

### 末世题材的特殊铁律
- 番茄读者**吃集体主义 / 家国情怀**，比个人英雄主义数据好。
- 囤货流可以写，但**别写成纯自私爽文**。加入"国家统筹、不放弃普通人"的价值观，数据明显更好。
- 主角可以冷静自保，但要有"守护"的东西（一群人、一座城、一个避难所），这是情感锚点。

### 要避开的雷
- 纯重生/纯系统/赘婿老套路——审美疲劳严重。**要在大品类里切细分标签**（我们选的"末世+基建避难所"就是切法）。
- 开局太惨、憋屈太久——免费读者没耐心，前期要"快速给糖"。
- 硬核设定糊脸——世界观慢慢渗透，别在第一章甩科普。

## 三、黄金三章公式（决定生死）

前 3 章（约 6000–9000 字）必须完成下面这套动作。**这是签约与留存的命门。**

### 第 1 章：代入 + 灾变 + 金手指到手
- 前 300 字内让读者**代入主角处境**（一个具体的、有紧迫感的场景，不要背景介绍）。
- 灾变发生 / 或主角已知灾变将至（重生、预知、系统提示）——制造信息差优势。
- **金手指在第 1 章内到手或觉醒**，别拖。
- 章末抛第一个小钩子。

### 第 2 章：第一次"掌控感"小爽点
- 用金手指解决一个具体的小危机（囤到关键物资 / 秒杀一只丧尸 / 抢先一步占据据点）。
- 让读者第一次"爽到"——"有这金手指真香"。
- 展示金手指的**成长潜力**（暗示它能升级、能滚雪球）。

### 第 3 章：升级钩子 + 长线悬念
- 把爽点抬一级（从"自保"到"开始建设/收第一个人"）。
- 抛出一个**长线大钩子**：避难所另有秘密？灾变背后有黑手？主角身份不简单？
- 让读者产生"我得追下去看看"的冲动。

> 检验标准：把黄金三章给一个没看过的人读，他读完会不会想点"下一章"？会 → 及格。犹豫 → 重写。

---

## 四、追读率维护（第 4 章往后）

- **章末钩子不能停**：每章结尾留一个"未解决"（悬念/危机/新信息），像连续剧。
- **爽点节奏**：小爽点每章都有，大爽点每 5–10 章一次（详见 `爽点与钩子库.md` 和 `节奏与情绪曲线.md`）。
- **信息差红利**：主角的"先知/科技优势"要持续兑现成具体好处，别只挂在嘴上。
- **避免中期塌房**：写到 20–30 万字最容易乏力，靠"分卷换目标 + 新势力/新危机"续命（见分卷纲设计）。
