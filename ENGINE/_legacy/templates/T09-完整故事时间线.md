# 完整故事时间线（Story Bible Timeline）· 模板

> 和《全书事件线》互补：
> - 《全书事件线》＝"**怎么讲给读者**"（叙事顺序，从开篇写起）。
> - 本表＝"**世界真实发生的一切**"（故事顺序，从最早起因到结局，**含读者看不到的前史**）。
>
> "先画骨架"的最底层。提笔前，把从一切起因到最终结果编年想全。产出存到 `02-大纲/完整故事时间线.md`。

## 为什么要它
即使采用倒叙 / 从中间切入，作者也必须先知道"事情从头到尾是怎么发生、演化到结果的"。否则读者读到的每个谜，作者自己都没答案，逻辑必崩。

## 一、分纪编年（按世界真实时间顺序）
把故事世界从最早的起因，一段段编年下来。每段写：**时间锚点 / 发生了什么 / 为什么 / 导致什么**。
- **前史（第零纪，读者看不到、作者必须想全）**：核心矛盾与大反转的真正起因、各主要角色在故事开始前的经历与状态。
- **开篇纪**：故事正式开始（读者第一次读到的时间点）发生了什么。
- **发展 / 高潮 / 结局纪**：主要事件顺着因果演化到结果。

## 二、真相揭示节奏
前史里对读者隐藏的部分，规划"读者在第几卷/第几阶段知道哪一块"——逐步揭开、与大反转主链一致，不早泄、不最后一次性倒出。

## 三、与其他骨架的关系
- 前史 → 补进《世界圣经·真相层》。
- 开篇纪之后的叙事事件 → 就是《全书事件线》。
- **本时间线是"世界真相的编年"，是世界圣经和全书事件线的共同源头。**
