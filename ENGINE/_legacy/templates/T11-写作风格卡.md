# 写作风格卡 · 模板

> 定下全书的"作者腔"——视角、句式、语气、用词习惯。**全书 40 万字用同一个声音**，杜绝忽冷硬忽抒情的拼接感。
> 产出存到 `01-设定/写作风格卡.md`。

---

## 一、基本定位
- **模仿对象 / 参考作家**：（如"番茄某爆款作者的叙述口吻""某本大热末世文的对话风格"）
- **整体语气基调**：（冷硬 / 热血 / 痞气 / 冷幽默 / 朴实 / 爽快……选 1–2 个主基调）
- **一句话概括本书记叙声音**：（如"一个理工男用吐槽的口吻讲述他如何在末世捡破烂建堡垒"）

## 二、叙述视角
- **人称**：（第三人称贴身限知为主 / 偶尔切第一人称内心独白）
- **镜头绑定规则**：（始终贴在主角身上 / 特殊章节可切配角视角但不超过 X 次/卷）
- **主角判断的渗透度**：（叙述中是否频繁夹带主角的主观吐槽？频率多高？）

## 三、句式
- **句子长度偏好**：（短句为主 10–15 字 / 长短交替 / 高潮处短句砸）
- **句式习惯**：
  - 尽量用 **主谓宾直陈**，少用倒装、被动、长从句
  - 段落长度：（3–5 句一段 / 高潮 1–2 句一段）
- **修辞节制**：（一章比喻不超过 X 个 / 不用生僻词 / 不用文言句式）

## 四、对话风格
- **对话占比目标**：（≥40%）
- **语气词/口语化程度**：（大量/"嘛呢吧啊"用起来 / 适量 / 克制）
- **脏话尺度**：（允许"卧槽""他妈的"，一章 1–2 次 / 更奔放 / 基本不用）
- **人物辨识度**：（每个人物有独特的口头禅/说话节奏，对话不贴标签也能认出是谁）

## 五、用词习惯
- **禁用词**：（如"倏地/蓦然/旋即/凛冽/故而/如此"等文绉绉词汇——少年向铁律）
- **偏爱词 / 常用句式**：（如主角口头禅、常用来形容方舟的词）
- **成语使用**：（一章不超过 3–5 个，且必须"一听就懂"的）

## 六、环境描写
- **节制原则**：只在三种位置给环境描写——场景切换定位 / 制造威胁紧张 / 制造情绪氛围
- **杜绝**：物品型号、颜色、材质、无关摆设等废笔

## 七、情绪表达
- **情绪直给（少年向铁律）**：直接说"他慌了"，不写"眼神闪过一丝复杂"
- **L3 深度刻画时**：情绪通过身体反应写（心跳/呼吸/手抖/喉咙发紧），不通过抽象词汇
- **主角吐槽**：遇到离谱的事要吐槽——这是少年向代入感的核心

## 八、网感
- **网络用语使用**：允许使用（无语/离谱/破防/真服了 等），但要自然，不硬凹
- **目标读者验证**：每章写完问自己——"这段话一个初一生能一眼看懂吗？"
