# 世界圣经 · 模板

> 全书"物理事实"的**唯一真相源**。凡是要出场的空间、元素、规则，先在这儿定死，正文不许违背。
> 治"角色凭空出现、楼有几层没定、竖井通哪不知道、掉下去的东西没后续"这类漏洞。
> 骨架先行的第一块。产出存到 `01-设定/世界圣经.md`。

## 一、核心场景的空间结构（最易崩，务必定死）
对每一个会反复出场的重要场景（主角据点、关键建筑），写一张"空间说明"：
- **整体结构**：几层/几个区域？每层每区是什么、做什么用？
- **连接关系**：楼梯/门/通道/竖井/窗，各通向哪里？哪些相通、哪些封死？
- **出入口**：从外面怎么进来？逃生路线？
- **关键物件的固定位置**：能源、总闸、水源、粮食……在哪。
- **一次定死**：正文涉及这个空间时一律以此为准，不临时脑补。

示例格式（据点建筑）：
```
负一层：XX（谁在这、通向哪）
一层：  XX（对外出入口在哪）
二层：  XX
楼顶：  XX
竖井/电梯井：从X层通到Y层，井底是什么（掉下去的东西去了哪，必须有交代）
```

## 二、地理与地图
- **据点周边**：方圆多大内有什么（超市/医院/军营…）、距离、路线、安全度。
- **更大的世界**：城市、区域、重要地点，主角活动范围会扩到哪。
- 简单方位关系（谁在东南西北、多远）。

## 三、世界规则（完整机制，含对读者藏的真相）
- **灾变/超自然的完整机制**：怎么运作、规则边界、例外——作者必须完全清楚，哪怕对读者藏着。
- **力量/科技体系**：等级、成长路径、限制。
- **真相层**：藏在表象下的真相（与大反转一致），作者视角写清。

## 四、时间线锚点
- **世界的关键时间点**：灾变第 0 天发生什么，第 N 天世界变成什么样（威胁/秩序/资源的阶段——对照《末世演进的时间线规律》）。
- **当前故事进行到第几天/第几阶段**：随写作更新。

## 五、出场元素的"来龙去脉"登记（治"凭空出现"）
**每个要出场的人/物/地，出场前都要能回答**：是谁/是什么、从哪来、为什么在这、和主角什么关系。

| 元素 | 是谁/什么 | 从哪来 | 为什么在这（出场逻辑） | 与主角关系 |
|---|---|---|---|---|
| | | | | |

> 反例：一个角色突然出现在主角的封闭空间里，却从没交代她怎么进来的、为什么在这。**出场前必须先在这张表里说通。**

## 六、组织/势力（完整）
整合世界观卡的势力表，补全每个势力的来历、目的、与主角的关系演变、以及它"在末世第几阶段登场"（对照演进规律）。

## 七、一致性铁律
- 本圣经是"物理事实"唯一真相源；正文与它冲突时，**改正文，不改圣经**（除非有意修订圣经并全局同步）。
- 空间、来历、机制，一旦定死，全书统一。
