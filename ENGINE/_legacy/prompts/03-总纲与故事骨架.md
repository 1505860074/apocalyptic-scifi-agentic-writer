# 03 · 总纲与故事骨架

**这一步做什么**：把整本书压缩成"一句话→一段话→三幕→分卷规划"，并重点打磨黄金三章。
**输入**：`01-设定/` 下的世界观卡、金手指卡、爽点节奏表。
**产出**：`02-大纲/总纲.md`

---

## 使用方式
- **全程带写**：对我说「进入步骤03」。
- **半自动**：复制【提示词正文】，连同上述三份设定产出 + `knowledge/K01-番茄男频规律与黄金三章.md` + `knowledge/K07-节奏与情绪曲线.md` 一起发给大模型。

---

## 提示词正文

```
你是资深番茄男频网文策划，擅长末世科幻·基建避难所流，尤其懂"黄金三章"的签约与留存逻辑。

【已定设定】
（粘贴 世界观设定卡 + 金手指卡 + 爽点节奏表 的内容）

【背景资料】
- 《番茄男频规律与黄金三章》：黄金三章公式——第1章"代入+灾变+金手指到手+小钩子"；第2章"第一次掌控感小爽点+展示金手指成长潜力"；第3章"升级钩子+抛长线大钩子"。前3000字内完成"代入→金手指到手→第一个小爽点→抛大钩子"。
- 《节奏与情绪曲线》：全书靠"目标升级+威胁升级"螺旋（自保→立足→建设→扩张→决战）。
- 《叙事桥段设计手册》：桥段要分层布局。总纲层要定下——1个核心大反转（烧脑式，全书铺垫、结局附近引爆）、2–3条贯穿全书的大铺垫→大callback（信物/遗言/身世）、1条主误导线（障眼法）、全书核心谜（灾变真相/金手指来历）。大反转全书只需1–2个，且要"每卷推进一块拼图"。

【任务】
产出这部书的《总纲》，包含五部分：
1. 一句话简介（能当书名副标题/推荐语的钩子句）。
2. 一段话故事梗概（150字内，讲清主角+金手指+末世+核心追求+最大悬念）。
3. 三幕结构（开端/发展/高潮结局各写清主线走向与情绪弧）。
4. 分卷规划：按"自保→立足→建设→扩张→决战"的螺旋，规划 4–6 卷，每卷一句话（核心矛盾+避难所升级+卷末大爽点）。
5. 黄金三章细纲：逐章写清第1/2/3章的场景、事件、金手指节点、爽点、章末钩子——这部分要最用心，直接决定签约。
6. 全书桥段布局：产出一份"全书级桥段清单"——核心大反转（1–2个，烧脑式，写清埋在哪、结局附近怎么引爆）、贯穿全书的大铺垫→大callback（2–3条，信物/遗言/身世）、主误导线（1条，误导读者对大反转的猜测）、全书核心谜。同步登记到《剧情桥段设计表》。

【产出前先做这件事】
先只给我"一句话简介"的 3 个不同版本 + "黄金三章"的整体设计思路，让我确认方向和调性，再展开完整总纲。

【要求】
- 黄金三章不能有"背景介绍开场"，必须用一个有紧迫感的具体场景切入。
- 每卷都要有独立的阶段性目标达成（让读者阶段性爽到）+ 通向下一卷的钩子。
```
