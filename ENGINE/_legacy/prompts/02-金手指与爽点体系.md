# 02 · 金手指与爽点体系

**这一步做什么**：设计主角的科技金手指，并规划全书爽点节奏。
**输入**：`01-设定/世界观设定卡.md`
**产出**：`01-设定/金手指卡.md` + `01-设定/爽点节奏表.md`

---

## 使用方式
- **全程带写**：对我说「进入步骤02」。
- **半自动**：复制下面【提示词正文】，连同你的《世界观设定卡》产出、`knowledge/K08-爽点与钩子库.md`、`knowledge/K02-末世基建题材设定库.md` 一起发给大模型。

---

## 提示词正文

```
你是资深番茄男频网文策划，擅长末世科幻·基建避难所流。

【已定设定】
（此处粘贴 01-设定/世界观设定卡.md 的全部内容）

【背景资料】
- 金手指三性（必须满足）：成长性（能一路升级）、掌控感（主角说了算）、建设感（能滚雪球造避风港）。这三点是番茄末世读者的情绪刚需。
- 参考《末世基建题材设定库》的金手指原型与"基建流成长阶梯"。
- 参考《爽点与钩子库》：爽=落差的兑现；小爽点几乎每章有，大爽点每5–10章一次；别连续同类型爽点。

【任务一：设计科技金手指】
基于已定世界观，设计一个科技金手指，要求：
1. 满足成长性/掌控感/建设感三性；
2. 有明确的"滚雪球路径"（从简陋到宏大的升级阶梯）；
3. 有合理限制（能量/冷却/材料/前置科技），保留资源紧张感，不能"要啥有啥"；
4. 与世界观的科技脉络自洽，且能挂钩"灾变真相"（金手指来历可作为大伏笔）。
先给我 2–3 个金手指方案备选（各含机制+滚雪球路径+限制+差异化亮点），我选定后再细化成《金手指卡》。

【任务二：规划全书爽点节奏】
产出一张《爽点节奏表》：按"卷"为单位，规划每卷的核心大爽点、爽点类型轮换（打脸/建设/守护/暴兵/降维打击等别重复扎堆）、以及大爽点前的"憋"（铺垫落差）。

【输出格式】
金手指卡：机制 / 三性说明 / 滚雪球路径（分阶段）/ 限制 / 与灾变真相的挂钩 / 升级里程碑。
爽点节奏表：表格，列=卷，行=核心大爽点、爽点类型、前置铺垫。
```
