# 05 · 世界圣经与全书事件线（骨架先行）

**这一步做什么**：架构工坊的最后一步——把 步骤01–04 的零散设定**扩展、锁死、闭环**成一份完整的"创作蓝图包"，作为写作工坊的唯一真相源。**蓝图不闭环，不进写作工坊。**
**输入**：步骤01 世界观卡、步骤02 金手指卡、步骤03 总纲、步骤04 人物卡
**产出**：
- `01-设定/世界圣经.md`（空间结构、地理、规则、来龙去脉）
- `02-大纲/全书事件线.md`（全书因果事件链）
- `03-人物/人物弧光线.md`（核心人物随事件怎么变）
- `02-大纲/完整故事时间线.md`（世界真实发生的一切，含前史）

> **位置说明**：步骤05是"架构工坊 → 写作工坊"的**交接点**。步骤01–04 草拟基础设定后，步骤05把它们扩展成闭环蓝图。蓝图锁定之后，进入写作工坊（步骤06→08→10→11），只负责按图施工——改正文不改蓝图。

## 使用方式
- 全程带写：对我说「进入步骤05，建世界圣经 / 全书事件线」。
- 半自动：复制下面提示词 + 世界观卡/金手指/总纲/人物卡 +《世界圣经》《全书事件线》模板 +《逻辑一致性规范》《末世演进的时间线规律》。

## 提示词正文
```
你是一位严谨的小说架构师，任务是把零散的设定，扩展成一副"从头到尾无逻辑漏洞"的完整骨架。

【已有基础设定】
（粘贴 世界观卡 + 金手指卡 + 总纲 + 人物卡）

【任务一：世界圣经】
按《世界圣经》模板，把世界扩展并定死，重点补齐最容易崩的三块：
1. 核心场景的空间结构（主角据点等建筑的完整楼层/通道/竖井/出入口，一次定死）；
2. 每个要出场元素的"来龙去脉"（谁、从哪来、为什么在这），杜绝"凭空出现"；
3. 世界规则的完整机制 + 时间线锚点（对照《末世演进的时间线规律》）。

【任务二：全书事件线】
按《全书事件线》模板，把全书各卷从头到尾的主要事件，按因果编排成完整闭环的骨架：
- 每个事件有前因、有后果，前后勾连成链；
- 大反转/核心谜每卷推进一块，最后能圆上；
- 做闭环自查，杜绝断裂、凭空、挖坑不填。

【任务三：人物弧光线】
按《人物弧光线》模板，为每个核心人物（主角、核心配角、终极反派）建一条"随事件演化的动态线"：
- 沿全书事件线的关键节点，标注每个人物从什么状态变到什么状态、因什么而变；
- 这是写作工坊里"写哪章用哪个弧光阶段"的依据。

【任务四：完整故事时间线】
按《完整故事时间线》模板，编年记录"世界真实发生的一切"（从最早起因到结局，含读者看不到的前史）：
- 前史里对读者隐藏的部分，规划"读者在第几卷知道哪一块"——逐步揭开、不早泄；
- 这是世界圣经和全书事件线的共同源头。

【要求】
- 先粗后细：先立全局主脊，再补细节。
- 蓝图必须闭环——空间定死、来历说通、事件因果成链——之后才允许进入写作工坊。
- 发现基础设定里的矛盾，直接指出并给修正建议。
```

## 完成后
产出四份文件，构成完整的**创作蓝图包**（架构工坊的最终交付物，写作工坊的唯一真相源）：
1. `01-设定/世界圣经.md`（空间结构、规则、来龙去脉）
2. `02-大纲/全书事件线.md`（全书因果事件链）
3. `03-人物/人物弧光线.md`（核心人物随事件怎么变）
4. `02-大纲/完整故事时间线.md`（世界真实发生的一切，含读者看不到的前史）

> 蓝图包锁定后进入写作工坊。写作时只通过三层上下文加载体系（快照卡 → 卷上下文 → 本章焦点卡）按需读取蓝图包条目，不把整本塞给 agent。写每章对照焦点卡的"逻辑雷区"自查（见《逻辑一致性规范》）。
