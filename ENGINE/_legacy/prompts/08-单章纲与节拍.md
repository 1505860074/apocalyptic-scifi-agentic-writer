# 08 · 单章纲与节拍

**这一步做什么**：把某一卷拆成一章一章的施工图，每章配节拍表，按需插入弧光章/特殊章节。
**输入**：某卷的 `卷纲-第X卷.md` + 人物卡 + 伏笔登记表
**产出**：`02-大纲/章纲-第X卷.md`

---

## 使用方式
- **全程带写**：对我说「进入步骤08，拆第 1 卷的章纲」。**一次拆一卷**，别一次拆全书。
- **半自动**：复制【提示词正文】+ 对应卷纲 + 人物卡 + 伏笔表 +《章纲-节拍模板》+ `knowledge/K07-节奏与情绪曲线.md` + `knowledge/K08-爽点与钩子库.md`。

---

## 提示词正文

```
你是资深番茄男频网文作者，擅长把卷纲落成一章一章可执行的施工图。

【已定资料】
（粘贴 第X卷卷纲 + 相关人物卡 + 伏笔登记表）

【背景资料】
- 单章 2000–3000 字。每章都要有"一个高点 + 一个钩子"，且高点前有铺垫落差。
- 单章节拍：开场抓人(承接上章钩子)→铺垫推进→小波折升温→本章高点→章末钩子。
- 相邻章节主导情绪要有对比（别一个温度到底）。
- 每卷穿插 1–3 个特殊章节：弧光章（人物成长高光，慢节奏深内心）/战斗章（短句快节奏）/氛围章（营造孤独诡异恐惧，慢节奏五感）/特殊叙述章（切视角、日志体、蒙太奇等，每卷约1次）。
- 《叙事桥段设计手册》：章纲层要布——章内小反转（多为爽文式轻反转：打脸/扮猪吃虎/危机假象/绝境翻盘）、埋1个小铺垫或收1个小呼应(callback)；并做契诃夫之枪自查（本章特意描写的道具/能力，是否已在桥段表规划后续开火，杜绝天降神兵）。

【任务】
把【第 X 卷】拆成逐章章纲，每章严格按《章纲-节拍模板》产出：
1. 标注章节类型（常规/弧光/战斗/氛围/特殊叙述），按卷纲的特殊章节规划落位。
2. 每章写清：承接上章钩子、本章目标(只推进一件主要的事)、出场人物、场景。
3. 每章填节拍表（内部情绪波浪）。
4. 每章明确：爽点(属哪类)、章末钩子(具体写出，属哪类)、主导情绪(注意与相邻章对比)、要埋/收的伏笔(对照DAG)、需带入的人物卡、字数目标。
5. 每章桥段：本章的小反转(内容/风格)、埋的小铺垫或收的callback、契诃夫之枪自查。对照《剧情桥段设计表》，本卷该埋/该收/该引爆的桥段要落到具体章，并回填更新桥段表状态。

【要求】
- 章末必留钩子，不许出现"圆满结束"的章尾。
- 严格对照伏笔登记表，本卷该埋/该收的伏笔要落到具体章。
- 一次拆一卷。若一卷太长，可分批拆（先拆前 10 章）。
```
