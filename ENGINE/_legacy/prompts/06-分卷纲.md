# 06 · 分卷纲

**这一步做什么**：把总纲的分卷规划，展开成一卷一卷的详细卷纲。
**输入**：`02-大纲/总纲.md` + `03-人物/` + `01-设定/爽点节奏表.md`
**产出**：`02-大纲/卷纲-第X卷.md`（一卷一个文件）

---

## 使用方式
- **全程带写**：对我说「进入步骤06，展开第 1 卷」。**一次只展开一卷**，写到哪展到哪，别一次拆完全书。
- **半自动**：复制【提示词正文】+ 总纲 + 人物卡 + 爽点节奏表 + 《卷纲模板》+ `knowledge/K07-节奏与情绪曲线.md`。

---

## 提示词正文

```
你是资深番茄男频网文策划，精于长篇的分卷节奏设计。

【已定资料】
（粘贴 总纲 + 相关人物卡 + 爽点节奏表 的内容）

【背景资料】
- 《节奏与情绪曲线》：一卷是一条完整情绪抛物线——卷首(张力起)→小高潮→中段低谷(短暂虐一下制造落差)→蓄力转机→卷末大高潮→卷尾钩子。中段低谷是新人最易漏的一环。
- 每卷=避难所升一级+一个更大的威胁。
- 《叙事桥段设计手册》：卷纲层要布——1个中反转（卷中或卷末，可爽可深）、若干跨卷铺垫（本卷埋、后卷收）、本卷要回收的前置铺垫（callback）、以及"推进全书大反转的一块拼图"（每卷揭一点）。

【任务】
把【第 X 卷】展开成详细卷纲，严格按《卷纲模板》填写：
1. 核心三要素：核心矛盾 / 主角大目标 / 卷末高潮。
2. 情绪抛物线：逐段写清卷首、小高潮、中段低谷、蓄力转机、卷末大高潮、卷尾钩子的具体内容。
3. 基建成长：本卷开始/结束时避难所的状态对比（升了什么、收了多少人）。
4. 金手指进展：本卷解锁/升级什么。
5. 人物：本卷新登场人物 + 谁在本卷有重要弧光推进（标记可能的弧光章）。
6. 伏笔：本卷埋下/回收哪些伏笔（提示同步登记 DAG）。
7. 特殊章节规划：本卷计划安排的弧光章/战斗章/氛围章/特殊叙述章，各约在第几章。
8. 桥段布局：本卷的中反转（内容/尺度/风格/落在哪章）、本卷新埋的跨卷铺垫、本卷回收的前置铺垫(callback)、本卷推进全书大反转的"这一块拼图"是什么。同步更新《剧情桥段设计表》。

【要求】
- 卷末大高潮要对应爽点节奏表里为本卷规划的核心大爽点。
- 中段一定要有一个（短暂、点到即止的）低谷，制造爽点落差。
- 一次只展开一卷，等我确认再展开下一卷。
```

---

## 完成后
每卷存成 `02-大纲/卷纲-第X卷.md`。卷纲是 步骤07（伏笔）、08（章纲）的输入。
