# 07 · 伏笔钩子 DAG

**这一步做什么**：把全书的伏笔/钩子做成一张"埋点→回收"的登记表，杜绝挖坑不填。
**输入**：`02-大纲/总纲.md` + 已展开的卷纲 + 人物卡
**产出**：`02-大纲/伏笔登记表.md`（**持续更新**的活文件）

---

## 使用方式
- **全程带写**：对我说「进入步骤07，整理伏笔表」。这张表会随写作持续更新，不是一次性的。
- **半自动**：复制【提示词正文】+ 总纲 + 卷纲 + 人物卡（命运层的伏笔）+《伏笔登记表(DAG)》模板。

---

## 提示词正文

```
你是擅长长篇伏笔管理的网文责编，任务是帮作者建立并维护一张伏笔登记表，杜绝"挖坑忘填"和"回收烂尾"。

【已定资料】
（粘贴 总纲 + 各卷卷纲 + 核心人物卡"命运层"里的伏笔/秘密）

【背景资料】
- 借用 DAG（有向无环图）思想：每条伏笔标清"埋点(卷.章) → 回收(卷.章)"和"依赖前置"；回收章不能早于埋点章；有依赖的伏笔前置没揭开不能揭后置。
- 伏笔分三类：全局大伏笔（灾变真相/金手指来历/主角身世，追读总引擎）、中线伏笔（跨若干章的悬念）、章级小钩子（重点登记跨章的）。

【任务】
1. 从设定、总纲、卷纲、人物命运层中，梳理出全部值得追踪的伏笔，按《伏笔登记表(DAG)》模板填成总表（编号/内容/类型/埋点/回收/依赖/状态）。
2. 画出关键伏笔的"依赖关系"箭头图（谁必须在谁之前揭开）。
3. 检查并指出：有没有"埋了没规划回收"、"回收早于埋点"、"全局大伏笔揭示节奏太挤/太拖"的问题，给出修正建议。
4. 特别确认：全局大伏笔要"每卷推进一点"，不能憋到最后一次性倒出。
5. 同步初始化/更新《剧情桥段设计表》：从总纲、卷纲、人物命运层中，梳理出反转点、铺垫→callback、误导线、契诃夫之枪、双线交汇，填进桥段表，并检查"反转是否有前置铺垫""铺垫是否都规划了回收""大反转是否每卷推进一块拼图"。

【输出格式】
严格按《伏笔登记表(DAG)》模板：总表 + 依赖关系图 + 回收进度自查结论。
```

## 完成后
存到 `02-大纲/伏笔登记表.md`。**这是活文件**——之后每写一章、每展开一卷，都要回来更新伏笔状态（已埋/进行中/已回收）。写正文（步骤10）时必须对照它。
