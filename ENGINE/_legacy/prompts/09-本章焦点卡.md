# 09 · 本章焦点卡（写正文前的焦点收束）

**这一步做什么**：写第 N 章正文之前，先根据章纲**自动生成一张《本章焦点卡》**——只圈定这一章要加载的设定/人物/前文，杜绝"把整本设定塞给 agent"。
**输入**：第 N 章《章纲》+ 快照卡 + 按需查骨架文件
**产出**：《本章焦点卡》（即时生成，可存 `04-正文/焦点卡-第X章.md`）

> 这是写作工坊"三层上下文加载体系"的第三层，也是写每章正文前的**固定动作**。

---

## 使用方式
- **全程带写**：对我说「写第 N 章」，我会**先自动生成焦点卡**（列出只需加载什么），再据此写正文。
- **半自动**：把第 N 章章纲 + 快照卡发给大模型，让它先按《本章焦点卡》模板生成焦点卡。

---

## 提示词正文

```
你是小说写作的"责任编辑"，任务是在作者动笔写第 N 章前，先给他备好一张"只看这些就够"的焦点卡。

你的核心原则：**筛掉一切与本章无关的，只留本章真正需要的。** 这张卡的价值就在"精"——不是少，是精准。

【快照卡】（始终参考）
（粘贴当前快照卡——书名、主角、当前进度、核心风格约束）

【第 N 章章纲】
（粘贴该章章纲，节拍表里已有细化等级标注）

【可查的骨架】（按需查，不必全读）
- 世界圣经（查本章涉及的场景空间结构、世界规则条目）
- 全书事件线（查本章对应的事件节点）
- 人物弧光线（查本章出场人物"此刻处于哪一阶段"）
- 伏笔登记表（查本章要埋/收的伏笔编号与内容）
- 剧情桥段设计表（查本章要推进的桥段）

【任务】
按《本章焦点卡》模板，生成第 N 章焦点卡，每栏**只列这一章真正用得上的**：
1. 本章目标（抄章纲）
2. 承接（上一章结尾状态——只一句话，读上一章的最后一段即可）
3. 在场人物 + 各自此刻弧光阶段（查人物弧光线，一人一行："他现在处于哪一阶段、该是什么状态"）
4. 涉及的世界设定——**只列条目名称/编号，不抄内容**（如"世界圣经·负一层空间结构""金手指·回收限制规则"）
5. 推进的事件/伏笔/桥段（一一列出编号 + 本章是埋还是收）
6. 本章细化节奏分配（抄章纲的细化标注，确认 L3 在哪、展开什么）
7. 本章写作要点：爽点 / 章末钩子（写得越具体越好，20 字内） / 主导情绪
8. 逻辑雷区自查（从以下角度点出本章最易踩的 1–3 个坑：空间动线 / 人物认知不超前 / 物质守恒 / 人物用错弧光阶段 / 道具来源合理）
9. 加载清单：明确列出写本章要读的文件及条目（写正文时只加载这些）

【要求】
- 精准，只列相关。别把整本设定抄进来。
- 焦点卡本身控制在半页到一页，别让它变成第二个章纲。
- 加载清单里的每一条，都是写本章正文时必须对照的——无关的多写一条就是给 agent 添一分噪音。
```

---

## 完成后
把焦点卡作为 步骤10写正文的**唯一加载清单**——agent 只读焦点卡指向的内容，写完按焦点卡的"逻辑雷区"自查。
