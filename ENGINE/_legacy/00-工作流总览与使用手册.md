# 工作流总览与使用手册

这是整套工作流的**地图**。读完你就知道：一部书从 0 到成稿，中间要走哪几步、每步产出什么、每步的产出又喂给谁。

---

## 一、架构总览：两大工坊，一个蓝图包

整套工作流分成**两个独立的工坊**，中间用一份**创作蓝图包**衔接：

```
┌──────────────────────────────────────────────────┐
│               架构工坊（一次性）                    │
│   01 → 02 → 03 → 04 → 05                        │
│   世界观 + 金手指 + 总纲 + 人物 + 收束成蓝图        │
│                     ↓                             │
│              创作蓝图包                            │
│    （世界圣经 + 全书事件线 + 人物弧光线…）          │
│                     ↓                             │
│               写作工坊（循环）                      │
│   06 → 07 → 08 → 09 → 10 → 11 → 下一章          │
│   卷纲 + 伏笔 + 章纲 + 焦点卡 + 正文 + 润色        │
│                                                   │
│   写作时加载：快照卡（始终） + 卷上下文（按需）        │
│              + 本章焦点卡（每章）                    │
└──────────────────────────────────────────────────┘
```

### 为什么要拆成两个工坊？

因为**架构设计和正文写作是两种完全不同的思维模式**：
- **架构工坊**：上帝视角、全局统筹、一次定死。想的是"整个世界长什么样、故事从头到尾怎么走"。这是设计师的工作。
- **写作工坊**：贴着主角走、一章一章推进。想的是"这一章读者爽不爽、下一章想不想追"。这是写手的工作。

混在一起只会互相干扰——架构时不敢定死（怕写正文时被绑住），写正文时又纠结设定（动不动就想改世界规则）。**解耦之后，架构层只管"造蓝图"，写作层只管"按图施工"。**

## 二、第一工坊：架构工坊（一次性，动笔前完成）

### 铁律：蓝图不闭环，不进入写作工坊。

架构工坊五个步骤，按顺序走：

| 步骤 | 做什么 | 产出 | 对应提示词 |
|------|--------|------|-----------|
| **01** | 定末世的科幻内核和世界观 | `01-设定/世界观设定卡.md` | `prompts/01-世界观与科幻内核.md` |
| **02** | 设计主角金手指 + 全书爽点节奏 | `01-设定/金手指卡.md` + `爽点节奏表.md` | `prompts/02-金手指与爽点体系.md` |
| **03** | 全书故事骨架 + 黄金三章 | `02-大纲/总纲.md` | `prompts/03-总纲与故事骨架.md` |
| **04** | 人物建卡（主角 + 核心配角 + 反派） | `03-人物/` 下各人物卡 | `prompts/04-多层人物卡.md` |
| **05** | 收束成闭环蓝图（架构工坊最后一步） | `01-设定/世界圣经.md` + `02-大纲/全书事件线.md` + `03-人物/人物弧光线.md` + `02-大纲/完整故事时间线.md` | `prompts/05-世界圣经与全书事件线.md` |

**步骤05是架构工坊的最后一步**——把前面 01–04 的零散设定**扩展、锁死、闭环**成一份完整的"创作蓝图包"。

### 创作蓝图包（架构工坊的最终交付物）

写完工坊后，这四份文件就定死了。它们是写作工坊的**唯一真相源**：

1. **世界圣经**：空间结构、地理、世界规则、来龙去脉登记表——所有"物理事实"的唯一来源
2. **全书事件线**：全书从头到尾的因果事件链——"会发生什么"的骨架
3. **人物弧光线**：每个核心人物随事件怎么变化——"人怎么变"的骨架
4. **完整故事时间线**：世界真实发生的一切（含读者看不到的前史）

> 进入写作工坊后，**改正文不改蓝图**。如果正文写不下去，说明蓝图有问题——回到架构工坊修蓝图，再全局同步受影响的部分。

## 三、第二工坊：写作工坊（逐卷逐章循环）

蓝图在手之后，进入日更循环。写作工坊分两段：

### 上手段（每卷一次）

| 步骤 | 做什么 | 产出 |
|------|--------|------|
| **06** | 把总纲的该卷规划展开成详细卷纲 | `02-大纲/卷纲-第X卷.md` |
| **07** | 整理/更新伏笔登记表 | `02-大纲/伏笔登记表.md`（**活文件，持续更新**） |
| **08** | 把该卷拆成逐章章纲（施工图） | `02-大纲/章纲-第X卷.md` |

### 日更段（每章一次——这就是你的日常）

```
09（生成焦点卡）→ 10（写正文）→ 11（润色）→ 存档 → 下一章
```

| 步骤 | 做什么 | 产出 |
|------|--------|------|
| **09** | 根据章纲生成本章焦点卡（只加载相关上下文） | `04-正文/焦点卡-第X章.md`（即时生成） |
| **10** | 按焦点卡 + 细化等级写正文（2000–3000 字，L3 处可超） | `04-正文/第X章-标题.md` |
| **11** | 五轮润色定稿：去 AI 味 → 少年向 → 出戏自查 → 三层校验 → 符号标点审查 | 覆盖更新正文文件 |

## 四、解决上下文爆炸：三层上下文加载体系

小说越长，agent 要参考的东西越多。如果把整本设定、整条事件线、所有前文都塞进上下文，agent 会 Hallucinate（幻觉）甚至完全跑偏。

**解决方案：分层加载——像人类作者一样，写哪章只看哪章相关的。**

### 第一层：快照卡（始终加载，极简）

这份卡在任何时候都要让 agent 看到，但它只有 **半页到一页**：

- 书名 + 一句话梗概
- 主角是谁、核心欲望是什么（一句话）
- 当前进度：第几卷第几章、刚发生了什么（一句话）、接下来要发生什么（一句话）
- 核心风格约束：大白话/短句/对话 40%/初高中生能读懂（5 条硬规矩）

**快照卡的作用**：换一个新 agent 接手，读完这个就知道"这是啥书、现在写到哪了、用什么风格写"。

### 第二层：卷上下文（换卷时加载，约 1–2 页）

进入新卷或需要更大视野时加载：

- 本卷卷纲摘要（核心矛盾 + 卷末高潮 + 情绪抛物线）
- 本卷活跃人物的当前弧光阶段（一行一个）
- 本卷要动的伏笔列表（编号 + 状态）

### 第三层：本章焦点卡（每章加载，步骤09生成）

写一章正文时，**只加载焦点卡列出的内容**：

- 本章目标（一句话）
- 上一章结尾状态（一句话）
- 本章出场人物 + 各自此刻弧光阶段
- 本章涉及的世界设定条目（仅列出用到的几条）
- 本章要推进的事件节点 + 要动哪条伏笔
- 本章爽点 / 钩子 / 主导情绪
- 本章细化节奏分配（哪些节拍 L2、哪处 L3）
- 逻辑雷区自查（1–3 条）

**焦点卡的价值**：筛掉一切与本章无关的东西。agent 不再吞整本设定，只消化这一章需要的。换个新 agent 也一样能接手续写。

## 五、解决"只会描述发生了什么事"：细化等级体系（L0–L3）

详细规范见 `knowledge/K04-细化等级与节奏分配体系.md`。

### 四个等级一句话

| 等级 | 叫什么 | 读者感受 | 字数 |
|------|--------|----------|------|
| **L0** | 一笔带过 | "知道了" | 一句话 |
| **L1** | 简要叙述 | "了解了大概" | 100–200 字 |
| **L2** | 标准展开 | "看到了画面" | 200–500 字 |
| **L3** | 深度刻画 | "心跳加速/鼻子酸" | 300–800 字（无上限） |

### 每章的分配铁律

- **每章至少 1 处 L3**（通常是本章高点——爽点爆发 / 情感转折 / 人物抉择）
- **每章最多 3 处 L3**（多了读者麻木，高潮不值钱）
- **主体推进用 L2**（有画面有对话，正常展开）
- **过渡/铺垫用 L1/L0**（不拖节奏）
- L3 放在**最值得让读者记住的地方**——比如"林晚给周铁山包扎"那种情感交流的细腻瞬间
- 战斗的高潮、爽点的爆发、人物"变了"的那个瞬间——必须 L3

### 怎么在章纲里标注

章纲的节拍表新增一列"细化等级"（见模板 `T14-章纲-节拍模板.md`），写完章纲就知道每一段的力道分配。

## 六、解决"文绉绉"：少年向风格体系

目标读者：**12–18 岁初高中生，手机端碎片阅读**。

详细规范见 `knowledge/K05-少年向网文风格指南.md`。六条铁律：

| 铁律 | 一句话 |
|------|--------|
| **大白话** | 用你跟同学聊天的语气写，别用写作文的语气 |
| **对话多** | 每章对话占比不低于 40%，纯叙述不超过 150 字一段 |
| **情绪直给** | 别暗示、别含蓄——"他慌了"不是"他的眼神闪过一丝复杂" |
| **快节奏** | 开章三句内进戏，场景不超过 600 字，章末钩子 20 字内砸下 |
| **网感** | 用初高中生的语言：无语、离谱、破防、真服了…… |
| **能念出来** | 写完后大声念一遍，别扭就改 |

> 少年向风格天然就是去 AI 味的——AI 最不擅长大白话、短句、对话、情绪直给。所以步骤11润色阶段，少年向风格是去味的终极标准。

## 八、给"全程带写"用户的操作话术

你对我说这些话，我就知道你要进哪个步骤：

**架构工坊**（开始一本新书时）：
- 「进入步骤01」→ 我读 `prompts/01`，问你选择题，生成世界观卡
- 「进入步骤02 / 03 / 04」→ 依次往下走
- 「进入步骤05，收束蓝图」→ 我把 01–04 的零散设定锁死成闭环蓝图

**写作工坊**（蓝图闭环之后）：
- 「展开第 X 卷」→ 步骤06 + 07 + 08 一起走，产出卷纲 + 章纲
- 「写第 N 章正文」→ 步骤09生成焦点卡 → 步骤10写正文（带细化等级） → 步骤11润色

**日常询问**：
- 「现在写到哪了？」→ 我读快照卡和最新进度，汇总给你
- 「第 N 章不满意，加点 L3 深度刻画」→ 我回到那章，把指定位置从 L2 升到 L3
- 「这一章太文绉绉了，改少年向」→ 我用少年向指南重润一遍

## 十、重要原则（贴在心上）

1. **蓝图不闭环，不进写作工坊**。前面每偷一步懒，后面正文就会崩一次逻辑。
2. **一次一章**。正文永远单章推进，别让 AI 一口气写多章。
3. **每章必有 L3**。没有 L3 的章节是流水账。
4. **每章必过步骤11（五轮润色）**。AI 初稿 → 去AI味 → 少年向定稿 → 出戏自查 → 三层校验 → 符号标点审查，五轮跑完才算完工。
5. **设定即法律**。改正文可以，改蓝图要走流程——回到架构工坊，全局同步。
6. **大声念一遍**。句子念出来别扭就改。初高中生要一眼看懂，最好还能念出来不卡。
7. **焦点卡是 agent 的生命线**。不给 agent 塞不需要的上下文，只给焦点卡指向的内容。
