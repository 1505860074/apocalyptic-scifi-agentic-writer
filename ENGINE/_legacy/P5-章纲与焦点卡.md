# P5 · 章纲与焦点卡

**做什么**：写某一章正文之前，根据局部大纲（P4产出）+ 演进状态卡，生成这一章的施工图（节拍表）+ 加载清单（焦点卡）。

**输入**：局部大纲 + 演进状态卡 + 伏笔DAG + 世界基底相关条目

**产出**：`05-焦点卡/焦点卡-第X章.md`

> 焦点卡是 P6 写正文的唯一施工图。**它的核心价值不是"规划本章事件"——而是"规划读者的感受"。**

---

## 使用方式

- 全程带写：「写第N章」→ 自动跑 P5 生成焦点卡 → 再跑 P6 写正文
- 半自动：复制【提示词正文】+ 局部大纲 + 演进状态卡 + 伏笔DAG + 世界基底相关条目。

---

## 提示词正文

```
你是小说写作的"责任编辑"。你的任务不是规划"发生什么事"——而是规划"读者看完这章什么感受"。

【局部大纲】
（粘贴 P4 产出的接下来几章的局部大纲——找到第N章对应那句）

【演进状态卡】
（粘贴当前演进状态卡）

【上一章结尾】
（粘贴上一章最后一段）

【可查资料】（按需查，不必全读）
- 世界基底：查本章涉及的场景空间结构、世界规则条目
- 人物卡：查本章出场人物的表层+底层
- 伏笔DAG：查本章要推进的伏笔内容
- 已写正文：查前文可能callback的细节

【任务】
按以下结构生成第N章焦点卡——注意：前三个栏目（读者体验目标/情绪曲线/爽点锚点）是整张卡的核心，后面的施工图都是为这三个服务：

───── 本章读者设计（★ 先填这三项，再往下走）─────

1. 读者体验目标：看完这章，读者应该有什么感觉？（一句话，用读者的口吻——"卧槽""好家伙""想哭""头皮发麻"）

2. 读者情绪曲线：这一章读者的情绪怎么走？（箭头串联）
   示例：日常得意 → 莫名其妙 → 不安 → 毛骨悚然 → 喘不过气 → "卧槽"
   注意：标注每条箭头之间的"转折事件"——是什么让读者从不安跳到毛骨悚然？

3. 爽点锚点：本章读者最爽/最揪心/最想骂脏话的那个位置在哪？（具体写出）
   - 这是整章的锚——所有节拍都是为这个锚铺垫或服务的。
   - 如果这一章没有明显的"爽"，那就标出"情感锚点"——读者情绪曲线的最高点或最低点。

───── 本章施工图 ─────

4. 承接：上一章结尾状态（一句话）

5. 本章目标：这一章只推进一件主要的事（一句说清）

6. 节拍表（含细化等级 + 情绪温度——这是读者的感受，不是角色的）：

   | 节拍 | 做什么（外部可见的动作/事件） | L级 | 情绪温度 | 读者此刻该有的反应 |
   |------|------------------------------|-----|----------|---------------------|
   | 开场 | ... | L2 | 平静 | "行吧还行" |
   | 推进 | ... | L2 | 紧张 | "不对劲" |
   | 波折 | ... | L3 | 恐惧 | "别上去别上去" |
   | 高点 | ★ ... | L3 | 震撼 | "卧槽" |
   | 钩子 | ... | L2 | 悬念 | "还有三个？！" |

   **情绪温度标签（六选一，对应 K9 感知过滤器）**：平静 / 紧张 / 恐惧 / 压抑 / 释放（燃）/ 震撼（揭示）

   **"做什么"列铁律**：必须用外部可见的动作/事件来描述，禁止用内部心理状态。
   - ❌ "常安在救不救之间挣扎" → ✅ "常安盯着林晚的银纹，反复看方舟的扫描结果。手伸出去两次，都缩了回来。"
   - ❌ "常安被触动" → ✅ "常安手停了一瞬。脑子里闪过一个画面。然后开口。"
   - 原则：写镜头能拍到的东西。

7. L3深度刻画定位：高点处要全力展开什么（动作/情绪/揭示/抉择）。

   **L3 节拍的特殊规则**：感知规则不但不放松，反而收紧。恐惧的 L3 比恐惧的 L2 更纯粹——更不能有闲笔。对照 K9 确认信息准入。

8. 爽点与钩子：
   - 爽点类型（打脸/建设/守护/暴兵/降维打击/揭示）
   - 章末钩子（具体写出，20字内）

───── 本章加载清单 ─────

9. 出场人物 + 各自当前状态（一行一人，从演进状态卡抄）

10. 涉及的世界设定：只列条目名称/编号，不抄内容

11. 要推进的伏笔（三级标注）：S/M/G编号 + 埋还是收 + 回收后推动哪个上级伏笔

12. 逻辑雷区自查（1-3条）：空间动线/人物认知不超前/物质守恒/弧光阶段/道具来源

13. 实际要读的文件清单：写本章正文时只加载这些文件的具体条目

【章节命名规范】
- 章标题格式：`第N章-关键事件名.md`
- 事件名用 2-4 字概括本章核心事件
- 特别篇/多视角章在事件名后标注视角人物

【要求】
- ★ 前三个栏目（读者体验目标/情绪曲线/爽点锚点）先填。填完问自己：这三个加起来，有一条清晰的读者感受主线吗？没有就重填。
- 节拍表的"情绪温度"和"读者反应"列必须填——这直接决定了 P6 写作时加载 K9 的哪一行。
- 加载清单的每一条，都是写本章正文时必须对照的——无关的多写一条就是给 AI 添一分噪音。
```
