# P4 · 演进大纲（★核心生长步骤）

**做什么**：写完3-5章正文后，回看已写内容，生成接下来3-5章的局部大纲。这是替代"定死全书蓝图"的核心机制——大纲随故事生长。
**输入**：已写正文 + 演进状态卡 + 伏笔DAG + 人物卡 + 世界基底
**产出**：更新 `02-大纲/演进状态卡.md` + 生成 `02-大纲/局部章纲-第X-Y章.md`

> **这是新模式的心脏**。旧模式是"先画好整本施工图再写"，新模式是"写一段、看一段、再规划下一段"——像人类作者真实的创作过程。

---

## 什么时候跑P4

- **每写完3-5章后运行一次**
- 第一卷前三章写完后必须跑一次（因为前三章是P3写死的，第4章开始需要演进大纲）
- 发现"已经偏离之前的大纲方向"时立即跑一次
- 避免每章都跑——太频繁会变成"过度拟合上一章"

### 已有预测性章纲时的共存规则

如果项目目录中已有较远的章纲规划（如 `章纲-第1卷.md` 中第N章起），这些视为**"预测方向"**，不是**"已定稿蓝图"**。P4的职责是：

1. **审视预测章纲是否仍然合理**——基于已写内容，检查预测章纲的方向、事件顺序、人物走向是否还站得住；
2. **如果合理**：局部章纲直接引用/细化预测章纲中的对应条目，标注"引用预测章纲第X章"；
3. **如果不合理**：大胆调整，并在产出中标注"偏离原预测章纲的原因"，以便作者理解修改逻辑。

> 预测章纲是路标，不是轨道。P4是驾驶员，有权根据实际路况转向。

---

## 使用方式
- 全程带写：「跑P4，生成接下来几章的走向」
- 半自动：复制【提示词正文】+ 已写正文 + 演进状态卡 + 伏笔DAG + 人物卡 + 世界基底。

## 提示词正文

```
你是小说架构师，任务是帮作者在写完一批章节后，看清"现在走到哪了、接下来往哪走"。

核心原则：**你不预设结局。你只基于已写的内容，推演最自然的下一步。**

【已写内容】
（粘贴最近的3-5章正文 + 前文摘要）

【当前状态】
（粘贴演进状态卡——含当前进度、已揭示的世界信息、活跃人物状态、活跃伏笔）

【可查资料】
- 世界基底（物理规则、场景空间）
- 人物卡（表层+底层+模糊弧光方向）
- 伏笔DAG（哪些已埋未回收）
- 故事种子（一句话方向+模糊分卷方向）

【任务一：态势分析】

先回答以下问题（基于已写内容，不是基于预设蓝图）：

1. 主角现在在哪、有什么资源、面临什么威胁？
2. 最近几章发生了什么变化？（据点变了吗、人物关系变了吗、世界信息揭示了吗）
3. 当前最紧迫的矛盾是什么？（外部威胁/内部矛盾/资源短缺/信息谜团）
4. 有哪些伏笔正处于"该推进但还没推进"的状态？
5. 读者读完最近一章，脑子里最可能在想什么？（"接下来会怎样"的疑问）

【任务二：反向伏笔发现】

扫描最近几章正文，找出可以加以利用的"意外伏笔"——这些是你写作时随手写下的细节，还没登记到DAG：

- 一句可以被callback的台词
- 一个没解释的细节（谁半夜出去了？某扇门为什么打不开？）
- 一个被提及但没展开的设定
- 一个关系中的模糊点

把这些登记为**短期伏笔 S**（编号 S-xxx），因为它们是最具体的、可快速回收的。然后反向归类——这个S属于哪个中期伏笔M？如果还没有对应的M，就创建M。M属于哪个全局伏笔G？如果还没有对应的G，就创建G。

**嵌套原则**：先发现S（具体），再往上归类到M（中等），再往上挂到G（模糊）。不要反过来——不要从模糊的G去"编一个"具体的S。

【任务三：生成局部大纲（接下来3-5章）】

基于态势分析 + 伏笔DAG三级状态，生成接下来3-5章的局部大纲。

**只定方向和关键事件，不定死每句话怎么写：**
- 每章一句话：核心要发生的一件事
- 这3-5章的整体弧：起→承→转→合
- **伏笔推进计划（三级）**：
  - 本批要埋的S：___（写正文时自然埋入）
  - 本批要回收的S：___（写正文时callback）
  - 本批要推进的M：___（回收某个S后，M走到哪一步）
  - 本批是否推进G的拼图：___（回收哪个M，揭示哪块拼图）
- 人物可能的变化方向
- 章末钩子方向
- 爽点类型分配

**不定死的内容：** 同上。

【任务四：更新演进状态卡】

根据已写内容 + 局部大纲，更新演进状态卡：
- 当前进度
- 已揭示的世界信息
- 活跃人物当前状态
- **伏笔三级状态简报**：
  - 全局G：已推进拼图 X/总数
  - 中期M：已有几个、活跃几个、已回收几个
  - 短期S：已埋几个、已回收几个、哪些该收还没收
- 最新章末钩子

【要求】
- 基于"已写内容"推演，不要基于"你预设的蓝图"
- 发现已写内容中有逻辑矛盾或错失的伏笔机会，直接指出
- 局部大纲保持"够用就好"——3到5章，不多规划
```
