# 工作流问题诊断 · 待反馈（临时文档）

> 状态：**问题二/三/一已按诊断直接改进工作流文件（2026-08-11），待用重新生成的正文验证效果**。这份文档记录了诊断过程和已完成的改动清单，方便回溯。

---

## 背景

用户反馈：工作流产出的正文和主流网文文笔有差距。差距点：整体网感/爽感/钩子、描写细腻度/画面感、对话真实感/情绪代入、句子节奏/韵律；且内容单调，像"一条主线硬撑到底"，实际信息量少、有凑字数感。对比方式：工作流产出正文 vs 具体网文/作家段落。

已确认这次审视范围：**整个工作流架构（含节拍/焦点卡/大纲层）**，不只是"写手"这一步的提示词。

---

## 问题一：微观层——焦点卡/写手规则把"作者式废话"当噪音防掉了

**现象**：人类作者的作品会附加很多"技术上非必要"但让文本更生动的内容——专业细节展开、动机的私人化解释、玩梗吐槽、看似离题的联想。这些东西现在的工作流基本生成不出来。

**根因**：
1. T9 焦点卡"做什么"列规定"只写镜头能拍到的外部动作，禁止内部心理状态"——玩梗、专业展开、动机私货大多不是"外部可见动作"，节拍设计这一步就没给它们留位置。
2. K9 情绪感知过滤器只在"平静"温度允许"闲笔"，其余五种情绪温度全部限制/禁止"离题"内容。但人类作者的废话不看情绪温度脸色。
3. K7 铁律四"信任读者，不替读者交代"+ 黄金样张"一件事说一遍说清就走"——本意是删AI式复述（"这些词他没听过"），但边界太宽，容易连坐删掉"读者不知道、但作者想多讲一点"的内容，这跟AI啰嗦是两回事，现在规则没区分。
4. L3/L4 的"状态预算认领"逻辑是纯事实驱动的：每章只认领"必须落地"的1-3项，没有一步问"这章作者想不想借这个场景聊点别的"。

**初步改法方向（未定稿）**：
- P5b/T9 新增"闲笔授权点"字段（跟已有的"性格速写触发点"同一逻辑：事件触发式，不是每章硬配额）。
- K9 新增"闲笔"独立于情绪温度的开关（类似N档独立于L级）。
- K7 铁律四加边界，区分"AI式复述"vs"作者式冗余"，只删前者。
- P6 写手指令在闲笔授权点处放开字数/跑题限制。

## 问题二：宏观层——大纲层只生成一条主线，配角/支线没有生成入口

**现象**：用户自己手动构思过"某配角特别篇"这类配角支线内容，证明素材库/世界观其实能撑起更丰富的内容；但纯跑工作流时生成不出这类东西，最终成品呈现"一根筋主线到底"，可发挥空间被自我限制，容易出现凑字数/硬凑剧情的空转章节。

**根因**：
1. L2 故事弧大纲的任务二明确是"设计主要事件表——只到主角+主要事件的颗粒度"，输出是**一条**主线事件表，没有并行支线的设计任务。
2. L3 状态预算完全从 L2 这一条主线拆解"必须变什么"，没有"配角自己的支线也单独拆一份预算"的概念。
3. L4 每章从 L3 的预算池认领1-3项——池子里只有主线的量，配角/支线永远只是主线场景的附庸，长不出自己的故事。
4. K5 桥段与伏笔手册里其实提到过"双线/多线交汇"（第8条）、支线轻反转（第三节），但这些只是概念性存在——L2 的实际执行任务里没有一步真正落地去问"配角这条线现在能不能单独拆一段"，纸面有、流程里没有被执行。

**初步改法方向（未定稿）**：
- L2 新增"支线线程"任务：每个故事弧除主线外，至少规划1条配角/世界向支线（可以只是候选池，不强制每弧都用）。
- L3 给支线单独拆一份轻量状态预算。
- L4 认领时增加一个选项："这章要不要插一个支线/番外向内容"。

## 重新审视结论（2026-08-11）

反馈收集完毕后一起审视，发现问题一/二/三不是并列关系，而是**依赖链**：

```
问题二（大纲层单线，无支线）→ 决定"有没有料可写"，素材层，是地基
问题三（只会顺叙，无倒叙/插叙）→ 决定"料怎么排列出场"，结构层
问题一（作者废话被规则删掉）→ 决定"排出来的每一段用什么质感写"，文字层，是装修
问题四（参考作品提纯工坊）→ 不是独立问题，是验证前三条诊断对不对的手段
```

**已决定的推进顺序**：先做问题四（提纯工坊），拿真实参考文本验证/校准问题一~三的假设，再统一定问题一二三的改法方案，避免照着未经验证的假设改工作流、改完发现方向不对要返工。

## 问题三：叙事结构层——只会"跟随主角实时顺叙"，没有倒叙/插叙/延迟揭示

**现象**：人类作品常常不按事件发生顺序讲——先写主角做了A、B，再插入一段"隐藏信息"（主角之前其实做过C），再解释"C是为了什么"，给读者恍然大悟的解密快感。现在的工作流写出来的都是纯时间顺叙、边发生边讲，没有这种"叙事顺序≠情节顺序"的错位感，故事显得单调，缺一种"读者一直在解密、不断拿到答案"的推进感。

**根因**：
1. P5a 章纲节拍表的结构本身就是"承接上一章结尾→铺垫推进→小波折→本章高点→章末钩子"——严格按时间线性排列，节拍表里没有"叙事顺序"这个独立于"情节发生顺序"的设计维度，也没有"倒叙插入""延迟揭示动机"这类选项。
2. K4 节奏与爽点里提到的"特殊叙述章"（日志体/蒙太奇/切视角）虽然算是非线性叙事的口子，但被定义为"每卷约1次"的**实验性例外**，不是常规工具箱的一部分——而用户想要的是"先给行动结果、后插叙动机"这种手法可以**常态化、几乎每章都能用**，不是稀有特殊章节才有资格用。
3. K5 桥段与伏笔手册里的"悬念与谜题""信息型callback"是跨章级的伏笔埋/收操作，颗粒度是"故事弧/卷"级别，没有覆盖"一章/一个场景内部，先给结果，隔几段再补一段解释"这种更细颗粒度的叙事顺序技巧。
4. 焦点卡（T9/P5b）和 P6 写手指令里，没有一个字段允许标注"这个节拍先不解释来龙去脉，动机留到后面/本章末/下一章开头再补"——写手没有被授权"卖关子"，只能老老实实按认领到的事实顺序直给。

**初步改法方向（未定稿）**：
- P5a 节拍表新增一栏"叙事顺序 vs 情节顺序"，允许某个节拍标注"倒叙插入"或"延迟解释"，并注明"这个信息在情节时间线上其实发生在哪、打算什么时候揭示"。
- 把"先给行动结果、后插叙动机"这类技法从 K4"特殊叙述章"的例外名单里拆出来，单独在 K5 或新条目里定义为一种**常规**的场景级叙事手法（类似"揭示钩子"但是主动设计的结构，不是偶然）。
- P5b/P6 相应加一个"本节拍是否隐藏信息，隐藏到哪一拍揭晓"的标记，避免 V4/V5 校验时误判为"逻辑断层/伏笔漏埋"。

## 提案：新增"参考作品提纯工坊"（独立于主创作流程，待建）

> **状态：暂缓（2026-08-11）**。番茄小说的正文有专门的反爬字体混淆保护（底层文字是错的，靠自定义字体渲染才显示正确），批量脚本化抓取/截图会构成对该保护机制的规避，评估后决定不做这类自动化工具。个别段落仍可由用户手动截图、我读图分析（人工小规模，不构成批量还原）。这条路线暂时搁置，先回到问题一/二/三本身继续推进；后续如用户手动积累到足够的参考截图，或换成无保护的文本来源，再捡回来。

**动机**：用户看过一些作品，有"这就是我想要的感觉"的直觉，但说不清具体是什么手法——想通过让我实际阅读这些作品，反向提炼出可复用的规律，再决定要不要写回主工作流。**目的是学作品的"文笔/结构/技法"，不是学内容/情节**（版权与原创性考虑）。

**已确认的约束**：
- 文本来源：需要写爬虫脚本采集（目标作品/平台还没定，先把爬虫框架搭好待用）。
- 使用范围：**仅本地个人研究用**，规律提炼完成后原文即删除，不对外发布/分享，不长期留存原文库。
- 产出形式：① 提炼成文字规律/特征清单（类似《黄金样张》的扩充版）；② 对比报告（工作流产出正文 vs 参考作品，具体差在哪）。

**待定/待补充**：
- [ ] 具体目标作品/平台（用户后续告知）——不同平台反爬机制、页面结构差异很大，"通用框架"只能做到"可插拔适配器"的程度，遇到具体平台还需单独写适配逻辑。
- [ ] 新工坊的文件/流程命名（暂拟：独立于 P/K/T/L 现有体系的新前缀，比如 R1-作品采集 / R2-规律提炼 / R3-对比报告，避免和主流程序号混淆）。
- [ ] 提炼出的规律最终并入主工作流的哪些文件（大概率是黄金样张 + K7/K9 + 新的叙事结构类知识文件），等提炼报告出来后再定。
