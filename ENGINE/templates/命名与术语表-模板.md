# 命名与术语表 · 模板

> 解决的问题：给能力/组织/地点/物品/群体起专有名词（比如给某个安全区、某种弥漫的危险物起个专名），能造认知锚点——读者记得住、能拿去评论区玩梗传播、世界观有质感、喊出来有爽感。但**命名一旦泛滥就变成另一种AI味**：生造词堆砌、读者记不住、风格前后不统一、同一个东西写着写着换了名字。
> 这张表干两件事：① 定死本书的**命名调性**（统一风格 + 命名哪些类别 + 克制原则）；② 增量登记所有专有名词，当"唯一真相源"，防止同一个东西全书名字漂移。
> 产出存到 `01-设定/命名与术语表.md`，命名调性由 世界观与金手指/故事种子与世界基底 定，术语表随写作**增量登记**（每章写完把本章新造的专有名词登记进来，像伏笔登记表那样是活文件）。

---

## 零、最高原则：克制，专有名词是点缀不是堆砌

**默认不造新词。** 只有当一个东西同时满足下面几条时，才值得给它一个专有名词：
- 会**反复出现**（一次性的道具/龙套/场景不值得命名，直接用大白话描述）；
- 值得读者**记住**（记不住的名字等于没起）；
- 能被**传播/玩梗**，或喊出来有爽感/仪式感。

反模式（独立正文自查要挑出来）：一章里生造一大堆新词砸读者脸上、给根本不重要的东西起复杂名字、名字之间风格打架。**宁可少，不可滥**——一本书真正让读者记住的核心专有名词，可能就那么十几个，剩下的都用大白话讲清楚就行。

---

## 零之二、造词前先分清：现实已有 vs 世界观特有（★对治"把现实事物随手造成新词"）

第零条管"要不要造一个新专名"；这一条管"这东西到底该不该由你来造词"。判断只有一步：

> **这东西，现实世界里有没有现成的通行叫法？**
> - **有 → 一律沿用现实通用名，绝不自造词。** 地面就叫地面/甲板，门就叫门，酒就叫酒，枪就叫枪，地图就叫地图。把现实已有的东西硬拼成一个新词（如"铁地"＝铁+地），既不自然、又不精准，是最没必要的一种生造。
> - **没有、是本世界观特有的新事物 → 这才轮到造词**（晶核、神经同调、裸同调、清源组）——也就是第零条管的那些。

**一句话：造词权只给"现实没有的东西"。现实有的，你的活是挑那个最准最自然的现实词，不是另起一个。**

**常用名物要统一**：地面、墙、门、灯、通道这类反复出现的场景名物，即使不进上面的专名登记表，也要在下面"常用名物对照"栏定一个统一的现实通用名、全书照它用——别随手换说法（同一个地面写成"铁地/地板/金属地"三种，就是没统一）。

## 一、命名调性（开书时定，之后基本不变）

- **本书整体命名风格**（选一个主基调，别混）：如"口语化冷幽默风"/"古典中二风"/"冷硬科技风"/"民俗怪谈风"……
  - 一句话描述这个风格听起来什么样，举2-3个符合的示例名。
- **本书重点命名哪些类别**（随题材配置，勾选，别全开）：
  - [ ] 能力/技能/功法/境界名
  - [ ] 组织/势力/角色群体代号
  - [ ] 地点/域/空间名
  - [ ] 物品/机制/黑话术语
  - [ ] 其他（本书特有的，写明）
  - > 没勾选的类别，默认用大白话描述，不刻意起专有名词。
- **命名禁忌**（本书不要什么样的名字）：如"不要生僻字堆砌""不要中英混搭""不要超过4个字"等。

## 二、术语登记表（增量，每章新造的专有名词登记进来，只追加）

| 术语 | 类别 | 指的是什么（一句话） | 首次出现章 | 为什么值得命名（对照零原则） | 别名/易错写法（防漂移） |
|---|---|---|---|---|---|
| （如"净土区"） | 地点/机制 | （某种安全区，危险浓度低于临界值的范围） | 第1章 | 全书反复出现的核心生存概念 | 别写成"隔离区""安全屏障" |
| | | | | | |

> **"别名/易错写法"列**是给校验用的：登记这个东西**绝对不能**被写成的其他说法，独立正文自查/写作时照这里查，发现漂移就改回来。

## 二之二、常用名物对照（现实已有、反复出现的场景名物——不造词，挑一个现实通用名，全书统一）

> 和上面"术语登记表"分工：术语表登记**世界观特有的专名**（造出来的新词，如晶核）；这张表登记**现实已有、但反复出现**的场景名物的**统一叫法**（不造词，挑最准最自然的现实词，全书照用、别混叫）。随写作增量登记：发现一个反复出现的场景名物，就在这里定名。

| 名物 | 全书统一叫它 | 别写成（防混用/生造） |
|---|---|---|
| （如 停泊环地面） | 甲板 | 铁地 / 金属地 / 地板 |
| | | |

## 使用流程

1. **定调性**：世界观与金手指（世界观）或故事种子与世界基底（收束）时，定命名调性（风格+命名哪些类别+禁忌），并把设定阶段已经产生的核心专有名词（世界观卡/金手指卡里的）登记进术语表。
2. **写作时用**：焦点卡加载清单里，若本章要用到已登记术语，列上"命名与术语表：相关词"→ 正文生成照术语表用词，不自造同义词（别把定好的专名写成近义的另一个词）。
3. **写作时新造**：正文生成如果这一章剧情自然需要一个新专有名词——先对照"零、最高原则"掂量它值不值得命名（不值得就用大白话）；值得的话，符合命名调性地起一个，写完在章末收尾登记进术语表。
4. **校验**：独立正文自查查两件事——① 一致性（正文里的专有名词和术语表对得上吗？有没有把已登记的东西写成别名？）② 泛滥（本章新造的专有名词，是不是每一个都过了"零原则"？有没有给不值得的东西乱起名、一次性砸太多新词？）。
