# 关系情感状态卡 · 模板

> 专门追踪"人物关系/情感进度"的活文件——之前这类信息散落在人物卡的N档字段和演进状态卡里，容易在长上下文中丢精度、前后不一致。
> **这是连续量，不是清单量**：不要把关系推进写成"打勾/未打勾"的checklist，要写清楚"现在在哪个阶段、上次是怎么走到这一步的、还欠读者什么"。
> 产出存到 `03-人物/关系情感状态卡.md`，**活文件，每个故事弧结束（故事弧状态预算阶段）更新一次，正文写作中途不直接改**。

---

## 使用规则

- 每一对"读者会关心的关系"占一行，不是所有人物两两组合都要建——只建有情感张力/正在演化的关系。
- "当前阶段"用具体描述，不用"好/中/差"这种笼统标签。
- "未兑现的情感债"是关键字段——它是防止"情感线突然爆发得没有铺垫"或"情感线该收的时候被遗忘"的核心机制。

## 情感债台账（独立追踪，防止遗忘）

> "情感债"：读者已经感知到、但还没被兑现的情感张力（如"两人之间那句话一直没说开""某个亏欠一直没还"）。
> 这张台账的作用类似伏笔登记表，但专门管情感，不管事件。

| 编号 | 债务内容（读者在等什么） | 涉及关系对 | 欠债起点（哪一章/哪个弧） | 预计兑现区间（模糊） | 状态 |
|---|---|---|---|---|---|
| E-01 | | | | | 未兑现/兑现中/已兑现 |

## 每个故事弧结束后更新清单

- [ ] 本弧推进了哪些关系对？更新"当前阶段"和"上次推进事件"
- [ ] 本弧有没有产生新的情感债？登记为新 E
- [ ] 本弧有没有兑现某条情感债？标记"已兑现"
- [ ] 有没有 E 欠了超过2个故事弧还没兑现？→ 下一弧的 故事弧大纲/故事弧状态预算 优先安排
- [ ] 有没有关系推进得太快（没有对应事件支撑）或太慢（读者会觉得在拖）？→ 在 故事弧状态预算 状态预算里提出调整

## ★范文学到的关系推进法（跨本·2026-08-22 · 范文分层学习提炼）

> 由隔壁蛇蛇/巨龙/推理万人迷/末日副本 ch1-30 提炼，只抽关系推进法则、不抄具体桥段。尤适甜宠/多男主/慢热线。

1. **★行动证据代替表白，慢升温**：关系靠一连串"服务型细节"递进（给药/上药/收行李/投喂/挡雨/递伞），而非直白告白；起点常是利益交换（交易→组队→互助→真心），符合成熟人际逻辑。
2. **身体信号先于言语写心动**：角色尚未自知情感时，先写生理反应（僵硬/心跳/耳根燥热/目光不受控）并点一个"陌生的"让角色自己都不解，克制不点破——读者比角色先嗑到。
3. **多POV错位/信息差养糖**：同一次接触，一方当无事发生、另一方内心翻涌，糖藏在"读者全知、当事人各自半知"的信息差里。
4. **好感量化成可见进度条**：把暧昧做成可积累、可消费的数值资源（爱慕值→换道具），既让读者"看见关系在涨"，又给主角"为别的目的赚值"的去恋爱脑正当动机。
5. **甜必配怼防腻**：每段暧昧/糖点后紧跟一句吐槽/白眼，甜与怼交替，中和纯甜的腻。
6. **里程碑用"保护方向反转"**：一贯被保护者豁出去反挡在对方身前（"这次换我"），完成情感质变。
7. **情绪双轨 + 创伤挂钩**：轻喜主线情绪克制，重锤留给创伤/失去高潮（长排比蓄势+复沓短句砸实）；把"疗愈某人创伤"设成关系推进的正当抓手（情感线与主线共用一个抓手）。
8. **双视角戏剧性反讽**：让读者比场中角色多知道一层危险/真相，制造"眼睁睁看着TA浑然不觉"的持续悬心/揪心。
