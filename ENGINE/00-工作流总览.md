# 工作流总览 · V2

> **核心哲学变化**：V1是"建筑设计模式"——先画好整本施工图，再按图施工。V2是"生长模式"——播下种子，故事在写作中自然生长，大纲随正文演进。

---

## 一、架构总览：播种 → 生长

```
┌──────────────────────────────────────────┐
│           架构工坊（播种，不是定死）         │
│   P1 世界观+金手指 → P2 人物种子 → P3 收束  │
│                                               │
│   只定死：物理规则 / 金手指机制 / 人物底层      │
│   留白：灾变真相 / 金手指来历 / 全书结局        │
│                     ↓                         │
│               故事种子 + 世界基底               │
│                     ↓                         │
│           写作工坊（生长模式）                  │
│                                               │
│   P4 演进大纲 ←── 写完3-5章就跑一次            │
│        ↓                                      │
│   P5 章纲+焦点卡 → P6 正文 → P7 润色          │
│        ↑_____________________________↓        │
│           写完一批后回到P4，大纲演进             │
│                                               │
│           人工Review（穿插）                   │
│   P8 Review修改 ←── 「这里需要改」            │
│       锁定修改点 → 拉通上下文 → 精准手术        │
└──────────────────────────────────────────┘
```

**V1 vs V2 根本区别**：
| 维度 | V1（蓝图模式） | V2（生长模式） |
|------|--------------|--------------|
| 大纲 | 全书事件线一次性定死 | 局部大纲，每3-5章演进一次 |
| 世界真相 | 架构工坊就定死 | 物理事实定死，大秘密留白，写作中逐渐揭示 |
| 人物弧光 | 全书节点全部定死 | 只定模糊方向，在故事中自然生长 |
| 伏笔 | 全部预先设计 | 正向登记 + 写作中反向发现 |
| 写作体验 | 按图施工，完成"分配的任务" | 跟着角色走，记录"正在发生的事" |

## 二、8步工作流

### 架构工坊（3步，播种）

| 步骤 | 做什么 | 产出 | 定死的 | 留白的 |
|------|--------|------|--------|--------|
| **P1** | 世界观与金手指 | `世界观设定卡` `金手指卡` | 灾变物理规则、金手指机制、限制 | 灾变真相方向、金手指来历方向 |
| **P2** | 人物种子 | `03-人物/` 主角+核心配角卡 | 表层+底层（欲望/恐惧/创伤） | 命运层→模糊弧光方向 |
| **P3** | 故事种子与世界基底 | `世界基底` `故事种子` | 物理事实（空间结构/规则）+ 前三章 | 全书事件线、分卷详细规划、最终结局 |

### 写作工坊（5步，生长+Review）

| 步骤 | 做什么 | 产出 | 频率 |
|------|--------|------|------|
| **P4** | ★ 演进大纲（核心生长步骤） | 更新`演进状态卡` + `局部章纲` | 每3-5章跑一次 |
| **P5** | 章纲与焦点卡（二合一） | `焦点卡-第X章` | 每章 |
| **P6** | 正文生成 | `第X章-标题.md` | 每章 |
| **P7** | 润色定稿（五轮） | 覆盖更新正文 | 每章 |
| **P8** | Review修改（上下文手术） | 覆盖更新正文 + 同步更新DAG/状态卡 | 人工Review后触发 |

**日更循环**：
```
（新卷/每3-5章）P4 → P5 → P6 → P7 → （人工阅读）→ （如需修改）P8 → 更新状态 → 下一章P5 → ...
```

## 三、V2核心创新

### 1. 演进大纲（P4）
替代V1的"全书事件线+定死卷纲"。写完3-5章后回看已写内容，生成接下来的局部大纲。大纲是活的——每次跑P4都可能调整方向。

### 2. 叙事情绪温度
V1只教AI"写什么"（L0-L3细化等级）。V2加入"用什么情绪嗓音写"——每段的文字节奏必须和角色的情绪温度同频。该慌的时候文字要碎、短、感官直出；该平静的时候才从容。

### 3. 反向伏笔发现
V1的伏笔全部预先设计。V2保留伏笔DAG的正向登记，新增"反向发现"——写完几章后，扫描已写内容中可做伏笔的细节（随手写下的台词、没解释的异常），登记到DAG。

### 4. 表演式描写禁令
识别并禁止AI的"签名式写法"：单字形容词断句（"细细的，凉。"）、简单事件上的诗意化堆砌、"不是...而是..."无效对比。用"角色即时感官"替代"作家事后修辞"。

### 5. Review上下文手术（P8）
人工阅读后说"第X章第Y段需要改"——系统不是直接改这一段，而是自动拉通前后文、伏笔、人物状态、设定，分析影响范围后再下刀。改完同步更新DAG和状态卡。

## 五、操作话术

**新书开始**：
- 「进入P1」→ 同时设计世界观+金手指
- 「进入P2，先做主角」→ 建人物种子
- 「进入P3」→ 收束种子和世界基底

**日常写作**：
- 「写第N章」→ 自动 P5→P6→P7
- 「跑P4」→ 写完3-5章后，回看态势，生成接下来走向

**人工Review**：
- 「修改第X章第Y段，问题：XXX」→ P8 自动拉通上下文，分析影响，精准修改
- 修改意见可以是任何类型：太啰嗦/情绪不对/人设崩了/逻辑bug/加对话...

**状态查询**：
- 「现在写到哪了？」→ 读演进状态卡
- 「有什么伏笔还没收？」→ 查伏笔DAG
- 「接下来几章往哪走？」→ 看局部大纲

## 六、铁律（贴在心上）

1. **只定物理规则，不定全书结局**。大秘密留白，在写作中发现。
2. **一次只写一章**。写完立刻润色。
3. **每章必有L3**。没有深度刻画的章节是流水账。
4. **每章必有情绪温度**。文字的嗓音要跟角色的感受同频。
5. **每章必过P7五轮润色**。AI初稿默认带味。
6. **大纲是活的**。写完3-5章跑一次P4，别死守最初的方向。
7. **伏笔可以"后发现"**。写作中随手写下的好细节，回头登记到DAG。
8. **大声念一遍**。念出来别扭就改。初高中生要一眼看懂。
