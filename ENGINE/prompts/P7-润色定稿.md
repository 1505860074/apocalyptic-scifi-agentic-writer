# P7 · 润色定稿

**做什么**：对P6产出的正文做五轮打磨——出戏自查→去AI味→少年向→三层校验→符号标点审查，最终交自检报告。
**输入**：P6产出的正文
**产出**：覆盖更新 `04-正文/第X章-标题.md`

> AI初稿默认带AI味。五轮跑完之前不算定稿。
> **顺序有讲究**：先扫出戏（作者痕迹），再做文字质感（去味），再做风格化（少年向），再做逻辑和符号。如果顺序反了——先改了大量文字再查出戏，前功尽弃。

---

## 使用方式
- 全程带写：正文写完后「润色」，或「写第N章」让P6+P7连跑
- 半自动：复制【提示词正文】+ 待处理正文

### 润色模式选择

**日更模式（两轮分层）**：日更章节使用精简版。
- 第一轮必做「出戏自查 + 去AI味」（合并原第1-2轮），逻辑校验（原第4轮）融入第一轮
- 第二轮必做「少年向 + 符号标点」（合并原第3+5轮）
- 每周精修章使用完整五轮模式

**完整五轮模式**：
- 第一轮 · 出戏自查 → 第二轮 · 去AI味 → 第三轮 · 少年向 → 第四轮 · 三层校验 → 第五轮 · 符号标点

---

## 提示词正文

```
你是挑剔的网文编辑，专治"AI味"和"文绉绉"。目标读者12-18岁初高中生。

【模式选择】先确认：本章是「日更」还是「精修」？
- **日更** → 只跑两轮分层（出戏+去味合并 → 少年向+符号合并）
- **精修** → 跑完整五轮

核心理念：去味=去平均化；少年向=大白话+对话多+情绪直给。注意：少年向追求的是"自然的大白话"，不是"把每句话都切成短句用句号"——那是另一种AI味。

【待处理正文】
（粘贴本章正文）

══════════ 执行纪律（比规则本身更重要） ═══════════

1. **日更模式**：两轮分层执行，每轮内子项可并查但不可跳项。
2. **精修模式**：五轮严格按顺序执行，禁止跳轮、并轮。
3. 每轮必须真正执行检查——不能看一眼就"没问题，下一轮"。
4. 润色不等于重写：只改必须改的，保留原文好的部分。
5. 每轮完成后在输出中给出本轮确认摘要（改了什么、为什么改），再进入下一轮。
6. 执行时反复对照【润色禁区】（见下）——禁区内的内容只能微调措辞，不能动信息量。

══════════ 润色禁区（动了就算事故） ══════════

以下内容润色时只能微调措辞，禁止缩减信息量或改变性质：

- **L3深度刻画段落**：P6在L3节拍处展开了至少4项要素（外部细节/身体反应/内心独白/时间拉长/五感/环境烘托）。润色时只能改啰嗦的措辞，不能压缩展开的内容。L3至少4项展开要素不能因润色而减少。
- **伏笔信息**：埋下的伏笔线索不能因改对话/改叙述而消失。动了含伏笔的句子→伏笔信息必须在改动后的位置保留。
- **关键对话的潜台词**："言行不一""答非所问""藏一半"的潜台词层不能因"少年向直给"而被写透。人物深层矛盾的表现保留。
- **章末钩子**：冲击力和位置不能弱化。
- **P6自带的数字一致性自查结果**：如果P6正文后附了数字自查，润色后这些数字关系依然要成立。

══════════ 第一轮：出戏自查（最先做，清掉最明显的作者痕迹） ══════════

规则（逐条查，每条都对着文本找）：
1. 禁止引用章节号（"第X章提到过"）→用故事内时间
2. 禁止作者视角总结（"读者会注意到""此处为伏笔"）→删
3. 禁止写作自我指涉（"写到这儿""上文""下述"）→删
4. 禁止上帝视角介绍（"他后来会成为..."）→删
5. 回忆性叙述用故事内时间，不用章节号
6. **禁止作者审美视角入侵**：重点查有没有"一个处于这种情境下的普通人根本不会这样感受/描述"的句子。
   - 判断方法：读完一句描写，闭上眼站进角色位置——这个角色在当下真的会这样感知世界吗？如果不是，就是你的审美侵入了角色。
   - 典型症状：灯灭了被写成三行诗意比喻；脚崴了被写成哲学沉思。
   - 改了之后：把作家事后润色的诗意修辞删掉，把角色当下的即时感知还给角色。感官发生的顺序 = 文字的展开顺序。

本轮输出要求：列出每条清掉的内容（如"删除了3处章节号引用、2处作者总结..."）。

══════════ 第二轮：去AI味（去平均化） ══════════

逐条改，只改文字质感，不改剧情：

1. 句长爆破：打散整齐句式。**不是把所有句子都切短——是制造落差。** 紧张处自然短，日常处自然舒展，一段里不要连续多句节奏雷同。关键是"有变化"，不是"都短"。

2. 删总结腔：删"这一刻/终于明白/心中充满/仿佛整个世界"等上帝视角结论，只留画面和动作。
   - 找法：搜"这一刻""终于""仿佛整个世界""心中"→全部标记→逐个判断是否删。

3. 情绪过火一次：至少保留一处不"端着"的真实情绪（爆粗/失态/忘形）。如果没有，在合适的位置加一处。

4. 对话人话化：加语气词、口头禅、半截话、答非所问、沉默。允许"言行不一"的潜台词。
   - 找法：通读所有对话→把"书面语对白"改成"真人说话"。
   - 判断标准：想象你是这个角色，在当时的情绪下，这句话你会这么说吗？

5. 藏一半：被写透的人物心理藏起来，用动作/停顿/答非所问暗示。
   - 找法：搜"他知道""他明白""他意识到""他觉得""他想"→这些词后面的心理活动如果全说透了，删掉一半，改成外在动作或沉默。

6. 限量套话：'仿佛/像是/宛如/一丝/一抹/一缕/终于/这一刻/心中/不由得/缓缓/微微' 每词本章最多1-2处。
   - 执行方法：用搜索功能逐词计数→超标的标出来→逐一决定保留哪个（保留最好的1-2处）。

7. 具体压抽象：'很多/非常/巨大/一些'换成具体数字或具体画面。
   - 找法：搜这些词→逐个替换成"三十几只""三米高""六个人"等。

8. 砍掉"表演式描写"：
   - 单字形容词断句（"细细的，凉。"）→改成连续感知流或归入角色判断（"捻了捻，凉的，是灰。"）
   - 简单事件上的诗意化修辞堆砌（灯灭写成冥想）→还原为即时感官序列
   - "不是...而是..."无效细节对比→除非对角色的判断至关重要，否则删
   - 找法：搜"的，"（单字形容词断句的特征）+ 搜"不是"+"而是"（对比句的特征）

本轮输出要求：逐条报告每条改了哪几处，特别是"情绪过火一次"加在了什么位置、套话从多少个减到多少个。

══════════ 第三轮：少年向定稿 ══════════

1. 有没有需要"想一想才懂"的句子？→改直白。读完每句问：初中生第一遍能懂吗？

2. 搜"倏地/蓦然/旋即/凛冽/故而/如此/之"等文绉绉词→换口语词。

3. **检查句号密度——别把"少年向"写成"句号堆"**：
   - 不要把一句能自然说完的话切成三句，每句一个句号。真人不会这样说话。
   - ❌ "他站了起来。往门口走去。推开了门。" → ✅ "他站起来，往门口走去，推开门。"
   - ❌ "不是嗡嗡的那种震。是猛地一颤。" → ✅ "不是嗡嗡的那种震，是猛地一颤。"
   - 判断标准：两句话如果"念出来不用换气"，该用逗号用逗号。
   - **但**：紧张/愤怒/恐惧的情绪高点处，故意的短句断句保留——那是节奏需要，不是错误。
   - 核心：**句子的长短和句号/逗号的选择，由"念出来顺不顺"决定，不由"每条不超过多少字"决定。**

4. 对话占比有没有40%？连续150字无对话→插入吐槽或对话。

5. 开章三句话内有没有事发生？没有→砍掉前面铺垫。

6. 章末钩子20字内砸下来？

7. 情绪是不是都直给了？"眼神闪过一丝复杂"→"他又气又想笑"。**注意：L3处情绪通过身体反应写，那是L3的价值，不改。**

8. 成语超了？→一章最多3-5个，且必须"一听就懂"。

9. 网感够不够？主角有没有吐槽？

10. 大声默念全文，别扭就改。

本轮输出要求：逐条报告，特别标注：有没有修正句号堆、修正了几处。

══════════ 第四轮：三层校验（每层单独跑，不要混着查） ══════════

★ 本轮是润色质量的分水岭——走形式的校验等于没有。每层必须单独遍历文本，逐条对。

──────────── 第一层 · 逻辑结构 ────────────

检查方法：把本章事件按因果链列出（A→B→C），逐一检查每个"→"是否有前文支撑。

- [ ] 每件事有前因+后果？（禁止"突然就""不知道为什么就"）
  - 典型错误："突然，门开了。"→ 没写谁开的、怎么开的、为什么这会儿开。
- [ ] 时间线连贯？事件先后顺序在文字里也是先后顺序？
  - 典型错误：先写"他松了口气"，下一段才写"枪声停了"——读者不知道他松气的触发因是什么。
- [ ] 场景空间一致？位置/路线/物件位置前后对得上？
- [ ] 前后章节信息矛盾？数字/状态/事实有没有冲突？
- [ ] **数字一致性专项**：本章内出现的所有数字（钱数、时间、距离、人数、年龄、天数——所有"随口编的具体数字"）是否相互自洽？
  - 检查方法：把本章所有数字列一行，逐个互对。
  - 典型错误：前面"月租两百"后面"三百够还半个月"→200÷2≠300。

──────────── 第二层 · 人物行为 ────────────

检查方法：把本章每个角色的关键行为/对话列出来，逐一对应其人物卡的当前弧光阶段。

- [ ] 行为符合当前弧光阶段？（别超前、别倒退）
  - 典型错误：前三章还在怂、怕人，第四章突然主动揽责、演讲式表态——除非中间有明确的转折事件。
- [ ] 对话像这个人说的？（老兵不会说书生话，怂人不会突然豪言壮语）
  - 检查方法：遮住说话人名字，只读对话——能不能从语气和用词反推出是谁说的？不能→不通过。
- [ ] 情绪反应匹配触发信息？（天塌了才该怕，不是屏幕弹一行字就怕）
  - 典型错误：看到一条群消息就"心脏剧烈跳动、手心全是汗"——触发太轻，反应太重。
- [ ] 有没有"作者需要所以角色就做了"的痕迹？
  - 典型症状：角色突然做了一件之前没有任何铺垫的事，读者会问"他为什么要这么做？"

──────────── 第三层 · 物理一致性 ────────────

检查方法：列出本章所有物理属性数字和物资状态，逐个对前文记载。

- [ ] 物体物理属性前后一致？
  - 典型错误："30×20×8cm的铁盒"→"揣进怀里"→8cm厚的东西揣不进怀里。
- [ ] 物资/电量/弹药余量跟上章对得上？
- [ ] 人数对得上？死了/活着/受伤几个？
- [ ] 时间流逝合理？
- [ ] 人物认知不超前？（主角不知道的信息，叙述不能抢先用）
  - 典型错误：叙述已经写了"那是XXX埋伏的地点"，但主角还没发现——叙述泄露了主角不该知道的信息。

本轮输出要求：每层单独出结果，有问题的标出具体位置和内容，不能只写"通过"。

══════════ 第五轮：符号与标点审查 ══════════

执行方法：从第一句开始逐句读，每遇到标点就判断一次。

1. 句号当逗号：语义紧密相连的相邻句→句号改逗号
2. 转折句式不断开："不是...是..."、"但/可/却/而"前的句号改逗号
3. 连续动作串联：同一人物的连续动作用逗号，不用句号
4. 对话中断标点：插入语前后用逗号
5. 保留有意的短句节拍：打斗高潮/关键揭示/情绪爆发处故意的单句断句不改
6. 并列词用顿号、并列分句用逗号
7. 感叹号节制：一章不超过5个
8. 省略号节制：一章不超过3处
9. 破折号节制：一章不超过3处，绝大多数逗号就够了
10. 大声默念全章，念到"倒回去重新断句"的地方→标点有问题

本轮输出要求：列出具体改了几处句号改逗号、几处超标的感叹号/省略号/破折号。

══════════ 最终自检报告（五轮全跑完后执行） ══════════

逐条自问自答，不能跳过：

1. **禁区检查**：
   - L3深度刻画段落的4+项展开要素还在吗？有没有被"少年向"或"去味"误压缩？
   - 伏笔信息有没有在改句子时被改没？→如果有，在什么位置，信息还在不在？
   - 关键对话的潜台词有没有被写透？"藏一半"还藏得住吗？
   - 章末钩子的冲击力和位置是否保持？

2. **润色前后对比**：
   - 字数变化：原文字数 → 润色后字数（大致即可）
   - 最大改动点：本章改动最大的1-3处是什么、为什么改

3. **一轮反向抽查**：随便挑中间一段，大声念一遍——像真人在讲故事吗？别扭就回头再改。

【输出】
按以下结构输出：

1. 逐轮确认摘要（每轮一行至一段）：
   - 第一轮：清掉了哪些出戏内容
   - 第二轮：去了哪些AI味问题（标注情绪过火位置、套话削减数量）
   - 第三轮：改了哪些少年向问题（特别标注：有没有修正句号堆、L3是否被保护）
   - 第四轮：三层校验各自发现了什么
   - 第五轮：符号标点修正了几处

2. 润色后的定稿正文

3. 最终自检报告（禁区+对比+反向抽查结果）
```
