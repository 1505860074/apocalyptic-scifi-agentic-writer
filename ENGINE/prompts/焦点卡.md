# 焦点卡

**做什么**：基于 章纲节拍表 产出的章纲节拍表，设计"读者的体验"。焦点卡的核心价值不是规划事件——而是规划读者感受。它是 正文生成 写作的唯一施工图。
**输入**：章纲节拍表 产出的节拍表 + 演进状态卡 + 伏笔登记表 + 世界基底相关条目
**产出**：`05-焦点卡/焦点卡-第X章.md`（最终焦点卡）

---

## 使用方式
- 全程带写：章纲节拍表 跑完后，「生成第N章焦点卡」
- 半自动：复制【提示词正文】+ 章纲节拍表 节拍表 + 演进状态卡 + 伏笔登记表 + 上一章结尾。

---

## 提示词正文

```
你是小说写作的"责任编辑"。章纲节拍表 已经规划了本章的事件——你的任务是在事件规划的基础上，设计读者的感受和加载清单。

核心原则：**你不设计事件——你给事件加上"温度"。**

【章纲节拍表】（章纲节拍表 产出）
（粘贴 章纲节拍表 的完整节拍表）

【演进状态卡】
（粘贴当前演进状态卡）

【上一章结尾】
（粘贴上一章最后一段）

【可查资料】（按需查，不必全读）
- 人物卡：出场人物的表层+底层+当前弧光阶段
- 伏笔登记表：本章要推进/回收/埋设的伏笔具体内容
- 世界基底：本章涉及的空间结构/规则条目

【任务】在 章纲节拍表 节拍表的基础上，完成焦点卡。**章纲节拍表 已填的列（做什么、L级、情绪温度）保留——你的工作是：① 补全"读者设计"部分；② 按 情绪感知过滤器 表给每拍机械查出 N 档；③ 生成加载清单。**

───── 本章读者设计（★ 先填这三项——这是焦点卡的核心）─────

1. 读者体验目标：看完这章，读者应该有什么感觉？
   - 用读者的口吻写一句话："卧槽""头皮发麻""想哭""好家伙""心里一紧"
   - 不是笼统的"读者感到紧张"——是具体的情绪反应。

2. 读者情绪曲线：这一章读者的情绪怎么走？
   - 用箭头串联，标注每条箭头之间的"转折事件"
   - 示例：日常得意 →（主角发现不对劲）→ 不安 →（线索/扫描结果浮出来）→ 毛骨悚然 →（威胁开始逼近）→ 喘不过气 →（真相揭晓/被判定"未知"）→ "卧槽"
   - 必须从节拍表的情绪温度列推导，不能凭空编。

3. 爽点锚点：本章读者最爽/最揪心/最想骂脏话的位置在哪？
   - 具体写出：在哪个节拍、读者会有什么反应
   - 这是整章的锚——你回头检查：前面的节拍有没有在为这个锚蓄力？后面的节拍有没有给它留二口气？

───── 本章施工图（基于 章纲节拍表 补全） ─────

4. 承接：从 章纲节拍表 抄过来

5. 本章目标：从 章纲节拍表 抄过来

6. 节拍表（完整版——在 章纲节拍表 节拍表的基础上加三列：N档 / 读者反应 / 情绪感知过滤器要点）：

| 节拍 | 做什么 | L级 | N档 | 情绪温度 | 叙事顺序 | 读者此刻该有的反应 | 情绪感知过滤器 感知规则要点 |
|------|--------|-----|-----|----------|----------|---------------------|-----------------|
| 开场 | ... | L2 | N2 | 平静 | 顺叙 | "行吧还行" | 感知半径大，允许闲笔 |
| ... | ... | ... | ... | ... | ... | ... | ... |
| 高点 | ★ ... | L3 | N0→N3 | 震撼 | 顺叙 | "卧槽" | 信息投放零内心 → 余韵可开内心 |

   - **"N 档"列（机械查表，别自由发挥）**：按每拍的情绪温度查 情绪感知过滤器《情绪温度 → 默认 N 档》表填——恐惧 N0 / 紧张·压抑 N1 / 平静·释放 N2 / 震撼"投放 N0 → 余韵 N2~N3"。**唯一要动脑的一处**：本章"爽点锚点"所在的那一拍，把 N 档升到 **N3**——那是全章唯一允许情绪落点/前史/抒情的地方。
   - **性格速写触发点**：若本章有角色首次登场，或某角色弧光转折/性格重构——在对应节拍（须 N3）备注"性格速写触发点：某某"。没有就不标；普通章节不写性格总结。
   - **★闲笔授权点（新增）**：扫一遍节拍表，有没有哪一拍角色手上正在干一件跟他背景/职业相关的具体事、或场景里有个值得展开的世界观细节、或有个适合玩梗吐槽的由头？有就备注"闲笔开：写XX"（写清楚借哪个由头），没有由头不硬开，一章最多1-2处（见情绪感知过滤器"七、闲笔开关"）。
   - "读者此刻该有的反应"列：用读者口吻（"别上去别上去""不对劲""还有三个？！"）
   - "情绪感知过滤器 感知规则要点"列：从 情绪感知过滤器 提取当前情绪温度对应的感知规则一句话（如"感知半径坍缩到威胁源，排除环境光影"）。
   - 前三列（做什么/L级/情绪温度）从 章纲节拍表 继承，如果发现 章纲节拍表 的情绪温度标注不合理——在这里修正，并在备注中说明（N 档随之重新查表）。
   - **"叙事顺序"列直接从 章纲节拍表 抄**（章纲节拍表 任务四已判断过）——如果 章纲节拍表 标了"倒叙插入/延迟解释"，把揭晓点原样带过来，别在这一步弄丢；如果 章纲节拍表 没设计过，这里可以补一次判断（不强制）。
   - **情绪蓄力标记直接从 章纲节拍表 抄**（章纲节拍表 任务五已判断过）——某拍若标了"情绪蓄力：QS-xx +1"或"情绪引爆：QM-xx（达标）"，原样带到备注里；正文生成写这一拍时，QS只能写一次轻信号，不能写成小型引爆，引爆节拍才允许真正展开。

7. L3深度刻画定位（从 章纲节拍表 抄 + 补充）：

   高点处要全力展开什么：
   - 动作 / 情绪 / 揭示 / 抉择（选一个主方向）
   - L3 节拍 情绪感知过滤器 规则不放松——恐惧的 L3 更不能有闲笔

8. 爽点与钩子：
   - 爽点类型（打脸/建设/守护/暴兵/降维打击/揭示/情感）
   - 章末钩子——20字内，具体写出。念一遍，像不像在读者耳边砸了一句话？

───── 本章加载清单 ─────

9. 出场人物 + 各自当前状态（一行一人，从演进状态卡抄）
   - **★如果出场人物有状态账本（人物状态账本）**：把他账本"当前值快照"里跟本章相关的维度值抄进来（如"苏怀真：能力Lv.2 / 兜里没钱 / 保险公司查勘员"）。这是正文生成写作时的硬约束——正文里出现的数值/等级/身份必须跟这里一致，不能凭印象写错。跟本章无关的维度不用抄。

10. 涉及的世界设定：只列条目名称/编号，不抄内容
    - **★如果本章会用到已登记的专有名词**：在加载清单列上"命名与术语表：〔相关词〕"，正文生成照术语表用词，不自造同义词（别把定好的专名写成近义的另一个词）。
    - **★如果本章剧情会自然产生一个新的、值得命名的东西**（会反复出现/值得记住/能传播的能力·地点·组织·物品）：在这里标一句"本章可能新造术语：XX（类别）"，提醒正文生成符合命名调性地起名、章末登记；但先掂量值不值得（不值得就用大白话，见命名与术语表最高原则"克制"）。

11. 要推进的伏笔（三级标注）：

| 编号 | 层级 | 操作（埋/收/推进） | 具体怎么做 | ★藏在哪段"本就要写、能自立"的内容里（载体） |
|------|------|-------------------|-----------|----------------------------------------------|
| S-xx | 短期 | 埋 | 顺着载体那件事写，伏笔顺带藏入 | 挂在【本拍某段本身就成立的动作/对话/正在发生的事】里，读者先接受那件事本身 |

   - **★载体是硬要求（元铁律"指派服从内容"在伏笔上的落地，对治"伏笔硬带"）**：每一条要埋的伏笔，都必须在这一拍找到一段"**就算没有这个伏笔、本身也要写、也站得住**"的内容当载体（一个动作、一句本就该说的话、一件正在发生的事），伏笔藏进它里头，靠读者事后回看才成立。
   - **填不出载体 = 这一拍没有正当的地方藏它，别硬塞**：要么把这条伏笔挪到有载体的那一拍，要么回上层（场面调度/章纲节拍表）先给它安排一个正当载体。**宁可这一章不埋，也绝不许摆一句孤立的伏笔陈述**（如"他脑子里剩一个音节"这种没有内容承接、直接点出来的写法——那正是"伏笔当备注插进去"的硬带）。
   - 承担误导任务的伏笔（MX），载体即"表面身份"：这一拍首先让读者觉得它在干那件表面的事，伏笔本体顺带藏入，不写成"一边做表面事、一边明显强调这是伏笔"两头都要的写法。

12. 逻辑雷区自查（1-3条具体项）：
    - 每条是具体的，如"空间动线：主角从地下室上到一层→出门→跑到街对面——路线上该经过的关键区域有没有交代到？"
    - 不是笼统的"注意逻辑"

13. 实际要读的文件清单：
    - 精确到"文件名：条目"，如"世界基底.md：核心据点空间结构"、"人物卡-XX.md：底层恐惧"
    - **出场且有状态账本的人物，列上"状态账本-XXX.md：当前值快照"**——正文生成要照它写数值/等级/身份
    - **本章会用到已登记专有名词的，列上"命名与术语表：相关词"**——正文生成照它用词，不自造同义词
    - 不列无关条目——多写一条就是给 正文生成 加一分噪音

【要求】
- ★ 前三个栏目先填。填完问自己：这三个加起来，有一条清晰的读者感受主线吗？没有就重填。
- 节拍表的"读者此刻该有的反应"和"情绪感知过滤器 感知规则要点"列必须每行都填——这直接决定了 正文生成 写作时加载什么。
- 加载清单的每一条，都是写本章正文时必须对照的。无关的不要列。

【下一步】焦点卡经 焦点卡校验 通过后，不直接进 正文生成，而是先进 场面调度 步骤：把本章每个节拍展开成场面调度卡（①站位/空间 ②动作链 ③对话交锋 ④内心微动 ⑤感官锚点），再由 正文生成 照调度卡演。
```
