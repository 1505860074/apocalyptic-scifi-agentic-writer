# 用词优化工坊（★元工作流 · 工作流自优化）

> **这不是写书的工序,是优化工作流本身的工具。** 它跑在写书主管线之外:拿一篇标杆范文当"标准答案",逆向拆出它的骨架 → 让工作流拿同样的骨架**盲写一遍** → 比出差距 → 把差距**抽象**回填工作流,让工作流的用词和风格逐步逼近范文。
>
> 核心思路 = 把"作者手改→提炼规律→改工作流"这个手动循环,做成可复用的自改进闭环。

---

## 做什么 / 输入 / 产出

**做什么**:用一篇范文反推工作流在"用词和风格"上的短板,并抽象地回填各层。

**输入(可插拔)**:
- **标杆范文**:一篇你认可的、比工作流当前产出更好的文本。外部优秀网文 或 项目内定稿章节均可,**跑时指定**。以**一章**为单位(一整篇太大,且骨架提取会失真)。
- **当前工作流**:ENGINE 各层(现状,作为被优化对象)。

**产出**:
1. 《工坊报告》:逆向骨架 + 盲重建稿 + 差距分析(抽象层)+ 对各层的抽象优化建议。
2. (经作者确认后)对工作流各层的实际改动。

---

## 四条铁律（这个工坊的红线,违反即结果作废）

1. **盲重建**:正向重建的子agent **只拿骨架、绝不接触原文**。看了原文＝作弊,测出来的不是工作流的真实能力。逆向提取的agent 和 盲重建的agent **必须是不同的、互不传原文的**。

2. **只优化文风层**:骨架喂了相同的情节/人物/节拍 → 情节结构本应一致 → 差距集中在**用词、句子、节奏、质感**。所以回填**只动文风相关层**(去AI味与叙事质感 / 优秀网文写作法 / 本书写作风格卡 / 正文生成的文风部分 / 场面调度的对话),**不碰情节、结构、设定层**。若发现情节结构也差很多,那是"逆向提取没提准",回工序1,不是拿它优化。

3. **不举例、只抽象(★作者硬要求)**:差距回填工作流时,**绝不把范文的具体词句当例子写进规则**。只能把差距提炼成各层的**抽象倾向**(如"该层应更强调动词贴角色职业"),不能出现"范文里写了X所以规则加X"这种。这是为了保住工作流的通用性,别被一篇文章的确切文字污染(同"去文风污染"一条心)。

4. **防过拟合**:一篇范文里,有些特征是**通用网文规律**,有些只是**这位作者的个人风格**。差距**必须能上升为"一类通用网文原则"才回填**;纯属单篇个性的(比如某作者特别爱用某种句式),**丢弃、不入规则**。宁可不改,不可把一篇的个性当通法。

---

## 五工序（用子agent编排,盲测隔离）

### 工序1 · 逆向提取器(蒸馏骨架)

派一个agent读范文这一章,逆向填出工作流的中间产物:
- 命名/常用名物、人物落笔(表层+底层的可见部分)、事件与大纲、焦点卡(节拍 · 情绪温度 · L/N · 爽点锚点)、场面调度(站位 · 动作链 · 对话意图 · 感官锚点)、句意稿(每拍要落实的内容点)。
- **只拆骨架:情节、人物、场景、节拍、"要说清的内容点"。剥掉原文的用词、句子、比喻、腔调、节奏**——那些正是要考工作流的东西,不能泄给下游。

**关键自检**(不过就重来):把提取物交给一个没读过原文的人,他应当能据此知道"这章发生了什么、什么节奏、什么情绪、每拍要落实什么",但**无法复原原文的具体文字**。如果提取物里还残留原文的句子、独特比喻、标志性用词 → 没剥干净,重提。

### 工序2 · 正向盲重建

派**另一个(未接触原文的)agent**,拿工序1的骨架,走现有正向链:场面调度 → 句意稿 → 正文生成 → 独立正文自查,生成这一章。
- **用现在的工作流、现在的规则,原样跑**——这才测得出工作流"当前"的真实水平。
- 全程不得接触原文。

### 工序3 · 对比器(提差距,只比文风)

派一个agent把盲重建稿 vs 原文对齐(同一骨架的两个实现),逐维度比**用词/句子/风格**:
- **用词**:动词精准度、修饰密度、名物词(现实名 vs 生造)、口语 vs 书面。
- **句子**:长短节奏、断句、直给 vs 绕。
- **风格**:情绪直给 vs 解说、潜台词密度、描写落地 vs 悬浮、有没有记忆点。

- 情节/结构层面的差异**忽略**(骨架相同,那不是本工坊的目标)。若结构也差很多 → 回工序1(骨架没提准)。
- **输出差距清单:每条是一个抽象倾向差异**(如"重建稿动词偏泛用,原文动词更贴角色的手艺/职业"),**描述倾向,不抄原文例句**。

### 工序4 · 抽象优化器(差距 → 通用原则 → 定位到层)

派一个agent,把每条差距过两道闸:
- **闸一(防过拟合)**:这条差距能不能上升为"一类通用网文原则"?不能(纯单篇个性)→ 丢弃。
- **闸二(定位)**:能的话,对应工作流哪一层(知识层规则 / 模板 / prompt)?

产出:对各层的**抽象**优化建议——只说"该层的规则该往哪个方向调、补哪条抽象原则",**不写范文的具体例子**(铁律3)。

### 工序5 · 回填 + 迭代(经作者确认后)

- 按工序4的建议,抽象地改对应的文风层。
- 改完可**再跑一轮工序2-3**(用新工作流重新盲重建、再对比),看差距有没有缩小——形成闭环,直到收敛或作者叫停。

---

## 使用方式

- 全程带跑:「跑用词优化工坊,范文＝<某章/贴文>」
- 半自动:贴范文一章 + (可选)指定要重点对标的维度(用词/句子/风格)。

## ★ 规模提示

这是**多子agent高消耗**流程(逆向提取1 + 盲重建1~若干 + 对比1 + 优化1,可能迭代多轮)。**每次跑前先报规模、经作者同意再跑。**
