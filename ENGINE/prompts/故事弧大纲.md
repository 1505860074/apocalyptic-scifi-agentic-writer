# 故事弧大纲

**做什么**：基于世界线纪要的最新宏观素材 + 最近1-2个故事弧的结尾状态（滑动窗口，不读全部历史），设计下一个故事弧的大纲——颗粒度到主角+主要事件，但不到具体章节。
**输入**：
- 世界线纪要（最新版，通常不长）
- 最近1-2个故事弧大纲的收尾状态（滑动窗口——不要把更早的故事弧全文塞进来）
- 关系情感状态卡（当前版本）
- 伏笔登记表（当前版本，用于误导设计时核对证据链）
- 演进状态卡（当前进度、主角状态）
**产出**：`02-大纲/故事弧大纲-第N弧.md`（含误导设计表，如本弧涉及中/大反转）

> **总纲约束**：设计每一弧时，回看一眼 `00-立项/立项书.md` 的核心命题/主线走向/情感内核/差异化卖点——故事弧是全书主线的分段兑现，方向要始终朝着立项定的那口气走，别越写越偏离立项初衷。

> 这一步承接原"局部大纲"的职能，但两处关键改动：① 输入不再是"最近3-5章正文"而是"世界线纪要+滑动窗口的前情故事弧"，避免长上下文精度衰减；② 弧的边界由戏剧节拍决定，不是固定章数。

---

## 使用方式
- 全程带写：「跑故事弧大纲」
- 半自动：复制【提示词正文】+ 世界线纪要 + 前1-2弧的故事弧大纲 + 关系情感状态卡 + 演进状态卡。

---

## 提示词正文

```
你是小说故事弧规划师。你的任务是设计下一个故事弧——一组围绕同一个小目标展开、以一个转折点/小高潮收尾的章节集合。

核心原则：**弧的边界由戏剧节拍决定，章数是结果不是输入。先定"收尾在哪个转折点"，再倒推大概需要几章。**

【世界线纪要】（最新版）
（粘贴 世界线纪要 全文——通常不长，不需要裁剪）

【前情故事弧】（滑动窗口——只给最近1-2个弧，不给更早的）
（粘贴最近1-2个《故事弧大纲》的完整内容，重点看它们的"收尾状态"）

【关系情感状态卡】（当前版本）
（粘贴 关系情感状态卡 全文）

【伏笔登记表】（当前版本）
（粘贴 伏笔登记表 全文，用于误导设计时核对证据链）

【演进状态卡】（当前进度）
（粘贴 演进状态卡 全文）

══════ 任务一：判断本弧的驱动力 ══════

1. 外部驱动力：世界线纪要里有哪条宏观事件适合作为这个弧的外部推力？
   - 只是"原材料"，你需要把它转译成具体的、涉及主角的事件——世界线纪要本身不能直接抄。

2. 内部驱动力：主角/核心配角当前最迫切的短期目标或欲望是什么？
   - 参照演进状态卡的"当前状态"和"近期变化"。

3. 本弧要回答读者的哪一个疑问？（上一弧收尾时留下的钩子，这里必须回应）

══════ 任务二：设计主要事件表 ══════

按 故事弧大纲 模板"主要事件表"——只到"主角+主要事件"的颗粒度，不写"第几章发生""具体怎么展开"。

══════ 任务二.5：设计支线线程池（★新增，不是可有可无） ══════

主线事件表只回答"这一弧的核心目标怎么推进"——但一个故事弧里，配角和世界本身也在同步发生事情，不是只有主角这一条线在动。这一步的任务是**开一个候选池**，不是硬性要求每弧都用满：

1. 扫一遍本弧会出场/在场的配角（演进状态卡里当前活跃的人物）——挑1-3个，问："这个人这段时间，脱开主角的视角，自己会经历什么？"（不需要多重大，可以是一段独立的小事：他自己的顾虑、他背着主角做的一件事、他和另一个配角之间的摩擦）
2. 扫一遍世界基底里跟本弧场景相关、但主线事件表没提到的角落——问："这个地方/这群人，本弧期间自己会发生什么，跟主线不直接相关，但读起来有质感？"
3. 每条候选线程只需要写一句话种子（谁+大概什么事+为什么值得写），不用展开成事件表。**够不够用弧内再说——池子里的东西不用完也没关系，但不能不开这个池子。**

按 故事弧大纲 模板"支线线程池"表输出：3列——线程种子（谁+什么事）/ 独立性（能不能脱离主线单独成一整章，还是只能穿插几段）/ 建议使用位置（主线的呼吸章/过渡章，还是不确定，留给章节状态分配挑）。

══════ 任务三：先定收尾，再估章数 ══════

1. 本弧收尾的转折点/小高潮是什么？（这是第一个要定的，不是最后）
2. 收尾判定标准——写清楚"当XXX发生，这个弧就该收了"的具体条件。
3. 基于以上，倒推预计章数区间（如"8-12章"）——这是估算，不是承诺。

══════ 任务四：关系情感线 + 伏笔操作计划 ══════

对照关系情感状态卡：
- 本弧要推进哪几对关系？推到什么阶段？靠哪个主要事件推动？
- 有没有欠了超过2个故事弧的情感债（E编号）——本弧要不要安排兑现？

对照伏笔登记表：
- 本弧的S/M/G操作计划

══════ 任务四.5：误导设计（★新增，本弧涉及中/大反转时必做，不是每弧都有） ══════

**这是全流程里唯一负责设计"伏笔怎么伪装、读者当下该信什么"的一步——放在这里而不是留给写正文时现想，是因为误导要在故事弧内跨章节维持一致的假象，等写到章节层（焦点卡/正文生成）再想已经来不及埋够支撑。**

先问：本弧的主要事件表里，有没有条目对应一次"中反转"以上的转折（桥段与伏笔"B类·转折"定义：读者会形成一个预期，后面被推翻）？

- 没有 → 跳过这一步，正常章节的埋/收不需要设计误导。
- 有 → 逐条设计：
  1. **真相方向**是什么（可以模糊，随写作调整）。
  2. **误导目标**：读者在揭晓之前，应该顺理成章地相信什么？这个"相信"必须是具体的一句话，不能是"制造悬念"这种空话。
  3. **证据链**：靠伏笔登记表里已有的或即将新埋的哪几条S/M伏笔来维持这个误导？每一条要能在下面的伏笔操作计划里对上号——**误导不是编造假信息，是让真实的伏笔信息被暂时解读成另一个方向**。
  4. **揭晓触发点**：预计哪个事件/哪个故事弧收尾时揭晓（可以是本弧，也可以是更后面的弧）。
  5. **回验证清单**：揭晓后，逐条列出"这句话/这个细节当时为什么没让人起疑，回头看又为什么说得通"——这一步现在就要想清楚，不要留到揭晓那一章现编。

按 伏笔登记表 模板"零、误导设计表"格式输出（编号 MX-01 起），并同步在下面的"伏笔操作计划"里，给相关的S/M伏笔标注"表面身份/掩护理由"字段。

══════ 输出 ══════

按 故事弧大纲 模板完整输出：基本信息 + 本弧驱动力 + 主要事件表 + **支线线程池** + 关系情感线推进计划 + 伏笔操作计划（含误导设计表，如有） + 收尾判定标准

最后一句话给 故事弧状态预算：本弧的哪个主要事件最"重"（对状态变化影响最大），故事弧状态预算生成时优先对照这个；支线线程池里的候选项不需要逐条处理，故事弧状态预算按需转成轻量预算即可；如果本弧设计了误导表，提醒故事弧状态预算把"表面身份"字段带进状态预算，别让下游只看到"埋/收"两个动作。
```
