# P4b · 局部大纲生成 + 状态更新

**做什么**：基于 P4a 的态势分析报告 + 反向伏笔发现，生成接下来 3-5 章的局部大纲，并更新演进状态卡。这是"望未来"的步骤——只规划和更新，不分析和发现。
**输入**：P4a 产出（态势分析报告 + 更新的伏笔DAG）+ 人物卡 + 世界基底
**产出**：`02-大纲/局部章纲-第X-Y章.md` + 覆盖更新 `02-大纲/演进状态卡.md`

> 拆分自原 P4。P4b 只做"望未来"的事——基于 P4a 的分析结论做规划。P4b 不应该重新分析——它应该用 P4a 的结论。

---

## 使用方式
- 全程带写：P4a 跑完后 → 「跑P4b」
- 半自动：复制【提示词正文】+ P4a 态势分析报告 + 更新后的伏笔DAG + 人物卡 + 世界基底。

---

## 提示词正文

```
你是小说大纲规划师。P4a 已经分析了"现在走到哪了"——你的任务是基于 P4a 的结论，规划"接下来往哪走"。

核心原则：**你不重新分析。你基于 P4a 的结论做规划。**

【态势分析报告】（P4a 产出）
（粘贴 P4a 的完整态势分析报告 + 反向伏笔发现）

【已更新的伏笔DAG】（P4a 已登记了新的反向发现）
（粘贴伏笔DAG 的当前状态）

【人物卡】（按需——出场人物的表层+底层+模糊弧光方向）
【世界基底】（按需——物理规则、场景空间）

══════ 任务一：生成局部大纲（接下来3-5章） ══════

基于 P4a 的态势分析 + 伏笔DAG 三级状态，生成接下来 3-5 章的局部大纲。

**大势一句**：这 3-5 章的整体走向用一句话概括。

**每章规划**：

| 章 | 核心事件（一句话） | 读者情绪目标 | 伏笔操作 | 衔接钩子 |
|----|-------------------|-------------|----------|---------|
| N+1 | ... | 这章让读者什么感受 | 埋/收/推进什么 | 章末钩子方向 |

**不定死的内容**：
- 每章具体怎么写（那是 P5a 的工作）
- 对话、节奏、L级别分配（那是 P5a 的工作）
- 不要写"第N章主角做了XXX，然后他说YYY"这种细节

**伏笔推进计划（三级）**：

```
本批要埋的 S：（写正文时自然埋入）
本批要回收的 S：（写正文时 callback）
本批要推进的 M：（回收某个S后，M走到哪一步）
本批是否推进 G 的拼图：（回收哪个M，揭示哪块拼图）
```

**人物弧光推进**：这 3-5 章中，哪些角色的弧光会往前推一步？推动事件是什么？推到什么位置？

══════ 任务二：更新演进状态卡 ══════

根据已写内容 + 局部大纲，生成更新后的完整演进状态卡。以下是需要更新的条目：

- **当前进度**：更新"最近一章写了什么" + "最新章末钩子"
- **主角当前状态**：位置、资源、威胁、情绪/心态、近期变化
- **据点/避难所状态**：规模、居民、最近升级、当前短板/隐患
- **活跃人物状态**：逐人更新——当前状态、与主角关系、最近的弧光变化
- **已揭示的世界信息**：最近新揭露了什么
- **伏笔三级状态简报**：
  - G 级：已推进拼图 X/总数
  - M 级：已有几个、活跃几个、已回收几个
  - S 级：已埋几个、已回收几个、哪些该收还没收
- **剧情节奏记录**：最近几章的主导情绪温度变化、最近一次爽点、读者憋了多久

══════ 输出 ══════

1. 局部大纲（大势一句 + 每章规划表格 + 伏笔推进计划 + 人物弧光推进）

2. 更新后的演进状态卡（完整内容——不是"增量更新"几个字段，是完整覆盖）

3. 一句话提示给 P5a：
   - 大纲中最重要的需要注意的衔接点是什么？
```
