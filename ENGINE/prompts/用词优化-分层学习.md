# 用词优化 · 分层学习框架（★全管线范文学习 · 升级层）

> **和 `用词优化-总览` 的关系**：`总览` 定义的四步管线（逆向提取→盲重建→对比差距→抽象优化与回填）与四条铁律，原本只作用在**最内层（正文/文风）**。本文件把同一套四步**推广到写书管线的每一层**——`总览` 的文风分支＝本框架的**第 11 层（正文/文风）实例**，其三路回填与文风包机制原样沿用。
>
> **为什么要分层**：工作流的毛病遍布各层（作者痛点：**命名很怪**、人物扁、世界观薄、大纲塌），不只在文字。分层后每层都能被单独测出短板、单独回填。
>
> **方向＝外→内**（与写书管线一致，粗到细）；**每层只凭它前面已提取的更外层信息生成**。

## 二、四条铁律（在 `总览` 四铁律基础上的分层升级）

1. **分层盲测隔离（铁律1升级为逐层）**：生成第 N 层的 agent **只能拿范文逆向提取出的"更外层"产物（1..N-1 层）**，对**范文的第 N 层及更内层完全盲**。逆向提取 agent 与盲生成 agent 不同、互不传该层原文。方向外→内。

2. **分层归位回填（★取代 `总览` 旧铁律2"只优化文风层"）**：每层差距回填到该层自己的家（见层映射表）。文风差距→文风工坊（三路）；命名/人物/世界观/大纲/情绪等各中间产物的**手艺差距**→各自模板/知识。**唯一不在本工坊硬改的是"节点级结构"（增/拆/合/删节点、改管线顺序）**——转交架构优化（见 `用词优化-抽象优化与回填` 第四节）。

3. **内容/设定层只抽法则、不抄具体（★版权+污染双红线，扩展 `总览` 铁律3）**：
   - **命名、人物、世界观、剧情桥段** = 范文专属**内容/设定 + 第三方版权**。这些层回填**只提炼"抽象法则"**（命名法/塑造法/设定法/结构法），**绝不抄范文的具体名字/人设/设定/桥段**，且**不建例库**。
   - **只有"文风层（第11层）"的声音例子可进文风包 `02-范文例库/`**（声音是可模仿的通用手艺、且隔离随包挂载）——这条沿用 `总览` 铁律3 的三路机制，仅限文风层。
   - 一句话：**内容/设定层＝纯抽象法则、零例子；文风层＝抽象纪律 + 隔离例库。**

4. **防过拟合 + 分层过闸**：沿用 `总览` 铁律4（密度层不动 + 执行层提纯），逐层适用。

## 三、四步怎么按层跑（复用现有4节点，参数化到"层"）

- **逆向提取**：读范文，**外→内分层**填出各层产物（各用其模板格式，见各模板新增的"★逆向填法"段）；`01-逆向骨架.md` 按层分节。
- **盲重建（盲生成）**：换 agent，**外→内逐层生成**；生成第 N 层只喂范文提取的 1..N-1 层（铁律1）；`02-盲重建.md` 按层分节。
- **对比差距**：每层"盲生成 vs 范文提取"逐层比，`03-对比差距.md` 按层出差距 + 分层过闸标注。
- **抽象优化与回填**：各层差距过两道闸→**按层归位回填**；文风走三路（文风包），内容/设定层走"抽象法则→模板/知识"，结构残差转架构优化。

> 落盘：文风层跟目标文风包走（`文风库/<包>/04-优化留档/`）；其余层的分层留档落 `ENGINE/_用词优化留档/<范文标识>-<日期>/`（按层分节）。

## 四、格式化决定（作者授权我定）＋逆向填法通用协议

**复用现有模板当各层中间产物的统一格式**，不另造 schema。逆向提取/盲生成/对比**直接对着各层现有模板的字段走**，格式天然统一。

**★逆向填法·通用协议**（逆向提取步对任一层都照此办，不必每个模板各写一遍）：
1. **按模板字段填**：读范文，把本层该定的东西按该层模板的栏目填满。
2. **剥更内层 + 剥腔调**：只留本层该定的，剥掉比本层更内层的信息（见层映射表，本层下面的都算更内）和一切用词/句子/比喻/腔调。
3. **内容/设定层只留"可抽象成法则"的骨架**：命名/人物/世界观/桥段等，提取时记录的是"规律/结构/维度"，落回工作流时只出抽象法则，绝不把范文的具体名字/人设/设定/桥段抄进模板或知识（铁律3）。
4. **盲生成隔离**：生成本层的 agent 只拿范文提取的更外层（1..N-1），对本层及更内层全盲（铁律1）。

> 痛点层（命名）在 `templates/命名与术语表-模板.md` 另附一段更具体的"★逆向填法"示范；其余层照上面的通用协议即可，无需逐个模板加注。
