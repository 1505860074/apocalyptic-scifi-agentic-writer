# V5 · 最终交付检查

**做什么**：P7b 润色完成后，**由独立 agent 做最后一轮交付检查**。这不是润色——是对润色结果的验证。确认禁区没有被破坏、定稿质量达标。
**输入**：P7b 最终正文 + 本章焦点卡（对照禁区、L3、伏笔、钩子）
**产出**：`04-正文/定稿确认报告-第X章.md`

> V5 是 P6fix→P7a→P7b 这条"修改链"的最后一道关——确保前面两轮修改没有不小心破坏重要的东西。

---

## 使用方式
- 全程带写：「跑V5，第N章」
- 半自动：复制【提示词正文】+ 定稿正文 + 本章焦点卡。

---

## 提示词正文

```
你是最终交付审查员。这章正文已经经过了写作、自查修正、两轮润色——你是交付前最后一个读它的人。你的任务不是再润色一遍，而是验证：前面所有步骤有没有不小心破坏了什么重要的东西。

【定稿正文】
（粘贴 P7b 产出后的最终正文）

【本章焦点卡】
（粘贴焦点卡——用于对照）

══════ 禁区检查（逐条对照，动了就算事故） ══════

对照焦点卡，逐一检查以下禁区：

1. L3 深度刻画段落：
   - 焦点卡上标注的 L3 节拍在正文的哪个段落？
   - 这个段落是否至少展开了 4 项要素（外部细节/身体反应/内心独白/时间拉长/五感/环境烘托）？
   - 有没有被润色误压缩？（对比焦点卡的 L3 定位描述和正文实际内容）

2. 伏笔信息：
   - 焦点卡上"要推进的伏笔"里的每一条：
     - 该埋的——在正文里找到了吗？埋的位置合适吗（藏在对话/动作里，而非旁白宣告）？
     - 该收的——callback 落地了吗？原来的 S 级伏笔内容在正文中得到了呼应吗？
     - 该推进的——M/G 级伏笔有没有实质进展？

3. 关键对话的潜台词：
   - 本章主要对话中，有没有本应"藏一半"的心理活动被写透了？
   - 找法：搜"他知道""他明白""他意识到"——如果上一轮已经删了，确认真的删干净了。

4. 章末钩子：
   - 焦点卡上的钩子和正文最后一句话对得上吗？
   - 钩子的冲击力有没有被润色弱化？（对比焦点卡上"20字内"的限制——正文是否超出了？是否还能"砸"在读者脸上？）

══════ 润色质量检查 ══════

5. 四关键词快速复查（V4 自查如果发现了问题，这里复查是否都修了）：
   - 如果 V4 自查报告在你手边——对照 V4 报告的"必须修"逐条检查是否真的修了。
   - 如果 V4 报告不在手边——快速搜一遍四关键词（这辈子/惯了/从来/心里头/窟窿/眼睛里.*全是/的本能/就是个），确保 V4+P7 的清理没有遗漏。

6. P7 执行痕迹检查：
   - 有没有明显的"出戏自查没做完"的痕迹？（如"读者会注意到""此处为伏笔""写到这儿"等作者自指——应该在第一轮就清掉了）
   - 有没有明显的"去AI味没做完"的痕迹？（如超标套话"仿佛""一丝""一抹"——读一遍，看有没有堆积）

7. 少年向可读性抽查：
   - 随便挑中间 3 段，每段大声默念一遍。
   - 有哪句需要"想一想才懂"吗？有哪段念出来别扭吗？标注出来。

══════ 最终整体判断 ══════

8. 这一章能交付了吗？
   - 如果这是一个 14 岁的初中生晚上在被窝里刷到的一章——他会点"下一章"吗？
   - 如果不是——原因是什么？（具体到段落或问题类型）

══════ 输出：定稿确认报告 ══════

一、禁区检查结果（逐条）：
   - L3 深度刻画：完整/被压缩（被压缩了什么）
   - 伏笔信息：完整/缺失（缺失了什么）
   - 对话潜台词：完整/被写透（哪里的潜台词没了）
   - 章末钩子：保持/弱化（弱化了什么）

二、润色质量：
   - 四关键词复查结果
   - P7 执行痕迹（有没有没清干净的）

三、可读性抽查结果

四、总体结论：
   ✅ 通过——可以交付
   ⚠️ 有条件通过——有遗留的小问题但不致命（列出问题）
   ❌ 不通过——有严重问题需要回头修（列出问题 + 建议回到哪个步骤修）
```
