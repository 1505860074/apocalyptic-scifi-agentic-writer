# 立项工坊 · 立项自查

**做什么**：立项书出稿后的一道**轻量校验门**（立项工坊最后一步）。在真正投入 新建项目/世界观与金手指 之前，快速体检一遍立项书——省得地基歪了却一路盖到十几章才发现。
**输入**：`BOOKS/书名/00-立项/立项书.md`
**产出**：一份简短的《立项自查报告》（可直接落对话里，无需单独存档），结论二选一：**可进 新建项目** / **需回炉重问某几项**。
**下一步**：通过 → 进 新建项目 建目录；不通过 → 回「立项问答」补/改对应维度。

---

## 使用方式
- 本项目里：`「跑立项自查」`
- 纯聊天场景：把立项书全文 + 下方【提示词正文】发给任意大模型即可。

> 这是一道独立校验：最好换一次对话/换一个 agent 来跑，别让"写立项书的人"给自己判卷（和全流程"P 写 V 验分开跑"的思路一致）。

---

## 提示词正文

```
你是资深网文主编，现在做一道立项体检。下面是一份《立项书》，请你逐项核查，只挑真问题，不挑刺凑数。

（粘贴立项书全文）

【核查四关】

一、维度齐全关
  11 个维度是否都填了、且填的是"实质内容"而非空话套话？
  逐维度标：✅已实/⚠️空泛（写了等于没写）/❌缺失。

二、内在一致关（最重要）
  各维度之间有没有互相打架？重点查这几组：
  - 命题 ↔ 文风基调 ↔ 情感内核：三者是不是一股劲儿？（如命题"孤独求生"配文风"欢乐沙雕"配情感内核"温暖治愈"——就是三股劲儿，要标出来）
  - 目标读者/平台 ↔ 题材/文风/篇幅：读者吃这一套吗？（如目标"12-18岁番茄男频"却选了"沉郁文艺纯爱长评流"——错配）
  - 核心命题 ↔ 爽点引擎：命题想探讨的东西，和这本书主要提供的爽感，是不是同一个方向？
  逐组给：一致 / 有张力但可行 / 冲突（需改）。

三、平台读者关
  站在目标平台目标读者角度：这本书的钩子（一句话立项陈述 + 差异化卖点）够不够抓人？有没有踩题材雷区？（如手头有 平台与题材规律 就对照它，没有就凭经验判断。）

四、留白纪律关
  立项书有没有"手痒把情节写死"？凡是把具体真相/结局/反转在立项阶段就锁死的，都要标出来，建议挪进【留白区】改成模糊方向。命题有没有被写成说教口号（应是隐藏驱动力，不是贴脸标签）？

【输出格式】
1. 四关逐关结论（用上面的标记）。
2. 【必须改】清单：只列真正影响地基的问题（冲突/错配/情节写死/命题说教），每条给一句修改方向。
3. 总结论：
   - 「可进 新建项目」——没有【必须改】项，或只剩无关痛痒的小瑕疵；
   - 「需回炉」——存在【必须改】项，指明回「立项问答」要重问/重定哪几个维度。
```
