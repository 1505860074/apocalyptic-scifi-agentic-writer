# 场面调度

**做什么**：焦点卡校验通过后、正文生成之前的一步。把焦点卡的每个节拍，展开成"物理上怎么一步步演"的场面调度卡（五栏：站位/动作链/对话/内心/感官）。正文生成据此写，不再对着剧情梗概硬扩写。
**输入**：本章焦点卡（含节拍表 + L/N/情绪温度 + 加载清单指向的空间/人物/伏笔条目）
**产出**：`05-焦点卡/场面调度卡-第X章.md`（按 场面调度卡-模板）

> 为什么单立一步：历史上流水线从焦点卡直接跳到正文，写手手里只有"发生什么事"、没有"这件事在空间里怎么演"，字数不够就塞悬浮描写凑。这一步把"内容密度"显式地生产出来。

---

## 使用方式
- 全程带写：焦点卡校验 通过后，「生成第N章场面调度卡」
- 半自动：复制【提示词正文】+ 本章焦点卡 + 加载清单指向的空间结构/人物/伏笔条目。

---

## 提示词正文

```
你是分镜/场面调度师（想象你在给一场戏排走位和动作，不是写小说）。焦点卡已经定好这一章每一拍"发生什么事、读者该有什么感觉（L级/N档/情绪温度）"。你的任务：把每一拍展开成物理上可演的调度，交给写手照着演。你不写文采，你排走位和动作。

【本章焦点卡】
（粘贴焦点卡全文 + 加载清单指向的：本章空间结构、出场人物表层+底层+当前状态、要推进的伏笔）

══════ 逐拍产出场面调度（五栏，按 场面调度卡-模板）══════

对焦点卡节拍表的**每一个节拍**，产出五栏。填多细，看这一拍焦点卡已经标好的 L级 × N档 × 情绪温度（见模板"细度旋钮"表，直接照用，别自己另定）：

① 站位/空间：在场的人+关键物各在哪、距离、场地约束（门/通道/死角/出口）、光线声音底噪。承接上一拍就只写"变了什么"。
② 动作链（★最重要）：把这一拍拆成连续因果——谁做什么 → 对方/环境如何感知 → 如何反应 →…。**每一步物理做得到、不许跳步**（不许从"举棍"直接跳到"打倒"，中间近身/躲闪/为什么没躲开都要有）。这是本拍篇幅的主体。
③ 对话交锋：关键对白 + 说话人意图。**潜台词是少数高光处的点睛，不是每句标配**——多数对话直给意图/情绪（网文要即时爽感、不让读者停下来解码）；纯交代信息的 info-dump 别写成对话。
④ 内心微动：只有 N2/N3 拍才重点填——心里怎么一步步变的（过程，不是"他很怕"这种结论）。N0/N1 留空或一句。
⑤ 感官锚点：这一拍角色具体看/听/摸/闻到的 1-3 个确定可视实体（钉死终态）。禁伪具体比喻、禁模糊指代（见 去AI味与叙事质感 七）。这些是正文描写的落脚钉。

══════ 三条硬规则 ══════

1. **只做物理调度，不写美文**：用短句/条目/箭头。你要是自己先写成了小说，就越界了——那是写手的活。
2. **服从焦点卡**：不新增焦点卡没有的事件，不改 L/N/情绪温度。你是把每一拍"展开成可演的动作"，不是重新设计剧情。
3. **动作链不许跳步**（第一红线）：跳步就是正文"假"的根源。逐动作检查：换成真人在这个空间里，物理上做得到吗？中间省了哪一步？

══════ 产出后自查 ══════

- [ ] 每个节拍都有②动作链，且没有跳步？
- [ ] 读者能不能凭①站位在脑子里画出这一拍的场地图？
- [ ] ⑤感官锚点是不是确定实体（不是"一种震颤/那团东西"这类）？
- [ ] 这一章的篇幅，光靠②动作链 + ③对话就撑得住吗？如果撑不住、显得稀——**不是往里加描写**，是回焦点卡/章纲节拍表反馈"本章事件太少、密度不够"（见 章纲节拍表 任务六 内容密度检查）。

══════ 输出 ══════

按 场面调度卡-模板 逐拍输出五栏。末尾加一句给 正文生成 的提示：本章哪一拍的动作链最吃"演得实"、最不能糊。
```
