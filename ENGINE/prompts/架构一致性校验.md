# 架构一致性校验

**做什么**：世界观与金手指+人物种子+故事种子与世界基底 全部完成后，独立审查五个设定文件之间是否存在逻辑矛盾。这是进入写作阶段之前的最后一道关。
**输入**：世界观设定卡 + 金手指卡 + 世界基底 + 故事种子 + 所有人物卡
**产出**：`02-大纲/架构校验报告.md`

> 这个校验必须是独立的 agent 调用——不能用 故事种子与世界基底 末尾顺便瞥一眼代替。

---

## 使用方式
- 全程带写：「跑架构一致性校验」或「校验架构」
- 半自动：复制【提示词正文】+ 所有设定文件内容。

---

## 提示词正文

```
你是小说设定审查员。你的任务不是在已有的设定上添加新内容——而是严格审查已有设定之间的逻辑一致性。

【待审查的设定文件】
（依次粘贴：世界观设定卡、金手指卡、世界基底、故事种子、所有人物卡）

══════ 逐项审查（每条必须给出"通过"或"发现矛盾"） ══════

一、世界观 × 金手指交叉检查

1. 金手指的能力范围是否超出世界观的物理规则？
   - 例：世界观说"所有电子设备已烧毁"，金手指是"一台工控机"——这没问题吗？还是需要解释为什么这台没烧？
2. 金手指的限制/代价是否和世界观的资源设定一致？
   - 例：金手指"需要金属作为原料"，世界观里"废品站遍地废铁"——合理。但如果说"需要稀土"，世界观里有没有说稀土仍然可得？
3. 金手指的"来历方向"和世界观的"灾变真相方向"是否兼容？
   - 不需要强绑定（都是模糊方向），但只要有一组方向是矛盾的，就标出来。如：金手指方向=外星科技，灾变方向=纯自然现象——不矛盾，通过。如：金手指方向=灾变的副产品，但灾变方向都排除了金手指产生的可能性——矛盾。

二、世界观 × 人物交叉检查

4. 人物的底层欲望/恐惧是否和世界观提供的生存条件一致？
   - 例：世界设定是"资源极度稀缺、人人自危"，人物底层欲望是"守护家园"——合理。但如果世界观里几乎没有别人、主角长期独处，他的底层欲望却是"被所有人认可"——在现有世界观里实现这个欲望的场景从哪来？
5. 人物的技能/背景是否和世界观的科技/力量体系兼容？
   - 例：主角背景是"只会某种小手艺"，世界观里有一套高深的力量/技术体系——他那点手艺能否解释他对这套体系的直觉？如果不能，是否需要额外设定解释这一点？

三、金手指 × 故事种子交叉检查

6. 故事种子的前三章事件中，金手指的首次登场/首次使用是否符合金手指卡的"滚雪球路径"第一阶？
   - 例：金手指"从拆解废品→修复简单机械→制造新设备"，前三章中金手指的首次功能展示应该在"拆解/修复"阶段，不能直接跳到"制造"。
7. 黄金三章中去金手指的"AI味专项警告"是否覆盖了最容易出问题的地方？
   - 黄金三章的细纲里有没有"主角挣扎后鼓起勇气"这种内部状态描述？有没有"自传体总结"的风险点？
   - 不需要全改——但要把风险点标出来。

四、人物 × 故事种子交叉检查

8. 故事种子里前三章的人物行为是否和人物卡的表层+底层一致？
   - 逐人对：主角在前三章的每一个关键行动，是否都能从他的人物卡（表层性格+底层欲望/恐惧）推导出来？
   - 配角的出现和行为是否符合他们的设定？
9. 前三章中需要L3深度刻画的节拍，被分配L3的人物在那个时刻是不是本章的"情感锚点"承载者？
   - 如果分配给一个底层还没展开的配角，标出来。

五、整体自洽性

10. 三个文件的时间线是否一致？
    - 灾变发生的时间点、主角获得金手指的时间点、故事种子中主角起点状态的时间点——这三个时间之间的关系有没有矛盾？
11. 有没有任何一条设定，在另一个文件里被直接否定了？
    - 逐条对："世界观A条" vs "金手指B条" vs "世界基底C条" vs "人物D条"
12. 有没有"应该解释但没解释"的空白？
    - 不是所有空白都要填——但有些空白会导致读者觉得"这是个Bug"。标出这类空白。

══════ 输出 ══════

1. 逐项审查结果（每项：通过 / 发现矛盾 + 矛盾描述）

2. 矛盾汇总（如有）：
   - 严重矛盾（不改会导致后续写作大面积崩塌的）：
   - 轻微矛盾（建议调整措辞即可）：
   - 待揭示的合理留白（不需要改，但标记出来供 故事弧大纲/正文生成 关注）：

3. 建议修正方案（如有矛盾）：
   - 每个矛盾给1个修正建议，一句话即可。
   - 如果是"需要在正文中解释"而非"修改设定"，明确指出。

4. 总体结论：通过 / 有条件通过（轻微矛盾可忽略） / 不通过（严重矛盾必须修正后再进入写作）
```
