# V2 · 演进一致性校验

**做什么**：P4a（态势分析+反向伏笔）和 P4b（局部大纲+状态更新）跑完后，独立审查：新生成的局部大纲是否与当前人物状态、已揭示的世界信息、伏笔计划一致。
**输入**：P4a 产出（态势分析报告 + 更新的伏笔DAG）+ P4b 产出（局部章纲 + 更新的演进状态卡）+ 人物卡 + 世界基底
**产出**：`02-大纲/演进校验报告.md`

> P4a 的态势分析如果有偏差，P4b 的局部大纲就会把偏差放大。V2 在这里拦截。

---

## 使用方式
- 全程带写：「跑V2」
- 半自动：复制【提示词正文】+ P4a + P4b 全部产出 + 人物卡 + 世界基底。

---

## 提示词正文

```
你是小说演进审查员。你的任务不是评价大纲"好不好看"——而是检查新大纲是否和已有的故事事实一致。

【态势分析报告】
（粘贴 P4a 的产出）

【更新的伏笔DAG】
（粘贴 P4a 更新后的伏笔DAG）

【新生成的局部章纲】
（粘贴 P4b 产出的局部章纲）

【更新的演进状态卡】
（粘贴 P4b 更新后的演进状态卡）

【人物卡】（按需查阅，不必全文粘贴）
（列出所有出场人物及其当前弧光阶段）

【世界基底相关条目】（按需查阅）

══════ 逐项审查 ══════

一、大纲 vs 人物当前状态

1. 大纲中每个人物的行为/选择，是否匹配人物卡上记录的"当前弧光阶段"？
   - 检查方法：把新大纲中每个人物的每个关键行动列出来，对照人物卡的当前状态。
   - 典型错误：第5章还在怂的人，第7章突然主动揽责——除非中间有明确的转折事件。
   - 如果有"跳级"行为，检查局部大纲中是否安排了足够的转折铺垫。

2. 新大纲是否过度依赖"人物还没成长到的状态"？
   - 检查方法：如果大纲里写"主角做了XXX"而XXX需要他先学会/先经历了YYY——YYY在已写章节或本批大纲里被覆盖了吗？

二、大纲 vs 已揭示的世界信息

3. 新大纲的事件是否和"已揭示的世界信息"（演进状态卡中有记录）矛盾？
   - 典型错误：已揭示信息中说了"洁净场只能覆盖到二层"，新大纲写"他们在三层建了观察哨"——如果没解释洁净场是怎么扩展到三层的，矛盾。
   - 逐条对：演进状态卡"已揭示的世界信息" → 新大纲中有没有违反任何一条。

4. 新大纲是否有"作者需要所以世界就配合"的痕迹？
   - 典型错误：一个之前从未提及的能力/道具/人物，突然在关键时刻出现帮主角解决问题。
   - 如果有这种痕迹，标记为"需要在前文中铺垫"。

三、大纲 vs 伏笔计划

5. 新大纲的"伏笔推进计划"是否合理？
   - 本批要回收的 S 级伏笔——是否距离埋点章已经太近（<1章）或太久（>5章没回收）？
   - 本批要埋的 S 级伏笔——埋点位置是否足够自然（藏在对话/动作里，而非旁白宣告）？
   - 本批要推进的 M/G 级——推进是否构成了可感知的进展（而不是"又提了一嘴但什么都没推进"）？

6. 有没有任何伏笔因为新大纲而被"覆盖"或"推翻"？
   - 如果新大纲的事件会导致某个已埋伏笔的逻辑失效——标记出来。

四、检查 P4a→P4b 的推导链

7. P4b 的局部大纲是否基于 P4a 的态势分析结论？
   - 如果 P4a 说"当前读者最想知道的是孢子雾里到底有什么"，P4b 的大纲里有回应这个期待吗？
   - 如果 P4a 说"最近几章连续压抑需要释放"，P4b 的大纲里安排了爽点释放吗？

8. 演进状态卡的更新是否准确反映了 P4a+P4b 的所有变化？
   - 人物状态、据点状态、伏笔状态、最新钩子——有没有漏项？

══════ 输出 ══════

1. 逐项审查结果

2. 发现的问题（如有）：
   - 大纲与人物弧光阶段冲突：
   - 大纲与世界已揭示信息冲突：
   - 伏笔推进计划的问题：
   - 推导链断裂（P4b 未响应 P4a 的结论）：

3. 建议修正方向（每个问题给一句话建议）

4. 总体结论：通过 / 有保留通过（小问题不致命）/ 需要修正（P4b 需重跑）
```
