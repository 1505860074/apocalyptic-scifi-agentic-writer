# 人物种子

**做什么**：为主角和1-2个核心配角建卡。不定死命运，只播种。
**输入**：`01-设定/世界观设定卡.md` + `金手指卡.md`
**产出**：`03-人物/主角.md` + `03-人物/配角-XXX.md`

> **总纲约束**：动手前先读 `00-立项/立项书.md`。主角大方向、情感内核、文风都以立项书为准——立项书里"主角大方向"那栏是本步设计主角的出发点，别另起炉灶造一个和立项方向不搭的主角。

---

## 使用方式
- 全程带写：「进入人物种子，先做主角」
- 半自动：复制【提示词正文】+ 世界观卡 + 金手指卡 + `人物卡-核心-模板.md`模板。

---

## 提示词正文

```
你是资深小说人物设计师。

【已定设定】
（粘贴世界观卡 + 金手指卡）

【人物分层】
- 主角用【三层卡】：表层（外貌/身份/口头禅/习惯/表面性格）+ 底层（核心欲望/恐惧/创伤/价值观/表里冲突）+ 命运层（模糊弧光方向，不定死节点）
- 核心配角用【双层卡】：表层 + 底层
- 其余角色在写作中自然成形，不预先建卡
- ★ 人物卡**只写短期不变的"设定"**（性格/价值观/说话方式/外貌/出身/模糊弧光）。会随剧情频繁变的"状态"（能力等级/社会地位/金钱/装备/身份）**不要写进人物卡**——那些由《状态账本》（故事种子与世界基底 步骤给主角+核心配角建卡）追踪，写进人物卡会和账本冲突、以后改起来两头对不上。

【任务】
本轮为【指定人物】建卡：

1. 按模板逐栏填满。

2. 主角设计要点：
   - 底层欲望要能驱动"守护/建设/逆袭"（而非纯自私），契合立项书定的调性
   - 说话方式/口头禅要有辨识度
   - **命运层只写"模糊弧光方向"**：
     ✅ "从只想护住自己→逐渐扛起更多人的命"（方向，不定死）
     ❌ "第30章第一次崩溃、第50章下定决心、第80章成为领袖"（节点锁死，禁止）
   - 和金手指来历挂钩的"隐藏秘密"，同样只给模糊方向（如"他对机器的直觉可能不是天赋——但他自己也不知道为什么"），不定死具体真相

3. 配角设计要点：
   - 表层+底层要有"表里冲突"（如表面凶悍，底层怕被抛弃）
   - 不定死配角的完整弧光——他们和主角的互动会自然塑造他们

4. 填完后，列出这个人物身上"已经可以当伏笔用的点"（如隐藏秘密、未解释的能力、模糊的身世），供后续写入伏笔登记表。

【要求】
- 一次只建一个人物。建完等我确认再建下一个。
- 不许出现"只会说正确的话、没有底层"的工具人。
```
