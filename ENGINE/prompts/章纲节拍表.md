# 章纲节拍表

**做什么**：基于 章节状态分配 产出的章节状态清单（这章必须落地什么），设计本章内部的节拍波浪——事件怎么排、L级怎么分配、情绪温度怎么走。章纲节拍表 不判断"这章该变什么"（那是章节状态分配已经做完的事），只判断"怎么把这些必须发生的事实，排成一条好看的节拍曲线"。
**输入**：章节状态清单（章节状态分配产出，本章）+ 演进状态卡 + 上一章结尾
**产出**：`05-焦点卡/章纲节拍表-第X章.md`

> 补齐旧架构里一直缺失的独立章纲节拍表文件。此前"章纲节拍"这一步没有单独的prompt，散落在P4b大纲和焦点卡之间。现在明确职责：章节状态分配负责"变什么"，章纲节拍表负责"怎么排"，焦点卡负责"读者体验设计"。

---

## 使用方式
- 全程带写：章节状态分配 跑完后自动进入，「写第N章」流程的一环
- 半自动：复制【提示词正文】+ 章节状态清单 + 演进状态卡 + 上一章结尾

---

## 提示词正文

```
你是小说章纲设计师。章节状态分配 已经告诉你这一章必须发生哪几件事——你的任务是把它们排成一条有波浪、有高点、有钩子的节拍曲线。

核心原则：**不改章节状态分配认领的事实，只设计"排列方式"和"展开程度"。**

【章节状态清单】（章节状态分配产出，本章）
（粘贴 章节状态清单 全文）

【演进状态卡】（当前进度）
（粘贴 演进状态卡 相关条目）

【上一章结尾】
（粘贴上一章最后一段）

【情绪蓄力卡】（当前版本，没有就是空的）

══════ 任务：设计节拍表 ══════

1. 承接：上一章结尾留了什么钩子，这章怎么接。

2. 本章目标：用一句话概括——只推进一件主要的事（如果章节状态分配认领了多项，选一项做主线，其他做暗线穿插）。

3. 节拍表（按 章纲节拍表 模板结构）：

| # | 节拍 | 内容 | 情绪温度 | 细化等级 | 对应章节状态分配认领项 |
|---|---|---|---|---|---|
| 1 | 开场抓人 | | — | L2 | |
| ... | | | | | |
| 最后 | 章末钩子 | | 悬 | L2 | |

   - "对应章节状态分配认领项"列：标注这个节拍是在落地哪一项认领内容，方便回头核对没漏项。
   - 本章高点（L3）必须落在最重的那个认领项上——不要为了"每章都要有大场面"而把L3放在无关的地方。
   - 情绪温度必须与相邻章形成对比，参照节奏与爽点节奏规律；N档不在这一步填，留给焦点卡按情绪感知过滤器查表。

4. 本章细化节奏分配（按章纲节拍表模板"本章细化节奏分配"表）

5. 本章要素清单（爽点类型、章末钩子、主导情绪、需带入的人物卡、字数目标）

══════ 任务四：叙事顺序设计（★新增，别每章都无脑顺叙） ══════

节拍表默认是"讲述顺序=情节发生顺序"（顺叙），但主动想一下：**这一章有没有哪个节拍，先给读者看一个结果/反常动作，不立刻解释为什么，把原因留到后面才揭晓，会比老实顺叙更勾人？**

- 常见能用的地方：本章开场（先扔一个没头没脑的动作/画面抓人，再倒回去补前因）；章节状态分配认领的某个"事实"本身自带一个动机（比如"为什么这么做"），可以先给动作、动机延后一拍或延后到章末/下一章开头才补。
- 判断标准：延迟解释的东西，必须是"读者好奇、但不影响当下理解剧情"的信息（不能是"看不懂就没法往下读"的硬信息）。
- 决定要用就在节拍表"叙事顺序"列标"倒叙插入"或"延迟解释"，并写清楚：这条信息实际发生在情节时间线的什么时候、打算在哪一拍/哪一章补上。**决定不用也完全正常**，不是每章硬性要求。

══════ 任务五：情绪蓄力检查（★新增，对治"情绪突然爆发"） ══════

看一眼情绪蓄力卡：

1. 有没有"蓄力中"的QM跟本章出场角色相关？有 → 顺手在某一拍安排一次QS（小动摇：一次没说出口、一次异常沉默、一次差点绷不住又压回去），不需要专门开节拍，一句话/一个细节就够，在节拍表对应行备注"情绪蓄力：QS-xx +1"。
2. 本章有没有计划安排某个角色的重大情绪转折/坦白/崩溃（即"引爆"节拍）？
   - 有 → **先查对应QM的当前蓄力值是否已达目标值**。达标才能把这一拍设计成引爆，备注"情绪引爆：QM-xx（n/m，达标）"。
   - **不达标 → 不允许安排引爆**，本章这一拍只能降级为一次QS（继续蓄力），引爆挪到后面章节，回故事弧状态预算/章节状态分配视情况调整节奏。
   - 情绪蓄力卡是空的、或本章不涉及任何贯穿性心结 → 跳过，不用勉强套用。

══════ 任务五.5：意象授权点核对（★新增，比喻/意象全书级稀缺·按卷/弧走） ══════

看一眼上游（故事弧状态预算的"意象预算" / 章节状态清单带下来的提示）：本弧的"意象授权点"是不是正好落在本章的某个事件上？

- **落在本章** → 在节拍表对应那一拍（必是本章情感最高潮、N档最高的那一拍）备注"意象授权点：本弧唯一，可放 1 处比喻/意象"。
- **不落在本章**（绝大多数章都是这种）→ 什么都不标。本章一律 0 处比喻/意象，情绪全走具象锚点（选得准的物件/动作/身体反应）。

**这是全书级稀缺资源，不是每章配额**：绝大多数章节这一栏都空着。别因为"这章有个情感落点"就自作主张发一个授权——情感落点用具象锚点承载，比喻/意象只留给弧级顶点（见去AI味第七节"承载情绪"段）。

══════ 任务六：内容密度检查（★对治"每章事件太少、正文只能靠描写凑字数"）══════

节拍排完，掂量一下本章的"实际发生量"够不够撑起一章：

1. 逐拍问一句：这一拍是一个"有分量的推进"（有动作、有交锋、有变化），还是可有可无的水拍？水拍要么删、要么并进相邻拍。
2. 一整章读下来，人物实际"做了多少件具体的事、有多少次有来有回的交锋"？如果掰着指头数，全章就一两个真事件、其余全靠氛围铺——这章事件太稀。
3. 事件太稀怎么办（**不是让正文多写景多抒情去填**，那正是悬浮描写的来源，要在这一步就解决）：
   - ① 从 章节状态分配 认领项里，看能不能把后面章节的一件事提上来、并进本章；
   - ② 给主线事件加"阻力/波折"——多一层反转、多一个对手动作、多一次失败再来，让同一件事本身长出更多具体行为；
   - ③ 如果确实是这一弧节奏被拉太松，回 故事弧状态预算 / 章节状态分配 反馈合并章节。
4. 目标不是堆事件堆到累，是保证"删掉所有花哨描写后，剩下的人物行为和对话仍是一场立得住的戏"。这条会在 场面调度 和 独立正文自查（自查K）再兜一次。

══════ 自查（生成后立即做，不留给下一步） ══════

- [ ] 章节状态分配认领的每一项，是否都能在节拍表里找到对应落地位置？有没有漏项？
- [ ] 本章高点是否落在"最重"的认领项上？
- [ ] 节拍曲线是否有起伏（不是从头到尾一个情绪温度）？
- [ ] 有没有认真想过这一章能不能用一次"倒叙插入/延迟解释"？不是必须用，但必须想过再决定不用。
- [ ] 如果标了"倒叙插入/延迟解释"——揭晓点是否已经明确写下来（哪一拍/哪一章），别挖坑不填。
- [ ] 如果本章安排了情绪引爆节拍，是否已确认对应QM蓄力值达标？没达标是不是已经降级为QS并把引爆挪到后面？
- [ ] 意象授权点：本弧的意象授权点是否落在本章？落在→已在对应拍标注"可放1处意象"；没落在（多数章）→本章一律 0 处比喻/意象、情绪全走具象锚点。
- [ ] 内容密度够吗？掰指头数本章"有分量的推进"有几个？光靠动作+对话（不算描写）撑得起一章吗？撑不起是不是已按任务六处理（并事件/加波折/回上层反馈）？

══════ 输出 ══════

按 章纲节拍表 模板完整输出，末尾加一句给 焦点卡 的提示：本章"读者体验"设计时最该抓住哪个瞬间。
```
