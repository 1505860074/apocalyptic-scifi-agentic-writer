# P4a · 态势分析 + 反向伏笔发现

**做什么**：写完3-5章正文后，回看已写内容，做态势分析 + 反向伏笔发现。这是"回顾过去"的步骤——只分析和发现，不规划和更新。
**输入**：最近3-5章正文 + 演进状态卡 + 伏笔DAG + 人物卡 + 世界基底（按需）
**产出**：`02-大纲/态势分析报告-第X-Y章.md` + 更新 `伏笔DAG.md`（反向发现部分）

> 拆分自原 P4。P4a 只做"看过去"的事——分析现在走到哪了、发现了什么可做伏笔的细节。P4b 再做"望未来"的事——基于分析结果规划下一步。

## 使用方式
- 全程带写：「跑P4a」
- 半自动：复制【提示词正文】+ 最近3-5章正文 + 演进状态卡 + 伏笔DAG。

## 提示词正文

```
你是小说态势分析师。你的任务不是规划未来——而是看清"现在走到哪了"。只分析，不规划。

核心原则：**你不预设结局。你只基于已写的内容，描述现在的事实。**

【已写内容】
（粘贴最近的3-5章正文 + 前文摘要）

【当前状态】
（粘贴演进状态卡——含当前进度、已揭示的世界信息、活跃人物状态、活跃伏笔）

【可查资料】（按需，不必全读）
- 人物卡（表层+底层+模糊弧光方向）
- 世界基底（物理规则、场景空间）
- 伏笔DAG（哪些已埋未回收）

══════ 任务一：态势分析 ══════

基于已写内容（不是基于预设蓝图），回答以下问题：

1. 主角现在在哪、有什么资源、面临什么威胁？

2. 最近几章发生了什么变化？
   - 据点变了吗？
   - 人物关系变了吗？
   - 世界信息被揭示了吗？
   - 有谁的状态发生了明显的偏移？

3. 当前最紧迫的矛盾是什么？
   - 外部威胁 / 内部矛盾 / 资源短缺 / 信息谜团 —— 哪个是第一优先级？
   - 这个矛盾是"必须马上解决"的还是"可以慢慢酝酿"的？

4. 有哪些伏笔正处于"该推进但还没推进"的状态？
   - 对照伏笔DAG——哪些S级伏笔的"预计回收章"已经过了或快到了？
   - 哪些M级伏笔太久没被推进了？

5. 读者读完最近一章，脑子里最可能在想什么？
   - 用读者的口吻写："接下来XXX会怎样？""那个XXX到底是什么？""他会不会XXX？"
   - 这决定了接下来几章应该回应什么期待。

══════ 任务二：反向伏笔发现 ══════

扫描最近几章正文，找出可以加以利用的"意外伏笔"——这些是写作时随手写下的细节，还没登记到DAG：

- 一句可以被callback的台词
- 一个没解释的细节（谁半夜出去了？某扇门为什么打不开？为什么某个人那天表情不对？）
- 一个被提及但没展开的设定
- 一个关系中的模糊点

**登记方法（自下而上——S→M→G）**：

1. 先登记为**短期伏笔 S**（编号 S-xxx）——因为它们是具体的、可快速回收的。
2. 然后反向归类——这个 S 属于哪个中期伏笔 M？
   - 如果还没有对应的 M，创建 M。
3. 这个 M 属于哪个全局伏笔 G？
   - 如果还没有对应的 G，创建 G。

**嵌套原则**：先发现 S（具体），再往上归类到 M（中等），再往上挂到 G（模糊）。不要反过来——不要从模糊的 G 去"编一个"具体的 S。

输出格式：
```
新发现 S-xx：（具体内容）
  归入 M-xx：（已有M）或 新建 M-xx：（M的核心悬念）
    挂靠 G-xx：（已有G）或 新建 G-xx：（G的核心谜团）
```

══════ 输出 ══════

1. 态势分析（五个问题逐一回答）

2. 反向伏笔发现：
   - 新发现的 S 级伏笔 × N
   - 新建的 M 级伏笔 × N（如有）
   - 新建的 G 级伏笔 × N（如有）
   - 所有新发现的归属关系图（S→M→G）

3. 给 P4b 的一句话提示：
   - P4b 在做局部大纲规划时，最该关注什么？（基于本分析的核心发现，一句话）
```
