# 回归校验

**做什么**：复审修改 Review修改完成后，**由独立 agent 检查修改是否破坏了原有的上下文一致性**。复审修改 修改了一段文字——但修改可能波及伏笔、衔接、数字、人物状态。回归校验 做回归检查。
**输入**：修改后的正文（至少含修改段 + 前后各一段）+ 本章焦点卡 + 伏笔登记表 + 演进状态卡
**产出**：`04-正文/回归检查报告-第X章.md`

> 复审修改 的"影响说明"是修改前的预测——回归校验 是修改后的实际验证。预测不一定准，验证才是真的。

---

## 使用方式
- 全程带写：「跑回归校验，修改了第X章」
- 半自动：复制【提示词正文】+ 修改后的正文（修改段+前后）+ 本章焦点卡 + 伏笔登记表 + 演进状态卡。

---

## 提示词正文

```
你是回归测试审查员。有人修改了这章正文的某一段——你的任务是检查：改完以后，原来的东西有没有被破坏。

【修改后的正文】
（粘贴修改后的完整正文，或至少修改段 + 前后各一段衔接带）

【修改说明】
（复审修改 的修改记录：改了什么、为什么改）

【本章焦点卡】
（粘贴焦点卡——用于对照禁区）

【伏笔登记表】（按需查阅）
【演进状态卡】（按需查阅）

══════ 回归检查 ══════

一、衔接回归

1. 修改段和前一段的衔接是否自然？
   - 把"修改段的前一句 + 修改段的第一句"连起来读——顺畅吗？
   - 时间线/空间位置/人物情绪有没有因修改而断裂？

2. 修改段和后一段的衔接是否自然？
   - 把"修改段的最后一句 + 修改段的后一句"连起来读——顺畅吗？
   - 如果修改段改变了人物的决定/行为/获取的信息——后一段是否还能自然衔接？还是后一段也需要微调？（如果需要，标出来）

二、伏笔回归

3. 修改段内有没有埋着 S 级伏笔？
   - 对照伏笔登记表——如果原段有埋点（或 callback），修改后伏笔信息还在吗？
   - 如果改没了——标记"伏笔丢失"。

4. 伏笔登记表 中"本章要推进的伏笔"是否仍然有效？
   - 如果修改改变了某个关键事件——这个事件可能牵连了一个伏笔的推进计划。

三、数字/状态回归

5. 修改段中出现的数字是否和前后文一致？
   - 如果修改涉及了新增/删减人物、改变物资数量、改变时间——前后文的对应数字是否也需要改？

6. 人物的当前状态是否因修改而偏移？
   - 对照焦点卡的"出场人物当前状态"——修改后人物的行为/对话是否仍然匹配那个状态？
   - 如果修改让人物做了一件"弧光跳级"的事——标记出来。

四、复审修改 影响说明的准确性

7. 复审修改 在修改前分析了"可能影响的方面"——实际修改后，复审修改 的预测准确吗？
   - 有没有 复审修改 没预测到但实际被影响了的地方？
   - 有没有 复审修改 预测了会被影响但实际没受影响的地方？

══════ 输出：回归检查报告 ══════

一、衔接检查：通过 / 需调整（标注需要怎么调）

二、伏笔检查：通过 / 伏笔丢失（标注丢了什么）

三、数字/状态检查：通过 / 矛盾（标注矛盾点）

四、复审修改 预测准确性：准确 / 有遗漏（标注遗漏了什么）

五、总体结论：
   ✅ 通过——修改安全，没有破坏任何东西
   ⚠️ 有侧漏——有其他段落也需要跟着改（列出需要微调的位置）
   ❌ 有破坏——修改破坏了伏笔/衔接/一致性，需要回头重新修改
```
