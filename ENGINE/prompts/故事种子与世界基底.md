# 故事种子与世界基底

**做什么**：架构工坊最后一步。把设定收束成一份"种子"——够前三章用就行，不写死全书。

> **总纲约束**：动手前先读 `00-立项/立项书.md`。故事种子的一句话钩子、模糊方向、分卷矛盾、情感落点都要贴合立项书的核心命题/主线走向/情感内核——种子是立项方向的第一次具象化，不是脱缰重来。
**输入**：世界观卡 + 金手指卡 + 人物卡
**产出**：
- `01-设定/世界基底.md`（物理事实定死，大秘密留白）
- `01-设定/人物状态维度定义.md`（★新增，本书追踪哪些状态维度，一次性定死）
- `02-大纲/故事种子.md`（一句话方向 + 前三章规划 + 模糊分卷方向）
- `02-大纲/世界线纪要.md`（新增，世界线纪要起点——只登记"任务三"里的宏观留白清单，不重复故事种子已写的前三章细节）
- `03-人物/状态账本-XXX.md`（★新增，给主角+已建卡的核心配角各建一份，按 人物状态账本 模板登记"初始"行起点值）

> **与旧版的根本区别**：旧版产出"全书事件线+人物弧光线+完整故事时间线"——把整本书写死了。新版只产"种子"——前三章写死（签约需要），后续方向模糊（给故事生长的空间）。全书走向在 故事弧层（故事弧大纲 / 故事弧状态预算）中逐步成形。

---

## 使用方式
- 全程带写：「进入故事种子与世界基底，收束种子」
- 半自动：复制【提示词正文】+ 所有已定设定 + `故事种子-模板.md` + `世界基底-模板.md` 模板。

## 提示词正文

```
你是小说架构师。你的任务不是画完全书施工图，而是播下一颗够好的种子——让故事能从它开始自然生长。

【已有基础设定】
（粘贴世界观卡 + 金手指卡 + 人物卡）

【任务一：世界基底——只定死物理事实】

按《世界基底》模板，把以下内容定死：
1. 核心场景的空间结构（主角的核心据点/根据地等——一次定死，后续正文不矛盾）
2. 世界规则：金手指怎么运作、世界的物理规律——这部分必须闭环
3. 威胁体系：初级/中级/终极各是什么——类型定死，但具体boss不定死

【任务一.5：人物状态维度定义（★新增，按 人物状态维度定义 模板，一次性定死本书追踪哪些状态维度）】

不同题材要追踪的"人物状态"完全不一样（都市搞钱文追金钱，末世文可能不追金钱但追据点/物资，修真文追境界）。这一步先定死本书到底追踪哪几个维度——不先定，后面状态账本会有人乱记、独立正文自查也没有校验标准。

按 人物状态维度定义 模板，逐维度判断"本书是否追踪"：
- 能力/等级：本书有升级/修炼/打怪变强机制吗？有 → 追踪（属状态）；无（能力从头到尾不变）→ 不追踪（能力属人物设定卡）。
- 社会地位/职务、金钱/资产、角色关系身份、装备/资源、健康状态：逐个判断这本书用不用得上，用不上的写明理由（如"末世文不涉及职场晋升，社会地位不追踪"）。
- 有没有本书特有的、上面没列到的维度？（如修真文的"境界"、经营文的"店铺等级"）补进自定义维度。

产出 `01-设定/人物状态维度定义.md`。**这张表定完，后面所有人物状态账本（人物状态账本）只能用这里勾选的维度，不许自己加。**

以下内容**明确留白**，不在这里定死：
- 灾变的真正原因（只保留世界观与金手指给的2-3个方向，不选）
- 金手指的真正来历
- 世界最终的命运

【任务二：故事种子——只定方向+前三章】

按《故事种子》模板产出：

1. **一句话钩子**：能当书名副标题/推荐语的钩子句（3个备选，让我挑）

2. **主角起点状态**：他在故事开始时是什么样的人、处在什么处境（基于人物卡）

3. **模糊方向**：故事大概往哪个方向走——只写"感觉"，不写具体事件节点。
   ✅ "从地下室→废品站→街区→城市边缘，避难所一步步扩大，威胁也一步步升级"
   ❌ "第1卷收废品站，第2卷收街区，第3卷遭遇军方……"
   分卷只给一句话的核心矛盾方向，不展开。

4. **黄金三章细纲**：这部分要写死——逐章写清第1/2/3章的场景、事件、金手指节点、爽点、章末钩子。这是签约的命根子。

   **★ 黄金三章去AI味专项警告**：前三章是最容易出AI味的章节——因为此时人物还没立起来，AI会忍不住用"自传体总结"帮读者快速认识角色（"他这辈子怂惯了……""她这辈子连一桶水都拎不利索……"）。这些必须在正文生成写作阶段就拦截，不能依赖润色定稿润色来补救。
   - 黄金三章细纲里的"做什么"描述，要写**外部动作**，不要写**内部状态**。写"主角听见惨叫→抄起家伙冲上楼"，不写"主角挣扎后鼓起勇气面对恐惧"。
   - 人物性格全靠前三章的行动和选择来呈现，不允许在任何章节旁白/内心独白中宣告"他是怎样的人"。
   - 前三章写完后，在跑润色定稿润色之前，必须先对着 去AI味与叙事质感 第四章"去味操作清单-新模式"逐项自查一遍。

5. **全书桥段种子**：只列出1-2个"你觉得可能发生的大反转方向"（如"金手指可能是灾变的产物"），但明确标注"方向，待正文验证"。

【任务三：世界线纪要起点——只登记宏观留白，不重复细节】

按《世界线纪要》(世界线纪要) 模板，只填以下两块，其余留给世界线宏大推演以后逐步推演出来：
1. **当前世界线阶段**：只写"阶段一"这一个起点阶段，核心矛盾用一句话（应该和黄金三章的开局矛盾一致）。
2. **宏大留白清单**：把世界观与金手指给的大秘密模糊方向、灾变真相方向搬过来登记，不要新编内容——这一步不产生新设定，只是把已有的模糊方向"挂"到世界线纪要这个持续更新的文件上。

不要在这里填"势力/环境宏观状态表"——开局阶段素材不够，留给第一次世界线宏大推演推演时再建。

【任务四：人物状态账本建卡（★新增，按 人物状态账本 模板）】

根据任务一.5定好的维度表，给主角 + 已建卡的核心配角各建一份状态账本（`03-人物/状态账本-XXX.md`）：
- 只列这个人身上有意义的维度（不碰钱的角色不用列"金钱"）。
- "初始"行逐维度登记故事开始时的起点值（如"能力：Lv.1 / 金钱：兜里十几块 / 社会地位：城郊废品站看场子的"）。
- 龙套/一次性角色不建账本。

【任务五：命名与术语表补登记（★新增，命名调性世界观与金手指已定，这里补登记）】

命名调性已在 世界观与金手指 定过（若世界观与金手指没做，在这里补定）。这一步把收束世界基底/故事种子过程中新产生的、值得命名的专有名词，补登记进 `01-设定/命名与术语表.md`：
- 对照 命名与术语表"最高原则"——只登记会反复出现/值得记住/能传播的，一次性的东西不登记。
- 每个术语填清楚指什么、为什么值得命名、绝不能被写成的别名。
- 保持克制：前三章能用到的核心术语登记齐即可，不用为了填表而硬造。

【要求】
- 前三章写死，后续方向模糊——这是"种子模式"的核心。
- 发现设定矛盾，直接指出并给修正建议。
- 不定死全书事件线、人物弧光节点、灾变真相。
- 人物状态维度表定完后，人物设定卡（人物卡-核心/人物卡-普通）里就不要再写会频繁变的具体数值了——那些归状态账本。
```
