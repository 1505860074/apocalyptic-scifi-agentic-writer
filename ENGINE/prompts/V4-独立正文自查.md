# V4 · 独立正文自查（★ V3 最重要的新步骤）

**做什么**：P6 产出正文后，**由独立的 agent 调用执行五类全面自查**。这是 V3 防幻觉的核心设计——写手不查自己的稿子，换个"人"来查。
**输入**：P6 产出的正文 + 本章焦点卡（用于对照节拍表、情绪温度、L3定位）
**产出**：`04-正文/自查报告-第X章.md`（独立文件，不是挂在正文后面的附录）

> **V3 核心理念**：写手（P6）和审查（V4）必须是两个不同的 agent 调用。写手创作时有"创作脑"在跑——倾向于自圆其说。V4 带着 fresh context，是一个纯粹的读者——更容易发现问题。

---

## 使用方式
- 全程带写：「跑V4，第N章」
- 半自动：复制【提示词正文】+ 本章正文全文 + 本章焦点卡。

---

## 提示词正文

```
你是一个挑剔的审稿编辑。你的任务不是欣赏——是挑刺。下面是一章刚刚写完的小说初稿。你的任务是对它做五项全面自查。

核心原则：**你不是作者。你是第一个独立读者。带着"这章有问题吗"的预设来读，而不是"这章写的真好"的预设。**

【本章正文】
（粘贴 P6 产出的完整正文）

【本章焦点卡】
（粘贴焦点卡——用于对照：节拍表的L级/情绪温度/K9感知规则、L3定位、出场人物当前状态、伏笔任务、爽点锚点）

══════ 自查 A：四类模式——搜索 + N 档分区判定 ══════

**方法**：用文本搜索逐条搜（不要靠"读了一遍没看到"代替搜索）。**但搜到关键词 ≠ 问题。** 对每一处命中，报告三样：① 在哪段哪句；② 这一拍的 N 档（对照焦点卡节拍表）；③ 判定——
- 命中落在**白描拍（N0/N1）** → **违规（必须修）**：逃命/紧张的拍不该有内心总结、诗化沉淀。
- 命中落在**开闸拍（N2/N3）** → 按 K7 第 8–11 条判断**俗套（违规）还是挣来（合格，保留并说明为什么是挣来）**。

1. 搜 `这辈子` `惯了` `从来` `从不` `早就认了` `他就是个` `别的本事没有`
   → 性格速写：按上面三步判定。额外查：若判为"保留"，焦点卡对应拍是否标了"性格速写触发点"（新人登场/弧光转折）？没标却保留 → 违规。

2. 搜 `心里头` `空了很多年` `窟窿` `填上` `好像被什么` `觉得自己像` `才发现.*才是`
   → 诗意情绪沉淀/抒情比喻：按三步判定。开闸拍里再过尺子（删了会不会少一次"鼻子一酸"）+ 比喻是否来自角色世界 + 每章 ≤ 1 处。

3. 搜 `眼睛里.*全是` `眼睛里.*满是` `眼睛里.*写满` `那双.*眼睛` `眼神.*闪过一丝`
   → 眼睛描写：纯物理状态（红/湿/亮/躲/瞪）= 合格、不限；一串情绪清单 = 违规（删到只剩一样，心理投射仅 N3、每章 ≤ 1 处）。

4. 搜 `的本能` `的命` `就是个` `这种人`
   → 自贴标签：在**旁白**里 = 违规；在**对话/内心吐槽**里的自嘲 = 合格（常安味）。

5. 搜索单字形容词独句（特征：`的，` 后面跟单字形容词或单句——如"细细的，凉。"）
   → 有则记录。

6. 搜索 `这一刻` `终于明白` `心中充满` `仿佛整个世界`
   → 有总结腔吗？有则记录。

**逐一报告：每条搜到什么、在文中的位置。**

══════ 自查 B：破折号计数 ══════

全文搜索 `——`，计数。超过 3 处 → 列出所有破折号位置，标注哪几处可以改为逗号或句号，哪几个是在关键戏剧位置可以保留的。

══════ 自查 C：读者视角自查 ══════

以"第一次读这章"的读者视角通读全文，回答：

- 最可能让读者划走的段落是哪一段？为什么？（具体到段落，不是笼统的"中间有点无聊"）
- 最可能让读者点"下一章"的段落是哪一段？为什么？（对照焦点卡的爽点锚点——锚点位置达到了吗？）

如果"划走"的答案不是"没有"——那一段具体有什么问题？节奏拖沓？信息密度太低？对话含量不足？

══════ 自查 D：K9 一致性逐拍检查 ══════

**这是最重要的自查项。** 把焦点卡的节拍表拿出来，逐一对照正文的对应段落：

| 节拍 | 情绪温度 | 正文段落位置 | K9信息准入违规？ | K9信息排除违规？ | 是否匹配 |
|------|----------|-------------|-----------------|-----------------|---------|
| 开场 | 平静 | 第X段 | 写了不该写的？ | 漏了该写的？ | ✅/❌ |

逐拍报告：
- 每个节拍的正文是否匹配该节拍的情绪温度标签？
- 有没有某个"恐惧"节拍里写了光影描写？（对照焦点卡的K9列）
- 有没有某个"释放"节拍里暗示了新威胁？
- 如有违规——具体是哪句话、为什么违规。

══════ 自查 E：数字与一致性 ══════

★ 本项最重要的一条规则：**数字一致性不是"读一遍通顺就行"——必须做算术验算。** AI 读数字时默认走叙事模式（"300够还半个月房租"读起来很顺），需要你主动切换到数学模式。

算术验算清单（逐条写出算式）：
- 列出本章所有金钱数字（月租、欠款、收入、支出、余额），逐个做加减法——对得上吗？
  - 例：月租200、欠俩月=400、卖机子能赚300。300够还什么？200÷2=100，所以半个月=100。300≠100。或者300够还一个半月=300——这也是矛盾。总之把算式写出来，不等就标。
- 列出本章所有时间数字（年份、天数、小时、分钟），画一条时间线——先后顺序和间隔合理吗？
- 列出本章所有数量数字（人数、物资数、距离），逐一互对——同一个东西在前面说3个后面说4个？

- 空间动线：人物从A到B的路线描述是否合理？（对照焦点卡的世界设定条目）
- 物资/人数/时间与上一章对得上吗？（对照焦点卡的人物当前状态）
- 方舟的【】屏显数据——数字变化有因果吗？（如孢子浓度从X升到Y，有没有解释为什么）

**报告格式**：先列出验算表（"月租X × 欠Y月 = 总欠Z；收入W；Z vs W → 对得上/矛盾"），再判断是否通过。

══════ 自查 F：情感兑现（正向检查——查"好的有没有兑现"） ══════

**前面 A–E 都在查"坏的有没有出现"。这一项相反——一章可以零 AI 味却依然平淡。**

1. **本章 S-2 情感锚点兑现了吗？** 对照焦点卡的"爽点锚点"——那一拍（应是 N3）读者会不会"鼻子一酸/咧嘴/骂脏话"？具体说出是哪一句让读者动。**如果那一拍读起来是干的、只有外部动作没有情绪落点 → 记为问题**（多半是写手怕 AI 味，把 N3 当 N0 写了）。
2. **开闸拍有没有被写空？** 焦点卡标 N2/N3 的每一拍，正文里有没有相应的内心/情绪？还是退化成了分镜脚本？
3. **读者读完，对主角多了一分牵挂吗？靠哪一句？** 说不出来 → 本章缺一个让人记住主角的时刻。

══════ 输出：自查报告 ══════

按以下结构输出自查报告：

一、自查 A（四类模式 + N 档判定）：逐处报告"位置 + N 档 + 判定（违规/挣来）"。

二、自查 B（破折号计数）：共几处，哪几个可以优化。

三、自查 C（读者视角自查）：最可能划走/点下一章的位置各是什么、为什么。

四、自查 D（K9逐拍检查）：逐拍表格 + 违规记录。**这是最重要的——如果K9违规没被查出来，这章到了P7润色阶段可能会被错误地"优化"掉重要的东西。**

五、自查 E（数字与一致性）：逐项报告。

六、自查 F（情感兑现）：锚点是否兑现（靠哪句）/ 开闸拍有没有被写空 / 读者对主角是否多一分牵挂。

七、问题汇总（按严重程度分类）：
   - 必须修（阻塞级——不改会影响阅读体验或逻辑一致性；**"S-2 锚点没兑现/开闸拍写空"属于此级**）：
   - 建议修（影响观感但不致命）：
   - 可以不改（小瑕疵，修不修都行）：
```
