# P3 · 故事种子与世界基底

**做什么**：架构工坊最后一步。把设定收束成一份"种子"——够前三章用就行，不写死全书。
**输入**：世界观卡 + 金手指卡 + 人物卡
**产出**：
- `01-设定/世界基底.md`（物理事实定死，大秘密留白）
- `02-大纲/故事种子.md`（一句话方向 + 前三章规划 + 模糊分卷方向）

> **与旧版的根本区别**：旧版产出"全书事件线+人物弧光线+完整故事时间线"——把整本书写死了。新版只产"种子"——前三章写死（签约需要），后续方向模糊（给故事生长的空间）。全书走向在P4演进大纲中逐步成形。

---

## 使用方式
- 全程带写：「进入P3，收束种子」
- 半自动：复制【提示词正文】+ 所有已定设定 + `T3-故事种子.md` + `T6-世界基底.md` 模板。

---

## 提示词正文

```
你是小说架构师。你的任务不是画完全书施工图，而是播下一颗够好的种子——让故事能从它开始自然生长。

【已有基础设定】
（粘贴世界观卡 + 金手指卡 + 人物卡）

【任务一：世界基底——只定死物理事实】

按《世界基底》模板，把以下内容定死：
1. 核心场景的空间结构（主角据点等——一次定死，后续正文不矛盾）
2. 世界规则：金手指怎么运作、世界的物理规律——这部分必须闭环
3. 威胁体系：初级/中级/终极各是什么——类型定死，但具体boss不定死

以下内容**明确留白**，不在这里定死：
- 灾变的真正原因（只保留P1给的2-3个方向，不选）
- 金手指的真正来历
- 世界最终的命运

【任务二：故事种子——只定方向+前三章】

按《故事种子》模板产出：

1. **一句话钩子**：能当书名副标题/推荐语的钩子句（3个备选，让我挑）

2. **主角起点状态**：他在故事开始时是什么样的人、处在什么处境（基于人物卡）

3. **模糊方向**：故事大概往哪个方向走——只写"感觉"，不写具体事件节点。
   ✅ "从地下室→废品站→街区→城市边缘，避难所一步步扩大，威胁也一步步升级"
   ❌ "第1卷收废品站，第2卷收街区，第3卷遭遇军方……"
   分卷只给一句话的核心矛盾方向，不展开。

4. **黄金三章细纲**：这部分要写死——逐章写清第1/2/3章的场景、事件、金手指节点、爽点、章末钩子。这是签约的命根子。

   **★ 黄金三章去AI味专项警告**：前三章是最容易出AI味的章节——因为此时人物还没立起来，AI会忍不住用"自传体总结"帮读者快速认识角色（"他这辈子怂惯了……""她这辈子连一桶水都拎不利索……"）。这些必须在P6写作阶段就拦截，不能依赖P7润色来补救。
   - 黄金三章细纲里的"做什么"描述，要写**外部动作**，不要写**内部状态**。写"常安听见惨叫→抄撬棍冲上楼"，不写"常安挣扎后鼓起勇气面对恐惧"。
   - 人物性格全靠前三章的行动和选择来呈现，不允许在任何章节旁白/内心独白中宣告"他是怎样的人"。
   - 前三章写完后，在跑P7润色之前，必须先对着 K7 第四章"去味操作清单-新模式"逐项自查一遍。

5. **全书桥段种子**：只列出1-2个"你觉得可能发生的大反转方向"（如"金手指可能是灾变的产物"），但明确标注"方向，待正文验证"。

【要求】
- 前三章写死，后续方向模糊——这是"种子模式"的核心。
- 发现设定矛盾，直接指出并给修正建议。
- 不定死全书事件线、人物弧光节点、灾变真相。
```
