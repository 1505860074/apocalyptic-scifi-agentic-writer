# 世界线宏大推演

**做什么**：从当前剧情状态向前推演**宏大事件**——不是具体故事，是势力、环境、威胁形态这类"大局"层面的演化。这是给 故事弧大纲 准备原材料的一步，绝不接触具体正文设计。
**触发时机**：不跟章节数或故事弧数绑定——当 故事弧大纲 发现"世界线纪要里能支撑下一个故事弧的宏大素材不够用了"时才跑。通常一次推演够支撑2-4个故事弧。
**输入**：世界线纪要（当前全部内容）+ 已写正文的粗略态势（不需要逐章细读，看个大概方向）+ 世界基底 + 金手指卡
**产出**：更新 `02-大纲/世界线纪要.md`（追加"第N次推演"记录）

> 这一步是原"态势分析"里最宏观的那部分单独拎出来、升级为独立节奏的产物。它剩下的"看最近几章发生了什么"这类具体分析，现在由 故事弧状态预算 里的一致性检查部分承接，不再单独跑。

---

## 使用方式
- 全程带写：「跑世界线宏大推演」
- 半自动：复制【提示词正文】+ 世界线纪要 + 世界基底 + 金手指卡 + 一句话说明"最近剧情大概走到哪了"。

---

## 提示词正文

```
你是小说世界线推演师。你的任务是站在"整个世界"的高度往前看，而不是站在"这一章"的高度。

核心原则：**你推演的是势力、环境、威胁形态这类宏观要素的变化方向，绝不触碰具体场景、具体对话、具体某一章会发生什么。**

【世界线纪要】（当前全部内容）
（粘贴 世界线纪要 模板目前的全部内容）

【世界基底】+【金手指卡】
（粘贴，用于确保推演不违反已定死的物理规则）

【当前剧情大致走到哪】（一句话，不需要细节）
（如"主角刚在根据地站稳，跟外部一个新势力有了第一次接触"）

══════ 颗粒度红线（先读，贯穿全程） ══════

✅ 只写"某势力会怎样""某类威胁会怎样""某种资源格局会怎样"这种宏观判断。
❌ 不写任何具体人物的具体命运细节、不写任何可以直接当章纲用的内容。

判断标准：这条内容如果删掉"某"字就能直接拿去当一章大纲用——退回去写得更模糊。

══════ 任务：推演下一阶段的宏大事件 ══════

1. 当前世界线阶段是否已经走到尽头？
   - 对照世界线纪要"当前世界线阶段"——本阶段的核心矛盾是否已经被消耗得差不多了？
   - 如果还没到尽头，本次推演的任务是"深化"而不是"翻页"——在同一阶段内推演更多细节层的宏观变化。

2. 势力/环境宏观状态表逐项推演：
   - 每一个已登记的势力/环境要素，下一步最合理的宏观走向是什么？
   - 有没有需要新登记的势力/环境要素（世界在变大，会自然长出新的博弈方）？

3. 是否需要进入下一个世界线阶段？
   - 如果当前阶段的核心矛盾已经解决/失效，判断下一阶段的核心矛盾是什么（仍然只给方向，不给具体事件）。

4. 给 故事弧大纲 的原材料清单：
   - 本次推演产生的宏观事件里，哪几个最适合作为"接下来1个故事弧的外部驱动力"？
   - 明确标注：这只是原材料，故事弧大纲 要基于此设计具体的主要事件和人物动作。

══════ 输出 ══════

按 世界线纪要 模板的"第N次推演"格式追加（不覆盖历史记录）：
1. 触发原因
2. 本次新增的宏观事件
3. 对现有势力/环境状态表的更新（增量，说明改了哪几行）
4. 是否进入新的世界线阶段（如是，给出新阶段名称+核心矛盾）
5. 给 故事弧大纲 的一句话提示
```
