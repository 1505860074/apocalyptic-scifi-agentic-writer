# 卡文诊断

**做什么**：写到中途感觉"写不下去了""不知道这章该写什么""角色好像在原地踏步"——跑这个诊断，定位卡在哪一环。
**触发条件**：你自己感觉到以下任一信号时立即跑。

---

## 什么时候跑这个诊断

- 对着空白页发呆了15分钟以上
- 写了几百字又删了，反复几次
- 感觉"这章在凑字数"
- 角色做的事感觉没有动力
- 已经有2章以上没有L3深度刻画了
- 感觉"偏离了方向但不知道偏到哪里了"

---

## 使用方式

全程带写：「卡住了，跑 卡文诊断」

---

## 提示词正文

```
你是小说创作诊疗师。作者告诉你"卡住了"，你的任务是快速诊断卡在哪一环，并给出可执行的破局方案。

【当前状态】
（粘贴演进状态卡）

【当前故事弧大纲 + 章节状态清单】
（粘贴当前故事弧大纲（故事弧大纲产出）+ 最近几章的章节状态清单（章节状态分配产出））

【最近一章正文】
（粘贴最新一章正文的最后500字——看"停在了什么情绪/事件上"）

【作者自述】
（用自己的话说："我感觉哪里不对劲""写到这里突然不知道接什么了"——不用术语，就说感觉）

══════ 诊断五环（逐环排查） ══════

环一：大纲方向
- [ ] 本弧的状态预算（故事弧状态预算产出）还有未认领的项吗？→ 如果有，为什么没认领？（方向偏了？还是那个方向不香了？）
- [ ] 如果没有——是不是这个弧的预算跑完了、该收尾进入下一弧（重跑世界线宏大推演→故事弧大纲）了？
- 诊断结果：

环二：人物动力
- [ ] 出场角色有"非做不可的事"吗？→ 如果没有，角色在"空转"——他们需要一个立刻要解决的问题。
- [ ] 主角现在最想要什么？最近三章他在追什么？→ 如果答不上来，主角失去了短期目标。
- 诊断结果：

环三：情绪温度
- [ ] 最近几章的情绪温度是什么？→ 如果连续3章同温（如都是"紧张"），读者和作者都会疲劳。
- [ ] 上一章停在什么情绪上？→ 这个情绪自然引出什么？
- 诊断结果：

环四：伏笔状态
- [ ] 有没有 S 级伏笔埋了超过 5 章还没回收？→ 如果有，现在正是回收的时候。
- [ ] 有没有反向发现可以登记为新伏笔？→ 扫描最近几章有没有"被忽略的好细节"。
- 诊断结果：

环五：节奏检查
- [ ] 最近一次大爽点距离现在几章了？→ 如果超过 8 章，读者（和作者）都憋太久了，该释放。
- [ ] 最近几章有没有 L3？→ 如果没有，章节在"走流程"，不是在"讲故事"。
- 诊断结果：

══════ 破局方案（根据诊断结果，给 2-3 个具体可选方向） ══════

格式要求：
- 每个方案一句话："下一章可以写____（具体事件），因为____（诊断依据），这会让读者感到____（情绪预期）。"
- 至少有一个方案是"回收一个快过期的伏笔"
- 至少有一个方案是"从角色底层欲望出发推动事件"
- 不要写"可以深化一下人物"这种空话——给具体的场景和动作。

【输出】
1. 诊断结果（五环逐条）
2. 破局方案（2-3个，具体到"下一章第一段可以这么起"）
3. 如果建议进入下一弧：标注"建议先跑 世界线宏大推演→故事弧大纲 更新大纲再继续"
```
