# 用词优化 · 总览（★元工作流 · 工作流自优化）

> **这不是写书的工序,是优化工作流本身的工具。** 它跑在写书主管线之外:拿一篇标杆范文当"标准答案",逆向拆出它的骨架 → 让工作流拿同样的骨架**盲写一遍** → 比出差距 → 把差距**抽象**回填工作流,让工作流的用词和风格逐步逼近范文。
>
> 核心思路 = 把"作者手改→提炼规律→改工作流"这个手动循环,做成可复用的自改进闭环。

---

## 输入 / 产出

**输入(可插拔)**:
- **标杆范文**:一篇你认可的、比工作流当前产出更好的文本。外部优秀网文 或 项目内定稿章节均可,**跑时指定**。以**一章**为单位(一整篇太大,且骨架提取会失真)。
- **当前工作流**:ENGINE 各层(现状,作为被优化对象)。

**产出**:
1. 《工坊报告》:逆向骨架 + 盲重建稿 + 差距分析(抽象层)+ 对各层的抽象优化建议。
2. (经作者确认后)对工作流各层的实际改动。

---

## 四条铁律（本工坊红线,违反即结果作废；每一步都要遵守）

1. **盲重建**:正向重建的子agent **只拿骨架、绝不接触原文**。看了原文＝作弊,测出来的不是工作流的真实能力。逆向提取的agent 和 盲重建的agent **必须是不同的、互不传原文的**。

2. **只优化文风层**:骨架喂了相同的情节/人物/节拍 → 情节结构本应一致 → 差距集中在**用词、句子、节奏、质感**。所以回填**只动文风相关层**(去AI味与叙事质感 / 优秀网文写作法 / 本书写作风格卡 / 正文生成的文风部分 / 场面调度的对话),**不碰情节、结构、设定层**。若发现情节结构也差很多,那是"逆向提取没提准",回第1步,不是拿它优化。

3. **不举例、只抽象(★作者硬要求)**:差距回填工作流时,**绝不把范文的具体词句当例子写进规则**。只能把差距提炼成各层的**抽象倾向**(如"该层应更强调动词贴角色职业"),不能出现"范文里写了X所以规则加X"这种。这是为了保住工作流的通用性,别被一篇文章的确切文字污染(同"去文风污染"一条心)。

4. **防过拟合**:一篇范文里,有些特征是**通用网文规律**,有些只是**这位作者的个人风格**。差距**必须能上升为"一类通用网文原则"才回填**;纯属单篇个性的(比如某作者特别爱用某种句式),**丢弃、不入规则**。宁可不改,不可把一篇的个性当通法。

---

## 四步管线（用子agent编排,盲测隔离）

```
用词优化-逆向提取 → 用词优化-盲重建 → 用词优化-对比差距 → 用词优化-抽象优化与回填
   (蒸馏骨架)        (换个agent盲写)     (只比文风差距)      (抽象成通则+改层+可迭代)
```

1. **用词优化-逆向提取**:读范文,逆向填出中间产物(骨架),剥掉一切用词/句子/腔调。
2. **用词优化-盲重建**:**换一个没看过原文的 agent**,拿骨架走现有正向链盲写这一章。
3. **用词优化-对比差距**:盲重建稿 vs 原文,逐维度只比用词/句子/风格,输出抽象倾向差距清单。
4. **用词优化-抽象优化与回填**:差距过两道闸(防过拟合→定位到层),产出抽象优化建议;经作者确认后改对应文风层,并可再跑第2-3步看差距是否收敛(闭环迭代)。

---

## 使用方式

- 全程带跑:「跑用词优化工坊,范文＝<某章/贴文>」→ 依次跑上面四步。
- 半自动:贴范文一章 + (可选)指定要重点对标的维度(用词/句子/风格)。

## ★ 规模提示

这是**多子agent高消耗**流程(逆向提取1 + 盲重建1~若干 + 对比1 + 优化1,可能迭代多轮)。**每次跑前先报规模、经作者同意再跑。**
