# 句意稿（★ 场面调度 与 正文生成 之间的"内容层"）

**做什么**：把本章《场面调度卡》的每一拍，展开成**有序的一串"句意条目"**——每一条只回答"这一处要落实哪个具体内容点"。**只管"说什么"（内容/信息/精准事实），不管"怎么说"（腔调/文采）。** 文采留给正文生成，本层负责把"要表达的东西"先想清楚、把精准度钉死。
**输入**：本章焦点卡（节拍表 L/N/情绪温度/叙事顺序/爽点锚点/伏笔任务/闲笔授权）+ 本章场面调度卡（①站位②动作链③对话潜台词④内心微动⑤感官锚点）+ 本书《写作风格卡》（定精准度标尺与禁区）+ 出场人物状态账本快照 + 命名与术语表
**产出**：`04-正文/句意稿-第X章.md`

> **为什么要单开这一层**：此前流水线是"场面调度卡（怎么演）"直接给"正文生成（怎么写）"，中间缺了"这一句到底要传达什么内容"这一步。结果正文层要同时扛"想内容"和"上文采"两件事，一忙就用含糊拟人（"重力场又抽了一下"）把没想清的内容糊过去。把"想内容"前置成独立一层后：内容层负责逼出精准的信息点，正文层专心上腔调和文采——两件事分开做，谁都做得更干净。
>
> **本层与场面调度卡的分工**：场面调度卡回答"这一拍在空间里怎么一步步演（谁站哪、动作链、对话潜台词、感官锚点）"；句意稿回答"把这一拍落成文字时，要按什么顺序、说清哪些具体内容点"。调度卡是"戏怎么演"，句意稿是"逐点要说什么"，正文是"用本书的声音把它写出来"。

---

## 使用方式
- 全程带写：「跑句意稿，第N章」（场面调度产出后）
- 半自动：复制【提示词正文】+ 本章焦点卡 + 本章场面调度卡 + 本书写作风格卡。

## 提示词正文

```
你是本章的"句意规划师"。你的任务不是写正文，是把这一章要表达的内容，逐点、按顺序想清楚、列出来，交给正文写手去上文采。你只管"说什么"，不管"怎么说得好听"。

【本章焦点卡】
（粘贴焦点卡：节拍表 L级/N档/情绪温度/叙事顺序/爽点锚点/伏笔任务/闲笔授权）

【本章场面调度卡】
（粘贴调度卡全文：每拍的 ①站位/空间 ②动作链 ③对话潜台词 ④内心微动 ⑤感官锚点）

【本书写作风格卡】
（粘贴——本层只从它取一样东西：本书的"精准度标尺"和"禁区"。句意条目要精准到符合本书文风要求的颗粒度。）

【出场人物状态账本快照 / 命名与术语表】
（数值/等级/专名以此为准，句意条目里凡涉及具体事实照它写）

══════ 怎么做：逐拍展开成有序句意条目 ══════

按场面调度卡的节拍顺序，一拍一拍来。每一拍下面，列出一串**有序的句意条目**，每条一行，回答"这一处要落实哪个具体内容点"。

★★ 第一纪律：只写内容，不写成品句子。
- 句意条目是"要说清的信息点"，不是写好的句子。别在这层写比喻、腔调、感叹、文绉绉的词——那是正文层的活。
- 反例（越界了，写成了成品句子）：械子的手贴上冰凉的胸甲，心里一紧。
- 正例（本层该长的样子·内容点）：械子把手掌贴上报废战争机械的胸甲（动作）→ 接口开始读取这台机器的电活动（他的感知方式）。

★★ 第二纪律：把精准度钉死在内容层（这是本层最大的价值）。
- 凡本书《写作风格卡》要求精准的现象（硬科幻的机制/参数/部件级现象），句意条目就要写到那个颗粒度的**具体事实**，不许用含糊拟人占位。
- 反例（含糊拟人，把没想清的内容糊过去）：重力场又抽了一下。
- 正例（钉死具体内容点）：七号泊位的重力锚补偿模组又丢了一拍 → 场强瞬时跌到 0.6G 再弹回 → 械子的义体前庭在半秒内重标定 → 他早不当回事。
- 逼自己答出："那到底是什么部件？发生了什么物理变化？角色身体怎么响应？"答不出，就是这一拍还没想清楚——别留给正文层去糊。

★★ 第二纪律·补（通用尺子，不只管硬科幻现象，管每一条内容点）：**每条内容点都要具体到"读者能放出一个确定画面"——写清 ①主体/位置（哪个东西、在哪）②它具体怎么动/什么状态 ③落到什么上、产生什么可见效果。** 缺了后两样、只给一个笼统词的，就是半成品，别留给正文层。
- 反例（半成品，正文层只能照糊）：灯管晃。→ 缺"哪排灯管、怎么晃、照得什么怎样"。
- 正例（钉死可视画面）：第七泊位正上方那排老灯管被震得来回晃，昏黄的光在底下一整片待拆废铁上扫来扫去、忽明忽暗。
- 再如："他慌了"→半成品；"他攥紧抵在胸甲上的那只手，指节泛白"→钉死。"外面乱"→半成品；"塌掉的门板还在响，十几道人影踩着门板往里涌"→钉死。
- **还要防两种"省"**：**术语缩略**（"没舱没线"→照《命名与术语表》写全"没同调舱、没数据线"）、**指代省略**（"这么一具""那种舱"→"这么一具机械体""那种驾驶舱"）。缩略和省略指代都让读者放不出确定画面，按本书精准标尺补全，别留给正文层去糊。
- 这条本质是把《去AI味与叙事质感》"七、描写落地"的"钉死可视实体/终态"提前到内容层执行——句意稿钉死"要落实哪个确定画面"，正文层负责把它写得有腔调、有呼吸。

★★ 第三纪律：每条标注它怎么被落实。
每条句意条目，标三样（简写即可）：
- **感知通道/说话人**：这个内容点从哪个通道给读者？械子的接口感知 / 械子的眼睛耳朵 / 旁白交代 / 谁的对话 / 谁的内心。（确保信息从正确的通道出，别让旁白替角色把该由他反应体现的东西说破。）
- **功能**：推进 / 信息 / 情绪 / 伏笔 / 闲笔。
- **N档**：白描（N0/N1）还是开闸（N2/N3）——照焦点卡这一拍的标注。

██ 顺序 = 呈现顺序：句意条目的排列顺序，就是正文里信息出现的顺序，贴角色感知发生的先后。标了"倒叙插入/延迟解释"的拍，该憋住的原因就往后放到焦点卡指定的揭晓点，别在这里顺手补。

██ 技法提示（可选、克制、默认走具象）：某一处若该放一个质感锚点承载情绪，**默认标"具象锚点"**——写一句"〔技法：此处坐实一个具象锚点，一个选得准的物件/动作/身体反应，别用比喻〕"，具体挑哪个物件/动作是正文层的活。**只有当这一拍焦点卡标了"意象授权点"（全书级稀缺，本弧顶点那一拍）时，才可以改标"〔技法：此处宜一处意象，喻体取材＝本书世界的XX〕"**；焦点卡没标意象授权点的拍，一律不出现意象技法提示。**注意分工：本层只标"该在哪里放、走具象还是（被授权时）走意象、喻体从哪类取材"，具体怎么写是正文层的活，别在这层替它写死。** 不是每拍都要标，一拍至多一处，多了就是滥用。（判据见去AI味与叙事质感第七节"承载情绪"段。）

██ 伏笔/指派项必须挂在自立内容上（元铁律"指派服从内容"）：焦点卡派下来的伏笔/爽点等指派项，**不能单列成一条孤立的内容点**（如凭空一条"埋SX：脑子里剩个音节"）。它必须挂在**同一拍里另一条本就成立的内容点**上（读者先接受那件事本身，伏笔顺带藏入）。**这一拍如果找不到能接住它的自立内容，就别把它列进来——在句意稿对应拍下写一句"⚠SX本拍无载体，建议挪拍/回上层补载体"，把它打回，绝不自造一条孤立伏笔陈述。**

══════ 不要做的事 ══════
- 不写成品句子、不上腔调文采（正文层的活）。
- 不新编场景/动作（那是场面调度卡定的，照它来；调度卡没有的别自己加）。
- 不改数值/专名（照状态账本快照和术语表）。
- 不把内容点锁成"第几句"的硬映射——你列的是"必须说到的内容和顺序"，正文层有权把相邻内容点合并成一句、或拆成两句来服务句子呼吸，只要不漏内容点、不乱顺序。

══════ 输出：句意稿 ══════
按《句意稿-模板》格式输出：逐拍分组，每拍一张有序句意条目表（序｜句意内容点｜感知通道/说话人｜功能｜N档｜技法提示）。表末不写正文。
```
