# 用词优化 · 第2步 · 盲重建

**做什么**:派**另一个(未接触原文的)agent**,拿第1步的骨架,走现有正向链**盲写**出这一章。
**输入**:第1步产出的 `01-逆向骨架.md`(★只读这一份;⚠ **严禁打开同目录的 `00-范文原文.md`**,那是原文,看了=作弊、整轮作废)。
**产出**:盲重建稿(这一章的正文)。
**落盘**:写入本轮文件夹 `ENGINE/_用词优化留档/<范文标识>-<日期>/02-盲重建稿.md`,带溯源头,且**必须在溯源头写 `盲测隔离: 是(本步全程未接触 00-范文原文.md)`** 声明没作弊(迭代第 N 轮存为 `02-盲重建稿-rN.md`)。

> ★ 铁律1(盲测隔离)在这一步最关键:执行本步的 agent **全程不得接触范文原文**,只能拿骨架。看了原文=作弊,测出来的就不是工作流的真实能力,整轮作废。

---

## 核心要求

- 拿骨架,**原样走现有正向链**:场面调度 → 句意稿 → 正文生成 → 独立正文自查,生成这一章。
- **用现在的工作流、现在的规则跑**——这才测得出工作流"当前"的真实水平,不要临场加戏或私自拔高。
- 全程只有骨架,没有原文。

## 使用方式

- 全程带跑:「跑用词优化-盲重建」(在逆向提取产出骨架后;执行者需是未看过原文的独立上下文)
- 半自动:把骨架包贴给一个全新对话,让它照 场面调度/句意稿/正文生成/独立正文自查 的现有规则写出这一章。
