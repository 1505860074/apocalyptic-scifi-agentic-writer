# P1 · 世界观与金手指

**做什么**：同时定下末世的物理规则和主角的金手指。世界观中的科技脉络直接决定金手指的形态，放在一起设计更自然。
**产出**：`01-设定/世界观设定卡.md` + `01-设定/金手指卡.md`

---

## 使用方式
- 全程带写：「进入P1」
- 半自动：复制下方【提示词正文】，连同 `K1-平台与题材规律.md` 的内容一起发给大模型。

---

## 提示词正文

```
你是资深番茄男频网文策划，擅长末世科幻·基建避难所流。

【背景资料】
- 平台：番茄小说，男频，目标12-18岁初高中生，手机端碎片阅读。
- 读者刚需：精神解压+安全感。吃"主角掌控全局/降维打击/建避风港"。
- 末世文吃集体主义，别写成纯自私爽文。灾变逻辑要简单可信。

【任务一：世界观（物理层定死，真相层留白）】

设计两个层面：

A. 物理事实（必须定死——这是故事的地基）：
  - 灾变是什么、怎么发生的（一句话说清，简单可信）
  - 灾变后的世界变成什么样了（威胁体系：初级→中级→终极，为长线留空间）
  - 势力地图（含官方/军方残余）
  - 科技/力量体系的基本规则
  → 产出《世界观设定卡》

B. 大秘密（只给模糊方向，不定死——这是故事生长的土壤）：
  - 灾变的真正原因是什么？给出2-3个可能的方向（如"AI失控""外星造物""人类实验反噬"），每个方向一句话。写正文时你会慢慢发现哪个方向最对。
  - 金手指的来历：同样只给2-3个模糊方向。
  → 记录在设定卡的"待揭示"栏，不锁死。

先给我2-3个不同风格的"世界观方向"备选（各一句话概括+差异化亮点），让我选一个，再展开。

【任务二：金手指（机制定死，来历留白）】

基于选定的世界观，设计主角的科技金手指：

A. 机制（必须定死——这是读者爽感的引擎）：
  - 金手指能做什么、怎么用
  - 滚雪球路径：从简陋到宏大的升级阶梯（分阶段）
  - 合理限制：能量/冷却/材料/前置科技——保留资源紧张感
  - 三性检查：成长性（能一路升级）、掌控感（主角说了算）、建设感（能滚雪球造避风港）

B. 来历（只给模糊方向，不定死）：
  - 它是从哪来的？为什么选中主角？给出2-3个可能方向。
  → 产出《金手指卡》，来历栏标注"待揭示"

先给我2-3个金手指方案备选（各含机制+滚雪球路径+限制+差异化亮点），我选定后再细化。

【产出格式】
- 世界观卡：灾变类型 / 灾变后世界 / 威胁体系 / 势力地图 / 科技体系 / 价值内核 / 【待揭示】灾变真相方向（2-3个）+ 金手指来历方向（2-3个）
- 金手指卡：机制 / 三性说明 / 滚雪球路径（分阶段）/ 限制 / 【待揭示】来历方向（2-3个）
```
