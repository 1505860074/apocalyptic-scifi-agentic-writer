# 世界观与金手指

**做什么**：同时定下本书世界的物理规则和主角的金手指。世界观中的力量/科技脉络直接决定金手指的形态，放在一起设计更自然。
**产出**：`01-设定/世界观设定卡.md` + `01-设定/金手指卡.md` + `01-设定/命名与术语表.md`（命名调性 + 已产生的核心术语登记）

> **总纲约束**：动手前先读 `00-立项/立项书.md`。世界观与金手指必须服从立项书定下的题材/核心命题/爽点引擎/文风/差异化方向——与立项书冲突的方向不采用。下方【提示词正文】里的背景默认值（题材/调性等预设），若和立项书不一致，一律以立项书为准。

---

## 使用方式
- 全程带写：「进入世界观与金手指」
- 半自动：复制下方【提示词正文】，连同 `平台与题材规律.md` 的内容一起发给大模型。

## 提示词正文

```
你是资深网文策划。

【立项书（总纲，最高优先级）】
（粘贴 00-立项/立项书.md 全文——题材、核心命题、目标读者/平台、爽点引擎、文风、差异化都以它为准。下面的背景资料是默认值，和立项书冲突时以立项书为准。）

【背景资料】
- 平台：番茄小说，男频，目标12-18岁初高中生，手机端碎片阅读。
- 读者刚需：精神解压+安全感。吃"主角掌控全局/降维打击/一路滚雪球做大"。
- 调性贴题材（有的题材吃集体主义、别写成纯自私爽文；有的吃个人逆袭——以立项书为准）。核心设定逻辑要简单可信。

【任务一：世界观（物理层定死，真相层留白）】

设计两个层面：

A. 物理事实（必须定死——这是故事的地基）：
  - 灾变是什么、怎么发生的（一句话说清，简单可信）
  - 灾变后的世界变成什么样了（威胁体系：初级→中级→终极，为长线留空间）
  - 势力地图（含官方/军方残余）
  - 科技/力量体系的基本规则
  → 产出《世界观设定卡》

B. 大秘密（只给模糊方向，不定死——这是故事生长的土壤）：
  - 灾变的真正原因是什么？给出2-3个可能的方向（如"AI失控""外星造物""人类实验反噬"），每个方向一句话。写正文时你会慢慢发现哪个方向最对。
  - 金手指的来历：同样只给2-3个模糊方向。
  → 记录在设定卡的"待揭示"栏，不锁死。

先给我2-3个不同风格的"世界观方向"备选（各一句话概括+差异化亮点），让我选一个，再展开。

【任务二：金手指（机制定死，来历留白）】

基于选定的世界观，设计主角的科技金手指：

A. 机制（必须定死——这是读者爽感的引擎）：
  - 金手指能做什么、怎么用
  - 滚雪球路径：从简陋到宏大的升级阶梯（分阶段）
  - 合理限制：能量/冷却/材料/前置科技——保留资源紧张感
  - 三性检查：成长性（能一路升级）、掌控感（主角说了算）、建设感（能滚雪球做大）

B. 来历（只给模糊方向，不定死）：
  - 它是从哪来的？为什么选中主角？给出2-3个可能方向。
  → 产出《金手指卡》，来历栏标注"待揭示"

先给我2-3个金手指方案备选（各含机制+滚雪球路径+限制+差异化亮点），我选定后再细化。

【任务三：命名调性 + 核心术语登记（按 命名与术语表 模板）】

世界观和金手指定完，通常已经自然产生了一批需要专有名词的东西（灾变现象、金手指、关键地点/势力）。这一步做两件事：

1. **定命名调性**（开书定死，之后基本不变）：
   - 本书专有名词的整体风格基调（口语化/古典/科技/民俗……，选一个别混），举2-3个示例名。
   - 本书重点给哪些类别命名（能力·技能/组织·群体/地点·域/物品·黑话），随题材勾选，别全开。
   - 命名禁忌（不要生僻字堆砌/不要中英混搭/字数上限等）。
2. **登记已产生的核心术语**：把世界观卡、金手指卡里已经出现的专有名词登记进术语表，每个填清楚"指什么、为什么值得命名、绝不能被写成的别名"。

★ **克制原则（最高优先）**：专有名词是世界观的点缀，不是堆砌。只给"会反复出现、值得记住、能被传播"的东西命名，一次性的、不重要的东西用大白话描述。宁可少，不可滥。

先给我命名调性的2-3个风格备选（各举示例名），我选定后再登记术语。

【产出格式】
- 世界观卡：灾变类型 / 灾变后世界 / 威胁体系 / 势力地图 / 科技体系 / 价值内核 / 【待揭示】灾变真相方向（2-3个）+ 金手指来历方向（2-3个）
- 金手指卡：机制 / 三性说明 / 滚雪球路径（分阶段）/ 限制 / 【待揭示】来历方向（2-3个）
- 命名与术语表：命名调性（风格+命名哪些类别+禁忌）+ 核心术语登记（初始几个）
```
