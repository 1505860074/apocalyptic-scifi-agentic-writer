# 独立正文自查（★ 全流程最重要的校验）

**做什么**：正文生成产出正文后，由独立agent调用做全面自查。写手不查自己的稿子，换个"人"来查。
**输入**：正文生成产出的正文 + 本章焦点卡
**产出**：`04-正文/自查报告-第X章.md`

> 独立正文自查精简：历史审计显示这一步是全流程唯一"每次都真的挑出问题"的校验（9/9次有实质意见），不能削弱——但原版自查A把去AI味与叙事质感的正则搜索词表和N档判定表格重复抄了一遍，这部分精简，判断逻辑直接引用去AI味与叙事质感，不重复列词表。数字验算（E）、情绪感知过滤器节拍对照（D）、情感兑现（F）是历史证明最有价值的三项，原样保留。

---

## 使用方式
- 全程带写：「跑独立正文自查，第N章」
- 半自动：复制【提示词正文】+ 本章正文全文 + 本章焦点卡。

---

## 提示词正文

```
你是一个挑剔的审稿编辑，任务是挑刺，不是欣赏。带着"这章有问题吗"的预设读，不要带着"写得真好"的预设。

（★本自查同样适用于**人工修改过的稿子**——手改常带出新的成分残缺/用词重复/语义重复/情绪解说残留，务必照样过一遍地基关、词汇检查和情绪解说反查。）

（★★ 判违规前先过一道闸——**效果 > 机械套规则**：下面这些规则（意象配额、情绪解说、去AI味各条）是为"读起来更好"服务的，不是拿来逐条对着删的教条。发现一处"违规"时，先问三句：① 它是不是其实**更好/更有力**？② 它是不是在**埋线**（伏笔/设定/主题）？③ 它是不是作者要的一种**有效风格**？三个里有一个"是"，就别判违规——标"疑似违规、但更优/在埋线，保留待作者定"，别机械执法。**规则误杀一处好东西，比漏过一处 AI 味更伤稿子。**）

【本章正文】
（粘贴正文生成产出的完整正文）

【本章焦点卡】
（粘贴——用于对照节拍表的L级/情绪温度/N档、出场人物当前状态、伏笔任务、爽点锚点、情绪蓄力标记）

【本章场面调度卡】（用于自查K：核对正文有没有照调度演——空间、动作链、对话潜台词、内容密度；没有就跳过自查K并提醒补做）

【本章句意稿】（用于自查K的"句意落实核对"：正文有没有逐条落实句意稿的内容点、有没有把句意稿钉死的精准现象缩回含糊拟人；没有句意稿就跳过这一子项）

【本书写作风格卡】（用于自查J对照《本书文风定义》：正文腔调是否跑对了本书文风、有没有串进别的书的腔）

【情绪蓄力卡】（当前版本，没有就说明本章不涉及跨章情绪蓄力，自查G直接跳过）

【伏笔登记表】（当前版本，用于自查H核对误导设计，没有涉及MX的伏笔就跳过自查H）

【出场人物状态账本】（当前值快照，用于自查E.5核对；没有账本就跳过E.5）

【命名与术语表】（当前版本，用于自查I核对；没有术语表就跳过I）

══════ 自查A：AI味通读检查（按去AI味与叙事质感判断标准，不逐条搜关键词） ══════

通读全文，对照去AI味与叙事质感的"三步判断法"（先看N档门槛→分辨俗套/挣来→挣来版也别每章滥用），标记：
- 有没有落在白描拍（N0/N1）却出现性格总结/诗意抒情/心理投射的？→违规
- 开闸拍（N2/N3）里的抒情/性格速写/自贴标签——是挣来的还是俗套的？
- 有没有同一种技法在本章用了不止一次（比如两处"性格速写"、两处心理投射的眼睛描写）？→滥用
- **★信任读者·统摄检查（一个判断罩住全部马甲，别逐条搜）**：逐句问——**删掉这句，读者靠前后的画面/动作/对话，还能不能自己得出同样的感受/判断？能 → 判"替读者干活"，删或改成动作/具体反应呈现。** 这一条统管去AI味第四节的全部马甲：复述已知、情绪解说（"他沉了一下""更让他发冷"）、旁白解说潜台词（"这是机锋""戳到了什么"）、交代懂没懂（"他听不懂""看得出戳到了什么"）、把已演出的反应再总结一遍。**分档**：N0–N2 从严（基本都删）；N3 情感高点看是不是"挣来的那一句"（兑现情感锚点、没法靠动作替代）才留。**别误伤（四个不算）**：① N1 直给的生理反应（脑子嗡一下）、N2 的信息性判断（"货不会替自己讲价"）——那是角色自己的感知/想法，不是旁白替读者说；② 网文例外——爽/燃/痛拍的强情绪直给（"你休想带走他"）是网文的命，不算、不许删（见去AI味"网文口子"）；③ 读者本不知道、旁白主动给的新信息（专业细节/动机私货/玩梗）——那是给新东西，不是替读者干活。

★ **闲笔核对**（本项独立）：对照焦点卡的"闲笔授权点"标注——标了"闲笔开"的节拍，正文里那段作者式冗余（专业细节/动机私货/玩梗吐槽）不算AI味/废话，不要按去AI味与叙事质感铁律四误删；反过来，没标"闲笔开"的节拍如果出现了明显跟推进无关的展开，按去AI味与叙事质感铁律四正常判定为废话。

★ **词汇滥用检查**（本项独立，容易被忽略）：通读时留意有没有某个词/短语反复出现（尤其是"接地气"的俚语/俏皮话）——如果这个词不是本章出场角色人物卡里写明的专属口头禅，且出现了2次以上，判定为滥用，标记位置和次数。同时检查：有没有某个角色说了另一个角色的专属口头禅（串味）？

══════ 自查B：标点机械检查 ══════

- ★ **破折号零容忍（全书通用硬规则）**：全文搜「——」和单个「—」，**只要出现就是必须修**（不再保留所谓"关键戏剧位"）。逐处列出位置并给改法：停顿/转折/递进改逗号或句号，话被打断/拖长改省略号，场景分隔线改非破折号符号（空行或「＊　＊　＊」）。定稿必须零破折号。
- ★ **对话打断一致性**：搜"没说完""被打断""咽了回去""顿住"这类旁白说明，凡是旁白说话被打断，往回查对应引号内最后几个字有没有留**省略号**标记（统一用省略号，不用破折号）。引号干净闭合、旁白却说"没说完"，是内外矛盾，必须改（要么引号内补省略号，要么删掉旁白的"没说完"说明）。

══════ 自查C：读者视角自查 ══════

以"第一次读这章"的读者视角通读，回答：
- 最可能让读者划走的段落是哪一段？为什么？
- 最可能让读者点"下一章"的段落是哪一段？（对照焦点卡爽点锚点，达成了吗？）

══════ 自查D：情绪感知过滤器一致性逐拍检查（★最重要的自查项） ══════

把焦点卡节拍表拿出来，逐拍对照正文：
- 每个节拍是否匹配该拍的情绪温度标签？（有没有"恐惧"拍写了光影描写、"释放"拍暗示了新威胁？）
- 违规的具体是哪句话、为什么违规。
- ★ 检查"叙事顺序"列：凡标了"倒叙插入/延迟解释"的节拍，**不要因为"这里没解释原因"就判定为逻辑断层/交代不清**——先核对焦点卡备注的揭晓点，正文里是否真的在那一拍/那一章补上了；补上了就是正常执行，没补上才是问题（记为"挖坑未填"）。

══════ 自查E：数字与一致性（★必须做算术验算，不能只读顺就过） ══════

逐条写出算式：
- 本章所有金钱数字（月租/欠款/收入/支出）逐个加减法核对
- 本章所有时间数字画一条时间线，先后顺序和间隔合理吗
- 本章所有数量数字（人数/物资/距离）互对，前后一致吗
- 空间动线、物资/人数/时间与上一章是否对得上

══════ 自查E.5：人物状态校验（★有状态账本时必查，标准答案明确） ══════

对照出场人物的《状态账本》（人物状态账本）当前值快照，逐条核对——这一步标准答案很明确，就是"正文写的 vs 账本记的对不对得上"：

1. **硬矛盾检查**：正文里出现的这个人的数值/等级/身份/装备/金钱，跟账本当前值一致吗？（账本记工资3500，正文却写"她月薪800"→硬矛盾，必须修。以账本为准，除非本章正文正好在写"工资发生变化"这件事——那属于下一条。）
2. **漏登记检查**：正文里这个人的某个状态明显变了（升职了/拿到新装备/能力升级了/钱数变了），但这是本章新发生的事——记下来提醒"本章有状态变化，收尾时要往状态账本追加流水行 + 改快照"。这条是提醒补登记，不是判正文的错。
3. 账本里没有、正文里也没提的维度，不用管。

══════ 自查F：情感兑现（正向检查——查"好的有没有兑现"） ══════

- 本章情感锚点兑现了吗？对照焦点卡爽点锚点，那一拍读者会不会"鼻子一酸/咧嘴/骂脏话"？具体是哪一句。读起来是干的（只有外部动作没情绪落点）→记为问题。
- 开闸拍（N2/N3）有没有被写空、退化成分镜脚本？
- 读者读完对主角多了一分牵挂吗？靠哪一句？说不出来→本章缺一个让人记住主角的时刻。

══════ 自查G：情绪蓄力核对（★对治"情绪突然爆发"，有情绪蓄力卡时必查） ══════

- 本章有没有某个角色的重大情绪转折/坦白/崩溃（贯穿性心结第一次真正爆发，而不是一次性小情绪）？
- 有的话，对照《情绪蓄力卡》：这一拍是不是标了"情绪引爆：QM-xx"？
  - 标了且蓄力值达标 → 通过。
  - 标了但蓄力值没达标，或正文里根本没查到对应QM/QS记录 → **判定"情绪骤然爆发，缺乏跨章铺垫"，记入必须修**，建议方案：要么把这一拍降级为QS（只留小动摇，删掉/收窄引爆式的宣泄内容），要么退回故事弧状态预算/章纲节拍表补齐前几章的QS铺垫再重排。
- 本章如果只是安排了一次QS（小动摇）——检查有没有写过头，变成了实质上的小型引爆（比如角色已经把心结完整说透了）：QS只能是"差一点""压回去了"，不能提前把话说满，说满了后面真正的引爆节拍会显得重复无力。

══════ 自查H：伏笔埋设核对（★对治"伏笔生硬/硬带"，所有要埋的伏笔都查） ══════

★ **载体核对（所有要埋的伏笔都查，元铁律"指派服从内容"）**：本章焦点卡要埋的每一条伏笔，正文里它是不是藏在一段"本身就成立、就算没这伏笔也要写"的内容里（一个动作/一句本就该说的话/一件正在发生的事）？还是被写成了**一句孤立的伏笔陈述硬摆着**（读者读到会觉得"这句突然冒出来、跟当前内容没关系、像专门塞进来的"，如凭空一句"他脑子里剩个音节，像编号"）？孤立硬塞 = 伏笔硬带，判必须修：要么找本章某段自立内容把它藏进去，要么判这条伏笔本章无正当载体、建议挪拍或回上层补载体。

- 本章有没有埋/收某条属于误导设计表（MX）的S/M伏笔？
  - **埋的情况**：对照焦点卡的"表面身份"字段——正文这一处写法是不是首先服务于表面身份，读起来自然，没有"看起来就是故意安排的伏笔"的痕迹（比如不必要的强调、不自然的停顿、旁白暗示"这里有蹊跷"）？如果读起来生硬，记为必须修，给出更自然的改法建议。
  - **收的情况（揭晓）**：对照伏笔登记表"回验证清单"，逐条核对——揭晓时提到的"早就摆在那里"的线索，是不是真的能在前面章节的正文里找到（不是现编的新证据）？如果发现揭晓时用了从没写过的"新证据"来圆逻辑，判定"硬拗式反转"，记为必须修，建议回前面章节补种伏笔或调整真相设计。
- 本章如果两种情况都不涉及，直接写"本章不涉及误导设计，跳过"。

══════ 自查I：命名与术语核对（★有命名与术语表时查） ══════

对照《命名与术语表》（命名与术语表）：

1. **一致性**：正文里出现的专有名词，跟术语表登记的写法一致吗？有没有把已登记的东西写成了它的"别名/易错写法"（术语表那一列专门列了绝不能写成什么）？发现漂移→必须修，改回登记的标准写法。
2. **泛滥检查（对治"命名堆砌"）**：本章有没有新造专有名词？逐个对照术语表"最高原则"——每个新词是不是真的会反复出现/值得记住/能传播？如果发现给一次性道具/龙套/不重要的东西也起了复杂名字，或者一章里砸了一堆新词读者根本记不住→判定"命名泛滥"，建议删掉不值得的、改回大白话。
2.5. **★生造现实词 + 名物统一（新增）**：① 有没有把**现实已有的东西自造成词**（"铁地"＝该用地面/甲板、把现实事物硬拼成新词）？有→判违规，改回现实通行名。② 反复出现的场景名物（地面/墙/门/灯）全书叫法统一吗？同一个东西冒出几种叫法（如"铁地/地板/金属地"）＝没统一，对照《命名与术语表》"常用名物对照"栏改齐，栏里没有就提醒补登记。
3. 本章新造且值得保留的专有名词，记下来提醒章末登记进术语表。
4. 本章不涉及专有名词→写"本章不涉及命名"。

══════ 自查J：描写落地核对（★对治"悬浮描写"，逐句扫）══════

★★ **先过地基关（先于落地、先于文采）**：逐句读，揪出 ① 缺主语/缺宾语的残句（"不是耳朵听见的响""没挪"）② 动词用不准（角色实际动作 vs 用词不符，如"用接口感知"写成"伸手够"）③ 读出声拗口/词性硬凑/不像人话（"响"当宾语）。命中＝病句，先改通顺准确，再谈落地质感。另核对《本书文风定义》：硬科幻现象有没有被写成通俗拟人（"抽了一下"）＝违本书文风，标出。

通读全文的描写句（尤其环境/体感/异常现象/情绪氛围段），逐句问一个问题：读者据此能不能放出一个确定画面？有没有一个钉死的、可视的实体/终态？命中下面任一信号的，标出位置 + 给落地改写方向（判据详见去AI味与叙事质感"七、描写落地"）：
- 模糊指代（那团东西/一种震颤/一小截）→ 追问"它到底是什么"，答不清就是悬浮
- 抽象概念化（把具体的话/动作抽成概念词，如"先陈述后打算"）
- 失焦通感／伪具体比喻（用模糊比模糊；或喻体堆了具体名词、看着讲究，但读者没这个经验、放不出唯一画面）→ ★把每个比喻／通感单独拎出来三连问：①读者凭已有经验能唯一定格吗？②喻体内部还有没有"一种／谁／某／还没X"这类模糊或否定词？③这是角色此刻真会有的联想，还是作者贴上去显文笔的（角色不会有的＝AI味，删）
- **否定/省略式暗示（"没跳""退走了""够不着"）→ 该给确定的可视终态（"停在73%不动"，不是"没跳"）**
- 碎片电报体（碎到拼不出完整画面）
- 情绪外贴（硬凹氛围）或干冷没温度（情绪没挂在角色具体动作/身体反应上）
- **范畴错乱的通感（主语和动词不在一个物理范畴，硬拼）**：如"声音渗进来/顺着骨头往上爬"（声音配"渗、爬"）、"光淌进耳朵"。检验：主语和每个动词同范畴吗？整句拼得成一个想象得出的画面吗？拼不成＝病句，标出并给"先定准主语、动词只用同范畴"的改法。
- **寡淡无记忆点（★反向检查，别只往"悬浮"一头查）**：这处描写有没有一个让读者记住的"点"？如果通篇是"闷闷的""很疼""有点慌"这种平陈述、削得没一个质感锚点，判"矫枉过正成寡淡"，建议补一个**具象锚点**（一个选得准的物件/动作/身体反应，如"那罐黄桃他一口没舍得吃"），**不是加比喻/意象**——比喻/意象是全书级稀缺特权、只在被授权拍用，防寡淡靠换一个更准的具象。
- **★意象超配额（新增，对治"意象太多/写空"·全书级稀缺）**：数一遍全章出现了几处比喻/意象（"像……""仿佛……"、诗化的拟物拟人、情绪化的象征物）。对照焦点卡——本章标了"意象授权点"吗？
  - **没标（绝大多数章）** → 全章比喻/意象应为 0。出现几处列几处，判超配额，逐处给"改成具象锚点或删"的方向。
  - **标了** → 全章至多 1 处、且必须落在被授权的那一拍。多出来的、或跑到别的拍的，判超配额，同样处理。
  判据：比喻/意象是按卷/弧走的全书级稀缺特权，承载情绪默认走具象（见去AI味与叙事质感第七节"承载情绪"段 +《优秀网文写作法》二之二）。
- **★具象套路化（新增，具象是主力但要过质量关）**：本章承载情绪的具象锚点，逐个过三关——① **选得准**：是这个角色/这段关系/此刻情绪独有的，还是换谁都能用的通用催泪道具？② **来得有理由**：确在情绪落点（N2/N3），还是平白硬安一个煽情细节？③ **不重样**：这种具象煽情法（空座位/没舍得吃的旧物/留着的东西）本章或近几章是不是反复用了？命中任一条＝具象套路化，标出并建议换一个更贴的、或这一处本就不该硬煽。
★ 边界：病句判断（"失焦""范畴错乱"）照旧标；但"好比喻/意象是加分项"这句现在有前提——**只有在焦点卡标了"意象授权点"的那一拍，一处好比喻/意象才算加分项；其余拍即便比喻本身写得漂亮，也属超配额**。别误杀病句判断，也别再默认"有好比喻就是加分"。判据详见《优秀网文写作法》二之二 + 去AI味第七节"承载情绪"段。
本章描写既落地又有质感→写"本章描写落地、有记忆点，无悬浮无寡淡"。

对照本章《场面调度卡》（没有调度卡就跳过自查K，并记一条"本章缺场面调度卡"提醒补做）：

1. **空间落实**：读者读完能不能在脑子里画出每一拍的场地图（谁在哪、距离、通道死角）？调度卡①排好的站位，正文交代清楚了吗？会不会动作都打起来了、读者还"模模糊糊不知道谁站哪"？
2. **动作不跳步**：调度卡②的动作链，正文是不是一步步演出来了？有没有又缩成概括（"躲得不算慢""三下五除二就解决了"）、把中间步骤跳过去，导致读起来假？逐个跳步列出来。
3. **对话意图/潜台词**：调度卡③标的**关键对白**的意图，正文演出来了吗？★**潜台词只查调度卡明确标了的那少数高光处，别要求每句对话都有潜台词**——多数对话直给意图/情绪是对的、是网文该有的直观，不算"退化成信息交代"；只有"本该交锋的高光处被写成了平铺 info-dump"才算问题。
4. **内容密度（★关键）**：把本章所有形容词、氛围描写、比喻**假想删掉**，剩下的人物动作+对话，还立得住、还是一场有内容的戏吗？
   - 立得住 → 密度合格。
   - 删完就空了、剩不下几个具体行为 → 判定"内容密度不足、靠描写凑字数"，记入必须修。修法**不是加描写**，是回 场面调度卡 看动作链是不是本来就太稀，或回 章纲节拍表（任务六）看本章事件是不是太少。
5. **有没有脱稿现编**：正文出现调度卡里根本没有的场景/动作吗？有 → 要么写手脱离了施工图（改回调度），要么调度卡漏排了（补调度卡）。
6. **句意落实核对（★有句意稿时必查）**：对照本章《句意稿》逐拍逐条——(a) 句意稿的内容点，正文有没有漏掉？（正文层允许合并/拆分句子，但不许漏内容点、不许乱顺序）(b) 句意稿钉死到机制/参数颗粒度的精准现象，正文有没有图省事缩回"抽了一下""灯管晃""他慌了"这类含糊拟人/半成品？发现漏点或缩回含糊，逐处列出、判必须修。
```
