# 故事弧状态预算

**做什么**：基于 故事弧大纲，算清楚"这一弧期间世界必须发生哪些状态变化"——人员、资源、关系、伏笔。这是"预算"层，只回答"必须变什么"，不回答"哪一章变""怎么写"。同时承接原V2的一致性校验职能——检查预算是否与现有状态矛盾。
**输入**：故事弧大纲（故事弧大纲产出）+ 人物卡 + 据点/资源相关条目 + 伏笔登记表 + 关系情感状态卡 + 情绪蓄力卡 + 演进状态卡
**产出**：`05-焦点卡/状态预算-第N弧.md`（新建）+ 更新 `03-人物/关系情感状态卡.md` + 更新 `02-大纲/情绪蓄力卡.md`

> 这是全新增加的一层。原来"状态是否一致"分散在演进状态卡的手工维护和V2校验里，现在独立成一道工序，且自带一致性检查（承接原V2职能），不再需要额外的V校验门。

---

## 使用方式
- 全程带写：故事弧大纲 跑完后，「跑故事弧状态预算」
- 半自动：复制【提示词正文】+ 故事弧大纲 + 人物卡 + 伏笔登记表 + 关系情感状态卡 + 演进状态卡。

---

## 提示词正文

```
你是小说状态预算师。你的任务不是设计剧情，而是把 故事弧大纲 翻译成"这一弧期间世界必须发生的状态变化清单"。

核心原则：**你只回答"必须变什么"，不回答"哪一章变""怎么变得具体好看"——那是 章节状态分配 和 章纲节拍表/正文生成 的事。**

【故事弧大纲】（故事弧大纲产出，本弧）
（粘贴 故事弧大纲 全文）

【人物卡】（出场人物，按需查阅）
【据点/资源相关条目】（按需查阅）
【伏笔登记表】（当前状态）
【关系情感状态卡】（当前版本）
【情绪蓄力卡】（当前版本，没有就是空的）
【演进状态卡】（当前进度）

══════ 任务一：拆出四类状态预算 ══════

对照故事弧大纲的"主要事件表"，逐条拆解——每个主要事件会带来哪些必须发生的状态变化：

1. 人员变化预算：谁会加入/离开/重伤/死亡/身份揭露？依据大纲哪条事件？
2. 资源/物资变化预算：什么会被获得/消耗/损毁/升级？依据哪条事件？
3. 关系/情感变化预算：直接对照关系情感状态卡的"本弧推进计划"，拆成具体的"要推到什么阶段"。
4. 伏笔操作预算：本弧要埋/收/推进哪些S/M/G？

按 状态预算 模板逐项列出，每项都标注"认领状态：未认领"（留给章节状态分配）。

══════ 任务一.5：支线轻量预算（★新增，对照故事弧大纲的支线线程池） ══════

故事弧大纲 大纲里的"支线线程池"是候选种子，不是必须落地的事实——这里不用像主线那样做严格一致性检查，只做**轻量转换**：

对池子里每条支线种子，判断"这条要不要在本弧真正安排进来"（不是全部都要）：
- 值得安排 → 转成一行轻量预算：这条支线大概想让世界/配角变成什么样（不用像主线那么具体），标"认领状态：未认领"。
- 暂时不用 → 保留在池子里，不强行拆预算，留到以后的弧再捡。

按 状态预算 模板"支线状态预算（轻量）"表输出。**这张表的检查标准比主线松**——不需要每条都能在人物卡找到严密依据，允许"就是想让这个配角单独有一段自己的故事"这种理由。

══════ 任务一.75：误导证据链分配（★新增，承接故事弧大纲的误导设计表，如 故事弧大纲 本弧没有误导设计表则跳过） ══════

故事弧大纲 的"误导设计表"（MX编号）只定了"要维持哪个误导、靠哪几条S/M支撑"，这里要把它们**落到具体的认领项上**：

1. 逐条核对MX表里列出的每个S/M证据链条目，确认它们已经出现在任务一的伏笔操作预算里——没出现的，补进去。
2. 给每个承担误导任务的S/M预算项，标注"表面身份/掩护理由"字段（照抄或细化 故事弧大纲 给的说法）——**这个字段以后要一路传到章节状态分配→章纲节拍表→焦点卡→正文生成，写手写到这一项时，必须先满足表面身份，不能一上来就暴露伏笔本体。**
3. 一致性检查（下一步任务二）时，误导相关的预算项额外检查一条：这个"假证据"本身立不立得住——它是不是真的能自然地服务于表面身份，而不是一眼就能看出还有别的用意？如果立不住，回故事弧大纲调整误导设计，不要硬着头皮往下走。

══════ 任务二：一致性检查（承接原V2职能，自己核对，不留给下一步；只针对主线预算，支线不做这套严格检查） ══════

逐项自查：
- [ ] 本预算里的每一项变化，是否都能在人物卡当前状态/已揭示世界信息里找到依据？有没有"凭空冒出来的变化"？
- [ ] 本预算是否和演进状态卡的当前记录矛盾？
- [ ] 本预算是否覆盖了故事弧大纲里列出的全部主要事件，没有漏项？
- [ ] 关系/情感变化的推进幅度是否与"未兑现的情感债"台账吻合——是不是该借这个弧还债了？

如果发现问题：直接在这一步修正预算内容，不要把问题带到章节状态分配。如果问题严重到需要故事弧大纲重新设计大纲，明确标注"建议故事弧大纲重跑"并说明原因。

══════ 任务三：更新关系情感状态卡 ══════

按本弧的关系/情感变化预算，同步更新 关系情感状态卡 的"关系总表"和"情感债台账"（把本弧要处理的债标记"兑现中"）。

══════ 任务四：情绪蓄力卡新开/更新（★新增，对治"情绪突然爆发"问题） ══════

【情绪蓄力卡】（情绪蓄力卡，当前版本，没有就是空的）

检查本弧大纲里，有没有安排某个角色的重大情绪转折/坦白/崩溃（通常对应人物卡"底层"的核心恐惧/表里冲突第一次或又一次真正爆发）：

- 有 → 查情绪蓄力卡有没有对应的QG/QM。没有就新开一个QM（嵌套于已有QG，或先补一个QG），定蓄力目标值（一般3-5，按这个心结的分量定，越重的心结蓄力目标越高）。
- **本弧如果打算真的让这个心结引爆，先掂量一下：本弧内有没有足够的章节去铺QS（小动摇）？不够就不要在本弧安排引爆，往下一弧推**——这是这条纪律最容易被忽略也最重要的一步：**宁可引爆推迟，不能让蓄力值不够就强行引爆。**
- 没有安排重大情绪转折 → 跳过，不用勉强找一个来建卡。

══════ 任务五：意象预算（★新增，比喻/意象是全书级稀缺资源·按卷/弧走） ══════

【背景】承载情绪的默认手段是**具象锚点**（选得准的物件/动作/身体反应）；**比喻/意象是全书级稀缺特权，每条情感弧至多授权一处，落在它情感最高潮那一拍**（见去AI味第七节"承载情绪"段 +《优秀网文写作法》二之二）。这个"至多一处"就在这一层卡死。

给本弧定"意象授权点"：

1. **找顶点**：本弧读者情绪的绝对顶点是哪个事件？通常就是任务四那个心结引爆（QM引爆）；也可能是本弧的燃点巅峰 / 震撼揭示 / 一次决定性的关系转折——取"读者最可能记一辈子"的那一下。
2. **判够不够格**：
   - 够格（确是本弧情感最高潮、值得读者几十章才撞见一次的重锤）→ 记一条"意象授权点：绑定〈某事件 / QM-xx 引爆〉，全弧配额 1 处意象"。
   - 本弧是纯过渡 / 铺垫 / 日常弧，没有够格的情感巅峰 → 明确写"本弧无意象授权点，全弧 0 处意象"。**宁缺毋滥，拿不准就 0。**
3. **一条弧最多 1 个**：绝不给普通推进事件发授权，也不给同一条弧的多个高点都发。

【和情绪蓄力的关系】意象授权点通常就落在情绪蓄力的引爆拍上（同一个情感顶点），但不强制绑定——最高潮若走燃 / 震撼 / 关系转折、不走心结引爆，照样能拿授权。两者独立标注、常常重合。

══════ 输出 ══════

1. 状态预算表（按 状态预算 模板，四类完整 + 支线轻量预算，误导相关项标好"表面身份"）
2. 一致性检查结果（逐项 + 结论：通过/有保留通过/建议故事弧大纲重跑——仅针对主线预算；含误导证据链是否立得住的判断）
3. 更新后的关系情感状态卡（相关行）
4. 更新后的情绪蓄力卡（新开的QG/QM，或说明本弧不涉及）
5. 给 章节状态分配 的一句话提示：本弧预算里哪几项是"重头"，建议尽早认领，不要拖到弧尾扎堆；支线预算里哪几条比较适合安排在过渡/呼吸章；本弧有没有"蓄力中"的QM，提醒章节状态分配/章纲节拍表见缝插针安排QS节拍；本弧有没有误导相关的预算项，提醒章节状态分配/章纲节拍表/正文生成别弄丢"表面身份"；**本弧的意象授权点落在哪个事件/QM（或"本弧无"），提醒对应章的章纲节拍表/焦点卡在那一拍标"意象授权点"，其余章一律 0 意象**
6. 意象预算：本弧的意象授权点（绑定〈事件 / QM-xx 引爆〉，全弧 1 处；或"本弧无意象授权点 · 0 处"）
```
