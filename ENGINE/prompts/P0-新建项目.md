# P0 · 新建项目

**做什么**：从 ENGINE 模板初始化一个新的 BOOKS 子项目，创建完整目录结构和空白模板文件。

**适用场景**：开始一本新书时，这是第一步。

---

## 操作步骤

### 步骤 1：创建目录结构

在 `BOOKS/` 下创建以书名命名的文件夹，包含以下子目录：

```
BOOKS/书名/
├── 01-设定/          ← 世界观设定卡、金手指卡
├── 02-大纲/          ← 故事种子、世界基底、演进状态卡、伏笔DAG、章纲
├── 03-人物/          ← 主角卡、配角卡
├── 04-正文/          ← 每章正文
└── 05-焦点卡/        ← 每章焦点卡
```

### 步骤 2：复制模板文件

从 `ENGINE/templates/` 复制以下模板到对应目录，并按说明重命名：

| 模板 | 复制到 | 重命名为 | 用途 |
|------|--------|----------|------|
| T1-世界观设定卡.md | 01-设定/ | 世界观设定卡.md | 物理规则、灾变机制 |
| T2-金手指卡.md | 01-设定/ | 金手指卡.md | 金手指机制、限制、成长阶梯 |
| T3-故事种子.md | 02-大纲/ | 故事种子.md | 一句话方向 + 模糊分卷方向 |
| T6-世界基底.md | 02-大纲/ | 世界基底.md | 物理事实（空间结构/规则） |
| T7-演进状态卡.md | 02-大纲/ | 演进状态卡.md | 活文件，追踪写作进度 |
| T10-伏笔DAG.md | 02-大纲/ | 伏笔DAG.md | 伏笔登记与依赖追踪 |
| T4-人物卡-核心.md | 03-人物/ | 主角-xxx.md | 主角卡（xxx 替换为主角名） |

### 步骤 3：填充模板

依次运行以下三个步骤填充空模板（不可跳步）：

1. **「进入P1」** → 同时设计世界观 + 金手指，填写世界观设定卡和金手指卡
2. **「进入P2，先做主角」** → 建人物种子，填写主角卡；需要配角时再追加
3. **「进入P3」** → 收束故事种子和世界基底

### 步骤 4：开始写作循环

P3 完成后的下一批操作：

- **「跑P4」** → 基于 P3 产出生成第一批局部章纲（第4-8章）
- **「写第1章」** → 进入 P5→P6→P7 日更循环
- 每写完 3-5 章回到 P4 演进一次

---

## 注意事项

- **模板是空壳**——复制后必须经过 P1/P2/P3 才能填出有实际内容的工作文件
- **不要跳过 P3**——P3 把 P1+P2 的产出收束为可执行的第一批章纲，是新书的"点火"步骤
- **P4 替代了旧模式的"定死全书蓝图"**——不要试图在动笔前写完整本大纲
- 完整工作流说明见 `ENGINE/00-工作流总览.md`

---

## 操作话术

| 想做什么 | 说什么 |
|----------|--------|
| 开始一本新书 | 「进入P0，书名叫《XXX》」 |
| 从设定开始 | 「进入P1」→ 填世界观和金手指 |
| 做人物 | 「进入P2，先做主角」 |
| 点火开工 | 「进入P3」→ 收束种子 |
| 看接下来往哪走 | 「跑P4」 |
| 写正文 | 「写第N章」→ 自动 P5→P6→P7 |
