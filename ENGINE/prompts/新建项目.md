# 新建项目

**做什么**：从 ENGINE 模板初始化一个新的 BOOKS 子项目，创建完整目录结构和空白模板文件。

**适用场景**：开一本新书时，**先跑「立项工坊」**（立项问答 → 立项自查）定下这本书的命题/风格/主要内容并产出《立项书》，再跑本步 新建项目 建目录。新建项目 是"立项之后、写设定之前"的搭骨架步骤。

---

## 操作步骤

### 步骤 1：创建目录结构

在 `BOOKS/` 下创建以书名命名的文件夹，包含以下子目录：

```
BOOKS/书名/
├── 00-立项/          ← 立项书（★立项工坊已产出，新建项目 只需确认其存在，不要覆盖）
├── 01-设定/          ← 世界观设定卡、金手指卡
├── 02-大纲/          ← 故事种子、世界基底、演进状态卡、伏笔登记表、章纲
├── 03-人物/          ← 主角卡、配角卡
├── 04-正文/          ← 每章正文
└── 05-焦点卡/        ← 每章焦点卡
```

### 步骤 2：复制模板文件

从 `ENGINE/templates/` 复制以下模板到对应目录，并按说明重命名：

| 模板 | 复制到 | 重命名为 | 用途 |
|------|--------|----------|------|
| 世界观设定卡-模板.md | 01-设定/ | 世界观设定卡.md | 物理规则、灾变机制 |
| 金手指卡-模板.md | 01-设定/ | 金手指卡.md | 金手指机制、限制、成长阶梯 |
| 人物状态维度定义-模板.md | 01-设定/ | 人物状态维度定义.md | 本书追踪哪些状态维度（故事种子与世界基底定死，随题材可配置） |
| 命名与术语表-模板.md | 01-设定/ | 命名与术语表.md | 命名调性（世界观与金手指定）+ 专有名词登记（增量，克制不泛滥） |
| 写作风格卡-模板.md ★ | 01-设定/ | 写作风格卡.md | **本书文风层（③）**——★不是空壳复制，见下方「步骤 2.5」按选定文风包实例化 |
| 故事种子-模板.md | 02-大纲/ | 故事种子.md | 一句话方向 + 前三章 + 模糊分卷方向 |
| 世界基底-模板.md | 02-大纲/ | 世界基底.md | 物理事实（空间结构/规则） |
| 演进状态卡-模板.md | 02-大纲/ | 演进状态卡.md | 活文件，追踪写作进度 |
| 伏笔登记表-模板.md | 02-大纲/ | 伏笔登记表.md | 伏笔登记与依赖追踪（G/M/S三级）+ 误导设计表 |
| 人物卡-核心-模板.md | 03-人物/ | 主角-xxx.md | 主角卡（三层，只写短期不变的设定） |
| 人物卡-普通-模板.md | 03-人物/ | 配角-xxx.md | 配角卡（双层，只写短期不变的设定） |
| 人物状态账本-模板.md | 03-人物/ | 状态账本-xxx.md | 一人一个，追踪随剧情频繁变的状态（快照+流水），故事种子与世界基底建主角+核心配角的 |

> 注：章纲节拍表-模板.md 和 焦点卡-模板.md 不需要手动复制——章纲节拍表/焦点卡 运行时会自动生成对应格式的产出文件到 `02-大纲/` 和 `05-焦点卡/`。
> 关系情感状态卡、状态预算、情绪蓄力卡也是运行时（故事弧状态预算）生成，不在这里手动复制。

### 步骤 2.5：实例化《写作风格卡》（★把文风包落到这本书）

《写作风格卡》(`01-设定/写作风格卡.md`) 是本书文风层（③），**不是空壳复制，而是"按选定文风包实例化"**：

1. 读《立项书》#8 里选定的**文风包**（如 通俗少年向 → `ENGINE/文风库/通俗少年向/`）。
2. 复制 `templates/写作风格卡-模板.md` 到 `01-设定/写作风格卡.md`，把选定文风包的 `00-文风配置`（9维参数取值 + 声音定位 + 适配题材）与 `01-风格纪律` 的要点**灌进模板对应栏**。
3. 把立项书#8 定死的**叙事人称/视角**写进风格卡第二节。
4. override 区默认留空（完全继承包默认）；若立项时已知这本书要偏离包某几维，在 override 区写明。
5. 若立项选的是"自定义/新建"，先按 `文风库/_文风库总览.md` 第五节建好文风包，再回来实例化。

> 三层关系：通用引擎层(①，knowledge)讲"怎么写好" → 文风包(②，文风库)讲"这一类声音" → 写作风格卡(③，本书)讲"这一本书"。正文生成加载时，③＞②＞①。

### 附加目录（空文件夹，后续自动填充）
- `04-正文/` → 正文生成 产出章节正文
- `05-焦点卡/` → 焦点卡步骤产出每章焦点卡

### 步骤 3：填充模板

依次运行以下三个步骤填充空模板（不可跳步）。**这三步都要先读 `00-立项/立项书.md`，产出必须服从立项书定下的命题/题材/文风/差异化方向**：

1. **「进入世界观与金手指」** → 同时设计世界观 + 金手指，填写世界观设定卡和金手指卡
2. **「进入人物种子，先做主角」** → 建人物种子，填写主角卡；需要配角时再追加
3. **「进入故事种子与世界基底」** → 收束故事种子和世界基底

### 步骤 4：开始写作循环

故事种子与世界基底 完成后的下一批操作：

- **「跑故事弧大纲，开第1弧」** → 基于 故事种子与世界基底 给的黄金三章方向，设计第1个故事弧的大纲（第一次可不必先跑世界线宏大推演）
- **「写第1章」** → 进入 章纲节拍表→焦点卡→正文生成→润色定稿 日更循环
- 一个故事弧写完（命中弧收尾判定）→ 回 故事弧工坊 开下一弧

---

## 注意事项

- **模板是空壳**——复制后必须经过 世界观与金手指/人物种子/故事种子与世界基底 才能填出有实际内容的工作文件
- **不要跳过 故事种子与世界基底**——故事种子与世界基底 把 世界观与金手指+人物种子 的产出收束为可执行的第一批章纲，是新书的"点火"步骤
- **故事弧工坊替代了旧模式的"定死全书蓝图"**——不要试图在动笔前写完整本大纲
- **每次写作对话第一轮加载 `铁律总纲.md`**——这是从全部文件中提取的核心规则压缩版，优先级最高
- 完整工作流说明见 `ENGINE/工作流总览.md`

## 操作话术

| 想做什么 | 说什么 |
|----------|--------|
| 开始一本新书（立项） | 「进入立项，书名《XXX》」→ 逐维度选择题定命题/风格/内容 |
| 立项体检 | 「跑立项自查」→ 通过再进 新建项目 |
| 搭目录骨架 | 「进入新建项目，书名叫《XXX》」（立项之后） |
| 从设定开始 | 「进入世界观与金手指」→ 填世界观和金手指 |
| 做人物 | 「进入人物种子，先做主角」 |
| 点火开工 | 「进入故事种子与世界基底」→ 收束种子 |
| 看接下来往哪走 | 「跑故事弧大纲，开第1弧」 |
| 写正文 | 「写第N章」→ 自动 章纲节拍表→焦点卡→正文生成→润色定稿 |
