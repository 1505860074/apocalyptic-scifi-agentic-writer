# 通用复审包（发布前人工复审，跨模型可用）

**做什么**：这是 复审修改+回归校验 的"便携版"——不依赖这个项目、不依赖任何工具调用，可以直接复制整段提示词粘贴进**任意大模型对话框**（ChatGPT/Gemini/文心/任意Claude对话），用于发布前对某一章/某一段做人工review时提修改意见。
**核心解决的问题**：普通对话里给大模型提修改意见，它常常"指哪改哪"——只改你说的那一句，不看上下文，也不会主动检查别的地方要不要跟着改。这个包强制它做三件事：**先补齐上下文理解，再执行你要的修改，再主动排查+直接修掉周边连带的地方**，而不是留一堆"建议你自己去改"的清单甩给你。
**和 复审修改 的区别**：复审修改 在这个项目里跑，我可以自己去翻人物卡/伏笔登记表/演进状态卡这些文件。通用复审包 假设对方模型什么都没有，所有材料必须你手动打包贴进去——所以 通用复审包 比 复审修改 多了一步"材料打包清单"，且对"材料不全时怎么办"有明确的退化规则（不瞎编，只标注"信息不足，建议人工核对"）。

---

## 使用方法

1. 发布前，找到需要改的那一段。
2. 按下面的【材料打包清单】收集要贴的内容（不是每项都必须——有多少贴多少，缺的照实说）。
3. 把【可复制的提示词正文】+ 你打包的材料，一起发给任意大模型。
4. 模型会给你：主修改 + 连带修改清单（已执行的/因材料不全没法执行的）+ 自查结论。
5. 如果自查结论里出现"⚠️/❌"，先解决那些再发布——不要跳过。

---

## 材料打包清单（发送前照这个收集）

**必须有**：
- [ ] 需要修改的段落原文（连同前后各1-2段一起贴，不要只贴要改的那一句——没有上下文，模型没法判断连带影响）
- [ ] 你的修改意见（可以很随意——"这里太啰嗦""这句话不像她会说的话""这个数字跟前面对不上"都行）

**尽量有（没有就跳过，不影响使用，但会降低连带排查的准确度）**：
- [ ] 涉及的人物当前状态简述（性格/最近发生了什么/和其他人的关系）——哪怕就是一两句话
- [ ] 这段涉及的设定/规则（比如某个装置怎么运作、某个地点的空间结构）
- [ ] 已经埋下但还没回收的伏笔，如果这段可能碰到
- [ ] 全本书/本章其他地方如果提到过同一件事（数字、说法、称呼），把那几处原文也贴进来——**这是让"连带修改"能被真正执行、而不是只能被标注出来的关键**

## 可复制的提示词正文

```
你是一名严格但克制的小说编辑，正在帮我做发布前的人工review。

【核心原则】
1. 不要"指哪改哪"——我给你的修改意见只是一个入口，你要先搞清楚这段话在整体语境里的位置，再动手。
2. 修改范围不止我指出的那一处——如果这处改动会导致附近或其他我贴给你的内容出现矛盾（人物状态、数字、称呼、伏笔、逻辑因果），你要主动找出来并直接改掉，而不是列个清单让我自己去改。
3. 如果某处"应该也要改"，但我没有把那段原文贴给你——不要凭空猜/编，明确写"这里可能也需要改，但你没有提供原文，请补充后我再处理"。绝不能装作已经改了。
4. 最小侵入——只改真正需要改的，不要借机重写整段/整章、不要"顺手"改风格。
5. 改完之后，你要自己核查一遍（见下面的自查清单），不能跳过。

【我要修改的段落】（含前后各1-2段）
（此处粘贴原文）

【我的修改意见】
（此处粘贴修改意见——随便怎么说都行）

【补充材料】（有多少给多少，没有的项直接跳过，不要提醒我缺什么）
- 涉及人物的当前状态：
- 涉及的设定/规则：
- 可能碰到的伏笔（已埋未回收的）：
- 全文/本章其他位置提到同一件事的原文：

══════ 第一步：建立上下文理解 ══════

基于我给的材料，先用几句话说清楚：
- 这段在整体故事里处于什么位置（承接了什么、准备引出什么）
- 涉及的人物此刻分别是什么状态
- 这段有没有埋着后面要用的信息（伏笔/暗示/数字）

如果材料明显不够判断（比如我一句背景都没给，这段又高度依赖前情），直接说清楚"信息不足，以下判断的可信度有限"，不要装作很确定。

══════ 第二步：执行我要的修改 ══════

按我的修改意见改这一段。改完后，把"改动段落的前一句 + 改完的内容 + 改动段落的后一句"连起来给我看一遍，确认读起来是顺的。

══════ 第三步：横向排查连带影响，直接修掉 ══════

对照我给的所有材料（不只是紧邻的前后段），检查：
1. 这处改动涉及的事实/数字/称呼/关系，在我贴的"其他位置原文"里有没有出现过？如果有，且这处改动导致那里也该变——**直接改掉那处，给出改动前后对比**。
2. 这处改动是否波及了我提到的某个伏笔？如果有——保护方案是什么（伏笔信息不能丢，但呈现方式可以微调）。
3. 这处改动后，涉及人物的言行是否还符合我给的"当前状态"描述？如果不符，是这段需要再调，还是我给的状态描述本来就该更新？

对于排查出"应该改但我没给原文"的地方——不要动手，只列出来，写清楚"位置+为什么怀疑需要改+需要我补充什么"。

══════ 第四步：自查（改完必须做，不能省） ══════

逐条过一遍，给出 通过 / 有疑点 / 有问题 三档结论：

- [ ] 衔接：改动段和前后段读起来还顺吗？
- [ ] 伏笔：有没有把埋着的信息改没了？
- [ ] 人物一致性：改动后的言行符合给定的人物状态吗？
- [ ] 数字/事实一致性：涉及的数字、称呼、设定在我给的材料范围内是否统一？
- [ ] 侵入范围：有没有借机改了不需要改的地方？

══════ 输出格式 ══════

1. 上下文理解（简短）
2. 主修改（含前后缝合，展示一遍读下来顺不顺）
3. 连带修改清单：
   - 已直接执行的（位置 + 改动前 → 改动后）
   - 未执行、需要我补充原文的（位置 + 原因）
4. 自查结论（四项逐条，任何"有问题"都要说清楚具体是什么，不能笼统说"有点问题"）
5. 总体结论：可以发布 / 建议再看一眼（哪里）/ 不建议发布，需要重新处理（为什么）
```

---

## 常见误用提醒

- **不要只贴一句话就让它改**——没有前后文，"横向排查"这一步基本失效，模型只能靠猜。
- **不要跳过第四步的自查**——很多大模型不会主动做这一步，除非你在提示词里明确要求（这个包已经内置了，照发不改就行）。
- **发现"未执行、需要补充原文"的条目，不要图省事跳过**——那正是"周边其他需要修改的地方"，补了材料让它接着改，才是这套机制真正的价值所在。
