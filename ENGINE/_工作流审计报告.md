> 目的：找出"会把成品写得不像真人"的规则、冗余可删的步骤、方向错了在拖累成品的步骤。

## 0. 总诊断：两个系统病 + 一个反直觉的关键点

**病一 · 方向性绝对命令 → 过冲成反向 AI 味。**
工作流治 AI 味的方式，大多是发"单向绝对命令"——"更短！""删情感！""禁 X！""搜到就删"。agent 很听话，把每条命令推到极端，于是**冲过头、撞进相反的另一种 AI 味**。已见两例：去情感 → 正文写空（已用 N 档修）；极短破碎 → 一字一句 staccato（待修）。这是同一个病的反复发作。

**病二 · 校验/加工步骤过多且多处重复。**
日更 9 步（P5a→P5b→V3→P6→V4→P6fix→P7a→P7b→V5），其中 3 道独立校验门；数字算术验算在 4 个地方重复；V4 与 V5 大面积查同样的东西；P7 拆成两个必须独立调用的 agent。实跑下来，多步是空转或重复。

**★ 反直觉关键点：过度加工本身 = "干/不像真人"的来源。**
每一道去味/校验 agent 都倾向于"向均值回归"——磨平特异、机械执行规则、把不合模板的好东西当成 AI 味删掉（staccato 保护、V5 误删破折号都是实例）。**所以"精简步骤"不只是省 token，它直接是一条质量修复：加工链越短，人味被磨掉的机会越少。**

## A. 会把成品写"不像真人"的规则（知识层 · 最高优先级）

| # | 问题 | 在哪 | 病（都是"方向性绝对命令"的变体） | 改法 |
|---|------|------|------|------|
| A1 | **一字一句 staccato** | K9 恐惧节"极短破碎" + 它的**示例范本**（"没想。…膝盖磕了。没顾上。"）；P7b/K7 把恐惧断句列为"禁区保留" | 命令"更碎"，agent 碎到一个词一个句号。真人紧张是"逗号连成的急促流"，不是砸句号 | K9 恐惧节加边界"破碎≠单字独句，单字独句全章≤1处只给最重一下"；**换掉那个病例范本**；K7 把"单字独句堆"列进表演式描写（含恐惧）；P7b"恐惧断句保留"改成有上限 |
| A2 | **"情绪直给"被做成"只准写'他慌了'"** | K3 第3条、K0、P6 step16（step16 已部分用 N 档修） | 命令"别写空洞修饰"，agent 过冲成"只贴情绪标签、零质感" | 明确："直给"是砍"眼神闪过一丝复杂"这种空洞文艺腔，**不是**禁止用身体/动作/一句判断把情绪演出来；在 N2/N3 拍尤其要演不要贴 |
| A3 | **硬字数上限自相矛盾** | K3："一段纯叙述≤150字""一个场景≤600字""连续300字无对话"——同一份 K3 又说"句子长短由念出来决定，不由硬字数" | 硬数字命令逼 agent 切碎/硬塞对话，和"念出来"原则打架，强化 choppy | 把 150/300/600 这类硬上限降级为"参考"，统一以 K3 自己的"念出来顺不顺"为准 |
| A4 | **L3"凑够4项要素"→公式化深度** | K2 的 L3 写法要素清单 | 清单式命令 → agent 机械凑外部细节/身体反应/五感/…，像填表 | 说明"4项是下限提示、不是填空表"；深度靠这一下值不值得慢，不靠凑够项数 |
| A5 | **"对话≥40%"硬配额** | K3、K0、P6 | 机械配额，可能往紧张/恐惧段硬塞吐槽凑比例 | 降为"整章大势"参考，明确恐惧/追逐段的留白不算违规（实跑里已默认处理，但规则没写清） |

> 共性修法（治本）：**把所有"去AI味"规则从"单向命令"改成"双边有界目标"**——短要有下限、删要留边界、直给要有质感。并且 **agent 抄示例甚于读规则，务必把 K 文件里"示范成极端"的例子逐个换掉**（重灾区＝K9 恐惧示例）。

## D. 精简后的日更管线建议（9 步 → 5~6 步）

```
现在： P5a → P5b → V3 → P6 → V4 → P6fix → P7a → P7b → V5
        （9 步，3 独立校验门，多处重复）

建议： P5(a+b 可保留拆分) → V3(轻·填全没) → P6 → V4(唯一数字/自查权威关)
        → P7(合并一道·带N档+N3禁区+软标点) → [V5 条件触发·仅查润色是否弄坏]
        （核心防幻觉关 V4 保留；P6fix 默认跳过；V5 大多数章跳过）
```
好处：加工链短一半，token 省一半，**而且成品被"磨平"的机会也少一半**。
