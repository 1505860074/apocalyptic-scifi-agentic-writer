# K9 · 情绪感知过滤器

> **这是写作时最重要的参考卡。** 每个节拍的情绪温度不只是"文字节奏"——它是一套感知规则：决定了角色在此刻的注意力和感知半径。什么进入文本，什么被过滤掉。

---

## 核心原理

**感知半径 = 情绪状态的函数。**

一个正在逃命的人，不会注意到阳光的颜色、空气的味道、旁边架子上摆着什么。他的世界坍缩到了威胁源和逃生出口。

一个刚打完胜仗的人，会突然注意到战友脸上的表情、风吹过来的感觉、刚才有多惨现在有多爽的对比。

这不是"文风选择"——这是**真人感知的底层规律**。AI味的本质，是写了一个逃命的人却在描述光影。

---

## 两轴：L 级 与 N 档（写作前必须分清）

过去只有一根「细化等级 L」，它同时管了两件本来无关的事，导致"恐惧的 L3"这种自相矛盾（L3 要你进内心，恐惧不让你进内心）。现在拆成两根**互相独立**的轴：

| 轴 | 管什么 | 档位 | 定义在哪 |
|----|--------|------|----------|
| **L 级** | 镜头拉多近、展开多细、篇幅、慢镜头 —— 只管**节奏与画面密度**，不管进不进内心 | L0 一笔带过 → L3 慢镜头 | K2 细化等级体系 |
| **N 档** | 允许多少**内心与抒情** | N0 → N3 | 本卡（K9） |

**两轴自由组合**：恐惧高潮 = `L3 + N0`（慢镜头，但零内心）；救人成功的情感锚点 = `L3 + N3`（既慢又全开）；过渡句 = `L1 + N1`。**L 和 N 各标各的，谁也不强制谁。**

### N 档四级阶梯（逐级累加，高档包含低档允许的内容）

| N 档 | 允许写到哪 | 明确禁止 |
|------|-----------|----------|
| **N0 零内心** | 只有外部动作 + 感官（看/听/触/嗅 + 外显的身体本能：手抖、后退、僵住） | 任何"脑子里的东西"——想法、判断、评论、回忆、比喻、给情绪命名 |
| **N1 即时反应** | N0 + **1 拍**当下的生理-情绪反应，直给且短（"脑子嗡一下""后脖子发凉""腿一软"） | 判断/决定的内心独白、前史闪回、抒情比喻、性格总结 |
| **N2 内心独白** | N1 + 一两句此刻的想法/盘算/判断/决定（"三个。就在楼上。他天天路过"） | 前史闪回、抒情/诗化比喻、情绪沉淀、性格速写 |
| **N3 情绪全开** | N2 + 前史闪回 + 情绪沉淀 + 挣来的比喻 + 性格速写 | 无硬禁——但受 K7 的"挣来"质量关 + 每章配额约束 |

### 情绪温度 → 默认 N 档（P5b 做焦点卡时查这张表，把 N 档钉进每个节拍）

| 情绪温度 | 默认 N | 说明 |
|----------|--------|------|
| 恐惧 | **N0** | 逃命间隙最多 N1；禁一切内心独白/比喻/回忆 |
| 紧张 | **N1** | 只即时反应，不展开判断 |
| 压抑 | **N1（憋着的 N1）** | 允许"被放大的知觉 + 负面预感"，但**禁抒情、禁幽默、禁诗化比喻** |
| 平静 | **N2** | 可内心独白、闲笔、吐槽 |
| 释放 / 燃 | **N2** | 若这一拍正好是爽点锚点 → 升 **N3** |
| 震撼 / 揭示 | **投放瞬间 N0 → 余韵 N2~N3** | 一个节拍拆成两拍两档：信息投放时零内心（角色滞后），信息消化的余韵才开内心 |
| 〔情绪落点 / 情感锚点〕 | **N3** | 不是第七种情绪，是"释放/震撼/暖"里那一个 S-2 锚点拍的特殊高配——焦点卡在锚点拍直接标 N3 |

> **给写手的一句话**：写每一拍前，先看焦点卡上这一拍的 N 档数字，照 N 档那一行的"允许/禁止"写。**你不判断"该不该动情"——你只认那个数字。** 判断在 P5b 定焦点卡时就做完了。

## 六种情绪温度的感知规则

### 平静

| 项目 | 规则 |
|------|------|
| 感知半径 | 大——周围环境、远处的声音、身体的小动作 |
| 信息准入 | 环境细节 ✅ / 闲笔 ✅ / 物品描述 ✅ / 气味 ✅ / 身体小动作（蹭汗、叼烟）✅ |
| 信息排除 | 无 |
| 句子行为 | 自然舒展。这是唯一允许"停下来看一眼"的情绪。可以写闲笔。 |
| **判断标准** | 这段如果删掉，会损失角色日常感的铺垫吗？如果不会——说明不是平静节拍该写的。 |

**示例**：
> 常安把最后一颗螺丝拧进去，用袖子蹭了蹭脸上的汗。桌上那台军绿色旧工控机嗡了一声。屏幕亮了。他把嘴里叼着的半截烟拿下来，笑了——一块钱一斤收来的破烂，还真能亮。

---

### 紧张

| 项目 | 规则 |
|------|------|
| 感知半径 | 收缩到一米以内。反复确认行为。异常声音被放大，无关背景被忽略。 |
| 信息准入 | 异常声音 ✅ / 反复检查行为 ✅ / 身体本能反应 ✅ / 逃生路径 ✅ |
| 信息排除 | 环境颜色 ❌ / 无关物体 ❌ / 天气/气味（除非与威胁有关）❌ / 大段环境描写 ❌ |
| 句子行为 | 短，有确认式的重复。注意力跳——从一件事跳到另一件，不展开。 |
| **判断标准** | 读者读完这段，心跳有没有比读上一段快一点？ |

**示例**：
> 常安摸了两下才摸到手机，拇指按上去。没亮。又按了一下。还是没亮。他把手机翻过来——壳子缝里正在往外渗东西。灰白色的，细得像粉笔末。他捻了捻。凉的。

---

### 恐惧

| 项目 | 规则 |
|------|------|
| 感知半径 | 坍缩到威胁源。世界只剩三件事：①威胁在哪 ②我怎么跑 ③我的身体怎么了。 |
| 信息准入 | 威胁源的每一个细节 ✅ / 逃生出口/路径 ✅ / 身体反应（心跳/冷汗/颤抖/呼吸）✅ |
| 信息排除 | 威胁以外的一切 ❌ / 环境的颜色/光线/气味 ❌ / 回忆/联想/诗化比喻 ❌ / 任何与逃生无关的思考 ❌ |
| 句子行为 | 极短，破碎，少修饰。不允许在恐惧节拍写比喻句——除非是从角色视角直接判断威胁（"像生锈的齿轮"可以，但"像一幅油画"不行）。 |
| **判断标准** | 读者读这段的时候，有没有忘记自己在看小说？ |

**示例——正确**：
> 老张站起来了。不是"站起来"——是弹起来。膝盖还拧在那个角度。头歪过了。朝他迈了一步。常安跑了。没想。转身就跑。冲下楼梯。铁扶手哐当响。膝盖磕了。没顾上。

**示例——错误**（恐惧中写环境光影）：
> ~~老张朝他走来。窗外午后的阳光穿过卷帘门的缝隙，在水泥地上投下一道道淡金色的光斑。~~ ← 谁在逃命的时候看光斑？

---

### 压抑

| 项目 | 规则 |
|------|------|
| 感知半径 | 迟钝。世界变得钝而慢。小细节被放大——钟的滴答声、墙上的裂缝、自己的呼吸声。 |
| 信息准入 | 被放大的小细节 ✅ / 时间流逝感 ✅ / 物理上的闷/重/沉 ✅ / 负面预感 ✅ |
| 信息排除 | 全局视野 ❌ / 积极信息 ❌ / 幽默/吐槽 ❌ / 对策/方案 ❌ |
| 句子行为 | 句子像被压着，长而闷。允许描述时间变慢的感受。 |
| **判断标准** | 读者读完这段，有没有觉得胸口闷？ |

**示例**：
> 孢子浓度还在涨。洁净场的边界从墙根缩到楼梯口，又缩到二楼走廊。没人说话。老周靠着墙，闭着眼。小丫头缩在老头背后，攥着他的衣角。常安看着方舟屏幕上的数字，一秒跳一下。四一零。四一一。四一二。

---

### 释放/燃

| 项目 | 规则 |
|------|------|
| 感知半径 | 瞬间扩大。成果的细节被放大。身边人的反应被注意到。对比和反差浮现——"刚才多惨，现在多爽"。 |
| 信息准入 | 成果细节 ✅ / 同伴反应 ✅ / 对比反差（刚才→现在）✅ / 身体放松的感受 ✅ |
| 信息排除 | 负面信息 ❌ / 新威胁暗示 ❌ / 过度反思 ❌ |
| 句子行为 | 舒展，可以有长句。允许一句得意的吐槽。 |
| **判断标准** | 读者读到这里，会不会不自觉地咧嘴？ |

**示例**：
> 围墙立起来的那一刻，老周拄着铁棍站了三秒，然后骂了句脏话。修车的中年人一屁股坐在地上，仰头看着墙，嘴咧开了。常安没说话。他看了一眼方舟屏幕——【一号据点·防御评级：D级】。好家伙。D级。从零到D，就这几天的事。

---

### 震撼/揭示

| 项目 | 规则 |
|------|------|
| 感知半径 | 时间暂停。世界安静。注意力全部集中在那一个信息上。身体反应是滞后的。 |
| 信息准入 | 被揭示的信息本身 ✅ / 角色的身体反应（滞后）✅ / 声音突然变远/变静 ✅ |
| 信息排除 | 思考/分析/对策 ❌——这些是下一拍的事 |
| 句子行为 | 信息一行一行出来。角色不说话或只说一两个字。时间拉长。 |
| **判断标准** | 读者读完，会不会自己也停了一秒？ |

**示例**：
> 屏幕上绿色的字一行一行往外跳。
>
> 【警告：检测到高浓度数据尘。】
>
> 【当前区域浓度已达临界值。】
>
> 【暴露者将在数分钟内触发神经同步——大脑被覆写，躯体金属化。】
>
> 常安盯着屏幕，嘴唇动了两下。
>
> "……什么玩意儿？"

## 使用规则（P6 写正文时严格遵守）

1. **写每一段之前，先看焦点卡上本节拍的两个标签：情绪温度 + N 档。**
2. **按情绪温度加载本卡对应行的"信息准入/排除"表；按 N 档加载"N 档四级阶梯"对应行的"允许/禁止"。**
3. **写完后快速扫两遍**：① 有没有写了情绪温度"信息排除"区里的东西？② 有没有超出本拍 N 档允许的内心/抒情？有就删。不是改，是删。
4. **L 与 N 是两码事，别互相替代**：L3 只是"镜头拉近、慢下来"，不等于"要进内心"。恐惧的 L3 = 慢镜头 + N0，比 L2 更纯粹、更不该有内心闲笔；情感锚点的 L3 = 慢镜头 + N3，那里才开内心。**看 N 档决定进不进内心，别拿 L 级替 N 档做决定。**

## 常见违规对照表（自查用）

| 节拍情绪 | 常见违规（AI 最爱写的） | 为什么错 |
|----------|------------------------|---------|
| 恐惧 | 写光线/颜色/气味/环境 | 逃命的人不关心这些——他只关心威胁在哪、门在哪 |
| 恐惧 | 写诗化比喻（"像一只折翼的蝴蝶"） | 恐惧中大脑没有余裕做文学联想 |
| 紧张 | 写人物在紧张中突然想起往事 | 紧张时注意力被压缩——回忆需要平静 |
| 紧张 | 写大段环境铺垫 | 紧张是"确认威胁"状态，不是"观察环境"状态 |
| 压抑 | 写角色吐槽/冷笑话 | 压抑时幽默感关闭 |
| 释放 | 立刻暗示新威胁 | 让读者爽完——新威胁是钩子的事，不是释放节拍的事 |
