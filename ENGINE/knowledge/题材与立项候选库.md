# 题材与立项候选库

> **给"立项工坊-立项问答"当灵感底料。** 立项问答原来让模型每个维度凭空现场生成候选，模型即兴想会本能收窄到几个最眼熟的选项（题材一想就是末世/都市/玄幻），越冷门、越新兴融合越想不全。这份库把网文常见的大量题材/子类/玩法、以及各维度的丰富候选列出来，立项时**从库里取+组合+按这本书补充**，而不是从零想。
> 用法：立项问答走到某个维度时，先扫这份库对应小节，挑贴合的候选给作者，再按"这本书"的具体情况增删。库是灵感池，不是限制——作者的自定义永远优先。
> **冷热度标注**（帮作者既能选安全大盘、也能一眼看到新颖方向）：【大盘】主流主力、盘子大但竞争激烈；【饱和·慎入】写烂了、新人硬刚很难出头；【小众稳定】盘子不大但有稳定受众、竞争小；【新兴】近一两年上升、红利期、适合差异化。冷热度会随时间变，是参考不是定论。

### 融合玩法 / 新兴方向（差异化主战场，★重点给作者看）

> 现在纯单一题材越来越难出头，两种题材的"化学反应点"是最容易做出差异化的地方。列一批已被验证或正在上升的融合：

- 末世 + 种田治愈（灾难紧张感 × 囤货种田的安稳感，反差）【新兴·热】
- 科幻皮 + 爽文核（黑科技外壳，内里是打脸/升级爽点，降低硬科幻门槛）【新兴】
- 规则怪谈 + 职业（把一个真实职业的黑话/流程包进诡异规则里）【新兴·热】
- 冷门行业 + 灵异/悬疑（殡葬·古董·深海打捞·文物修复 × 超自然）【新兴】
- 发疯文学 + 任意题材（主角不按常理出牌、突破规则的叙事基调）【新兴·热】
- 无限流 + 情感/群像（副本轮回里做人物关系和牵挂，不只是闯关）【新兴】
- 历史考据 + 匠人/非遗（把真实工艺细节做成卖点）【小众·新兴】
- 反派/恶役视角 + 反套路（不当正派主角，写"注定要死的反派"如何翻盘）【新兴】
- 系统 + 反系统（主角识破/对抗/利用系统本身，而非乖乖做任务）【新兴】

## 使用规则（立项问答对照）

1. 走到"题材"维度：先给作者看**大类谱系**定位大方向 → 在选定大类下给**子类**候选（带冷热度）→ 单独提**融合玩法**候选（尤其当作者想要差异化/新颖时，重点推融合和【新兴】标注的）。
2. 其他维度：从对应候选池挑贴合的给作者，再按已定维度补充——不要只凭空想那几个最眼熟的。
3. 冷热度只是参考：作者要挑【饱和·慎入】的也行（只要差异化卖点够硬），要挑【新兴】的也行（红利大但风险是盘子可能不够）。你的职责是把利弊讲清楚，不是替作者拍板。
4. 这份库是"够不够宽"的底料，不是"必须选这些"的清单——作者的自定义永远优先。
