# 情绪感知过滤器

> **这是写作时最重要的参考卡。** 每个节拍的情绪温度不只是"文字节奏"——它是一套感知规则：决定了角色在此刻的注意力和感知半径。什么进入文本，什么被过滤掉。

---

## 核心原理

**感知半径 = 情绪状态的函数。**

一个正在逃命的人，不会注意到阳光的颜色、空气的味道、旁边架子上摆着什么。他的世界坍缩到了威胁源和逃生出口。

一个刚打完胜仗的人，会突然注意到战友脸上的表情、风吹过来的感觉、刚才有多惨现在有多爽的对比。

这不是"文风选择"——这是**真人感知的底层规律**。AI味的本质，是写了一个逃命的人却在描述光影。

---

## 两轴：L 级 与 N 档（写作前必须分清）

过去只有一根「细化等级 L」，它同时管了两件本来无关的事，导致"恐惧的 L3"这种自相矛盾（L3 要你进内心，恐惧不让你进内心）。现在拆成两根**互相独立**的轴：

| 轴 | 管什么 | 档位 | 定义在哪 |
|----|--------|------|----------|
| **L 级** | 镜头拉多近、展开多细、篇幅、慢镜头 —— 只管**节奏与画面密度**，不管进不进内心 | L0 一笔带过 → L3 慢镜头 | 细化等级体系体系 |
| **N 档** | 允许多少**内心与抒情** | N0 → N3 | 本卡（情绪感知过滤器） |

**两轴自由组合**：恐惧高潮 = `L3 + N0`（慢镜头，但零内心）；救人成功的情感锚点 = `L3 + N3`（既慢又全开）；过渡句 = `L1 + N1`。**L 和 N 各标各的，谁也不强制谁。**

### N 档四级阶梯（逐级累加，高档包含低档允许的内容）

| N 档 | 允许写到哪 | 明确禁止 |
|------|-----------|----------|
| **N0 零内心** | 只有外部动作 + 感官（看/听/触/嗅 + 外显的身体本能：手抖、后退、僵住） | 任何"脑子里的东西"——想法、判断、评论、回忆、比喻、给情绪命名 |
| **N1 即时反应** | N0 + **1 拍**当下的生理-情绪反应，直给且短（"脑子嗡一下""后脖子发凉""腿一软"） | 判断/决定的内心独白、前史闪回、抒情比喻、性格总结 |
| **N2 内心独白** | N1 + 一两句此刻的想法/盘算/判断/决定（"三个。就在楼上。他天天路过"） | 前史闪回、抒情/诗化比喻、情绪沉淀、性格速写、**情绪解说（旁白给情绪命名/点破/染色，如"他沉了一下""怕里掺进了别的东西"——情绪靠动作/事实呈现，别旁白说破；见去AI味第四节）** |
| **N3 情绪全开** | N2 + 前史闪回 + 情绪沉淀 + 性格速写；**承载情绪默认用具象锚点（一个选得准的物件/动作/身体反应）** | 无硬禁——但受 去AI味与叙事质感 的"挣来"质量关 + 每章配额约束。**★ 比喻/意象是例外不是标配**：只有焦点卡在本拍标了"意象授权点"（全书级稀缺、按卷/弧走，见去AI味第七节"承载情绪"段）才可放一处；没标＝禁比喻/意象，情绪走具象 |

### 情绪温度 → 默认 N 档（焦点卡 做焦点卡时查这张表，把 N 档钉进每个节拍）

| 情绪温度 | 默认 N | 说明 |
|----------|--------|------|
| 恐惧 | **N0** | 逃命间隙最多 N1；禁一切内心独白/比喻/回忆 |
| 紧张 | **N1** | 只即时反应，不展开判断 |
| 压抑 | **N1（憋着的 N1）** | 允许"被放大的知觉 + 负面预感"，但**禁抒情、禁幽默、禁诗化比喻** |
| 平静 | **N2** | 可内心独白、闲笔、吐槽 |
| 释放 / 燃 | **N2** | 若这一拍正好是爽点锚点 → 升 **N3** |
| 震撼 / 揭示 | **投放瞬间 N0 → 余韵 N2~N3** | 一个节拍拆成两拍两档：信息投放时零内心（角色滞后），信息消化的余韵才开内心 |
| 〔情绪落点 / 情感锚点〕 | **N3** | 不是第七种情绪，是"释放/震撼/暖"里那一个 S-2 锚点拍的特殊高配——焦点卡在锚点拍直接标 N3 |

> **给写手的一句话**：写每一拍前，先看焦点卡上这一拍的 N 档数字，照 N 档那一行的"允许/禁止"写。**你不判断"该不该动情"——你只认那个数字。** 判断在 焦点卡 定焦点卡时就做完了。
>
> **另记死一条（贯穿所有 N 档）**：情绪默认用**具象**承载——一个选得准的物件/动作/身体反应（"妹妹爱吃的黄桃罐头一口没舍得吃"），让读者自己撞上情绪，不"说"情绪。**比喻/意象只在焦点卡标了"意象授权点"的那一拍放一处**，那是全书级稀缺特权（按卷/弧走），别当每段的调味料。遇到"这段有点平"，第一反应是换一个更准的具象，不是加一个比喻。
>
> **再记死一条（呼应去AI味第四节·情绪解说）**：情绪靠动作/事实/对话**演**出来，旁白别替角色**说**出来——N0–N2 不写"他沉了一下 / 更让他发冷 / 明白过来一件事 / 怕里掺进了别的东西"这类情绪解说；N3 至多一句挣来的、且能靠动作演的就别用旁白。区分：N1 直给的生理反应（脑子嗡一下）、N2 的判断/盘算（"货不会替自己讲价"）不算情绪解说，保留。★**网文口子**：爽/燃/痛拍上的强情绪就该直给、扑面（"你休想带走他"），是读者要的即时反馈，不算情绪解说、不许删（见去AI味第四节"网文口子" + 铁律总纲 A-14）。删的只是低能量的絮叨点染。

## 六种情绪温度的感知规则

### 平静

| 项目 | 规则 |
|------|------|
| 感知半径 | 大——周围环境、远处的声音、身体的小动作 |
| 信息准入 | 环境细节 ✅ / 闲笔 ✅ / 物品描述 ✅ / 气味 ✅ / 身体小动作（蹭汗、叼烟）✅ |
| 信息排除 | 无 |
| 句子行为 | 自然舒展。这是唯一允许"停下来看一眼"的情绪。可以写闲笔。 |
| **判断标准** | 这段如果删掉，会损失角色日常感的铺垫吗？如果不会——说明不是平静节拍该写的。 |

**示例**：
> 他把最后一颗螺丝拧进去，用袖子蹭了蹭脸上的汗。桌上那台旧机器嗡了一声，亮了。他把嘴里叼着的半截烟拿下来，笑了——捡来的破烂，还真能使。

---

### 紧张

| 项目 | 规则 |
|------|------|
| 感知半径 | 收缩到一米以内。反复确认行为。异常声音被放大，无关背景被忽略。 |
| 信息准入 | 异常声音 ✅ / 反复检查行为 ✅ / 身体本能反应 ✅ / 逃生路径 ✅ |
| 信息排除 | 环境颜色 ❌ / 无关物体 ❌ / 天气/气味（除非与威胁有关）❌ / 大段环境描写 ❌ |
| 句子行为 | 短，有确认式的重复。注意力跳——从一件事跳到另一件，不展开。 |
| **判断标准** | 读者读完这段，心跳有没有比读上一段快一点？ |

**示例**：
> 他摸了两下才摸到手机，拇指按上去。没亮。又按了一下。还是没亮。他把手机翻过来——壳子缝里正在往外渗东西。灰白色的，细得像粉笔末。他捻了捻。凉的。

---

### 恐惧

| 项目 | 规则 |
|------|------|
| 感知半径 | 坍缩到威胁源。世界只剩三件事：①威胁在哪 ②我怎么跑 ③我的身体怎么了。 |
| 信息准入 | 威胁源的每一个细节 ✅ / 逃生出口/路径 ✅ / 身体反应（心跳/冷汗/颤抖/呼吸）✅ |
| 信息排除 | 威胁以外的一切 ❌ / 环境的颜色/光线/气味 ❌ / 回忆/联想/诗化比喻 ❌ / 任何与逃生无关的思考 ❌ |
| 句子行为 | 短、急、少修饰。**但"破碎"≠一个词一个句号地砸。** 真人的恐惧句是短句用逗号连成的**急促的流**（"他往后退，脚跟磕在棱上，膝盖一软，坐倒了"），不是"黑。近。静。"这样一串单字独句。（注：全书禁用破折号，急促的流一律用逗号连，不用破折号）**单字/短词独句全章最多 1 处，只留给最重的那一下。** 不允许写比喻句——除非是从角色视角直接判断威胁（"像生锈的齿轮"可以，"像一幅油画"不行）。 |
| **判断标准** | 读者读这段的时候，有没有忘记自己在看小说？（以及：念出来是"停不下来的急"，还是"一顿一顿的电报"？后者就是砸句号砸过头了。） |

**示例，正确**（短促，但逗号连成"停不下来"的流；全段只有"那东西弹了起来"一个短起手，没有一串单字独句）：
> 那东西弹了起来——膝盖还拧在那个反着的角度，却直冲他扑过来。他往后退，脚跟磕在台阶棱上，膝盖一软就坐倒了，两手在地上乱抓，一下一下往后蹭。他爬起来就跑，冲下楼梯，铁扶手哐当撞响，膝盖磕在棱上，顾不上疼。

**示例——错误其一**（一字一句砸句号，像读电报，不像人在慌）：
> ~~那东西弹起来了。膝盖拧着。头歪了。扑过来。他退。腿软。坐地上。爬。跑。~~ ← 每个词一个句号，紧张变成了做作。

**示例——错误**（恐惧中写环境光影）：
> ~~那东西朝他走来。窗外午后的阳光穿过卷帘门的缝隙，在水泥地上投下一道道淡金色的光斑。~~ ← 谁在逃命的时候看光斑？

---

### 压抑

| 项目 | 规则 |
|------|------|
| 感知半径 | 迟钝。世界变得钝而慢。小细节被放大——钟的滴答声、墙上的裂缝、自己的呼吸声。 |
| 信息准入 | 被放大的小细节 ✅ / 时间流逝感 ✅ / 物理上的闷/重/沉 ✅ / 负面预感 ✅ |
| 信息排除 | 全局视野 ❌ / 积极信息 ❌ / 幽默/吐槽 ❌ / 对策/方案 ❌ |
| 句子行为 | 句子像被压着，长而闷。允许描述时间变慢的感受。 |
| **判断标准** | 读者读完这段，有没有觉得胸口闷？ |

**示例**：
> 那威胁还在逼近。安全的范围一点点被压缩，从墙根缩到楼梯口，又缩到二楼走廊。没人说话。有人靠着墙，闭着眼。孩子缩在大人背后，攥着他的衣角。他盯着那个还在往上跳的数字，一秒跳一下。四一零。四一一。四一二。

---

### 释放/燃

| 项目 | 规则 |
|------|------|
| 感知半径 | 瞬间扩大。成果的细节被放大。身边人的反应被注意到。对比和反差浮现——"刚才多惨，现在多爽"。 |
| 信息准入 | 成果细节 ✅ / 同伴反应 ✅ / 对比反差（刚才→现在）✅ / 身体放松的感受 ✅ |
| 信息排除 | 负面信息 ❌ / 新威胁暗示 ❌ / 过度反思 ❌ |
| 句子行为 | 舒展，可以有长句。允许一句得意的吐槽。 |
| **判断标准** | 读者读到这里，会不会不自觉地咧嘴？ |

**示例**：
> 墙立起来的那一刻，有人拄着铁棍站了三秒，然后骂了句脏话。旁边那人一屁股坐在地上，仰头看着墙，嘴咧开了。他没说话，只是盯着眼前这道刚垒好的墙。好家伙。从零到有，就这几天的事。

---

### 震撼/揭示

| 项目 | 规则 |
|------|------|
| 感知半径 | 时间暂停。世界安静。注意力全部集中在那一个信息上。身体反应是滞后的。 |
| 信息准入 | 被揭示的信息本身 ✅ / 角色的身体反应（滞后）✅ / 声音突然变远/变静 ✅ |
| 信息排除 | 思考/分析/对策 ❌——这些是下一拍的事 |
| 句子行为 | 信息一行一行出来。角色不说话或只说一两个字。时间拉长。 |
| **判断标准** | 读者读完，会不会自己也停了一秒？ |

**示例**：
> 屏幕上的字一行一行往外跳。
>
> 【警告：已检测到异常。】
>
> 【当前区域数值已达临界。】
>
> 【继续暴露将无法逆转。】
>
> 他盯着屏幕，嘴唇动了两下。
>
> "……什么玩意儿？"

## 七、闲笔开关（作者式冗余，独立于情绪温度，★新增）

上面六种情绪温度里，只有"平静"默认允许闲笔——但这管的是"这一拍能不能停下来看一眼环境"，跟"要不要写一段跟推进无关、但让文本有作者个性的东西"（专业细节展开、动机的私人化解释、玩梗吐槽、看似离题的联想）不是一回事。人类作者的这类"废话"不看情绪温度脸色——压抑里能有一句冷幽默，震撼后的余韵能扯远一截，紧张前的间隙能有一句吐槽。

**闲笔开关是独立于情绪温度、独立于N档的第三个标签**，只有两个值：开 / 关，默认关。

- **谁来开**：焦点卡 设计焦点卡时，事件触发式地判断——这一拍有没有"由头"（角色手上正在干的专业相关的活、一个值得展开的世界观细节、一个适合玩梗/吐槽的由头）？有由头才开，没有硬找由头就不开。跟"性格速写触发点"是同一个逻辑：不是配额，是触发式授权。
- **开了能写什么**：这一拍可以放开写一段技术上"非必须推进剧情"的内容——但要挂在这一拍实际发生的事情上（角色在修一个东西，就借着这个动作科普一句原理；角色做了一个决定，就顺手带一句他自己才有的、有点怪的理由；场景里有个梗，就让角色或旁白调侃一句）。**不是无中生有地插入一段作者感想**。
- **恐惧/紧张/压抑拍的闲笔开关默认关**：这几种温度感知半径本来就收缩、且压抑明确禁幽默，开闲笔会破坏真实感或直接撞上该温度表已经定好的"信息排除"项。**闲笔开关不能凌驾于情绪温度的物理感知规则之上，它只是在平静/释放/震撼余韵这类本来就允许喘口气的温度里，多给一个"离题"的口子。**
- **频率**：跟去AI味与叙事质感的"挣来也别每章滥用"同一个纪律——闲笔开关一章顶多开1-2处，多了就是话痨，不是有个性。
- **判断标准**：删掉这一处闲笔，读者会不会觉得这个角色/这个世界变得更单薄、更没记忆点？会→留；纯粹是为了凑字数或者秀知识→删。

## 使用规则（正文生成 写正文时严格遵守）

1. **写每一段之前，先看焦点卡上本节拍的两个标签：情绪温度 + N 档。**
2. **按情绪温度加载本卡对应行的"信息准入/排除"表；按 N 档加载"N 档四级阶梯"对应行的"允许/禁止"。**
3. **写完后快速扫三遍**：① 有没有写了情绪温度"信息排除"区里的东西？② 有没有超出本拍 N 档允许的内心/抒情？③ 有没有出现比喻/意象、而这一拍焦点卡并没标"意象授权点"？有就删。不是改，是删（第③条也可换成一个选得准的具象锚点）。
4. **L 与 N 是两码事，别互相替代**：L3 只是"镜头拉近、慢下来"，不等于"要进内心"。恐惧的 L3 = 慢镜头 + N0，比 L2 更纯粹、更不该有内心闲笔；情感锚点的 L3 = 慢镜头 + N3，那里才开内心。**看 N 档决定进不进内心，别拿 L 级替 N 档做决定。**
5. **闲笔开关是第三个独立标签，别跟N档混**：N档管"进不进内心"，闲笔开关管"能不能借这一拍写点跟推进无关的作者式冗余"——两者互不替代，一拍可以是"N2 + 闲笔开"，也可以是"N2 + 闲笔关"。具体见本卡"七、闲笔开关"。

## 常见违规对照表（自查用）

| 节拍情绪 | 常见违规（AI 最爱写的） | 为什么错 |
|----------|------------------------|---------|
| 恐惧 | 写光线/颜色/气味/环境 | 逃命的人不关心这些——他只关心威胁在哪、门在哪 |
| 恐惧 | 写诗化比喻（"像一只折翼的蝴蝶"） | 恐惧中大脑没有余裕做文学联想 |
| 紧张 | 写人物在紧张中突然想起往事 | 紧张时注意力被压缩——回忆需要平静 |
| 紧张 | 写大段环境铺垫 | 紧张是"确认威胁"状态，不是"观察环境"状态 |
| 压抑 | 写角色吐槽/冷笑话 | 压抑时幽默感关闭 |
| 释放 | 立刻暗示新威胁 | 让读者爽完——新威胁是钩子的事，不是释放节拍的事 |

## 八、情绪蓄力——为什么有些"释放/震撼"节拍读起来像突然转折

**本卡到目前为止管的都是"单个节拍此刻该怎么写"——但没有回答一个更上游的问题：这个节拍的情绪浓度，是凭空来的，还是攒出来的？**

如果一个角色的坦白/崩溃/爆发，前面没有任何铺垫，只是这一章刚好排到了"释放"温度，就直接让角色说出压了很久的心里话——读者会觉得"转折得莫名其妙"，哪怕这一拍本身单独看完全符合情绪感知过滤器的N3写法规则（不硬、不悬浮、挣来的情感落点）。**症状对，病根不对**：问题不出在这一拍怎么写，出在这一拍有没有资格写。

- **判断标准**：这个情绪节拍，是不是某个角色贯穿多章的核心心结（对应人物卡"底层"字段）第一次真正爆发？如果是，它不能凭空出现——前面必须能查到至少几次"小动摇"的信号（一次没说出口、一次异常沉默、一次差点绷不住又压回去），这条链路由《情绪蓄力卡》（情绪蓄力卡）追踪，跟伏笔登记表的S/M/G三级嵌套是同一个逻辑，只是追踪的是情绪而不是剧情信息。
- **使用时机**：章纲节拍表设计节拍表时，如果打算安排某个心结的"引爆"节拍，必须先查情绪蓄力卡对应QM的蓄力值是否已达标——不达标就不能在这一章引爆，要么本章只加一次"小动摇"（QS），要么把引爆挪到后面几章，先回去补几个QS。
- **和情绪感知过滤器本身的关系**：情绪温度/N档管的是"这一拍能写多深"，情绪蓄力卡管的是"这一拍能不能是引爆点"——两者互相独立、缺一不可。一个节拍完全可能是"N3+ 蓄力值已达标"的合法引爆，也可能是"N3但蓄力值不够"的非法引爆（写得再克制、再挣来，本质上还是"没攒够就爆了"）。

具体操作规则、模板结构见 `templates/情绪蓄力卡-模板.md`。

## 九、直说内心：有根 + 稀缺两道闸（★对治两头栽：一头无来由的情绪硬安，一头"一律不许直说"削成寡淡）

N 档决定这一拍"能不能进内心"。进了内心之后还有一层更细的问题：角色的心理状态，什么时候能**直接说出来**，什么时候得靠动作/身体长出来？

**先破一个误区**：不是"一律不许直说内心、全用动作演"——那会把文字削成没温度的电报体（另一种 AI 味）。**真实存在的内心状态，直说是可以的。** 要删的从来不是"直说内心"本身，而是下面两种：

- **闸一 · 有根**：这个内心状态，是不是**刚发生的事 + 角色内核（人物卡"底层"）真长出来的**？
  - 有根 → 合法：角色刚用出一套不属于自己的本事、盯着自己的手"觉得这只手陌生"，这是他核心心结的真实反应，直说没问题。
  - 无根 → 删：为显深刻硬安一个悬浮的情绪定性（"他忽然感到一阵苍凉""一种说不清的复杂涌上心头"），跟刚发生的事和这个人的内核都接不上。**这才是"贴情绪标签"真正要删的东西——删的是"没根的情绪"，不是"直说内心"。**
- **闸二 · 稀缺**：有根也要省着用。一章里"直接说出内心状态"只留少数几处（优先给弧光/情感锚点那一两拍）。**有根但满篇都在直说内心 = 泛滥**：把其中多数改回从一个具体动作、一次身体反应、一个他此刻真正在意的东西里长出来，只在最关键处留直说。

**一句话**：删的是"无根的情绪"和"泛滥的直说"；有根、且省着用的直说内心是对的，别连坐删成寡淡。（这是元铁律"指派服从内容"在情绪上的落地：情绪状态也只在有内容根、且不挤占的前提下才直接表达。）
