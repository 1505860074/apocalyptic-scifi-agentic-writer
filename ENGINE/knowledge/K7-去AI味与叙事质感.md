# K7 · 去AI味与叙事质感

> 合并自旧K11 + 新增叙事质感铁律。每章正文生成前（P6）、润色前（P7）必读。
> AI初稿默认带AI味。去味不是可选项，是定稿前的固定工序。
> **V3 更新**：四类高频AI模式（自传体总结/诗意情绪沉淀/眼睛信息过载/角色自贴标签）从"绝对禁用"改为"**N 档门槛 + 分辨俗套/挣来 + 每章配额**"——去 AI 味 ≠ 无差别删情感。配合 K9 的 N 档使用。

## 一、AI味长什么样

AI写作的通病本质是**"平均化"**——什么都取中间值，没有棱角、没有意外、没有人味。
更深层的病因是：**AI写小说像在"总结人物"而不是"成为人物"**。AI拿到焦点卡上的一句"常安在救不救之间挣扎"，就会用一个完整的自传体段落来展示这场挣扎，而不是让人物用行动和碎片的感官来表达。

| 类型 | 表现 | 例子 |
|------|------|------|
| 句式整齐 | 句子长度差不多、结构差不多 | 全文主谓宾工整，像播音稿 |
| 总结腔 | 动不动替角色/读者下结论 | "这一刻，他明白了……""仿佛整个世界都……" |
| 比喻同质化 | 滥用安全比喻，万物皆可"一丝" | "一丝慌乱""一抹微笑""一缕阳光" |
| 信息平铺 | 把人物心理全说透，没有潜台词 | 角色的每个想法都被旁白解释清楚 |
| 对话书面化 | 不说人话 | "我认为我们应该立刻撤退，因为这里太危险了" |
| **表演式描写** | 在简单事件上堆砌诗意化修辞 | "光和声音同时往下一沉，悄没声儿地，像被什么东西轻轻一抽，抽走了" |
| **单字形容词断句** | 用"xxx的，xxx"制造伪文学感 | "细细的，凉。""黏糊糊的。腥的。" |
| **作者审美视角** | 叙述者站在高处审美地描述，而非站在角色身体里感知 | 感官描写失去即时性，变成审视后的总结 |
| **自传体总结**（★新识别的重灾区） | 角色用一段完整的排比句总结自己的人生/性格/处境 | "他这辈子怂惯了。欠房租躲着房东走。被人骂了就嘿嘿笑。从不跟人争，从不跟人抢，从不出头。他早就认了——自己就是个废物。" |
| **诗意情绪沉淀**（★AI签名） | 在情绪高点后插入一段诗化的内心反思，把复杂情感压缩成精美的比喻 | "心里头。有个空了很多年的窟窿。好像被什么东西轻轻填上了一点点。" "他觉得自己像一株被踩进泥里的草，终于又抬起了头。" |
| **眼睛信息过载**（★AI签名） | 将多层复杂情绪全部塞进"那双眼睛"的描述里 | "那双亮得吓人的眼睛里，全是我还撑得住。" "那双XX的眼睛里，满是/写满了/全是……" |
| **角色自贴标签**（★AI签名） | 角色或叙述者用概括性标签定义角色 | "怂人的本能""他这辈子别的本事没有""废物一个，混一天算一天" |

## 二、去味核心心法：去平均化

### 1. 句长爆破
高潮/危机用短句砸，日常/氛围用长句缓。一段内句长有落差。
- ❌ 他感到非常害怕，握紧了手中的武器，慢慢向后退去。
- ✅ 他握紧了枪。铁的凉从掌心一直窜到后颈。往后退，一步，又一步——脚跟撞上了墙。

### 2. 删总结腔
只给画面和动作，让读者自己得结论。
- ❌ 这一刻，他终于明白了活下去的意义，心中充满了力量。
- ✅ 他把最后半块压缩饼干掰成两半，塞给身后那个孩子。自己咽了口唾沫，重新扛起枪。

### 3. 情绪过火一次
每章至少有一处情绪不"端着"——愤怒就爆粗、崩溃就失态、狂喜就忘形。

### 4. 对话人话化
加语气词、口头禅、半截话、答非所问、沉默。人物不会把话说完整。
- ❌「我认为我们现在应该立刻撤退，因为这里太危险了。」
- ✅「撤。」他只说了一个字，转身就走。

### 5. 藏一半
人物的真实想法别写出来，用动作/停顿/答非所问暗示。**读者从"言行不一"里读出真相，才有真实感。**

### 6. 限量套话
'仿佛/像是/宛如/一丝/一抹/一缕/终于/这一刻/心中/不由得/缓缓/微微' 每章每词最多1-2处。

### 7. 具体压抽象
"很多丧尸"→"三十几只，第一排那只没了下巴"。"环境很惨"→"路灯歪着，一只高跟鞋卡在下水道盖上"。**细节的颗粒感是人味的来源。**

### ★ 8–11 条总说明：这四类不是"绝对禁用"，是"N 档门槛 + 分辨俗套/挣来 + 配额"

这四类是真人作家也在用、而且网文读者最吃的手法——问题从来不是"用了"，是"用得俗、用得滥、用得不在地方"。所以规则不是"搜到就删"，而是三步：

1. **先看本拍 N 档**：这句在 N0/N1 的白描拍 → 一律删（逃命的人不做性格总结、不写诗化沉淀）。够不到该技法的门槛 N，就是纯违规。
2. **在门槛 N 之上，分辨俗套还是挣来**：俗套版删/改，挣来版留。
3. **挣来版也要守配额**：治的就是 AI"每章都来一遍"的滥用。

**唯一那把尺（只在 N3 拍用得上）**：删掉这句，读者会不会少了一次"鼻子一酸 / 对角色多一分牵挂"？会 → 它在兑现本章情感锚点（S-2），留；不会 → 它只是 AI 在替读者感受，删。

> 关键词（`这辈子`/`窟窿`/`那双.*眼睛` 等）仍然照搜——但搜到之后不是直接删，是走上面三步。**搜索只负责"找出来"，不负责"定罪"。**

### 8. 性格速写（门槛 N3 + 事件触发）

一段"这人是什么样"的速写。AI 的病是**不分场合、开篇 info-dump、纯抽象排比**；真人是**挑对时机、挂在一个具体动作上、短**。

- ❌ 俗套：他这辈子怂惯了。欠房租躲着房东走。被人骂了就嘿嘿笑。从不跟人争，从不跟人抢，从不出头。他早就认了——自己就是个废物。（开篇四段排比、纯标签、info-dump）
- ✅ 挣来：挂在当下动作上、短。"常安蹲在维修台前，拆那台两块钱一斤收来的破机器。就这点手艺——修好一台，够还半个月房租。"（速写和正在做的事长在一起，一两句带过）

**门槛**：只在 N3 拍允许。**触发点（二选一，否则配额=0）**：① 一个角色首次有实质戏份（新人登场，全书任何位置）；② 老角色遇到弧光转折/性格重构（写"更新版"速写，与他原来的样子形成对照——这个对照本身就是泪点/爽点）。既没新人、也没转折的普通章节，不主动写性格总结。
**配额**：每个触发点 1 处。**每处速写都要能对应到焦点卡标出的一个触发点，对应不上 = 多余，删。**
**判定法**：如果一段的核心功能是"向读者解释这人是谁"，且这一拍不是 N3、也没有登场/转折触发 → 删，性格靠行动流露。

### 9. 诗意情绪沉淀 / 抒情比喻（门槛 N3）

情绪高点后的一段落地反思。AI 的病是**每个高点后都固定来一段悬浮的诗、比喻跟角色身份无关、只抒情不落地**。

- ❌ 俗套：他觉得自己像一株被踩进泥里的草，终于又抬起了头。（"草"跟一个修理工的世界无关，是作者的审美硬塞给常安）
- ❌ 俗套：诗化断句 + 悬浮意象，且**用在了本不该沉淀的白描拍**（如刚逃完命还在喘）——这种直接删。
- ✅ 挣来：心里头那个空了很多年的窟窿，好像被谁拿块破布随手堵了一下。不严实，还漏风。可到底堵上了一点。（比喻来自角色自己的世界——修破烂的人会想到"破布""堵漏"；落回具体触感，不悬浮；且正好在救人成功这个 S-2 锚点上）

**门槛**：只在 N3 拍允许。**配额：每章 ≤ 1 处**，且比喻必须来自角色自己的生活/职业世界 + 落回一个具体动作或物件。
**判定法**：过那把尺——删了会不会少一次"鼻子一酸"？不会就删；比喻跟角色身份不搭 → 删或换成他世界里的东西。
**搜索处理**：搜 `心里头` `好像被什么` `空了很多年` `窟窿` `填上` `觉得` `发现.*才是`→ 标记 → 走门槛+尺子判断，不是见词就删。

### 10. 眼睛描写（物理状态不限 / 心理投射门槛 N3）

眼睛分两种写法，待遇不同：

- **物理状态**（红了/湿了/亮了/躲开/瞪着他）：**任何 N 档都允许，不限量。** 这是最省力的刻画窗口，鼓励用。
- **心理投射**（"眼睛里写满/全是……"一串抽象情绪）：只在 N3 拍允许，且**眼睛只承载一样东西，不堆一串情绪清单**。

- ❌ 俗套：那双眼睛里，写满了不甘、委屈，还有一丝微弱的希望。（一串抽象情绪塞进眼睛，像广告牌）
- ✅ 挣来：她瞪着他。那眼神不像求救，倒像赌气——赌你敢不敢管。（一个物理状态 + 至多一个具体推断）

**配额**：心理投射每章 ≤ 1 处；物理状态不限。
**搜索处理**：搜 `眼睛里.*全是` `眼睛里.*满是` `眼睛里.*写满` `那双.*眼睛` `眼神.*闪过一丝`→ 若是"一串情绪清单"→ 删到只剩一样，或降级为纯物理状态（"她咬着牙，眼眶红了，一声没吭"）。

### 11. 自贴标签（看"旁白"还是"角色的嘴"——与 N 档无关）

同样一句自嘲，谁说的决定它去留：

- **旁白替角色贴标签**（"怂人的本能""废物一个""他就是那种打死不低头的人"）：**永远删。** 叙述者在下结论，抢了读者从行动里推导的活。
- **角色自己嘴上/心里的自嘲**（"我就是个修破烂的""我这怂样"）：**保留，不限量。** 这是人物的声音、是"常安味"的来源——《写作风格卡》明确要这种"直接定义"。

- ❌ 旁白：怂人的本能，最会的就是这个。
- ✅ 角色自嘲："我图啥？我也不知道图啥。就我这修破烂的怂样，还想当救世主？"（带引号/内心吐槽语气，是角色在说）

**判定法**：这句是**叙述者说的**（删）还是**角色说的/心里吐槽的**（留）？看有没有引号或第一人称吐槽的语气——有角色声音就留，纯旁白定性就删。
**搜索处理**：搜 `的本能` `的命` `就是个` `这种人` `别的本事没有`→ 落在旁白里 → 删；落在对话/内心吐槽里 → 留。

## 三、叙事质感铁律（★新增核心）

### 铁律一：叙述贴角色感知，不贴作者审美

旁白不是作家在展示文笔，是透过角色的眼睛看世界。

- **感官优先于修饰**：先写"灯灭了""眼前黑了""什么也看不见"，别先写诗意化的总结
- **即时体验，不事后加工**：角色先感觉到冷、听到声音、心里一紧——按感官发生的顺序写
- **禁止一句话写完一个事件的"完整感受"**：拆成几步——灯灭了→黑了→这黑不对→怎么回事→安静的质感。让读者一步一步跟着角色经历。
- **感官发生的顺序 = 文字的展开顺序**

### 铁律二：叙事情绪温度

文字的"嗓音"必须和剧情情绪同频。写"他慌了"（内容）≠ 用慌了的语气写（声音）。

- 紧张/恐惧：短句、碎句、少修饰、感官直出
- 愤怒/爆发：硬词、短促、重复、少废话
- 平静/日常：可以舒展、带吐槽
- 压抑/憋屈：句子像被压住了，短而闷，没有感叹号

**检验：写完一段，问"这段文字读起来的节奏和温度，跟角色此刻的感受是一个频率吗？"**

### 铁律三：砍掉表演式描写

以下写法是AI在演一个作家，不是真人在叙事：

- ❌ **单字/短词独句堆**（不只形容词——"黑。""近。""静。"这类一个词一个句号、成串出现）："细细的，凉。" → ✅ 用逗号/破折号连成急促流："捻了捻，凉的，是灰。" **★ 恐惧/紧张高点也一样**：那里该用短句连成的流，不是一字一句砸；单字独句全章 ≤ 1–2 处，只给最重的那一下（如章末钩子）。"短"是情绪逼出来的，不是硬切句号切出来的。
- ❌ 简单事件上的诗意化修辞堆砌：灯灭就是灯灭，别写成三行诗。事件本身的重量决定描写的重量。
- ❌ "不是...而是..."无效细节对比：除非对比对角色的判断至关重要，否则删。
- 核心判断：**"一个处于这种情境下的普通人，他的感官会这样处理这个信息吗？"** 如果不是，就是你（作家）的审美侵入了。

---

### 铁律四：信任读者，不替读者交代 / 复述 / 解释

最隐蔽的废话不是华丽辞藻，是**旁白把读者（或角色）已经 get 到的东西再说一遍**。真人作者写得瘦——给具体的东西，然后闭嘴，让读者自己推、自己感。
**★ 边界（别过冲）**：这不是"删掉所有解释"。该交代的因果、必要的新信息留着；删的只是"**读者已经推得出、或角色的反应已经体现**"的那部分复述和交代。

- **不复述屏显 / 对话**：屏幕或对话刚给过的信息，旁白别再用陈述句总结一遍。
  - ❌【…同步个体×3】→"三个。……就一枚，压在三个那种东西的脚底下。"（"压在三个脚底下"＝把屏显复述给读者听）→ ✅ "三个。"＋一个身体反应，够了。
- **不交代"懂没懂"**：别写"这些词他一个都没听过""看得云里雾里""他听懂了：意思是……"。角色懂多少，用他的反应 / 下一步行动体现。
  - ❌"这些词常安没听过，云里雾里，就一件事他听懂了：得弄个大电池。" → ✅ 让他直接反应 / 去找，别旁白替他翻译。
- **声音给拟声词，别用动作动词重复冒充声音**：❌"拖，拖，拖"（重复动作）→ ✅ 一个真拟声"刷，刷，刷""嚓……嚓"。
- **氛围融进动作 / 物体，别当碎片甩**：❌"幽幽的绿。"（色彩独句）→ ✅ "屏幕泛起一点幽幽的绿光"（让光源在动，不留终端碎片）。
- **不用"他脑子里就一句 / 翻来覆去就一个念头：……"框架端出内心**：❌"常安心里翻来覆去就一句：别上去别上去。""脑子里就转着这两个字：锁上。""脑子里就一个念头：顶住。"——这是把内心活动打包交代给读者，没意义。→ ✅ 让动作/状态自己带（"死死顶着门闩，心跳比撞门声还快"已经够了，不用再补"脑子里就一个念头"）；真要给内心，直接给那句话本身、别加"他脑子里就……"的框。

**判据（写完 / 润色时逐句问）**："这一句，读者或角色是不是已经知道了？一个正常人会专门说这一句吗？" 会 → 多半是废话，删掉或并进动作。

**高频触发词**：搜 `这些词` `没听过` `云里雾里` `他听懂了` `也就是说` `意思是` `换句话说` `就一件事` `简单说` `翻来覆去就` `脑子里就` `心里就转着` `就一个念头` `就一句` → 逐句判断是不是在复述屏显/对话、交代"角色懂没懂"、或用框架端出内心；是则删，或改写成一个反应/动作。

## 四、去味操作清单（每章对照）

### 旧模式（V2.0原有）
- [ ] 有没有连续3句以上句长/结构雷同？→打散
- [ ] 有没有"这一刻/终于明白/心中充满"总结腔？→删，换动作画面
- [ ] 有没有至少一次"过火"的真实情绪？→没有就加
- [ ] 对话像不像真人说话？→太书面就改
- [ ] "仿佛/像是/一丝/一抹/缓缓/微微"超量？→各留1-2处
- [ ] 有没有把人物心理全说透？→藏一半
- [ ] 有没有笼统的"很多/非常/巨大"？→换具体
- [ ] 有没有"表演式描写"？→砍掉
- [ ] 有没有单字/短词独句堆（"黑。""近。"成串，**恐惧/紧张段也算**）？→合并成逗号/破折号的急促流，单字独句全章≤1–2处，只留最重一下

### 新模式（V3——按 N 档分区判断，不是无差别删）

> 每条都先做同一件事：**搜关键词 → 定位到节拍 → 看这一拍的 N 档 → 再决定删/留/改**。

- [ ] **性格速写**：搜 `这辈子` `惯了` `从来` `从不` `早就认了` `他就是个`——① 落在 N0–N2 拍 → 删；② 落在 N3 拍但没有"新人登场/弧光转折"触发点 → 删；③ 落在 N3 拍且有触发点 → 留（须挂具体动作、短、每触发点 1 处）。
- [ ] **诗意情绪沉淀/抒情比喻**：搜 `心里头` `空了很多年` `窟窿` `填上` `好像被什么` `觉得.*才是`——非 N3 拍 → 删；N3 拍 → 过尺子（删了会不会少一次"鼻子一酸"）+ 比喻是否来自角色世界 + 每章 ≤ 1 处。
- [ ] **眼睛描写**：搜 `眼睛里.*全是` `眼睛里.*满是` `眼睛里.*写满` `那双.*眼睛`——纯物理状态（红/湿/亮/躲/瞪）→ 留，不限；一串情绪清单 → 删到只剩一样，心理投射仅 N3 拍且每章 ≤ 1 处。
- [ ] **自贴标签**：搜 `的本能` `的命` `就是个` `这种人` `别的本事没有`——**旁白**里 → 删；**对话/内心吐槽**里的自嘲 → 留（这是常安味）。
- [ ] **重复感官模板**：搜 `后脑勺` `尾椎骨` `鼻子一酸` `手心全是汗` `头皮发麻`——同一种身体反应在同一人物身上每章最多 1 次，第二次换写法。（这条与 N 档无关，纯防重复。）
- [ ] **交代废话 / 过度解释**（铁律四·信任读者）：搜 `这些词` `没听过` `云里雾里` `他听懂了` `也就是说` `意思是` `就一件事` `翻来覆去就` `脑子里就` `心里就转着` `就一个念头`——是不是在复述屏显/对话、交代"角色懂没懂"、或用"他脑子里就一句：X"的框架端出内心？是 → 删或改成反应/动作。另查：声音有没有用动作重复冒充（"拖，拖，拖"）→ 换真拟声；氛围有没有当碎片甩（"幽幽的绿。"）→ 融进动作/物体。
