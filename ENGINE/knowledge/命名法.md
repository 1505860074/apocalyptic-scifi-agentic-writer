# 命名法（★对治"命名很怪"）

> 本文件只放**抽象命名法则**（换任何书任何题材都成立），不含任何具体范文的名字。命名的**登记与统一**走 `命名与术语表`（唯一真相源）；本文件管"怎么起一个不怪的名"。
> 由"用词优化-分层学习"的**命名层**跑档成长：从范文里学的是**命名规律**（音节/构词/调性/密度），绝不抄它的具体名字。

## 一、命名前先分类（决定要不要造词）
- **现实已有的事物 → 一律用现实通行名**（地面/甲板/酒/地图/门），**绝不自造词**（别把现实事物硬拼成新词，如"铁地""光门"）。造词权只留给**世界观特有、现实没有**的新事物。（呼应 正文生成 硬红线7）
- **通名 vs 专名**：能用通名说清的就别造专名；专名是点缀不是堆砌。一次别砸一堆新词。

## 二、一个好名的六条标尺
1. **贴世界观调性**：名字的语感要和世界设定同频——古风世界不用外来音译腔，科幻不用武侠味，都市异闻要"日常里透一点不对劲"。调性统一比单个名"好听"更重要。
2. **易读可辨**：读者一眼能读出音、能和别的名区分。避免生僻字堆砌、避免多个主要角色名首字/音近似（易混）。
3. **音义搭配**：音感与角色/事物气质match（凌厉的角色别起软绵绵的名）；但别把含义写在脸上（角色叫"忠勇"、反派叫"阴狠"＝贴标签，露怯）。
4. **不生造现实已有物**（见第一节，最常见的"怪"来源）。
5. **克制密度**：专有名词是稀缺资源。一段/一章内新专名别扎堆；反复出现、值得记住、能传播的才配拥有专名，否则用大白话。
6. **可延展**：同一体系的名（同族/同类/同势力）最好有可辨认的**共同构词规律**（词根/音节/后缀家族感），让读者能"望名归类"，也方便后续扩写不跑偏。

## 三、常见"AI味/怪"命名症状（照着自查）
| 症状 | 长什么样 | 改法 |
|---|---|---|
| 生造现实词 | 把现实事物拼成新词（铁地/光门/水食） | 用现实通行名 |
| 中二堆砌 | 一个名塞多个华丽词根（暗黑深渊灭世魔炎） | 砍到一个核心意象 |
| 贴脸含义 | 名字直接写出善恶/功能（忠勇/万能钥匙） | 让含义藏在音感/侧写里 |
| 调性串味 | 同一世界里古风/科幻/网络梗名字混杂 | 统一到世界观调性 |
| 近似易混 | 多个主要专名音/形太近 | 拉开首音节/字形 |
| 密度爆炸 | 开篇几段砸十几个新专名 | 分批引入、非必要用通名 |

## 四、与命名与术语表的分工
- **本文件**：怎么起名（抽象法则、自查表）。
- **`命名与术语表`**：起好的名**登记在册、全书统一用词**（唯一真相源；正文照用不许自造同义词）。
- 世界观与金手指步定命名调性 + 初始核心术语；故事种子与世界基底补登；章末收尾登记本章新造且值得留的专名。

## 五、跨范文学到的命名法则（★2026-08-22 · 4本范文分层学习提炼，均抽象·不含任何具体名）

> 来源：末日副本/双胞胎巨龙/推理万人迷/外星异种 ch1-30。标 ★ 的为多本复现、高置信。

1. **★双轨命名拉层级（3本复现·最强）**：一本书里按"实体类别"用两套命名腔并置——**现实向角色/事物用写实通行名**（压真实感），**非人/系统/道具/异族用另一套腔**（大白话功能名或异域音译），靠两套腔调差**一眼区隔"现实层 vs 系统层 vs 非人层"**。别让全书名字一个调。
2. **★命名承担叙事功能、不做装饰（3本复现）**：好名字顺带**暴露人设 / 标出强弱等级 / 制造幽默 / 埋线索**。如力量分级用"字母/数值阶梯"命名即自带强弱标尺（读者零门槛排序）；玩家/角色代号用"生活流网名/口癖"反衬底色。
3. **★望文知义 + 不生造拗口（3本复现）**：非人事物用"属性/材质 + 形态"复合直译（望文知种类与危险度），常见字构词、可念可记；靠调性而非陌生化取胜（呼应第二节标尺、第一节"现实有的不造词"）。
4. **系统/道具"功能白话名 + 半严肃说明书体"**：卡片/技能名直白如日用品，配一段带"说明/备注"栏的伪正经文本，备注里藏一句吐槽或情话——**笑点在格式反差**（庄重壳+世俗核）。
5. **★双名标记（表皮名 vs 本体名）**：给"披着人皮/伪装身份"的存在配两个名——默认用伪装名，**只在其非人/真实本质外泄的瞬间切换成本体名（或同句并置）**。名字一换＝面具滑落的无声开关，读者立刻会意。卧底/AI/鬼怪/异种通用。
6. **系统去人格化用数字/代号命名**，反衬其话痨拟人性格（冰冷编号 vs 话唠人设的反差萌）。
7. **机构/地名"可信但查无此地"**：仿真两三字命名 + 开篇明示架空，既可信又卸掉考据/对号入座压力。

8. **按阵营/文明分层定命名调性（ch31-50 增补·延伸法则1双轨）**：同一世界里不同阵营/文明各用一套命名腔（如玩家侧口语玩梗 vs 神权/原住民侧古语仪式化；人类侧写实 vs 异族侧音译），两套并置本身就生出层级感/异域感/恐怖感——是"双轨命名"的多阵营版。
