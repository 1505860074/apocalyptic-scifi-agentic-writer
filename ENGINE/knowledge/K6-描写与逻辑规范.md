# K6 · 描写与逻辑规范

> 合并自旧K10+K12。写正文时对照——治环境bug、视角混乱、逻辑断裂。

---

## 一、环境描写规范

### 场景首次出现要具体交代
- 空间大小、**光源**（光照是重灾区）、出入口、关键物件位置
- 之后就靠这张底图，不用反复描

### 光照一致性
- 说地下室"不见光"就别写"下午两点阳光洒进来"
- 灯灭后全黑→交代来由（没窗+灯灭）

### 环境视角 vs 主角视角要分开
- 旁白只负责"发生了什么"（客观）
- 主角负责"我怎么看它"（主观判断）
- 别把主观判断混进客观旁白

### 拟声/声音描写节制
- 同一动作序列里别连堆多个拟声词
- 选最关键的一个，其余用动作带过
- **写声音就给真拟声词，别用动作动词重复冒充声音**："拖，拖，拖"是把动作说了三遍，不是声音；真人会给它一个拟声——"刷，刷，刷""嚓……嚓"。（同理"金属刮水泥"这种只给了声源、没给声音，后面要落到拟声或质感。）
- **关键声音要落一个具体拟声**：惨叫/巨响/异响，别只用形容词干描述（"又尖又哑""劈了个怪调"不够，读者没有具体听感）——要有"啊——"那一下，把声音本身落出来，再配形容词修。

---

## 二、新现象的描写

写读者没见过的现象，抓住它独有的质感，别套用不贴切的日常经验做对比。
- "归零"不是停电——是设备本身死了，写它的寂灭感
- 别用"跳闸""断电"这类不贴切的比喻糊弄

---

## 三、描写现象要贴合它的内在逻辑

- 反例：写"归零导致电子失能"却用"啪一下"（那是电路瞬断的声音）
- 正例：写无声无息、连一点电流残响都没有地，屏幕、指示灯同时沉下去

---

## 四、细节描写原则

- 只保留推进剧情/塑造人物/制造情绪的细节
- 物品型号、颜色、无关摆设→删
- "灰扑扑的板子，老式接口，厂家倒闭快十年的型号"→除了凑字没用

---

## 五、逻辑一致性（七维自查清单）

### 0. 数字一致性专项（★高频bug区，放在最前面）

写作中随手编的数字——钱数、时间、距离、人数、年龄——是最容易自相矛盾的，因为它们不来自任何设定文件，是即兴发挥。

**规则**：本章内每出现一个数字，都要和其他数字对一遍。

> 执行分工：写正文时（P6）不必停下来算；**数字算术验算的权威执行关是 V4 自查E**（独立自查阶段集中做算式）。本节是方法说明——其他步骤（P7、V5 等）引用即可，不必各自重跑整套，只在自己改动了数字时复核。

| 类型 | 矛盾案例 |
|------|----------|
| 钱数 | 前面"月租两百"，后面"三百够还半个月" → 200÷2≠300 |
| 时间 | 前面"下午两点"，后面"天已经黑了" → 除非有特殊原因 |
| 距离 | 前面"走五分钟"，后面"跑了一小时" |
| 人数 | 前面"配电室三个"，后面打斗变成四个 |
| 天数 | 前面"三天前买的"，后面"昨天刚拿到" |

**自查方法**：写完一页，把本章所有数字圈出来列一行，逐个互对。

### 1. 因果链完整
- [ ] 每件事有前因？
- [ ] 后果有交代？
- [ ] 禁止"突然就""不知道为什么就"

### 2. 时间线连续
- [ ] 事件先后顺序在文字里也是先后顺序？
- [ ] 别先写后果再写前因（除非刻意倒叙+有标记）
- [ ] 时间流逝合理？（不会三天做了一天的事）

### 3. 空间一致
- [ ] 位置/路线/物件位置前后对得上？
- [ ] 前一章说某物在桌上，这章不能在地上（除非有人动过+交代）

### 4. 物质/能量守恒
- [ ] 回收什么原料→只能得对应产物
- [ ] 废铁变不出食物
- [ ] 道具来源合理——末世初期别冒出需要时间打磨的武器
- [ ] 武器不能凭空出现、不能凭空消失
- [ ] **动作物理落地**：角色每个动作物理上做得到吗？（光板铁盒挎不上肩→先用布/帆布带绑成挎带；一只手拎着就腾不出手打斗）

### 5. 人物状态一致
- [ ] 物资/电量/弹药余量跟上章对得上？
- [ ] 人数对得上？（死了/活着/受伤几个）
- [ ] 伤情延续？（上一章腿伤了，这章不能健步如飞）

### 6. 人物认知不超前
- [ ] 主角不知道的信息，叙述不能抢先用
- [ ] 主角没见过的名字，叙述不能先叫
- [ ] 情绪反应匹配触发信息（天塌了才该怕，不是屏幕弹一行字就怕）
- [ ] **但"认知不超前"≠ 专门写一句"角色不懂/没听过这些词"来交代**——那是交代废话（见 K7 铁律四）。术语只在屏显/对话里出现即可，角色用他自己的话反应、或直接行动，别旁白替他解释懂没懂。
- [ ] **真人本能反应 + 时机（★易错）**：以角色此刻已知的信息，一个真人会先做的本能动作别跳过（知道粉尘吸入会覆写→先护口鼻）；**但这个动作的时机不能早于他获得依据**——方舟还没告诉他"粉尘吸入会覆写"之前，他没理由去捂口鼻。防护/应对动作要落在"他知道了为什么"之后，不能提前。

### 7. 设定 / 术语一致（★ 别脑补、别自造）

- [ ] 正文不得与既定设定矛盾：主角处境/地点照设定（常安就在废品站看场子→别写"从别处蹬三轮拉回来"）。
- [ ] 专有名词照既定术语用，别自造同义词（"洁净场""数据尘""能源核心"是既定词——别写成"隔离屏障""纳米粉尘"之类）。
- [ ] 写前先看焦点卡钉的"本章地点 + 术语表"；焦点卡没给、拿不准的，宁可查设定文件，别脑补。
