# 逆向骨架 · 外部-隔壁蛇蛇 第7章

本章是一个**单场景内省章**：主角独自在新家客厅，先看聊天记录、后接一通电话，全程与祖母隔着屏幕/电话交锋，其余靠内心处理。物理动作极少，信息与情绪几乎全在主角脑内推进。

## A 命名与名物

- **人名**
  - 叶夕：主角（第一视角），年轻女性，祖母的孙女。
  - 叶覃：叶夕的祖母（"奶奶"），电话另一端。
  - 沈明矜：对门的漂亮邻居（本章**不出场**，仅被提及/回忆，是全章悬念对象）。
  - 抢手机的女人：叶覃身边的一名女性，插话、被叶覃斥为"神经病"；疑似叶覃的友人（无名）。
- **设定专名 / 概念**：四条规则（前文既定的、形似"游戏规则"的一组条文，本章未复述内容）；能治病的风水；有问题的祖坟；主角自认的"唯物主义"世界观。
- **地点**：半山灵苑（主角被安排暂住的小区/新家）；场景固定在新家客厅（沙发处）。
- **道具**：手机（先聊天、后通话、再开备忘录）；沙发；垂在头顶的白炽灯；一个抱枕；手机备忘录。
- **时间**：紧接前一章之后的同一段时间；主角淋雨、喉咙由痛转好之后的当天。

## B 人物落笔（不含文采）

- **叶夕（主角/POV）**

  - 表层：温和有礼、好说话的斯文老太太。

  - 本章状态：不出场，作为主角的疑问与恐惧焦点存在。

## C 事件与大纲

- **一句话主线**：叶夕在一场"祖孙彼此说谎"的通话后，把前文一堆怪事在心里收拢，确认半山灵苑与沈明矜都不对劲、自己的唯物世界观开始崩塌，最终决定主动去问沈明矜。
- **本章功能定位**：承上启下的**信息整理 + 情绪/动机转折章**。把此前散落的怪事（四条规则、强吻、低体温、"为何是人"之问）在主角内心汇成"这里恐怕有鬼"的怀疑；同时把主角从"被动顺着祖母、不多问"推到"主动探寻"的动机转向，为下一步她去接触沈明矜铺路。无强动作、无外部冲突，靠对话潜流 + 内心推演驱动。

## D 焦点卡层

### 读者设计
- **读者体验目标**：先跟着主角一起"这家人怎么全在瞒我"地憋闷发笑，再随她一点点后背发凉——"完了，这地方可能真有鬼"，最后被她那句"要不去问沈明矜"勾着想翻下一章。
- **情绪曲线**：压抑困惑（满屏撤回）→ 紧张（识破祖母在演）→ 一段"心照不宣互相演"的憋笑张力 → 短暂松弛（骗过祖母、挂断）→ 逐格下沉的恐惧（意识到可能有鬼、身体发凉）→ 落到冷静的决意与好奇（转向沈明矜）。
- **爽点/揪心锚点**：**Beat 10**——主角把"低体温＋'为何是人'＋能治病风水＋有问题祖坟"串成"世上该不会真有鬼"的一刻，是全章最揪心、最"头皮发凉"的锚点，其余各拍都为把读者送到这一刻服务。

## E 场面调度层（逐拍：①站位 ②动作链 ③对话意图 ④内心微动 ⑤感官锚点）

> 全章底图：主角独自在新家客厅沙发处，头顶一盏白炽灯，手机在手。除接电话外无第二人在场。以下只记调度，不写文采；③只记意图与信息、不抄原句；⑤只钉确定实体、不抄原文比喻。

**Beat 1（L2/N2/压抑）**
- ①站位：主角坐/靠在沙发上，手机举在面前，头顶白炽灯。
- ②动作链：低头看屏幕 → 屏幕强光刺眼、加上身体不适看得眼花 → 后背抵进沙发、双手放膝、攥紧手机 → 盯着满屏被撤回的消息发怔。
- ③对话：无。
- ④内心：一股"这算什么事"的荒谬憋闷压上来，隐约意识到自己撞见了不该看的东西。
- ⑤感官锚点：屏幕强光；头顶白炽灯；被攥紧的手机。

**Beat 2（L1/N2/紧张）**
- ①站位：同上，视线不离屏幕。
- ②动作链：消息被一条条撤回 → 转成语音接连发来 → 语音里夹进一句被抢手机者的女声反驳 → 又一句带怒的警告 → 随即全部撤回。
- ③对话（只记意图/信息）：祖母语音其一＝"你没看到刚才那些吧"的试探性遮掩；其二＝"手机被一个玩游戏玩疯的人抢了、别在意"的甩锅；夹入女声＝反驳"我不是神经病"；其三（带怒）＝命令主角远离对门那户女人、贬斥其家族连祖坟都有问题。
- ④内心：熟悉嗓音先让她松一下，但试探语气让她拿不准怎么接；察觉祖母在祈祷她别看见。
- ⑤感官锚点：一连串"撤回"提示；语音里那句压得很低的女声。

**Beat 3（L1/N2/压抑）**
- ①站位：同上，仍盯屏幕。
- ②动作链：主角回想印象中祖母的一贯温和 → 对比刚才罕见的怒音 → 推断祖母在跟人置气 → 把"抢手机者"和"插话女声"合并为同一人。
- ③对话：无（纯内心推演）。
- ④内心：一步步比对反常处，得出"这不是平时的奶奶"。
- ⑤感官锚点：屏幕上残留的对话框。

**Beat 4（L2/N2/紧张）**
- ①站位：主角接起电话，贴耳；仍在沙发。
- ②动作链：欲发消息 → 电话先打进来 → 接起 → 一问一答几个回合 → 主角刻意把嗓音扬得天真 → 祖母被安抚、松口 → 祖母抛出新遮掩借口 → 主角顺着接住。
- ③对话（意图/信息）：主角开口＝一声"奶奶"（甜嗓，安主角人设）；祖母＝确认喉咙好没好、有没有遇见人（紧张核实）；主角＝把喉咙转好归给"小区淋雨"、装天真高兴（转移+立无辜人设）；祖母＝"是雨就好"（暗自松气），再补"研究表情包误发"的遮掩；主角＝用"你以前嫌表情包丢形象、现在自己玩上了"的轻嗔接住（顺着给祖母想听的答案）。

- ⑤感官锚点：贴耳的听筒；电话那头一次明显的停顿/松气。

**Beat 5（L1/N3/平静·背景插入）**
- ①站位：静态，通话间隙，主角内心。
- ②动作链：无外部动作，纯背景铺陈。
- ③对话：无。
- ④内心：交代她几乎没有叛逆期、总尽量顺祖母心意；根源＝两人是彼此唯一的亲人、都经历过至亲尽失，她出于自觉去体谅、让祖母养她轻松些；因此祖母不想她问的，她就不问。
- ⑤感官锚点：（内省拍，可不设外部锚点或仅极轻一笔）

**Beat 6（L2/N3/紧张，含回忆插入）**
- ①站位：仍在通话，沙发。
- ②动作链：祖母话头绕回 → 一次长停顿 → 抛出关键试探 → 主角脑中闪回规则与祖母怒音、又闪回一次强吻 → 脸热、心虚 → 嘴上否认。
- ③对话（意图/信息）：祖母＝先泛问"新家住得怎样、遇见人没"，得"没啊"后停很久，再追一句"漂亮邻居也没有吗"（真正想确认的是沈明矜）；主角＝结巴否认（心虚遮掩）。
- ④内心：她把"莫名规则＋祖母怒音"与沈明矜挂钩，判断沈明矜身份不得了、好奇陡增；随即想到那次强吻、脸热、明知祖母看不见仍心虚。
- ⑤感官锚点：电话那头一次明显拉长的沉默；主角自己发热的脸颊（身体反应，非比喻）。
- 叙事提示：强吻属**回忆插入**（前文已发生的事），在此被主角主动记起，不是新事件。

**Beat 7（L2/N2/平静）**
- ①站位：通话尾声，沙发。
- ②动作链：祖母信了、语气轻快 → 承诺很快来接、不让住满半年 → 补一串叮嘱 → 主角撒谎保证 → 祖母放心 → 挂断。
- ③对话（意图/信息）：祖母＝轻松承诺尽快接她走（顺带暴露自己忘了当初是打"养病"半年的旗号）＋叮嘱别跟陌生人、尤其漂亮的人来往（暗指沈明矜）；主角＝满口答应"记住了、乖乖待着哪也不去"（明知已全违背仍撒谎安抚）。
- ④内心：她对祖母的健忘有点无奈；清楚自己不仅早跟沈明矜说过话、还亲过，按那几条规则甚至该她负全责；但绝不敢说，只能一路假话哄到挂断。
- ⑤感官锚点：挂断的动作/忙音。
