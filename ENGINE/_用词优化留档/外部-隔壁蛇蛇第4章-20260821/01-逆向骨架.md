# 逆向骨架 · 外部-隔壁蛇蛇第4章《亲密：谁在欺负谁》

> 说明：本章是**暧昧关系戏**（女女向），非战斗。情绪温度沿用模板六标签，但作了贴题材的映射（见 D 层节拍表脚注）。全章基本是叶夕单一视角。

## A 命名与名物

- **人名**：
  - 沈明矜（本章主动方；被叶夕称呼为"姐姐"）
  - 叶夕（本章视角人物、被动方）
- **设定专名 / 名物**：无新造专名。可保留的既定设定线索——沈明矜体质"偏凉/忽冷忽热"、叶夕体质"体温异常偏热"（既定背景，非本章新设）。

- **道具**：长绒地毯（贯穿全章的场地底图，且是一处反常细节的载体）；两人被冷水打湿的衣物（湿意/透湿是感官线索）。

## B 人物落笔（只记设定与状态，不含文采）

- **沈明矜**
  - 表层设定：外形出众、气质偏冷艳；体温偏凉、气息带凉与一种甜味气息。
  - 底层可见部分：**非人身份的悬念**——本章有一处"眼睛颜色瞬间异变"的异象被叶夕撞见（见 D/E 第4拍）；此前处于某种"燥热/需要降温"的异常状态，把与叶夕的亲密接触当作给自己降温的手段。性格上"傲娇、得了便宜倒打一耙"：主动挑起亲密，一旦异常状态退去立刻清醒、翻脸摆出被欺负的委屈姿态。
  - 本章当前状态：从"燥热主动"急转为"清醒羞恼"，再转为"体力被抽空、只能弱声央求"，姿势上由主动方沦为被压制的一方。
- **叶夕**
  - 表层设定：体温异常偏热，长期被这股热困扰；力气比外表大。

  - 本章当前状态：被动承受吻与贴近→生理与心理受强烈冲击（脸红、呼吸乱、紧张）→由警惕转为担心对方→被对方翻脸后产生"被抛弃"的失落→最后陷入"我明明是被动的，怎么成了欺负人的那个"的错愕。

## C 事件与大纲

- **一句话主线**：沈明矜主动吻并拽下叶夕、借亲密接触替自己平息某种燥热异常；异常一退她立刻清醒翻脸、傲娇地赶叶夕起身，还反过来摆出被欺负的委屈相，让本是被动一方的叶夕陷入"到底谁在欺负谁"的荒谬错愕。
- **本章功能定位**：
  1. **关系推进 + 性张力**：以一次亲密接触把两人暧昧往前推一格。
  2. **埋非人身份悬念**：借"眼中异象 / 反常地毯 / 对方体质忽冷忽热"三处细节，暗示沈明矜非普通人（当章不点破）。
  3. **立人设对照**：沈明矜"傲娇+倒打一耙" vs 叶夕"迟钝+体质异常+力气大"。
  4. **点题**：把标题"谁在欺负谁"用主动/被动身份对调演出来。

## D 焦点卡层

### 读者设计
- **读者体验目标**：先"心跳/脸红/替叶夕紧张"，中段"咦？（撞见异象的疑惑）"，结尾被反转逗到——"明明是你先动的手，怎么倒成她可怜了""这俩到底谁在撩谁"。
- **情绪曲线**：暧昧屏息（被吻·贴近）→ 心软担心（见对方可怜相）→ 一丝疑惑悬念（眼中异象、反常地毯）→ 情绪落差/失落（对方翻脸赶人）→ 张力回升（挣扎致更贴近、双双僵住）→ 荒谬释然（身份对调的错愕，钩子）。
- **爽点锚点**：**结尾的身份对调**——主动拽人、挑起亲密的是沈明矜，最后却是她摆出被困、被欺负的委屈相，而全程被动的叶夕反而站在了"施暴者"位置。这是全章的锚，所有节拍为这一反转蓄势。

## E 场面调度层（逐拍：①站位 ②动作链 ③对话意图 ④内心 ⑤感官锚点）

### 第1拍 · 吻落（L2/N2/紧张）
- **①站位**：两人已极近，沈明矜在上方俯身、叶夕在下方仰面承接；周遭为地毯房间。
- **②动作链**：沈俯身 → 唇落上叶夕唇 → 叶夕这次是看着吻来的、身体有预料 → 但仍停止思考、被动感受这个吻。
- **③对话**：无。
- **④内心**：叶夕虽有预料却仍失神；对比出对方带来的凉能压下自己长期的热。
- **⑤感官锚点**：对方唇温偏凉；对方气息偏凉且带一种甜味气息。（禁用"薄霜/糖果"一类喻体，只落"凉、甜味气息"这类确定属性。）

### 第2拍 · 被拽下·肌肤相贴（L3/N2/紧张）
- **①站位**：变化——沈的手臂勾上叶夕后颈；两人身体从"贴近"变为"叶夕整个下沉压向对方"。
- **②动作链**：沈的手臂搭上后颈用力 → 带着叶夕身体下沉 → 叶夕没能撑住、几乎撞在对方身上 → 裸露肌肤相贴、胸口相抵 → 领口残留的冷水湿意渗过衣料贴到叶夕身上。
- **③对话**：无。
- **④内心**：这种贴近对叶夕极其陌生（从未与人这样近）；生理反应逐层涨起——先耳根热、再脸颈泛红、呼吸乱掉、喉咙紧张吞咽（此前被灼伤的刺痛已消）、无意识攥紧手心。
- **⑤感官锚点**：湿衣贴身的凉；两人肌肤相贴处的温差（对方偏凉）；攥紧的手心。

### 第3拍 · 欲推→见可怜→转担心（L2/N2/紧张转心软）
- **①站位**：不变，仍贴压状态；叶夕手正欲伸出去推。
- **②动作链**：叶夕出于自保想推开对方 → 手还没伸出，余光先瞥见对方一副可怜、狼狈、惹人心软的样子 → 推的念头减弱 → 改为出声关心。
- **③对话**：叶夕问对方是否还好。**意图**：从警惕自保转为担心对方（直给关心，无潜台词）。
- **④内心**：想推自保 vs 被对方可怜相勾出的担心，两股拉扯，担心占了上风。
- **⑤感官锚点**：对方近在眼前的可怜姿态（用具象的表情/身形状态写，不用"娇花"喻体）。

### 第4拍 · 近距对视·眼中异象（L3/N2/震撼-微揭示）
- **①站位**：叶夕低头凑近，与对方零距离对视。
- **②动作链**：对方没应叶夕的问 → 叶夕自己低头细看 → 此距离能看清对方泛红皮肤、闻到气味、无障碍对视 → 撞见对方眼睛颜色骤变（先整片变成不自然的纯黑、无情感，随即一点红色出现并迅速扩散盖过黑色）→ 叶夕抬手在对方眼前晃、再问一声 → 揉眼再看，异象已消失 → 自我否定为"又眼花了"（联想到体温异常后眼花变多）。
- **③对话**：叶夕再唤一声"姐姐"。**意图**：确认对方状态、对异象的下意识试探。
- **④内心**：短暂的诡异感 → 迅速被"我大概又眼花了"压下（人物自我否定，正是留给读者的悬念）。
- **⑤感官锚点**：**对方眼球颜色的两段异变（纯黑→红色扩散盖过）**——这是确定可见实体，具象写、零喻体；对方泛红的皮肤；对方身上的气味。

### 第5拍 · 手陷反常地毯（L2/N1/平静·闲笔开）
- **①站位**：叶夕的手从悬空放下、掌心贴到地毯。
- **②动作链**：叶夕放下举着的手 → 手指陷进长绒地毯 → 掌心贴合毯面时察觉反常。
- **③对话**：无。
- **④内心**：轻度——对毯子反常的留意，一丝说不清的安心。
- **⑤感官锚点（闲笔展开处）**：地毯长绒过分柔软；两人都湿透、毯子却依旧干燥不沾湿意；抵着掌心有轻微痒感；一股令人安心的暖香。（借此埋"此地/此人不寻常"的世界观悬念。）

### 第6拍 · 对方清醒·翻脸赶人（L2/N1/压抑-骤冷）
- **①站位**：不变，仍是叶夕压在上、对方在下。
- **②动作链**：对方出声要叶夕起来 → 其眼中原有的异常情动褪尽、意识回到可控、面上浮起冷意 → 叶夕却认真追问对方"是不是好了" → 对方被这么问更羞恼、再次命令叶夕起来。
- **③对话**：对方命叶夕起身（**意图**：掩饰羞恼、划清界限、恢复冷淡人设）；叶夕真诚问对方是否已恢复（**意图**：字面的关心，完全没读懂气氛——制造反差喜感）；对方更羞恼地重复命令。直给情绪，无需潜台词。
- **④内心**：叶夕对这份骤冷有点没反应过来。
- **⑤感官锚点**：对方面上转冷的表情；语气里混进的羞恼。

### 第7拍 · 被弃的失落（L2/N3/压抑）
- **①站位**：不变。
- **②动作链**：交代——对方那股燥热异常来得突然、此刻退得也突然；燥热一退，叶夕这个"给对方降温的对象"就失去了被需要的价值 → 对方不道歉、还骤然冷淡 → 叶夕心里涌起一种不寻常的失落，连对方催促声都变得刺耳。
- **③对话**：无（对方催促声作为背景）。
- **④内心（本拍重点）**：一步步——先意识到刚才的亲密像没发生过、自己被"用完就丢" → 再意识到对方连道歉都没有、还转冷 → 生出反常的失落（连自己都说不清为何失落）。
- **⑤感官锚点**：对方催促声此刻听来的刺耳感。

### 第8拍 · 挣扎→更深摩擦→双双僵住（L2/N1/紧张）
- **①站位**：仍贴压，距离过近。
- **②动作链**：叶夕迟迟没拉开距离 → 对方下意识挣扎两下 → 因距离太近，挣扎非但没脱身、反而让两人身体产生更深摩擦 → 异常热意攀升 → 两人同时僵住 → 对方不敢再乱动、脖颈又红、只能更弱声央求叶夕起来。
- **③对话**：对方弱声央求叶夕起身。**意图**：既想脱身又怕越动越糟，语气软下来。
- **④内心**：一句带过——两人都被那股攀升的热意惊住。
- **⑤感官锚点**：更深摩擦处攀升的热；对方脖颈再度泛红。
