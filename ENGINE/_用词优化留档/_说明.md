# 用词优化 · 留档目录说明（这套元流程的「归档结构规范」）

> 本目录收纳**用词优化元工作流**（维护工坊 / 服务=工作流）每一轮的中间产物。
> 它跑在写书主管线之外、不属于任何一本书，所以 BOOKS 的归档规范管不到它——本文件就是它专属的归档规范。
> 权威流程仍以 `ENGINE/prompts/用词优化-总览.md` 为准，本文件只补充「产物怎么落盘」这一层。

---

## 一、设计哲学（沿用 BOOKS 归档规范的三条）

1. **不可变快照**：每一步产物一旦生成只增不改；迭代要改是新增带轮次后缀的文件，不覆写。
2. **固定语义槽位编号**：`00~04` 五个编号**绑定固定步骤**（见下表），跨轮、跨范文看同一个编号=同一步，便于横向对比。
3. **溯源信息头**：每份产物顶部带 YAML frontmatter，说明「我是哪步生的、吃了什么、依据什么规则」。

---

## 二、目录粒度：一范文一文件夹

每跑一篇范文（一章）开一个文件夹，命名 **`<范文标识>-<日期>`**：

- 范文标识：项目内定稿用「书名+章」，如 `星海弃兵第8章`；外部范文用「外部-<来源简称>」，如 `外部-某白金文`。
- 日期：`YYYYMMDD`，由执行该轮的 agent 用当天日期填。
- 例：`星海弃兵第8章-20260821/`、`外部-某白金文-20260821/`

```
<范文标识>-<日期>/
├── 00-范文原文.md      ★标准/参考   逆向提取步存入；⚠ 盲重建步禁止打开
├── 01-逆向骨架.md                   逆向提取产出（盲重建的唯一合法输入）
├── 02-盲重建稿.md      ★被测/重建   盲重建产出（与 00 并排对比的那份）
├── 03-对比差距.md                   对比差距产出（抽象倾向清单，不抄原文例句）
└── 04-优化建议.md                   抽象优化与回填产出（对各文风层的抽象建议）
```

---

## 三、编号槽位总表

| 编号 | 内容 | 由哪一步产出 | 语义 |
|---|---|---|---|
| `00-范文原文.md` | 标杆范文这一章的原文 | 用词优化-逆向提取（顺手存入） | **标准/参考文档** |
| `01-逆向骨架.md` | 剥掉用词腔调的骨架包 | 用词优化-逆向提取 | 盲重建的唯一合法输入 |
| `02-盲重建稿.md` | 拿骨架盲写出的这一章 | 用词优化-盲重建 | **被测/重建文档** |
| `03-对比差距.md` | 逐维度抽象倾向差距清单 | 用词优化-对比差距 | 只比文风，不抄原文 |
| `04-优化建议.md` | 对各文风层的抽象优化建议 | 用词优化-抽象优化与回填 | 《工坊报告》主体 |

**迭代多轮**（回填后再跑盲重建-对比看收敛）：`00`、`01` 不变，新一轮的盲重建稿/对比/建议加轮次后缀 —— `02-盲重建稿-r2.md`、`03-对比差距-r2.md`、`04-优化建议-r2.md`。轮次后缀 `-r2 -r3 …` 即闭环迭代的第几轮。

---

## 四、★ 盲测隔离红线（铁律1 在落盘层的落实）

`00-范文原文.md` 和 `02-盲重建稿.md` 放在**同一文件夹**是为了**事后并排对比**（第3步「对比差距」及人工回看），**不是给盲写时参考**。因此：

- `00-范文原文.md` 由 **逆向提取步** 存入；执行 **盲重建步** 的 agent（独立上下文、未看过原文）**只准打开 `01-逆向骨架.md`，严禁打开同目录的 `00-范文原文.md`**。看了=作弊，整轮作废。
- 为防手滑，`00-范文原文.md` 顶部溯源头下面**必须再写一行醒目警告**：`> ⚠ 本文件是范文原文，仅供第3步对比与人工回看；执行盲重建（第2步）的 agent 禁止阅读本文件。`
- 到 **第3步「对比差距」** 时盲测已完成，此时才可同时读 `00` 与 `02` 做对比。

## 五、溯源信息头（每份产物顶部）

统一 YAML frontmatter，字段：

```yaml
---
范文: 星海弃兵第8章        # 或 外部-某白金文
轮次: r1                   # 迭代第几轮，首轮 r1
步骤: 用词优化-盲重建       # 整洁中文步骤名
步骤类型: 盲写             # 提取 | 盲写 | 对比 | 回填
上游:                     # 这一步吃的上一版产物（可多个）
  - 01-逆向骨架.md
依据规则:                 # 走了哪些现有正向链/知识层规则（整洁名）
  - 场面调度
  - 句意稿
  - 正文生成
  - 独立正文自查
盲测隔离: 是（本步全程未接触 00-范文原文.md）   # 仅盲重建步需声明，写“是”即承诺没作弊
产出时间: 2026-08-21
执行: Claude Code / opus-4-8
---
```

- **提取步**（01、以及存入 00）：`步骤类型: 提取`。
- **盲写步**（02）：`步骤类型: 盲写`，且**必须带 `盲测隔离` 字段**声明没看原文。
- **对比步**（03）：`步骤类型: 对比`，`上游` 指向 `00` + `02`。
- **回填步**（04）：`步骤类型: 回填`，`上游` 指向 `03`。
