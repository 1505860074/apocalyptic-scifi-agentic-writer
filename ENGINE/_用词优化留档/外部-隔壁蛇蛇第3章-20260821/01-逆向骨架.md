# B 人物落笔（中性描述，不含文采）

### 叶夕（视角人物）
- **表层设定**：刚搬进这套新公寓不久、对格局还不熟；性格单纯、善良、有点迟钝（听不出话里的言外之意）；脖颈处有一颗红痣。
- **底层可见部分**：体温异常高（自身滚烫、能明显感到别人身上的凉）；淋雨对她无碍；儿时曾随祖母在山里住过几年，祖母常外出工作、留玩偶陪她；新家的布置（每处都铺长毛地毯）是祖母安排的。捏玩偶手臂时，她自己小臂对应位置会浮现指印——暗示她的身体与玩偶存在某种连结。被沈明矜当面断言"根本不是人"。（＝她自己也非普通人的伏笔）
- **本章当前状态**：把昏迷的邻居带回家照料；因体温互补而贪恋对方的凉；对玩偶室与旧物又惊又喜；先后被强吻两次，从暧昧、慌张到困惑（不懂对方为何控诉自己）。

### 沈明矜（另一主角）
- **表层设定**：叶夕的新邻居，容貌艳丽、风情浓；身上带一股甜香（有诱惑/吸引力）；说话声音软。
- **底层可见部分**：体温异常低（凉、寒）；淋雨后昏迷、醒来后神志半失控；腹部会透出细软白光（被抱枕/衣物遮挡）；像索取热源般主动缠上体温高的叶夕、并亲吻她；会自咬下唇渗血、像在克制某种渴求；当面指叶夕"不是人"、并质问对方"为何骗她能淋雨"（暗示她自己也非人、雨对她有特殊意义）。（＝她为非人/蛇类的伏笔）
- **本章当前状态**：从昏迷被抱回→醒来后失控索热、强吻→跳开自伤、控诉、委屈→再次拽叶夕入怀吻上。全程处于一种"被本能驱使、又努力克制"的矛盾态。

### 祖母（不出场）
- 只在叶夕回忆/心理中出现：儿时的照护者；曾把玩偶小夕收走、骗叶夕说丢了，如今又在新家出现；新家布置出自她手。年迈。（＝布置玩偶室、把小夕留给叶夕背后有隐情的伏笔）

# C 事件与大纲

- **一句话主线**：叶夕把昏迷的冰冷邻居沈明矜带回家照料，其间在隔壁发现一间藏着近千玩偶的房间（含儿时旧物粉兔"小夕"、以及一只会发光、被她摸过后变得更红的红蛇玩偶）；返回客厅后，醒来的沈明矜像索取热源般缠上体温滚烫的她、强行吻她，随即跳开、咬破自己嘴唇、控诉她"不是人"，最终又把她拽入怀中再次吻上。
- **本章功能定位**：①关系推进——完成"初吻"这一里程碑，把两人从"刚认识的邻居"迅速拉进暧昧强张力；②密集铺设超自然伏笔——双方皆非人的暗示、玩偶与身体相连、体温一冷一热的互补设定、腹部白光、红痣、红蛇玩偶变色；③以"二次吻＋对方的异常"收束成悬念钩子。

# E 场面调度层（逐拍·物理调度，不写文采）

### 节拍1（L2/N1/紧张）
- **①站位/空间**：电梯轿厢内，叶夕站立、双手托抱着昏迷的沈明矜；两人贴得近；视线正对电梯门。
- **②动作链**：叶夕托稳对方 → 近距离下更明显闻到对方身上的甜香 → 意识到这香带吸引力、下意识想靠近 → 反而绷紧、僵直背脊、连眼神都克制着不往下看对方的脸 → 死盯电梯门，等到站提示音响起才松一口气。
- **③对话交锋**：无（对方昏迷）。
- **④内心微动**：一句——从"闻到香"到"不敢看脸"的自我克制。
- **⑤感官锚点**：对方身上的甜香（近距离更浓）；电梯门；到站的提示声。

### 节拍2（L2/N1/紧张）
- **①站位/空间**：出电梯，走廊上；一盏老旧灯泡是唯一光源，昏暗、灯丝迸火花后越来越暗、有细碎光斑落在对方脖颈上；叶夕停在自家密码锁门前。

- **②动作链**：叶夕把人平放到沙发上 → 对方一沾沙发像有所感、随手抓过一个抱枕护在腹部 → 在抱枕盖住前，叶夕似看到对方腹部有细软白光透出布料 → 抬头看了眼明亮的顶灯 → 判定是对方太白＋灯太亮的错觉、说服自己是眼花。

- **④内心微动**：一闪的疑惑 → 迅速自我否定。
- **⑤感官锚点**：抱枕；腹部透出的白光；明亮的顶灯。

### 节拍4（L2/N2/平静）
- **①站位/空间**：沙发前，叶夕站/俯身处理湿衣的对方。
- **②动作链**：叶夕看着湿漉漉的对方犯难 → 想到湿衣睡觉会感冒、动念换衣 → 又想到两人今天才认识、换衣太逾越冒犯 → 放弃换衣 → 翻出浴巾把对方裹住吸水 → 再用厚毛毯裹起 → 小声祈祷别感冒。

4. 叶夕滚烫的呼吸打在对方脸颊上，对方像不受控地前倾。
5. 一个轻柔的吻覆上叶夕的唇（＝叶夕的初吻）。
6. （余韵）叶夕震惊瞪圆眼，意识到这是自己的初吻；尝到吻是甜的、湿的、还带一点奇怪的味道。

### 节拍13
1. 吻完，对方突然从叶夕背后跳下，身体晃、跌坐到客厅长毛地毯上。
2. 叶夕看清对方此刻：脸颈浮起异样潮红；下唇有明显被自己咬破的伤口在往外渗血珠，唇边有晕开的血。
3. 叶夕反应过来：刚才那股怪味就是血。
4. 叶夕判断对方在克制某种渴求、明显不对劲。
5. 叶夕既不敢靠近对方、也没跑远。

### 节拍14
1. 对方仰头与叶夕对视，压着声音让叶夕"别靠近我"。
2. 对方红着眼控诉叶夕"根本不是人"，质问她"明明能淋雨，为什么骗我"。
3. 叶夕完全不懂自己何时骗了对方：她从没说过自己不能淋雨，是对方自己判断后把她推进屋的；也没把这句当成"陈述句/揭示"来理解。
4. 叶夕觉得对方看着很可怜、不像真在骂人（声音软、脸上是委屈不是凶戾），一时不知该进该退、举着冰水僵在半空。
5. 叶夕想了想，还是把冰水递过去、劝对方喝点。
6. 对方手指突然搭上叶夕手腕、猛地把她往下拽。
7. 冰水泼在对方胸口，叶夕跟着跌进对方怀里，手臂压到一片柔软。
8. 叶夕反应过来压到哪，脸涨红、呼吸更烫。
9. 那含着甜香的吻再次覆上（章在此收，钩子）。
