# 人物卡 · 配角/阶段性反派（双层）·《我靠发疯续命》

---

## 基本信息
- **姓名 / 代号**："执笔人"（组织内部代号——他负责给触发者引发的事故编写官方定性说辞，讽刺意味明显；真名暂不设，留待写作中揭示）
- **角色定位**：隐藏组织在明面上的"清理/定性"专员，第1卷的直接对手/威胁来源
- **登场卷章**：第1卷中段（第3章前后察觉存在，中后期正式登场）
- **一句话人设**：一个手段温和、说话客气到让人发毛的"体制内的人"，专门负责把别人的悲剧写成"合理的意外"。

---

## 表层（外在 / 读者一眼可见）
- **外貌特征**：西装革履，永远得体，气质像"办事效率极高的公务员"，没有传统反派的凶相。
- **身份 / 职业 / 技能**：对外身份是某官方心理健康管理机构的"事故后心理评估专员"，实际是组织派驻处理触发事故的一线执行者；技能是能从公开渠道信息里快速识别出"异常事故"的蛛丝马迹（跟主角的直觉能力形成镜像/对照）。
- **说话方式 / 口头禅**：永远客气、永远慢条斯理，习惯用"为大家好"这类温和措辞包装冷酷的决定。
- **习惯动作 / 标志性小动作**：说话前习惯先推一下眼镜，动作缓慢、有仪式感，给人一种"一切尽在掌握"的压迫感。
- **表面性格**：温文尔雅，礼貌周到，让人本能地想信任他——这正是他好用的地方。

---

## 底层（内核 / 行动的真实驱动力）
- **核心欲望**：维持"秩序"——他真心相信自己在做的事是在防止社会大规模恐慌，是"必要的恶"。
- **核心恐惧**：怕失控——怕自己当年（暂定：也曾是触发者，或亲历过一次未被控制住的触发事故）经历过的惨剧重演。
- **创伤 / 来历**：方向留白，暂定他自己或身边人也曾是野生触发者，正是因为亲眼见过失控的代价，才彻底倒向"必须被控制/驯化"这一边——这样他和主角是同一种创伤的两种选择结果，避免脸谱化反派。
- **价值观 / 底线**：为达成"秩序"可以牺牲少数人，但不会毫无理由地虐杀——他不是纯粹的恶人，是一个选错了方法的、有自己逻辑自洽的人（呼应"势力非好即坏"的创作原则，不写绝对正邪）。
- **表里冲突**：表面温和讲道理，内核是把"控制"等同于"安全"的偏执，一旦这个逻辑被戳破会有明显的裂缝。

- **剧情作用**：第1卷的直接威胁来源，也是组织"到底是不是纯粹恶"这一命题的具体载体；后续可能揭示他和主角至亲事故的关联。
- **与主角的关系弧**：陌生的威胁 → 正面交锋的对手 → （方向不定死，可能走向"理念对撞但互相理解"，也可能走向彻底对立，写作中收束）。
- **结局去向**：不定死。
