# 人物卡 · 主角（三层）·《我靠发疯续命》

---

## 基本信息
- **姓名 / 代号**：苏怀真（同事私下叫他"苏疯子"）
- **角色定位**：主角
- **一句话人设**：保险公司事故查勘员，靠夸张发疯撑过每一次"真心快要爆炸"的临界点，是这世上唯一活着还搞明白怎么控制的"疯子"。
- **贯穿全书的核心标签**："全公司最会演的疯子"——名字里的"怀真"是反讽：他怀里揣着这辈子最不能说出口的真心。

---

## 第一层 · 表层（外在 / 读者一眼可见）
- **外貌特征**：长相普通、气质温吞，标准"社畜脸"，没什么记忆点——这是他刻意维持的，情绪爆发时越没人记得住他长什么样越安全。
- **身份 / 职业 / 核心技能**：某保险公司理赔查勘员，五年工龄。核心技能是能从"不合常理的事故现场细节"里一眼看出蹊跷——这项技能其实部分借助他对**同类触发者遗留的环境物理痕迹**（如极轻微的电器失真、若有若无的"通电感"，见金手指卡"物理形象"条目）异常敏感，不是感知对方本人的情绪/体质状态（这违反体质"无法感知他人状态"的硬规则），他自己一直以为是纯粹的职业天赋，没意识到原因。
- **说话方式 / 口头禅**：平时说话四平八稳、滴水不漏（保险行业训练出的话术）。发疯时判若两人——台词浮夸、自称"本疯"，动手前有一句专属发疯宣言："不发疯，就得死人。"（他自己场合专属使用，不是全书信条，别的角色不能借用——见K7词汇多样性铁律）
- **习惯动作 / 标志性细节**：情绪临界前会先摸一下自己脖子后侧（那里会"发烫"，是他自己摸出来的预警信号）；发疯泄压时有一套固定的夸张肢体仪式（甩外套/跳上桌子/怪笑），像某种自创的"泄压咒语"。
- **表面性格 / 外界评价**：同事眼里"人畜无害但偶尔神经质"的老好人，查勘经验丰富、办事靠谱，就是"有点怪"。

---

## 第二层 · 底层（内核 / 行动的真实驱动力）
- **核心欲望**：想找到"不用发疯也能活下去"的办法——本质是想有一天能说一句真话，不用死人陪葬。
- **核心恐惧**：怕自己有一天控制不住，重演至亲当年那样的"消失"事故——而且这一次，身边可能是他真正在乎的人。
- **创伤 / 出身**：12岁那年目睹哥哥苏怀舟情绪失控后"消失"于一场被定性为天灾的厨房坍塌事故（哥哥出事前对他说的最后一句话是"等我"），从此被灌输"绝对别有情绪"的生存法则长大，直到成年后一次重大刺激下自己才首次觉醒——发现这条从小信奉的法则本身是错的。哥哥的姓名"苏怀舟"、临终遗言"等我"，已在第1弧收尾章（第7章）由苏怀真亲口喊出，定死不再更改。
- **价值观 / 底线**：宁可自己扛着、装疯卖傻，也不愿把这份"要命的真相"转嫁给任何一个不知情的人；绝不主动伤害无辜的野生触发者，哪怕组织开出诱人条件。
- **表里冲突**：表面是个滴水不漏、情绪稳定的"老好人"，内核是一个从不敢说真心话、随时可能因为一句真话要了自己或别人命的定时炸弹。
- **能力成长线**：本能式硬撑发疯 → 摸索出"分级泄压法" → 能主动引导释放方向 → 能对极少数信任者说部分真话（对应金手指卡"滚雪球路径"）。**注意（V1校验提示）**：多年来他并非从未失手——早年闯过几次没人知道的小祸，第1章的成功化解是"运气好+对手情绪不算复杂"，不代表他已经很熟练，写正文时应有一句自然侧写交代这一点，避免"练了五年怎么还这么菜/怎么突然就这么稳"的说服力落差。

## 第三层 · 命运层（秘密 / 弧光 / 宿命，多为长线大伏笔，读者逐步揭开）
- **隐藏秘密**：他对"事故现场蹊跷之处"的敏锐直觉，可能不是单纯的职业经验——而是体质带来的对**同类触发痕迹的物理敏感**（不是感知对方本人状态，只是能捕捉到环境里残留的异常物理信号）。他自己一直以为是天赋，不知道原因（模糊方向，不定死）。
- **成长弧光**：从"只能靠夸张表演代替真心、独自硬扛"，逐渐走向"能对少数信任的人说真话，并牵头建起一个让同类不必独自硬扛的地方"（方向，不定死具体节点）。
- **与主线的宿命联系**：他和隐藏组织、和至亲当年"消失"事故之间存在尚未揭开的因果关联（模糊，留待写作中发现）。
- **关键抉择点**（1-3个价值观级重大抉择，不定死具体章节）：
  1. 是否要为了自保，向组织交出一个刚觉醒的野生触发者。
  2. 是否要为了查明真相冒险直面组织，可能让身边人暴露在危险中。
  3. 在真的有机会对某个人说真话时，要不要冒着可能失控的风险说出口。
- **模糊命运方向**（不定死，只写"感觉"）：感觉是走向"和解与重建"，不是单纯打倒组织的爽文式终局，更可能是"活成一个让真话不再致命的先例"。两个可能方向：①牺牲式收尾——用一次可控的巨大真心释放换来关键胜利，自己承担代价但不一定死；②重生式收尾——彻底掌握体质，成为新一代互助网络的核心。写作中自然收束，现在不选。
