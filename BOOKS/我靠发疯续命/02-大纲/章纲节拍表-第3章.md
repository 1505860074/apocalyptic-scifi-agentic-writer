# 第 3 章 · 十七起 ·《我靠发疯续命》

- **章节类型**：常规
- **承接上章钩子**：林知遥质问"你是不是也一样？"
- **本章目标**：处理苏怀真对林知遥的回应，随后执笔人以官方身份登场，苏怀真察觉此人不对劲，组织线正式浮现
- **出场人物**：苏怀真、林知遥、执笔人
- **地点 / 场景**：心理援助热线办公室（延续上章）→ 保险公司（执笔人登门/致电）
