# 卷纲 · 第 1 卷《求生》（修订版 · 拉长至 50–60 章 · 主线做骨架，重心转向角色 / 悬疑 / 多视角）

> **修订说明**：原卷纲把"求生→围城"主线当成 50–60 章的主体，但实际写作以"一章一大节拍"的压缩节奏，到第 9 章已把主线骨架（归零→聚人→第一次围城守住）走完。本次按新方向重订：**卷 1 仍要 50–60 章，但不死磕主线**——主线只作骨架，绝大部分篇幅铺开**角色特别篇、方舟能力探索、悬疑 / 反转、多视角叙事、羁绊与据点成长**；**重心离开"战斗 / 危机"**，战斗只作点缀骨架的少数节点。

- **本卷在全书螺旋中的位置**：自保（螺旋第一环）
- **一句话**：归零后，常安从地下室巴掌大的洁净场起步，聚起第一批幸存者、打退第一波感染者潮立住名声；此后在这处据点里，一群劫后余生的人慢慢结成羁绊、把避风港越滚越大，而常安手里那台"什么都懂"的破机器，正一点点显露出它不该有的异常——第一卷在温情、悬疑与逐渐逼近的更大危机中走向卷末。
- **字数 / 章数**：约 12–15 万字 / 50–60 章
- **时间跨度**：归零第 0 天 ～ 约第 2–3 周（末世初期，威胁以感染者为主，人祸未起）

## 写作重心（本次修订的核心）
1. **主线只作骨架**：求生、资源、感染者危机是背景骨架，少而精，不靠密集战斗推进。
2. **角色为主体**：给每个据点成员足量的"特别篇"与内心戏——周铁山（退伍老兵的过去与入伙心路）、林晚（研究员的执念、银纹之谜）、老头与小丫头（来历与温情）、常安（"没用之人"的自我和解、妹妹的结）。
3. **方舟能力探索**：在和平 / 建设场景里逐步展开方舟的能力（进阶回收、数据碎片升级科技树、扫描分析、建造滚雪球），基建爽感不依赖战斗。
4. **悬疑 / 反转为暗线主引擎**：方舟的异常与隐瞒（S01 / S05）、林晚半重构之谜（S04）、常安未被同步之谜（S02）、城市中心的规律信号、数据尘 / 同步的真相碎片——用信息差与多视角，让"读者先于角色觉得不对劲"，攒反转势能。
5. **多视角 / 换主角叙事**：设"特别篇 / 特殊叙述章"，临时切到配角第一人称或贴身视角（如"我是周铁山……"、正在被同步的普通人视角）。**注意：常安贴身第三人称仍是全书默认主视角，多视角只用于明确标记的特殊章。**

## 核心三要素
- **核心矛盾**：活下去 + 人心 + "身边这台机器到底是什么"的暗涌不安。
- **主角大目标**：把第一个据点站稳、滚大，聚起并守住一群人；同时不知不觉被卷入方舟的秘密。
- **卷末高潮（重订 · 不以纯战斗为中心）**：一场"更大的危机 + 悬疑小爆点"叠加——例如孢子潮催出的更大规模感染潮压境，同时方舟的异常在关键时刻藏不住 / 救场，让常安第一次真切意识到"这机器有秘密"，据点惨胜或化解，卷 1 真正收尾。（具体形态写到再定。）

## 阶段结构（章块规划，不逐章拆死）
- **第一阶段 · 绝境起步（第 1–3 章，已定稿）**：归零→激活方舟→巴掌大洁净场→救林晚。黄金三章。
- **第二阶段 · 聚人立名（第 4–9 章，已写）**：安家→出门→收周铁山一行→内讧→高阶体→备战→**第一次围城守住、立"能活人"的名声**。（原定"卷末围城"在此**降格为阶段性立名之战**，非卷末。）
- **第三阶段 · 喘息与暗涌（第 10 章起，新重心）**：围城后的清点、疗伤、羁绊；方舟能力探索（回收同步体尸体得数据碎片、升级科技树、据点滚雪球）；名声外传引来零星投奔者；**悬疑线加重**——常安 / 林晚开始察觉方舟"懂得太多"。穿插角色特别篇（周铁山、林晚、老头小丫头）。
- **第四阶段 · 群像与谜团（中段若干章）**：多视角 / 特殊叙述章（同步者视角看"感染"的恐怖与悲凉；配角特别篇）；更多幸存者带来的新矛盾与温情（人祸仍留卷 2）；据点从安全屋成长为小据点；悬疑各线（S02 / S04 / S05）持续加压，抛出更多"读者先觉不对劲"的钩子。
- **第五阶段 · 真 · 卷末（卷末数章）**：更大危机 + 悬疑爆点叠加的卷末高潮；卷 1 收尾、立稳脚跟；卷尾钩子指向卷 2（方舟信号→旧世界设施线索、秩序崩坏 / 人祸苗头）。

## 情绪抛物线（重订）
冷峻绝境（归零）→ 第一次"护住人"的暖 → 聚人立名的紧张与燃（第一次围城）→ **转入喘息、温情、群像与逐渐发酵的悬疑不安（本卷主体）** → 谜团与更大危机双线收紧 → 卷末惨胜 / 揭一角，暖与悬疑并存收束。

## 基建成长
- **起**：孤身 + 一台工控机 + 巴掌大洁净场。
- **终**：能容纳十几人、有物资回收 / 建造 / 防御 / 初步分工的安全屋据点，方舟科技树初步铺开（数据碎片升级线启动）。

## 金手指进展
- 解锁：环境扫描 → 物质回收 → 洁净场 → 初级建造 / 防御 → **数据碎片升级科技树（本卷中段起，探索方舟更多能力）**。
- 达成里程碑 1：首个稳定洁净场。埋"算力 / 能源是瓶颈"的成长空间；载体升级留卷 2。

## 人物
- **新登场**：林晚、周铁山、老爷子、小丫头、后续零星投奔的幸存者。
- **弧光推进**：常安"装怂自保→主动扛起这群人"（弧光高光已在第 8–9 章围城当众担事兑现；本卷后段转入更内在的"自我和解"）；周铁山"只信自己人→认下常安、成最早臂膀"（已达，本卷后段用特别篇补厚）；林晚"怕变怪物→被接纳、显价值"（推进中，绑悬疑线）。

## 特殊章节规划（重订 · 大幅增加）
- **角色特别篇（多视角 / 换主角）**：周铁山特别篇（"我是周铁山"）、林晚特别篇（研究员与银纹）、老头小丫头（来历温情）等，穿插于第三、四阶段。
- **同步者视角特殊章**：中段某章，切到一个正在被同步、意识渐灭的普通人视角（悬疑 + 悲凉）。
- **氛围章**：死城踏查 / 孢子潮天气等，营造末世底色。
- **战斗章**：第一次围城（第 9 章，已写）；真 · 卷末更大危机（卷末）。**战斗少而精，不作主体**。

## 伏笔（悬疑线加重 · 同步进伏笔表 / 桥段表）
- 本卷埋并逐步加压：S01（方舟异常台词）、S02（常安未被同步之谜）、S04（林晚半重构有意识）、S05（方舟隐瞒的城市中心规律信号）。
- **新增悬疑手法**：多视角信息差——让读者透过配角 / 同步者视角，先于常安嗅到方舟与灾难的不对劲，攒"反转感"。
- 本卷以埋为主，基本不回收大伏笔（符合开局卷）。

## 注意（末世演进）
本卷仍是末世初期，威胁只有感染者 / 重构体等自然威胁；**有组织的人类掠夺者（铁蜂等人祸）留到第 2 卷**（秩序崩坏后）。详见《末世演进的时间线规律》。
