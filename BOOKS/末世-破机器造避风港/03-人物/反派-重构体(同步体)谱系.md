# 反派设定卡 · 重构体 / 同步体 谱系【进化型威胁】

> 灾变把暴露于数据尘的人/生物"格式化重构"成的半机械怪物。**设定称「重构体」，方舟扫描称「同步体」**（按"同步进度 %"分级）。本卡锁定各阶特点，保证上下文一致；随剧情进化，新阶在此**往下追加**。机制根源见《世界圣经》《世界观设定卡》。

## 通用特征（所有阶共有）
- **来历**：吸入过量数据尘 → 神经同步 → 大脑在数分钟内被覆写、丧失自主意识 → 躯体逐步金属化。
- **外观共性**：皮下爬着银色金属脉络（银线），越高阶越明显；喉咙 / 关节有齿轮般"咔咔"声。
- **心智（写作硬锚）**：意识被覆写，**不知疼、不知怕、不知累、不会退**。不像人会溃逃、不像野兽会趋利避害；前排撞死，后排**踩着同类的尸体往上爬**（第 8 章由林晚点破，第 9 章围城兑现）。
- **驱动**：靠追踪**活人的动静、热气、气味**猎食/攻击；随吸收金属 / 数据**持续迭代进化**（吸收越多，阶越高，规则明确、不忽强忽弱）。
- **核心**：体内有可回收的"**数据碎片**"（越高阶浓度越高），是金手指解锁科技的关键资源。

## 一阶 · 初级同步体（普通重构体）——第 1 章起
- **原型出场**：老张（第 1 章变的）——皮下银线往外拱、把皮撑得一鼓一鼓；喉咙"咔咔"响像齿轮没对上；动作僵直却快得不像人；眼睛直勾勾，却"像根本没在看"。
- **行为**：迟缓、成群、乱晃瞎撞、没个消停；**眼神不济**，主要靠声音 / 动静定位，找不准就散。
- **弱点（常安赖以保命）**：眼瞎耳钝 → 可用声东击西（第 5 章三轮撞煤气罐）、假热源 / 假动静引开、封门堵路躲避；迟缓，可跑可拖。
- **威胁级别**：初级。单个不难，**架不住数量**（成群、围城）。

## 二阶 · 高级同步体（进化体）——第 7 章首次出现
- **首次出场**：第 7 章巷口那一个，同步进度 **78%**，远高于常见个体。
- **外观**：乍看同普通重构体（银线、佝偻），但**站得笔直，脑袋缓缓转动，像在看、在找**。
- **能力（专门打破常安套路）**：**感官部分恢复，具备视觉与主动搜索**；会看、会找、会追热源 / 气味 / 热气；**力气极大**（一爪半截墙塌）；**聪明**——诱饵骗不久会起疑、会打转搜索。
- **弱点 / 打法**：仍可被"假热源诱饵"暂时引偏（但会识破）；须靠环境（塌楼、承重梁）＋ 协作 ＋ 陷阱才能险胜，硬拼代价大（第 7 章周铁山负伤）。
- **掉落**：高浓度数据碎片（硬币大小晶体、入手冰凉）。
- **威胁级别**：中级苗头。它的出现＝**威胁在进化**的信号（周铁山："要是它们都往这样变呢"）。

## 进化线定位（剧情用）
初级（靠数量、睁眼瞎）→ 高级 / 进化体（会思考、感官恢复）→ ……（更高阶：会用工具 / 群体协作；终极：神谕的"执行终端"，近纯机械、带旧世界军工科技）。**越往后越聪明、越强**，逼着常安"信息差 + 基建"的打法逐级升级。

## 写作注意
- 初级＝**睁眼瞎、靠动静**，常安的骗术才成立；别把初级写得会看会想。
- 高级＝**会看会找会起疑**，专门用来**打破**初级的套路、逼主角想新招；别让它被简单声东击西骗死。
- 心智那条（不知疼怕累、不退、踩同类往上爬）要贯穿，尤其围城 / 群战时——它决定了"堆墙没用、得逼窄道逐个收拾"的打法。
- 拟声（咔咔）节制；进化**有规则**（吸金属 / 数据越多越高阶），别忽强忽弱。
