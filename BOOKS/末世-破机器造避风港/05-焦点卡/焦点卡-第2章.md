# 第 2 章《巴掌大的安全》· 本章焦点卡（重写版）

## 施工图

### 承接
第1章末——常安在地下室铁门后，门外老张撞门，方舟告知配电室有三个宿主。

### 本章目标
常安利用方舟扫描的同步体弱点（靠声音定位）+ 废品站地形（电梯井），智取能源核心，建立第一个洁净场。

### 节拍表

| 节拍 | 做什么 | L级 | 情绪温度 |
|------|--------|-----|----------|
| 开场 | 承接撞门声，方舟补全同步体特性 | L2 | 恐惧→冷静 |
| 推进 | 猫出地下室→观察配电室三宿主 | L2 | 紧张 |
| 波折 | 钢管砸墙诱敌→四宿主坠入电梯井 | L2 | 刺激/爽 |
| 高点 | 接入能源核心→洁净场张开→第一口干净空气 | L3 | 释放/暖 |
| 钩子 | 配电室角落杂物堆后有东西动了一下 | L2 | 悬疑 |

### L3定位
- **高点L3**：洁净场张开的瞬间——光晕从方舟荡开，飘浮的灰尘碰到边界簌簌落下，常安扯下蒙脸布吸第一口气，那一口空气的"干净"要用全部感官写透。

### 爽点与钩子
- 爽点类型：智取（信息差 + 地形，一人一根撬棍解决四个同步体）+ 建设（第一个洁净场建立）
- 章末钩子：杂物堆后头有个人——女孩蜷在墙角，右臂爬着和老张脸上一模一样的银纹，可她的眼睛是活的。

## 加载清单

### 出场人物
- **常安**：弧光推进——"怂出智慧"，打不过但脑子快，自己的地盘自己熟
- **方舟**：弧光不变——纯工具腔，提供同步体弱点信息（声音定位/视觉退化）
- **林晚**：弧光起点——半重构女孩，银纹与老张相同但保有意识，"我还是人"定调

### 涉及设定
- 同步体特性（初级：靠振动和声响定位，视觉退化，动作僵而快）
- 洁净场机制（方舟+能源核心→半径3.2米光晕，主动净化数据尘）
- 能源核心接入方式
- 电梯井构造（贯通B1-2F，栅栏锁锈死，井底机坑光滑）
- 物质回收模块解锁（战后触发提示）

### 要推进的伏笔
- **F03 埋点**：林晚半重构却有意识（同步进度37%已停滞，与已知同步体完全不同）
- 电梯井封困四宿主（为后续潜在威胁埋线）
- 洁净场建立标记（第1卷首个里程碑）

### 逻辑雷区
1. 同步体弱点均来自方舟扫描，常安不自行推导科学原理
2. 智斗逻辑自洽：声音定位→钢管制造声源→井壁光滑爬不上→物理困住
3. 常安在林晚出现后本能藏方舟底牌，不亮所有功能
4. 林晚银纹描写节制——一句"跟她脸上一样"足矣，焦点在她眼睛
5. 空间动线：地下室→一层废品站→二层配电室→电梯井，路径清晰无误
6. 洁净场半径3.2米合乎能源核心功率，不完全罩住整栋楼
