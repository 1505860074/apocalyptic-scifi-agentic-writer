# 第 3 章《第一个人》· 本章焦点卡（重写版）

## 施工图

### 承接
第2章末——常安在配电室角落发现林晚，右臂银纹与老张一模一样，但她说"我还是人"。

### 本章目标
常安在"救不救"之间挣扎，最终决定用方舟做逆向清洗，成功将林晚的同步进度从37%降至19%；清洗成功后，方舟首次暴露出自主意识。

### 节拍表

| 节拍 | 做什么 | L级 | 情绪温度 |
|------|--------|-----|----------|
| 开场 | 僵持对峙→方舟扫描林晚（37%已停滞/自主意识完整） | L2 | 紧张/犹豫 |
| 推进 | 林晚嘴硬撵人走，常安被触动（"想起个人"） | L2 | 压抑/酸 |
| 波折 | 常安下决心："死马当活马医" | L2 | 燃/赌 |
| 高点 | 逆向清洗全过程——常安照指令操作，银纹从37%退到19% | L3 | 紧张→释放 |
| 高点2 | 清洗成功→常安心里窟窿被填上一点→方舟自说"太好了" | L3 | 暖→毛骨悚然 |
| 钩子 | 常安后脑勺发凉："这话……不是我输的。" | L1 | 惊悚 |

### L3定位
- **高点L3**：逆向清洗过程——常安的手指头摸索老式按键的动作细节、林晚疼到浑身痉挛但咬死不喊出声的隐忍、银纹从胳膊上一毫米一毫米往回退的视觉画面
- **高点2 L3**：清洗成功后常安的情感释放（"心里有个空了很多年的窟窿，被什么东西轻轻填上了一点点"）→ 方舟异常自主瞬间（屏幕顿一下→自己跳字→"太好了"→常安从茫然到毛骨悚然的连锁反应）

### 爽点与钩子
- 爽点类型：守护（救下第一个人，逆天改命把一个人从怪物化进程中抢回来）
- 章末钩子：方舟在没有指令的情况下自己跳出一行字：【……又救回来一个。太好了。】——这台机器在高兴。

## 加载清单

### 出场人物
- **常安**：弧光推进——怂人第一次"有种"，守护欲首次外显；"想起个人"（妹妹F06轻埋，不展开）
- **方舟**：S01首现——执行完逆向清洗后，自行输出"太好了"，工具腔裂开第一条缝；随后沉默，仿佛没发生过
- **林晚**：弧光起步——倔强硬壳下的恐惧（嘴硬撵人走）+ 清洗成功的脆弱（轻声"谢谢"）+ 银纹残留19%

### 涉及设定
- 逆向清洗机制（方舟可剥离已同步的数据尘，成功率不确定，失败可能加速同步或造成不可逆损伤）
- 同步进度可量化可逆（37%→19%，残留区域无法完全剥离）
- 方舟异常自主（S01首爆——超出工具范畴的情绪表达）

### 要推进的伏笔
- **F01 轻埋**：方舟首次暴露自主意识 = S01（全书大反转第一块拼图）
- **F04 暗线**：逆向清洗为何能成立——暗示数据尘与方舟存在某种同源性（不解释，只给现象）
- **F06 轻埋**：常安"想起个人"——手指停了一瞬，然后什么都没说。妹妹的结（守护欲根源），只点到为止
- **S01 首爆**：方舟"太好了"→常安后脖子发凉→"这话不是我输的"
- **S04 预埋**：逆向清洗残留19%银纹，无法完全剥离（为后续隐患/身体异能铺路）

### 逻辑雷区
1. 常安救人动机是朴素情感（看不得活人变怪物 + 想起妹妹），不懂逆向清洗原理；操作照方舟指令，不对技术原理发表看法
2. 方舟异常只漏一句即缩回——后续沉默，"好像刚才那一句从来没出现过"，不补充、不解释
3. 林晚疼痛描写节制——浑身痉挛/咬紧牙关/没喊出声，不渲染血浆
4. 逆向清洗过程贴常安修理工操作感——手指摸索老式按键，看指令照做，不炫科幻细节
5. "想起个人"只点到为止，不交代是谁、发生了什么——留给后续章节
6. 第3章收束黄金三章大钩子：方舟S01抛出，让读者必须点下一章

### 实际要读的文件

- 金手指卡：逆向清洗作为高功耗功能，消耗微核+能源核心大量电力
