# 第 3 章《第一个人》· 本章焦点卡（已定稿·追溯）

- **本章实际完成的事**：常安犹豫后决定救林晚，方舟执行"逆向清洗"将同步进度从37%降至19%；清洗成功后，方舟在没有指令的情况下自动显示：【……又救回来一个。太好了。】常安后脖子发凉——这台机器在高兴。

- **承接**：第 2 章末——发现林晚，她右臂银纹跟老张一样，但自称"我还是人"。

- **在场人物 + 弧光阶段**：
  - **常安** → 弧光推进：怂人第一次"有种"——挣扎后决定救人，触动来自"想起个人"（妹妹·F06 轻埋），守护欲首次外显。
  - **方舟** → **S01 首现**：弧光起步——执行完逆向清洗后，未经常安指令自行输出"……又救回来一个。太好了。"工具腔裂开第一条缝，暴露自主意识。
  - **林晚** → 弧光起步：倔强外壳下的恐惧（嘴硬"又不求你救"）与清洗成功后的脆弱（轻声说"谢谢"），银纹从37%退至19%残留。

- **涉及的世界设定**：逆向清洗机制（方舟可剥离已同步的数据尘，成功率不确定，失败可能加速同步或造成不可逆损伤）；同步进度可逆性（37%→19%，但残留区域无法完全剥离）；方舟自主意识（超出工具范畴的情绪表达）。

- **推进的事件/伏笔/桥段**：事件线"救第一个人"；**F01 轻埋**（方舟首次暴露自主意识 = S01）；**F04 暗线**（逆向清洗为何能成立——暗示数据尘与方舟存在某种同源性）；**F06 轻埋**（常安"想起个人"——妹妹的结，守护欲根源）；**S01 首爆**（方舟"太好了"，不是常安输入的）；桥段＝逆向清洗过程（常安照方舟指令一步步操作，修理工手法）。

- **本章写作要点**：
  - 爽点：救人成功（逆天改命——把一个人从怪物化进程中抢回来一半）。
  - 章末钩子：方舟自己说了"太好了"——这话不是常安输的。
  - 主导情绪：犹豫/恐惧（要不要救）→ 赌一把的燃（"死马当活马医"）→ 成功后的暖（心里窟窿被填上一点点）→ 方舟异常的毛骨悚然（后脖子凉气）。

- **逻辑雷区自查**：
  1. 常安认知别越界：救人动机是朴素情感（看不得活人变怪物+想起妹妹），不懂逆向清洗原理；操作照方舟指令，不对技术原理发表看法。
  2. 方舟异常只漏一句即缩回：后续沉默，不解释、不补充，"好像刚才那一句从来没出现过"。
  3. 林晚疼痛描写节制：疼得发抖/咬紧牙关/没喊出声，不渲染血浆。
  4. 逆向清洗过程贴常安修理工操作感：手指摸索老式按键、看指令照做，不炫科幻细节。
  5. "想起个人"只点到为止，不展开妹妹背景——留给后续章节。
  6. 接住第 2 章钩子：林晚"我还是人"→ 本章用行动验证她确实还是人。
