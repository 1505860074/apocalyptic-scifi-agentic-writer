# 第 4 章《安家》· 本章焦点卡（已定稿·追溯）

- **本章实际完成的事**：据点初建——常安用方舟物质回收模块变废为宝，加固卷帘门、清出二层住人区；林晚破冰——对方舟回收产生的灰说"跟外头把人变成怪物的，是一个路数"（暗示方舟与数据尘同源）；盘点：能源核心31%、口粮半箱；封井断后患；能源告急，决定出门。

- **承接**：第 3 章末——方舟异常一句"太好了"后归于沉默，林晚清洗成功但残留19%银纹，两人在配电室各自缩在一头。

- **在场人物 + 弧光阶段**：
  - **常安** → 弧光推进："守家"意识初步成型——从求生到安家，用回收模块变废为宝是天生本事，掰半块饼干给林晚是守护的朴素表达。
  - **林晚** → 弧光推进：破冰——从"别过来"到主动开口（"跟外头把人变成怪物的，是一个路数"），碎片透露实验室背景，点破方舟灰与数据尘同源（S03）。
  - **方舟** → 工具腔回归（主体），物质回收+能耗计算，异常蛰伏。

- **涉及的世界设定**：物质回收机制（废铁→方舟扫描→银灰粉末→金属材料，用于建造）；洁净场能耗机制（能源核心供电，31%告急，罩子大小与耗电成正比）；据点建筑布局（地下室/一层废品站/二层住人区/电梯井→已封堵）；口粮约束（老张囤的半箱泡面+压缩饼干+几瓶水）。

- **推进的事件/伏笔/桥段**：事件线"据点初建"；物质回收机制首次使用（变废为宝，建设爽感）；林晚"实验室背景"首次透露（碎片，不交代全貌）；**S03 埋点**（方舟回收灰 = 数据尘同源——林晚点破，为后续方舟与归零同源的悬疑打地基）；封井断后患（电梯井焊死，困住四宿主，呼应第2章）；桥段＝建设蒙太奇（拖废品→回收→敲打→加固）。

- **本章写作要点**：
  - 爽点：变废为宝的建设感 + 从"躲"到"安家"的归属感（据点的雏形）。
  - 章末钩子：得出门了——三成电撑不了多久。
  - 主导情绪：方舟异常后隐约的不安 → 建设的踏实感 → 林晚破冰的微暖（"吃吧，这楼往后我看着"）→ 能源告急的紧迫（"三成电"→窗外灰蒙蒙死城）。

- **逻辑雷区自查**：
  1. 常安认知别越界：不懂回收灰 = 数据尘，只当"磨出来的灰"；林晚点破他手一顿，但不追问原理。
  2. 方舟主体工具腔：物质回收+能耗计算+糙图纸，不给情绪，异常蛰伏（呼应第3章"好像刚才那一句从来没出现过"）。
  3. 林晚"实验室背景"只给碎片（"以前在实验室做事"+"归零那天"），不交代全貌，为后续章节留空间。
  4. 能源告急数值准确：31%，承接第2章洁净场初建后的消耗，为第5章出门找能源提供动机。
  5. 建设过程贴真实工程：角磨机/焊枪/千斤顶——废品站现成工具，常安修理工顺手。
  6. 口粮约束真实：半箱泡面+压缩饼干+几瓶水，不凭空多出物资；常安掰半块饼干的细节体现"省着"。
  7. 去 AI 味：建设场景用具体工具/动词，心理活动是大白话（"不能等死""省着点"）。
