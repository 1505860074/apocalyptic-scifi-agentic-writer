# 焦点卡 · 第 20 章《等什么》

## 本章定位
- **视角**：常安（贴身第三人称）。**类型**：悬疑 / 收束章（孢子潮退去 + 第三阶段收束）。
- **一句话**：孢子潮熬到第三天退了、据点撑过来了；可门外留下一具**死因不明的高阶同步体尸骸**，方舟扫描后异常沉默——比任何警报都让人发毛。
- **定位**：第三阶段（喘息与暗涌）收束章。**承接 ch19 特意留给本章的方舟悬疑**（城市中心 / 它们在等什么）。
- **不写**：血战 / 打怪（潮里没开打；尸骸是"发现"不是"打赢"）。**孢子潮不设生存危机峰**（作者定）——本章的劲全在悬疑 / 细思极恐，不在动作或紧张打斗。

## 主导情绪 / 对比
- 压抑（熬潮 / 人心浮动）→ 松一口气（潮退）→ **诡异发毛（尸骸 + 方舟沉默）**。和 ch19 的暖形成"暖 → 诡异"强对比。

## 锚点 / 钩子
- **锚点不是爽点，是"细思极恐"**：潮退后那具没人杀的高阶尸骸 + 方舟第一次面对东西说不出话。让读者比角色更早嗅到"外面有更大的东西在动"。
- **章末钩子**：方舟的沉默。它什么都能算，却对这具尸骸只回【……暂无可识别威胁】——这句"没事"比任何警报都吓人。（第三阶段收束：撑过了这次，但谁都知道下次没这么好运。）

## 据点当前状态（接 ch19《孢子潮》末）
- **人 5**：常安、林晚、周铁山（恢复中·能守门、仍不宜死力气）、老头（郭长贵）、小丫头。
- **能源核心**：孢子潮里洁净场耗电翻倍，熬到潮退时**降到约两成**（告急过、但没断）。潮退后耗电回落。
- **洁净场**：全程撑住（半径3米）、没断过——这是他们"撑过潮"的底。
- **材料 / 装备**：ch19 攒了一批（改造好的地下室 + 回收的巷口废金属）；临时口罩若干（滤芯已脏、需换）。
- **孢子**：潮持续三天、第三天退去（室外从常态四百多回落）。外面同步体一直围而不攻 / 杵着，潮退后散了 / 不见了，**只在破口外 / 巷口留下一具高阶尸骸**。
- **林晚**：银纹加深；潮里盯洁净场能耗、能感孢子浓度；潮退时能感到"外面那股共鸣退了"。
