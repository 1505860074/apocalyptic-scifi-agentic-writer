# 场面调度卡 · 第2章「不卖的货」

> 依据：焦点卡-第2章（6拍 + 情绪温度/N档）＋ 世界观/金手指/命名表 ＋ 人物卡（械子/老秦/戚凛）＋ 状态账本（本章处：械子 Lv.1 本能不受控·无机甲·无战损·身世碎片=1 段制式战斗记忆）。
> 只做物理调度，不写美文。写手照此演，动作不许跳步。

**贯穿底图（承第1章）**：锈港·停泊环。第七泊位有那台被覆写过、又重新趴死的报废战争机械，埋在残骸堆里。最外圈的封闭门白天被海盗撞塌，门板铺在地上。居住舱在环的一头，黑户住的居住格开着门缝。拆船厂在另一侧，卷帘门半升。锈市（卖情报/销赃的摊子）连着一片暗影。顶上一排老灯管，昏黄，嗡嗡地晃。重力场偶尔抽一下（脚底一沉，灯跟着晃）。

## 节拍 1：海盗退后，众人远远看着械子，没人敢近（后怕·孤立 / N2 / L1-2）

**① 站位/空间**
- 承第1章结尾（海盗连滚带爬退出塌掉的门）。械子在第七泊位、报废战争机械的残骸旁，半边义体接口残着一线将熄的幽蓝。
- 黑户从居住舱那头的门缝/通道口探出半个身子，围成一圈、离械子十几步，中间空出一大片，没人靠近。
- 老秦在拆船厂卷帘门那侧（第1章刚被打得半跪、半脸血），离械子七八步，正爬起来。

**② 动作链**
1. 械子撑着战争机械胸甲：先支起一条腿 → 扶残骸冰凉的边缘 → 慢慢站直。
2. 太阳穴还突突跳（第1章覆写反噬的余痛，未退）。
3. 他低头看左手，接口幽蓝一亮一暗；把这只手往裤缝上蹭两下，想蹭掉那点幽蓝，蹭不掉。
4. 他抬眼 → 黑户没一个过来，没人问一句"你没事吧"，只远远看。
5. 械子对上其中几双眼 → 那眼神跟他们看那台重新趴死的战争机械，一个样。
6. 械子把左手默默往身后挪（藏手，习惯动作变体）。

**③ 对话**：无（孤立靠"没人开口"演；沉默即调度）。

**④ 内心微动（N2，挑一步落地）**
- 站直后残着的后怕（那股劲差点没收住）→ 抬眼撞见那些眼神，不新鲜、他早该习惯 → 可这次他们怕的不是踹门冲进来的海盗，是他；"习惯"底下还是沉了一下。
- 落点在"把手往身后藏"这个动作上，不写"他很孤独"。

**⑤ 感官锚点**
- 残骸胸甲的冰凉（触觉）；接口将熄的幽蓝一亮一暗（视觉）；老灯管的嗡（听觉底噪）。

## 节拍 2：三瓣嘴凑上来，当众点破"裸同调=违禁实验体、换一船晶核"（暗涌·危险 / N2 / L2 · 埋追猎引线）

**① 站位/空间**（承拍1，只写变的）
- 三瓣嘴从居住舱那侧人堆里钻出来，凑到械子三四步外。脚边拎一台估价用的电子秤盘（黑市论斤估货的家伙）。
- 老秦还在卷帘门那侧擦血、没过来（给拍3留出场空间）。

**② 动作链**
1. 三瓣嘴"哟"一声，顺人堆挤到前排。
2. 他不看老秦，眼睛黏在械子半边身子、那些还泛幽蓝的接口上；脑袋偏着、往前凑半步，像估一件刚到手的货。
3. 械子往后退，后背抵上残骸，左手往身后收得更实。
4. 三瓣嘴啧一声，嗓门故意撑大（说给全停泊环听）：点破"那手是裸同调，没舱没线，空手盘活死铁"。
5. 他转身、伸手往四下一划，把探头的黑户挨个点一遍（把全场拉进来，把械子架成"货"）。
6. 抛定性：违禁实验体、星联《同调管制条例》里要回收的"资产"；伸三根手指慢慢搓，报价"卖星联或黑市，一具换一船晶核"。
7. 对老秦喊价："咱哥俩三七分？"
8. 停泊环那点动静全停；黑户眼神变了，那点怕里掺进"值多少钱"。
9. **（多轮/阻力，不改结果）** 人堆里有人被"一船晶核"勾动、往前挪半步、低声接一句（"够锈港这半熄的灯亮好几年"）；一圈人的气往械子这边压过来。械子看着那些眼神一寸寸从"怕"挪到"算钱"。

**③ 对话交锋**
- 三瓣嘴（漏风、故意大声）：意图＝当众把械子钉成"货"、逼老秦入局分赃、给黑市递投名状；潜台词＝我攥着你这条秘密，要么分钱、要么我把他卖了。
- 黑户接话（新增小回合）：意图＝试老秦松不松口；潜台词＝这买卖我们也想沾。

**④ 内心微动（N2）**
- "资产""货"这类词，械子不新鲜 → 但看着那些眼神一寸寸从"怕"挪到"值多少钱"，看得太清楚 → 他张了张嘴，最后什么也没说（说什么都是货在替自己标价），手往身后藏得更实。

**⑤ 感官锚点**
- 三瓣嘴漏风的尾音（听觉，钉死那张豁唇）；脚边的电子秤盘（视觉实体，拍3要被掀）；他搓动的三根手指（视觉）。

## 节拍 3：老秦拄义肢过来，掀翻秤盘，把械子从"货"按回"我的人"（温暖·护短 / N3 / 情感高点 · L高）

**① 站位/空间**（承拍2，只写变的）
- 老秦拄义肢从卷帘门那侧过来，穿过让开的人堆，走到三瓣嘴与械子中间。三瓣嘴的电子秤盘在他脚边地上。械子被挡在老秦侧后方。

**② 动作链**（N3情感高点：动作放缓，但关键物理一步不省）
1. "当啷"——老秦抬义肢，一下把脚边电子秤盘掀翻（声音先到）。
2. 秤盘磕在废铁上 → 屏面裂 → 数字乱跳两下 → 灭。（钉死终态：屏灭）
3. 老秦抬义肢，金属指关节点住三瓣嘴鼻尖（不打，威慑），骂"分你妈的三七"。
4. 定性句，一字一顿："这是我拆船厂的人。我的人。不是货。"
5. 三瓣嘴被冷义肢顶得往后仰，嘴上不服（为一个来路不明的杂役跟我翻脸？），**再撬一下钱**（那可是一船晶核，你掂量掂量）。
6. 老秦不接钱这茬，收回义肢、转身 → 面朝那圈眼神发绿的黑户（**多轮：从对三瓣嘴转到对全场——真正的威胁是被勾动的众人**）。
7. 老秦压低声音，把当年那条断胳膊的旧账拎出来当威胁（谁再当他是货，先问问我这条断胳膊当年怎么断的）。
8. 没人接话，黑户一个个低头、散。
9. 三瓣嘴讪讪捡起裂了的秤盘，退进锈市暗影；走前回头睃械子一眼（钩子：他还惦记这买卖）。

**③ 对话交锋**
- 老秦：意图＝当众把械子从"货"按回"人"、震住全场、断这桩买卖；潜台词（护短藏在骂里）＝这是我的人，动他就是动我。**温度靠三个动作演——掀秤盘＋义肢点鼻＋抖断胳膊旧账，不靠旁白说他善良**。断胳膊旧账是 S3 边缘（只露忌讳，别点破当年是什么事）。
- 三瓣嘴：意图＝不甘、用钱再撬一下；潜台词＝你会为一个杂役放弃一船晶核？我不信。

**④ 内心微动（N3，情感高点，填细但克制）**
- 械子先听见"当啷"、看见屏灭 → 再听见"我的人。不是货。" → 愣一下（这三个字冲着他说，头一回）→ 他那只藏在身后、本还想往更深处缩的左手，**停住了**。
- 落点就在"手停住"这一个具体动作上（扣命题"被当人"）；不展开成抒情，不写"他心里一暖"。

**⑤ 感官锚点**
- "当啷"秤盘落地声 ＋ 屏面裂、数字乱跳两下灭（钉死终态）；义肢金属指关节点在三瓣嘴鼻尖（视觉，冷硬）；（械子视角）藏在身后的左手停住（本体感，情感锚点）。

## 节拍 4：私下追问；老秦一听"裸同调"变脸，岔开话（悬疑·裂痕 / N2 / L2 · 埋 S3）

**① 站位/空间**
- 夜里，拆船厂堆料间。料架上堆着拆下来的零件。老秦靠着料架、有一瓶酒；械子在旁边。光更暗。远处重力场偶尔抽一下的闷响（底噪）。

**② 动作链**
1. 老秦扔给械子一支劣质止痛剂（关照藏在动作里）。
2. 老秦拧开酒，灌半口，剩半口照例往地上一泼——标志动作，念"敬熄了灯的星域"。
3. 械子捏着那支没拆封的止痛剂，盯自己的手看很久，才开口。
4. 械子讲脑子里进来的那段东西（承第1章身世碎片：一双手在很小的驾驶舱里、用白天那手法压一台机甲力矩开火、很稳、那不是我、我从没进过那种舱）。
5. 老秦泼完酒的手，顿一下（变脸信号①，动作外化）。
6. 械子把话头收到"裸同调"三个字上，问它到底是什么。
7. 老秦打断："睡觉。"声音和白天护他时判若两人，又干又硬（信号②）。
8. 老秦把酒瓶往料架一顿、背过身，去收拾根本不用收拾的零件，义肢在铁架上磕出一声不必要的响（信号③；S3 忌讳靠动作演，别点破）。
9. 老秦头也不回："死过一回了还问东问西。有些东西，不知道，活得长。"
10. 械子看老秦背影 → 收拾零件的手，比平时快，也比平时乱。

**③ 对话交锋**
- 械子：意图＝想知道自己是什么（核心欲望）、让老秦解释裸同调；潜台词＝白天那力量、那段不属于我的记忆，把我吓着了。
- 老秦：意图＝堵死这个话题；潜台词（S3，别点破）＝"裸同调"戳到他绝口不提的过去、他知道些什么，护得住械子的命，却不敢/不愿碰这个。
- "睡觉""不知道活得长"是挡箭牌，不是答案。

**④ 内心微动（N2）**
- 械子把碎片说出口时的迟疑（说出来像承认自己不是人）→ 老秦一反常态的冷硬让他察觉：老秦知道点什么、且不肯说 → 落点在他对背影的观察（护他时那么横，问一句裸同调就背过身去），械子没再问（用"没再问"这个具体选择接住裂痕，不旁白说"他感到了裂痕"）。

**⑤ 感官锚点**
- 没拆封的止痛剂（械子手里捏着，视觉/触觉）；泼在地上的半口酒（视觉，老秦标志）；义肢磕铁架那声"不必要的响"（听觉，钉死变脸）。

## 节拍 5：独自试着主动复现那股力量，失败，头痛欲裂，确认它不受控（无力·闷 / N2 / L2）

**① 站位/空间**
- 那天后半夜。停泊环第七泊位，那台报废战争机械（白天覆写过的那台）。械子一个人蹲在它跟前。四下没人。灯更少，冷。

**② 动作链**（逐动作拆细，防"他试了试没成功"）
1. 械子把左手手掌贴上战争机械冰凉的胸甲（和白天/第1章同一个起手）。
2. 闭眼，去够白天那股劲（回想白天：一贴上去死铁就在掌心底下嗡地活了，一股麻顺胳膊往上蹿）。
3. 这一次什么都没有；金属底下白天那点还热的火控，这会儿凉透了。（钉死终态：凉透，不是"没反应"）
4. 他加把劲，手指抠住胸甲的边缘，眉头拧起来往里够。
5. 太阳穴那点钝痛醒了，像有人拿撬棍撬（械子拆船工，撬棍是他日常工具，此比喻是他会有的联想）。
6. 他越用力去够，那撬棍往里撬得越狠，一下，一下，撬到眼前发黑。
7. 撑不住，松手，跪在地上，干呕。（钉死：干呕，非吐血——吐血是第3章才有）
8. 那力量跟白天来时一模一样：说来就来，说走就走。他够不着它。

**③ 对话**：无（独处沉默拍）。

**④ 内心微动（N2，落点＝本拍情绪核）**
- 不甘（白天能，凭什么现在不能）→ 一次次去够、一次次被头痛顶回来 → 落点：比头痛更让他发冷的那件事——他不知道那是什么；它住在他身子里，他却指挥不动它。（确认"不受控"）

**⑤ 感官锚点**
- 胸甲的冰凉 → 凉透（触觉，与白天"活了/麻"对照）；太阳穴被撬的痛（体感，糙比喻落地）；干呕（身体终态）；四下的静（对照白天满环的人）。

## 节拍 6：镜头切星联"清源"组；三瓣嘴的消息＋浮标波纹汇到戚凛，报出目标编号（冷·压迫 / N1 / 章末钩子）

**① 站位/空间**
- 场景切换。三百光年外，星联特勤局一间不亮灯的舱室。戚凛坐屏前，身后有组员。右眼一枚战术单片镜。冷，只有屏光。

**② 动作链**（N1，骨架，冷）
1. 两条线连夜前后脚汇进来：①第1章那枚旧浮标捕捉的裸的、无源的同调波纹＋一串锈港坐标，顺旧航道送到（承第1章钩子）；②三瓣嘴连夜把消息卖了、在黑市转两三手（"锈港有个杂役空手盘活死铁、是个能裸同调的东西"）。
2. 两样东西摆到同一张屏上。
3. 戚凛单片镜亮起一格冷光，把那段裸的、无源的波纹调出来，反复推演三遍；推一遍校一次单片镜刻度、再推一遍（校准小动作＝她那点不安，人物卡）。
4. 她很久没说话。
5. 抬眼，冲身后的人，平静地报出一串目标编号（报编号的习惯：像给一件入库的物品/货记账）。
6. 报定性："目标性质：违禁同调造物，疑似逃逸实验体。"
7. "清源组，申请前出锈港。"（章末钩子：追猎启动）

**③ 对话**
- 戚凛：公事公办、条例腔的平；意图＝启动清源前出；潜台词（N1不展开，只留冷）＝她已把械子归进"待回收资产"那一栏，扣得下扳机。
- **报编号＝把活人先变成一件货**——与拍3老秦"我的人，不是货"冷对照，章末压迫感由此反转而来。

**④ 内心微动**：空（N1）。只留"单片镜反复校准"这一个外化小动作（暴露不安），不进内心解释。

**⑤ 感官锚点**
- 单片镜亮起的一格冷光（视觉，钉死）；屏上那段"裸的、无源的"波纹（视觉实体）；她报编号的平稳嗓音（听觉，冷）。

## 给正文生成的提示（哪拍最吃"演得实"）

- **拍2-3 最不能糊**：三瓣嘴当众定价 → 众人被一船晶核勾动 → 老秦掀秤盘、义肢点鼻、转身抖断胳膊旧账震全场，这是"货 vs 人"的正面多轮博弈。动作（掀秤盘/点鼻/转身）和眼神（黑户从"怕"挪到"算钱"）一步都不能省，不能缩成"老秦骂了一句就把人赶跑了"。
- **拍5 逐动作演**：复现失败要一下一下把头痛演上去（贴手→够→凉透→加力→撬棍痛→发黑→松手→干呕），不能缩成"他试了试，没成功，头很痛"。
- **拍3 的 N3 情感高点落在械子"藏在身后的手停住"这一个动作上**，别扩成抒情段；老秦的温度全部由动作和反话（骂着护）承担，禁旁白说他其实善良。
