## 底图（全章共用，各拍只写"变了什么"）

停泊环是废弃军用中转站改的拆船厂，一个环形大舱。关键位置：
- **B7泊位**：在环的内端。泊位深处停着老秦藏了十年的走私破舰（引擎冷、锈死、十年没动）。泊位口有舷梯，接一条走私私道，私道尽头是耗子芯片里那条早该关闭的旧航道（＝第1章浮标发坐标走的那条）。
- **拆船厂主能源**：在环的另一侧、靠拆船厂核心，跟B7方向相反。老秦拆了半辈子船攒在那儿的东西，够把这半座停泊环连同追兵一起掀上天。
- **环外端**：清源先遣正在重整；戚凛在几百米外一台指挥机甲里（承接第7章"几百米外……握着操控杆"），右眼战术单片镜亮着刻度冷光，身旁有文书官。
- **环中段**：夺来的特勤机甲站着，主炮口被械子调反、对着追兵，撑着火力通道；十几架策反无人机散在它周围，红线本已灭、这会儿一明一暗地想闪回原主。
- **老秦的残机**：歪倒砸在铁地上，冒黑烟，紧挨一处被打塌的泊位支架。老秦独臂挂在裂开的舱沿。
- **械子**：跪在残骸堆里的铁地上，离老秦残机约十几步，左臂朝特勤机甲方向探着，半边身子的外露接口全亮，幽蓝的光在渗，正咬着这几条同调链子。
- **黑户**：十几个，耗子领着，连滚带爬往B7涌，还没上完。
- **环境**：顶上一排老灯管，昏黄、晃；硝烟；重力场偶尔抽一下（脚底一沉）；火光。

## 节拍1：老秦交船、留最后一句话（L2-3 / N3 / 揪心）

**① 站位/空间（变了什么）**
械子想过去够老秦，但一松手，特勤机甲就震一下要挣脱、一架无人机红线亮回。所以他是"半撑着链子、单手拖自己"往老秦那边挪的，不是丢下就冲过去。

**② 动作链**（不许缩成"冲过去"）
1. 械子本能想丢下同调、冲到老秦残机旁。
2. 他刚一分神，特勤机甲整个震一下、主炮口往回偏了半寸，一架无人机的红线"啪"地亮回来、机头开始转向自己人。→ 松不得。
3. 械子只能留最细的一缕同调咬着特勤机甲，另一只手撑着铁地、拖着膝盖，一点点挪到老秦残机下。
4. 够到老秦，伸手去拽他那条完好的左臂。
5. 老秦反手攥住械子的手腕，攥得很紧（他还有劲，是不让械子拽）。
6. 老秦从血里往外挤字，报B7泊位、报船、报芯片在耗子那儿。
7. 械子不接这话，继续想把他往起拽。
8. 老秦不松手，用攥着的力道把械子按住，把话说死。

**③ 对话交锋**
- 老秦："B7……泊位。有条船。走私用的破舰，我藏了十年。跑得动。芯片……耗子那小子有。"（潜台词：把后路一次性交清、催他快走，别在这儿耗）
- 械子："你跟我们一起走。"（不肯接受，还在拽）
- 老秦："我这把老骨头，上不了船了。械子……听着。"（把"一起走"这条路堵死，逼械子面对）

**④ 内心微动**（N3，填细，一步步）
械子先是纯本能要救人（手已经伸出去了）→ 手腕被攥住那下力道让他停住 → "藏了十年"这四个字慢半拍才砸进去：老秦早就备下了这一天 → 一层凉从腕子上老秦攥着的地方漫上来，他还不肯信 → 嘴上还犟"一起走"。

**⑤ 感官锚点**（确定实体）
- 老秦攥手腕的力道（还很硬，不像个要死的人）。
- 老秦手上的血是温的，糊在械子腕子上。
- 特勤机甲顺着那缕同调传回械子接口的那阵挣脱的顶劲（顶着他，一下一下）。

## 节拍2：老秦自断后路，爬向主能源，牺牲（L3 / N3 / 悲）

**① 站位/空间（变了什么）**
老秦松开手，用完好的左臂撑残机残骸，转身朝拆船厂主能源方向（背对B7、背对械子）。械子被他推得后仰半步。特勤机甲那缕同调还咬在械子手里，一直在拽。

**② 动作链**（逐动作，这是本拍主体）
1. 老秦松开攥械子手腕的手。
2. 用尽力气把械子往B7方向推出去（推得械子后仰、半个身子晃）。
3. 撂下一句"上船。别回头。"
4. 老秦扭过身，独臂撑着歪倒的残机外壳，把上半身拖下舱沿、落到铁地上。
5. 义肢那侧（右臂假肢）彻底废了、垂着，断口上火星子一明一灭；他只能靠完好的左臂，一寸一寸往铁地上拖自己，朝主能源爬。
6. 械子看着他爬的方向，认出那是主能源——明白老秦要做什么。
7. 械子张嘴要喊、想扑过去拦。
8. 手里那缕特勤机甲的同调又猛一震（要断），无人机的红线又亮了两架；械子一分神就前功尽弃，被生生拽回来，喊不出、也冲不过去。
9. 老秦头也不回，继续爬，把当年那笔账，用后背说给械子听。
10. 老秦爬到主能源那排机组边，独臂搭上去。

**③ 对话交锋**
- 老秦（背对着，边爬边说）："当年那批人，我漏走了坐标，没能亲眼看着他们活下去。这回……我看着。你给我，活着走出去。"（潜台词：用当年欠下的债还今天这一场；把械子跟"当年被当耗材的人"归成一类；这是他给自己的赎，不是煽情）
- 老秦（更早那句）："上船。别回头。"（命令口气，不留回旋；也是怕自己一回头就走不成）

**④ 内心微动**（N3）
械子认出主能源、看懂老秦要干什么 → 想喊、想冲 → 手里的同调链子和B7那头没上完船的黑户，两头把他钉在原地 → 一种撕扯：拦老秦，还是撑住这一船人的命 → 喊不出来（不是没张嘴，是喉咙里堵着，出不了声）。

**⑤ 感官锚点**
- 老秦独臂在铁地上拖自己，义肢刮过铁皮的声音（一下、一下，越来越远）。
- 老秦断了的义肢断口上那点一明一灭的火星。
- 主能源那排机组的黑轮廓（老秦正朝它爬）。

## 节拍3：引爆——械子第一次完全主动、清醒地掌控（L3 / N3 / 悲壮·燃）〔QM-01 引爆拍〕

> 全章最吃"演得实"、最不能糊的一拍。慢镜头逐格。投放的瞬间不进内心（纯动作/身体），情感余韵留到节拍5、6。掌控要写"完全主动"，但代价（反噬）必须在场，别写成无敌。

**① 站位/空间（变了什么）**
老秦爬到了主能源边、独臂搭上去、不再往前动（这是刺激械子引爆的那一下）。械子仍跪在残骸堆里，接口全亮。特勤机甲快挣脱，无人机大半红线闪回，B7那头黑户还有几个没上舷梯，环外端清源先遣压上来。

**② 动作链**（最细，逐格拆，防糊）
1. 老秦在主能源边趴下不动了。→ 械子体内那股力量本来在乱撞（怕它、往回拽它，跟前七章一样）。
2. 这一次，械子不再往回拽。他松开对它的抗拒——不是失控被它推着走，是主动把手里的闸松开、把自己交给它。（这一下给极短一句内心即可，见④）
3. 幽蓝的光顺着接口匀匀铺开。对照第1章/第7章那种"乱窜、刺眼、他怕它"，这一次它匀匀地贴着每一道接口淌。
4. 械子"感"到了停泊环里每一台还有回路的机器：夺来的特勤机甲、坠落的无人机、瘫在各处的清源器械、B7深处那艘睡了十年的破舰。（只感"哪台还活、哪根线还在动"，不灌记忆碎片——本章不新增身世线索）
5. 逐台接管，一台一台演出来，别一句"全亮了"糊过去：
   - **特勤机甲**：械子不再"咬"着跟它较劲，是顺进它。机甲缓缓横过身，把整个装甲侧面横到撤退的黑户和追兵之间，替他们吃下最后一轮火力（炮打在装甲上，火星、闷响）。
   - **无人机群**：十几架红线齐灭，又齐齐亮成械子这边的调子，掉头，织成一道弹幕的墙封住通道口；两三架直接撞向压上来的清源动力甲。
   - **破舰（阻力，别顺）**：B7深处那艘睡了十年的破舰，引擎冷、固定夹锈死、晶核近见底。械子的同调够进它的引擎回路——冷启动顶不动，回路里那段点火指令一遍遍往前撞、过不去（同第1章那台报废火控"走到一半就停了"的手感）。械子往里再灌一把（超限），引擎才一点点醒过来，从一声闷到轰。
6. **代价（反噬，必须在场）**：同时撑这么多台、还超限硬启破舰，械子扛不住：接口烧灼、一股焦味、鼻子里下来一道血、耳朵嗡、眼前一阵阵发黑，左半身某处义体烫得发疼。他咬着牙撑住，没松。
7. 械子退向B7，边退边撑着这张网，让最后几个黑户先上舷梯。
8. 械子自己最后退上舷梯（这一次是他在喊）。

**③ 对话交锋**
- 械子："上船！"（唯一一句，短促。对照第7章是老秦喊"上船"，这一次换成械子喊——权重换手了，但别点破）
- 耗子在B7舱口拼命招手、喊械子的名（E-03：黑户在等他、把他当自己人）。

**④ 内心微动**
投放的瞬间——基本空，交给动作和身体演。只在第2步"松开抗拒"那一下给一句极短的（他不再怕它了／他不再往回拽它了），然后闭嘴。绝不在这里旁白总结"他终于成为了……"。

**⑤ 感官锚点**
- 蓝光匀匀贴着接口淌（对照前几章的乱窜刺眼——这是"掌控"的可视终态）。
- 破舰引擎冷启动那声从闷到轰的转变。
- 械子鼻子下来的那道血、那股焦味（代价的实体）。

## 节拍4：戚凛慢半拍、同调败给引爆态的械子，破舰强行折跃（L2-3 / N3→N2 / 脱出）

> 主要走械子视角（他"感"到那堵熟悉的墙又压上来、这次顿了一下），戚凛的裂缝外化成械子感到的"顿"；戚凛完整的内心留到收尾coda。

**① 站位/空间（变了什么）**
破舰引擎已亮，挣脱锈死的固定夹，撞进B7私道。械子在破舰里（刚上船），同调还连着这一整张网。戚凛在几百米外的指挥机甲里。

**② 动作链**
1. 破舰引擎轰鸣，撞开锈死的固定夹，冲进B7私道，撞向私道尽头那条旧航道（＝第1章浮标走的那条）。
2. 戚凛"感"到破舰要折跃，她的同调顺着回路压过来，要锁死破舰的航道、掐断这次折跃（手法跟第7章她封械子一模一样，稳、准、锋利）。
3. 械子"感"到那堵熟悉的墙又压到破舰的引擎上——就是第7章那只攥紧的手。
4. 可这一次，那只手压到一半，顿了一下。（她的裂缝：第7章"它在护着那些人""它会痛"还压在她心里，她没像平时那样一刀切下去）
5. 就这半拍。械子引爆态的同调（超限、多目标、不讲道理地灌）漫过她那道锁，把它弹开。
6. 破舰强行点燃折跃（晶核近见底，勉强够这一跳）。
7. 折跃的强光从舷窗外包上来。
8. 破舰跃出。锈港、追兵、那堵墙，一起从械子的"感"里断掉。

**③ 对话交锋**
- 这一拍基本沉默（极限脱出段，别硬凑对话）。
- 可给戚凛一个习惯动作：开火/下令前她惯于极轻报一句目标编号——这次报了半句、没报完（暴露不安）。

**④ 内心微动**（戚凛，短，N3→N2）
戚凛的同调够到破舰引擎的一瞬，本能要掐断 → 文书官那句"它在护着那些人"跳出来 → 手上顿了半拍 → 等她再压下去，破舰已经从她锁里挣出去了 → 她盯着那个空掉的泊位，右眼单片镜的刻度光炸开。

**⑤ 感官锚点**
- 械子"感"里那只压过来的手顿了一下的那个空当。
- 折跃强光；星海在舷窗外拉成一片流光。
- 戚凛单片镜的刻度光剧烈闪。

## 节拍5：破舰跃出，回望熄灯焚毁的锈港（L1-2 / N2 / 苍凉·余韵）〔闲笔授权点：可轻开〕

**① 站位/空间（变了什么）**
破舰舱内。械子站在舷窗前。耗子和十几个幸存黑户挤在舱里，静。舷窗外是折跃前最后一眼的锈港。

**② 动作链**
1. 折跃强光包上来的前一秒，械子最后望一眼舷窗外。
2. 拆船厂主能源方向腾起一团刺目的白光（老秦引爆——他等到破舰点着了才动手）。
3. 火焰顺着一排排泊位炸开，吞掉追进来的清源、那些嗡鸣的红点、连同锈港这个被文明忘了半辈子的破地方。
4. 折跃强光彻底包上，锈港从舷窗里没了。
5. 舱里很静。耗子和黑户挤着，谁都没说话。

**③ 对话交锋**
- 少或无（N2余韵，留白最好）。
- 若要一句，给耗子一句很轻的（例：晶核只够这一跳了）——收束"晶核近见底"，也点出他们的处境，别多。

**④ 内心微动**（N2，一点点，别成长独白）
械子看着那团火光在身后越缩越小 → 那个叫他"械子"、又把他当人护到最后一刻的老头，也在那团火里没了 → 苍凉。一两句收住。

**⑤ 感官锚点**
- 舷窗外那团火光越缩越小。
- 舱里那种没人说话的静。
- 老秦引爆的那团白光。

**闲笔授权（轻开）**：可挂在"耗子和这些黑户什么都没了"上，轻轻一笔他们此刻的处境（活下来了、可什么都没了，械子欠这一船人一个去处＝E-04起点）。克制，一小段就收。

## 节拍6：收尾——械子低头看自己的手，这一次没有缩（L1-2 / N2 / 定音·扣书名）

> 全章情感落点。只用"没有缩"这一个动作定音（对照第1章"往后缩了一下"）。绝不旁白总结"他终于成为了人"。

**① 站位/空间（变了什么）**
破舰舱内，静。械子低头，看自己那只左手。

**② 动作链**
1. 械子低下头。
2. 看着自己那只左手：半边义体、外露的接口，接口上还带着刚才引爆烧过的焦痕、微烫（代价的余温）。
3. 这只手害死过人，也刚刚护住了一船人。它到底属不属于一个"人"，他还是不知道。
4. 他盯着它，看了很久。
5. 没有缩。（对照第1章"极轻地、下意识地往后缩了一下，像怕那只手"）

**③ 对话交锋**：无。

**④ 内心微动**（N2，克制）
它到底属不属于一个"人"，他还是不知道 → 可这一次，他盯着看了很久，没缩。就到这儿。扣书名（从"械子"这个像机器的东西，迈出争一个名字的第一步）靠动作定音，不点破、不写"从此他要证明自己是人"这种话。

**⑤ 感官锚点**
- 左手外露接口上的焦痕、微烫（引爆代价）。
- 义体在舱灯下的那点光。

## ＊　＊　＊ 收尾coda：戚凛重新评估（承接节拍4之后 / N2）

> 说明（修正一处旧矛盾）：旧正文此段设在"三百光年外"，但第7章已把戚凛坐实在锈港几百米外的指挥机甲里，紧接着"三百光年外"是空间矛盾。故本卡把coda落在"清源先遣撤离燃着的锈港之后、戚凛自己指挥舰的舱室"，保留全部伏笔载荷（波纹存档、不追、上报、重估目标性质），去掉矛盾的距离设定。见文末给正文的提示。

**① 站位/空间**
追击令没有下。清源先遣从燃着的锈港残骸边撤开。戚凛回到自己指挥舰那间不亮灯的舱室。

**② 动作链**
1. 戚凛摘下右眼的战术单片镜。
2. 镜片存档区里，静静躺着一段刚录下的同调波纹——比第1章锈港浮标那次清晰百倍，完整、沉静、无源。
3. 她盯着那段波纹看了很久，久到副手第三次来问是否申请追击。
4. 她开口："不追。"（这两个字比平时轻，她自己没听出来）
5. "上报特勤局。"
6. 她顿了顿。
7. "目标性质，重新评估。"

**③ 对话交锋**
- 副手（公事）："是否申请追击。"
- 戚凛："不追。""上报特勤局。""目标性质，重新评估。"（潜台词：她那套"你是待回收资产"的编号话术，第一次抠不下去了；E-02 那一问仍悬着、她用行动先偏了一格）

**④ 内心微动**（N2，一点）
她自己没听出那两个字比平时轻——裂缝外化成这一个她没察觉的细节。别替她总结心理。

**⑤ 感官锚点**
- 单片镜存档区里那段波纹（完整、沉静、无源）。
- 不亮灯的舱室。
