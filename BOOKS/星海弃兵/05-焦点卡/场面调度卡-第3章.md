# 场面调度卡 · 第3章「待回收资产」

> 施工图，不写文采。五栏服从焦点卡，动作链不许跳步。
> 本章空间底图（承接第1、2章）：**停泊环**是一长条金属平台，天顶一排老灯管（昏、晃，因重力场偶尔抽一下）。一头是**黑户居住舱**，另一头是**老秦拆船厂**（卷帘门 + 堆料间）。中间是**开阔地**，四散着**残骸堆**（掩体）、一台**报废搬运机**、第七泊位那台**报废战争机械**。无人机从天顶压下来。

## 节拍 1：数日后·天亮前，清源无人机群封锁天顶，冷声广播"清点资产"（压迫·冷 / N2 / L1-2）

**① 站位/空间**
- 天亮前，外头微光。天顶那排老灯管还亮着，昏。灯管更高处，几十架同型号无人机悬在同一高度，把天顶封成一层。每架底部一道红扫描线，待机，先不扫。外壳印星联徽记 + 一行小字"清源"。
- 械子在拆船厂堆料间地铺（承接第2章夜里）。黑户居住舱在停泊环那一头。老秦在拆船厂卷帘门里。
- 底噪：几十架同型号无人机叠在一个频率上的低频嗡鸣（不是引擎，是同频）。

**② 动作链**
1. 械子醒。不是耳朵先醒，是左半身接口先感到那一层同频的电，麻，顺骨头爬。
2. 他坐起，摸黑到堆料间门口，抬头看天顶。
3. 合成音广播顺着停泊环滚下来。
4. 黑户从居住舱探头，又缩回去。
5. 天顶那层里，一架无人机降下高度，脱离队列，压低到人头顶几米，红扫描线亮起来，开始扫。

**③ 对话交锋**
- 广播（合成音，冷、平、像念条例）："锈港停泊环即刻封锁。清源组执行《同调管制条例》。所有单位原地待清点。抵抗者，视同违禁资产处置。"
- 潜台词：把活人预先归成"单位/资产"，不留商量口子；先立威。

**④ 内心微动**（N2，开一点，一两句体感，不写主题）
- "清点"两个字落进耳朵，械子懂它在星联嘴里指什么（黑户＝没在册＝可清点的东西）。后背合金一寸寸发凉。
- 第一反应不是自己，是往居住舱那头看一眼——那头有跑不动的人。

**⑤ 感官锚点**
- 接口先感到的那层同频的电（顺骨头爬的麻）。
- 天顶那层无人机底部的红扫描线（待机时一排静止红点）。
- "清点"两个字。

## 节拍 2：无人机开始"清点"，误伤居住舱一个黑户（瘸腿老吴）（紧张·愤 / N3 / L2）

**① 站位/空间**（承接1，只写变的）
- 降下来那架无人机压在开阔地上空几米。红扫描线一个一个扫从居住舱涌出来的黑户。
- 老吴（瘸腿，常在拆船厂帮工）跑得慢，落在人堆最后，卡在居住舱门口到残骸堆之间的开阔地上。
- 械子从堆料间门口走出来两步，停在残骸堆边缘的阴影里。

**② 动作链**
1. 黑户被红线赶着往居住舱那头缩，像退潮。
2. 红扫描线扫到老吴身上，停住（他瘸腿，落在最后，跟不上）。
3. 无人机侧舷一个小口无声张开。
4. 合成音判定："资产无关项，驱离。"
5. 一束低功率驱离弹擦着老吴的腿打下去。
6. 老吴腿一软，惨叫，栽倒在开阔地上，腿上焦黑一片，爬不起来，用手撑地往残骸堆这边挪。
7. 械子的手已经按在残骸堆的铁棱上（本能想同调，又顿住——一动就暴露，他知道）。
8. 那架无人机没走，红线还钉在趴地的老吴身上，侧舷口又开始蓄能（第二下要来）。

**③ 对话交锋**
- 合成音："资产无关项，驱离。" 潜台词：老吴连"资产"都算不上，是"无关项"，顺手清掉——比骂人更冷，压根没当他是账上的东西。
- 老吴：碎音求饶（"别……我这就走……"），没说完被蓄能的第二下逼断。

**④ 内心微动**（N3）
- 械子看红线钉在老吴身上，看那小口蓄能。手指在铁棱上收紧。（愤，但先在算：冲出去＝暴露＝三天前那道浮标的事找上门，他知道代价。）
- 老吴在往他这边爬，够不着掩体。别写"他挣扎"，写他按铁棱的手，指节发白。
- 最后不是想清楚了才动，是身子先动了（呼应第1章"没想清楚自己要干什么"）。

**⑤ 感官锚点**
- 老吴腿上焦黑一片（钉死）。
- 无人机侧舷小口蓄能那点亮（第二下要来）。
- 械子按铁棱、指节发白的手。

## 节拍 3：械子冲进火线拖老吴和老秦，被逼到掩体后，接口骤亮，一口气搅乱数架无人机（爆发·爽 / N3 / L3·★最吃演得实）

**① 站位/空间**
- 开阔地：老吴趴在中间偏残骸堆一侧；老秦从卷帘门冲出来、拄义肢站在开阔地另一侧朝无人机骂；械子从残骸堆阴影冲进开阔地。
- 天顶那层无人机还在；降下来那架在头顶几米。械子身边有一台报废搬运机（同调锚 + 半个掩体）。掩体＝残骸堆，在开阔地边缘。

**② 动作链**（★最细，逐格，不许跳步）
1. 械子冲出阴影，几步到老吴身边，一把抓住老吴胳膊，半拖半抱往残骸堆拽。
2. 老吴腿使不上劲，全靠械子拖；拖过铁地，焦黑的腿蹭出一道痕。
3. 械子把老吴塞进残骸堆掩体后，回头——老秦还在开阔地另一侧，拄义肢，梗脖子骂无人机，没退。
4. 械子扑过去够老秦，一把攥住他那条独臂往下拽。
5. 就在械子进开阔地、接口渗光的这一下，头顶那架无人机的红线从老吴身上移开，落到械子半边发亮的义体上。
6. 合成音变调："目标锁定。违禁同调造物。优先清除。"
7. 天顶网上，三架无人机脱离队列压下来，侧舷口一齐张开（不再是驱离弹口径，是清除口径）。
8. 械子来不及把老秦拽进掩体，只能就地把老秦按倒在自己身下，自己压上去护住。
9. 械子反手一掌重重按在旁边报废搬运机的外壳上（本能：紧张时手贴金属；这次是要同调）。
10. 接口"唰"全亮，比第1章更亮，幽蓝顺半边身子的合金纹路暴涨。
11. 那股力量又来了，不听招呼，一大片；它没进他按的这台搬运机，而是越过它，顺接口窜上去，够向头顶三架无人机的回路（写出"它自己挑了目标"，不受控）。
12. 三架无人机红线齐灭，在半空一个踉跄。
13. 这一下大规模同调的特征信号一炸，天顶网上更多无人机的红线齐刷刷转过来对准他；械子顺那股劲，本能地往外一推，想把够到的都摁住（主动够更多——这是失控的种子）。
14. 被他够住那几架，掉转机头，朝自己队列乱冲乱撞：金属相撞、坠落、炸开，火光在天顶连成一串。
15. 黑户看呆：那个"晦气的机器"，一个人，让清点网自己咬自己。

**③ 对话交锋**
- 合成音："目标锁定。违禁同调造物。优先清除。" 潜台词：从"清点资产"升级到"清除"——械子被系统重新归成最高优先级危险物（呼应戚凛后面的"性质已核"）。
- 老秦（被按在身下，短促急喊）："放开我，你这……"／"你干什么！" 潜台词：他不是怕自己，是怕械子暴露、怕这孩子把命搭进去。
- 黑户无台词，看呆。

**④ 内心微动**（N3，但投放拍留空，余韵开一句）
- 覆写发生的当口：不进内心，全是身体/画面（接口暴涨、力量窜上去、红线灭）。
- 余韵只一句爽：那一瞬间是爽的，他自己都被那股汹涌托着，几乎要站直。别铺开成主题。

**⑤ 感官锚点**
- 接口暴涨的幽蓝光（比第1章更亮，顺合金纹路窜）——**S2接口异光**。
- 三架红线齐灭 → 半空踉跄 → 相撞坠落的火光在天顶连成一串（钉死可视终态）。
- 械子按在报废搬运机外壳上那只手（触觉锚，冰凉金属）。

## 节拍 4：失控——一架被搅乱的无人机偏射，打中他刚拖进掩体的老吴（骤痛·失控 / N3 / L3·★慢镜头，一格不能糊）

**① 站位/空间**（承接3）
- 械子按着老秦、手按搬运机，在开阔地。老吴在残骸堆掩体边缘（刚被拖进去，还露着半个身子）。天顶一片乱，无人机相撞坠落。

**② 动作链**（★慢镜头逐格）
1. 太多目标，一大片，他兜不住——够住的越多，每一架越松。
2. 其中一架被他搅乱的无人机，坠落前机身一歪。
3. 它侧舷那个还开着的口，蓄着的那束没收住，"啾"地斜擦出去。
4. 这一束不是冲械子，是斜的，扫向掩体边缘。
5. 正打在老吴身上。正对胸口。（老吴刚被拖进掩体、还露在边缘）
6. 老吴连声音都没来得及发。
7. 械子亲眼看着那束光穿过他刚拖进掩体的人。

**③ 对话交锋**：无（极限动作 + 骤痛，沉默留白）。

**④ 内心微动**（N3，投放拍空——只有画面和身体；余韵挪到节拍5）
- 投放当口：械子脑子空了一下。不是"他震惊"，是没有内心，只有那束光穿过老吴的画面钉在眼里。
- QS-02轻信号在这里起头，真正的"僵住/盯着手/怀疑"落在节拍5余韵。

**⑤ 感官锚点**
- 偏射那束光的斜线（"啾"一声，斜擦）。
- 光正打在老吴胸口（钉死终态：不是"老吴死了"，是那束光穿过胸口、老吴那双还睁着的眼）。
- 老吴没发出声音（沉默锚）。

## 节拍 5：反噬袭来，械子吐血跪地；戚凛穿硝烟而至，第一次照面（余悸·压顶 / N3→N2 / L2-3）

**① 站位/空间**
- 天顶的乱渐停（被搅乱的无人机坠得差不多）。硝烟、火光余烬。械子跪在开阔地铁地上，老秦从他身下爬出来、在旁边。老吴在掩体边不动。
- 硝烟里，从停泊环一头（清源来的方向），一双军靴不紧不慢走近。

**② 动作链**
1. 那一大片力量"哗"地退，退得比哪次都急（比第1章更急更狠——二次爆发反噬更重）。
2. 反噬顺退潮撞上来：械子眼前一黑，喉咙一甜。
3. 一口血喷在铁地上。
4. 他跪下去，一只手撑地。
5. 力量退走时，擦下一点碎渣黏在脑子里：不是画面，是一个音节，很短，他只记得的那一个，一闪，没抓住——**S2编号再现**（读者当反噬后遗症/幻觉，别解释）。
6. 他盯着老吴那双还睁着的眼，僵在原地。
7. 他缓缓低头，看自己那只还亮着微光的左手，像第一次看见它。想把手心那点微光蹭掉，手抬起来又没动——**QS-02落点**。
8. 硝烟里脚步声不紧不慢近来。
9. 一双军靴停在他面前。械子抬头。

**③ 对话交锋**：无（或极短）。留给节拍6。

**④ 内心微动**（N3→N2，QS-02轻信号，靠动作/生理，不宣讲）
- 不写"他怀疑力量只会害人"这种主题句。写：盯着老吴还睁着的眼 → 再看自己还亮微光的左手 → 刚才那股托着他、让他几乎站直的爽，这会儿缩成手心里一点不散的微光 → 想蹭掉、手抬起来又没动。怀疑＝靠"看自己的手/想蹭又没蹭"外化。
- 反噬余悸：喉咙血腥、太阳穴炸痛。

**⑤ 感官锚点**
- 喷在铁地上那口血（钉死）。
- 老吴还睁着的眼（钉死）。
- 械子左手还亮着的微光（钉死，QS-02的物）。
- 军靴停在面前（视觉锚，戚凛登场）。

## 节拍 6：戚凛举镜宣判"你是待回收资产"；械子反问"人该是什么样"；老秦挡在两人间，被单片镜认出旧脸（冷·顶点钩子 / N3 / L3·三线同炸）

**① 站位/空间**
- 械子跪在血里。戚凛站他面前（军靴的主人）。军装一丝不苟，右眼战术单片镜亮着刻度冷光。老秦从械子身后/身下爬起来。硝烟未散，天顶还有零星火。

**② 动作链**
1. 戚凛低头看跪着的械子，像核对一件登记在册的物品（脸上没恨，也没别的，那种平静比恨更冷）。
2. 她右手极轻地抬到单片镜边，校准一下（**戚凛标志小动作**——暴露不安，但读者此时当她冷酷）。
3. 她报编号/性质（开火前报编号的习惯，像给一件物品记账）。
4. 她抬手，单片镜刻度光锁定跪着的械子。
5. 她宣判《同调管制条例》第十一条（**MX1官方盖章**）。
6. 械子没看她的枪，抬眼看那枚单片镜，反问"那你说，人该是什么样？"
7. 戚凛抬着的手，几不可察地停半秒（**底层裂缝**；给读者的钩子）。
8. 就在这半秒，老秦撞进两人之间，张开那条独臂和那截义肢，把械子挡在身后，正对戚凛、正对单片镜。
9. 单片镜冷光扫过老秦沾血、糊灰、一道旧疤的脸。
10. 刻度光猛地一跳。镜片里，一张早已归档、标着"除名""殉职存疑"的旧脸，从十几年前档案深处硬生生跳出来，和眼前这断臂老头，一格一格对上——**S3半揭：戚凛认出老秦旧脸**。
11. 戚凛第一次，没能立刻说出下一句话。（章末钩子定格）

**③ 对话交锋**（★本拍主体）
- 戚凛："编号未录，性质已核。……违禁实验体。" 潜台词：用编号/性质把械子非人化，好让扳机扣得下去（她底层怕抓错、怕对象是人，所以死抠"性质已核"）。
- 戚凛："按《同调管制条例》第十一条，你不是人。你是待回收资产。" 潜台词：官方盖章（MX1维持）；也是她念给自己听的咒。
- 械子："那你说，人该是什么样？" 潜台词：不是求饶，是把她那套人/非人的判定反手抛回去——他一直问自己的问题，第一次问到猎人脸上（他的口头禅落点，也是全书主命题第一次正面撞）。
- 老秦：无台词，或只一个字的短喝；把话留白，让"撞进来、张臂挡、被镜认出"的画面说话。

**④ 内心微动**（N3，但全靠对话/动作外化，不独白）
- 械子问那句时，不写他心里想什么，写他的声音：不高，却把周遭嗡鸣压下去一瞬。
- 戚凛那半秒停顿，不写她心里，写她的手停半秒。

**⑤ 感官锚点**
- 单片镜的刻度冷光（钉死，扫过老秦脸）。
- 刻度光"跳"（视觉终态：不是"她认出了"，是刻度光跳、镜里旧脸一格一格对上）。
- 老秦沾血、糊灰、断臂张开的轮廓（钉死）。
