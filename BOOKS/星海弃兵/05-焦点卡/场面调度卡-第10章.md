# 场面调度卡 · 第10章「用一次少一次」

> 焦点卡校验通过后、正文生成之前的施工图。只做物理调度（站位/动作链/对话/内心/感官），不写美文。
> 本章是"诊断+交锋"型场面，不是打斗——内容密度来自**桑给械子修接口这一整套具体医疗/技术操作**（工具、封板、探针、烧断的神经束、械子身体的反应）＋**多轮的付款与代价交锋**，而不是靠氛围描写。
> 焦点卡为精简版，只标了情绪·N档，未标 L 级；下面每拍的 L 级按情绪/节奏就近定级并注明。
>
> **底图（全章共用，只在变化处再写）**：桑的医铺＝黑市最边缘一个改装过的旧货舱。半舱堆着拆下来的义体零件（胳膊、腿、一节节接口，摞得老高）。空气里消毒水味冲，底下压一层苦叶的味。舱顶一盏灯，光硬。核心道具：一台老旧的调律仪（带一块读数屏、一根探针、几个导极），一张矮金属凳（给械子坐着让桑够到他左肩）。在场：桑、械子、耗子、两个黑户。械子左半边义体此刻发着乱光、还时不时从接口深处窜痛（承接第9章"撑不过三天"）。

### 节拍 1：械子被架去桑的医铺，桑冷淡开价"晶核先付"，一行凑不齐东拼西凑，桑嘴硬却已动手（L1 / N2 / 窘·冷）

**① 站位/空间**
- 承接第9章：桑说完"撑不过三天"就走了，铺子在黑市最边上。耗子＋两个黑户架着械子找过来。
- 进门：桑背对门口，蹲在调律仪前接线，头不回。械子被架在门内侧、站不稳。矮凳在调律仪旁边（后面械子会被放上去）。碎晶要摊的台面：调律仪边上那张操作台，离桑一步。

**② 动作链**（骨架为主，交锋是重点）
1. 耗子＋两黑户架械子进门，械子左腿义体拖着、使不上劲。
2. 桑不回头，手上接线不停，直接报价"晶核先付，三粒"。
3. 耗子脸垮，把贴身藏的东西掏出来摊在操作台上：老秦留下的那半块碎晶＋几个黑户凑的零碎，一小撮。
4. 桑只侧头瞥一眼，手没停，冷笑"这点够买我半句话"。
5. 耗子急，冲身后使眼色；一个黑户把腰上一个还能动的小机件摘下来添上去。桑连眼皮都不抬。（多一轮小阻力，见文末说明）
6. 械子想开口说这船人真就这点家当，接口深处的痛翻上来，把话顶回去，没说成。
7. 桑拧紧最后一根线，才转身。（"嘴硬却已动手"＝她根本没打算不修，报价只是姿态）

**③ 对话交锋**
- 桑"晶核先付。三粒。修改造货，费手，不讲价。"→ 潜台词：先立规矩、把自己摘干净，别让人以为她会心软。
- 桑"这点，够买我半句话。"→ 潜台词：羞辱这撮钱、也是给自己一个"我在乎的是钱"的台阶。
- （交锋不必你来我往很多句，耗子这边基本是动作在回应，不是嘴。）

**④ 内心微动**（N2，只给械子一点，不进桑）
- 械子：不是气她要价，是那句"这船人真就这点了"堵在喉咙口，被痛顶回去——他现在连替兄弟争一句的力气都吊在别人肩膀上。

**⑤ 感官锚点**（确定实体）
- 消毒水味冲、底下一层苦叶味。
- 老秦那半块碎晶摊在操作台上（成色差、缺一角）。
- 械子左腿义体拖地的声、撑在两人肩上的沉。

### 节拍 2：桑扯开封板，探针一探手忽然顿住——她认得这构造，没说破，只问编号（L2 / N3 / 悬疑·裂缝·S6）

**① 站位/空间**（只写变化）
- 械子被放到矮凳上坐下，左肩朝着桑。桑站在他左侧、调律仪在她手边。耗子他们退到门口那头。

**② 动作链**（★本拍最吃"演得实"，慢，逐步）
1. 桑拿钩子似的目光把械子从头到脚扫一遍，走过来。
2. 一把揪住左肩义体的封板，往外一扯。她的手很稳，稳得不像第一次碰这种东西。
3. 咔一声，封板开。底下外露的接口、烧灼发焦的神经束、还残着乱光的同调核心，一股脑露在灯下。
4. 桑从调律仪上拔下探针（探针尾巴拖一根线连回机器）。
5. 探针尖探进接口边上，调律仪的读数屏亮起来，屏上爬出一串跳动的数。
6. 桑的手忽然顿住。就一瞬。眼睛落在那颗同调核心上，钉住。（她认得这东西）
7. 她没说破。把探针收回来搁到一边，很平静地问一句。
8. 械子摇头（见对话）。
9. 桑盯他两秒，把眼里那点东西压回去，重新低头。

**③ 对话交锋**
- 桑"你这构造的编号，还记得吗？"→ 表面：老练调律师问一句技术信息（很正常的行当问法）。底层（藏）：她要确认这是不是她想的那批东西。**照硬红线8：先把"军医见多识广、随口一问"写像，伏笔本体（她怎么会问到编号）只当细节顺带藏，别暗示"这里有伏笔"。**

**④ 内心微动**（N3，重点填械子，桑靠动作外化不进内心）
- 械子：先是那个一直记不清的编号音节被她一问，又浮上来，堵在喉咙口拼不全；再是他反应过来——她那一顿，是"见过"。这世上认得他这身子的，本来只剩一个老秦，老秦没了；现在又多一个。心里一沉。
- 桑的裂缝**只走动作**（手一顿、目光钉住、把情绪压回去），不给她内心独白。

**⑤ 感官锚点**（对准威胁源/裂缝源，给足）
- 封板扣开那一声。
- 接口里残着的乱光（幽蓝）、发焦卷起的神经束、那颗同调核心。
- 调律仪屏上跳动的一串数。
- 探针的金属尖。

### 节拍 3：桑边修边摊开代价——活体接口、用一次少一次、锈港已烧掉一截；械子沉默没接话（L2 / N3 / 沉重·QS-06）

**① 站位/空间**（只写变化）
- 不变。桑俯身在械子左肩上干活，调律仪导极接到接口里。械子坐着，右手垂在膝上。

**② 动作链**（修＝真操作，一步步；代价穿插在动作里说，不是站着念）
1. 桑把嘴里那片苦叶吐掉（干活前的习惯动作）。
2. 重新拿探针，这回是干活：那几根烧断的神经束末梢发焦、卷成小团，她用探针尖一根根把它们挑开。
3. 夹住其中一根，接上调律仪的一个导极；一股电流过去，械子左肩猛地一抽，半边身子不受控跳一下。桑"忍着"。
4. 她一边接线一边说代价（活体接口／不是义体给的本事／用一次烧一截）。
5. 拧线力道重了些，像在跟那根线较劲。
6. 抬眼问他锈港烧掉多大一截。
7. 械子低头看自己那只左手，没接话（QS-06：把代价摊到明面，他沉默）。

**③ 对话交锋**（是"下判决"式的推进，不是信息播报——每句都在往械子身上压）
- 桑"你这不是普通义体。这叫活体接口。"→ 定性。
- 桑"我修过几个跟你差不多的。你这具，还不是常见的那种。"→ 表面：老调律师见过世面（写实）；顺带落"特殊批次"这层（登记进状态账本的信息），但**别点破她为什么见过**。
- 桑"你那只手空着就能同调的本事，不是义体给的，是你这条命本身在当接口。每用一次，烧掉你自己一截神经、一截义体。"→ 把金手指的代价第一次摊到明面（金手指卡"反噬/心智代价"落实为机体损耗）。
- 桑"烧掉的，长不回来。你锈港那一场，把自己烧掉多大一截，你心里没数？"→ 逼他面对第8章引爆的账。

**④ 内心微动**（N3，械子，填细一步步）
- 械子：想起锈港那一夜，那股力量头一回完完整整交到他手里，是那么顺、那么沉，他一直以为是自己终于压住了它——原来那份"顺"是拿这个换的。落到眼前这只左手上：这只手护住了一船人，这只手也在一点点烧掉他自己。
- 别写成"他很沉重"的结论，走"想起锈港→重新理解那份顺→看着左手"这条过程。

**⑤ 感官锚点**（挑，别铺满）
- 发焦、卷成小团的神经束末梢。
- 导极一通电、械子左肩那一抽（触觉/身体反应）。
- 械子低头看着的那只左手。

### 节拍 4：桑凉薄壳下露一丝东西又收回，把碎晶推回、一粒没收，重申"我只管修不管你是什么"（L1-2 / N2 / 克制）

**① 站位/空间**（只写变化）
- 桑接稳最后一根神经束、撤探针、合封板、扣死。人直起来，背要转开。

**② 动作链**（裂缝全靠动作外化）
1. 桑把最后一根神经束接稳，探针一撤，把封板合上、扣死（咔）。
2. 械子沉默很久，问出"你怎么会认得这个"。
3. 桑收拾探针的手停一下——没停多久。
4. 她把操作台上那一小撮碎晶零碎、连着老秦那半块，一把推回耗子面前，一粒没收。（＝她底层那道"下不去手"的裂缝，只用"不收钱"这个动作说，不解释）

**③ 对话交锋**
- 械子"你怎么会认得这个。"→ 潜台词：他抓住了那一顿，想知道这个人和他的来历有没有关系。
- （桑对这句不正面答，答句留到节拍5，是主动的卖关子/堵话。）

**④ 内心微动**（N2）
- 不进桑内心（焦点卡明令：桑的愧疚靠"手一顿/没看脸/不收钱"外化，不靠独白）。
- 械子这边可以一句：他看见她那只手停了那半秒，也看见她把钱推回来——比她嘴上说的任何话都响。

**⑤ 感官锚点**
- 封板扣死那一声。
- 那撮碎晶被推回、滑过台面到耗子面前。
- 桑收拾探针的手停住的那半秒（可挂她左手背那片旧烫疤）。

### 节拍 5：钩子——械子问怎么认得，桑不答只说"想活别再用它"；浮渊外流民潮消息传来，钩爷秩序要绷不住（L1 / N1 / 不祥）

**① 站位/空间**（只写变化）
- 桑背过身，往嘴里塞一片新苦叶，把话堵死。械子被扶出医铺，到黑市外面。镜头拉到浮渊腹地：一片忽明忽暗的黑市灯。

**② 动作链**（骨架，收）
1. 桑背过身，摸出一片新苦叶塞进嘴，含混把话堵死："我只管修，不管你是什么。记住，别再用它。走吧。"（对"怎么认得"不答＝主动卖关子，S6留长线）
2. 械子被扶出医铺。
3. 浮渊腹地骚动起来，黑市里的人往一个方向涌，议论声嗡嗡压过来。
4. 耗子拉住一个跑过的人问两句，回来时脸白了。
5. 耗子报消息：争议星域打过来了，一大批流民往浮渊涌，好几千人。
6. 械子回头，望向浮渊腹地那片忽明忽暗的灯。（章末画面钩子）

**③ 对话交锋**
- 桑"我只管修，不管你是什么。记住，别再用它。走吧。"→ 潜台词：把门关死，别再问、也别指望她。
- 耗子"争议星域那边……打过来了。一大批逃难的流民，正往浮渊涌。好几千人。"→ 世界线阶段二·流民潮正式压到眼前（不是因械子而起，是文明退潮的自然恶化）。

**④ 内心微动**（N1，几乎空）
- 械子望着灯，心里那句不必写透：钩爷那条勉强撑着的规矩、这口死地里最后的活气，要被几千张要吃要住要活的嘴压垮了。

**⑤ 感官锚点**
- 桑嘴里新嚼的苦叶（含混）。
- 浮渊腹地忽明忽暗的黑市灯。
- 议论声嗡嗡；耗子发白的脸。

## 给正文生成的提示

- **最吃"演得实"、最不能糊的是节拍2和节拍3**：节拍2的"扯封板→探针探进→读数屏亮→手顿住→问编号"这条链，是全章的悬疑支点，一步都不能跳（尤其"顿住"要有前因：她先看到了屏上的数/那颗同调核心，才顿）；节拍3的"挑开烧焦的神经束→夹住→接导极→通电→械子一抽"是本章内容密度的主要来源，就是靠这套真操作撑起篇幅，别缩成"她三两下把他修好了"。
- 桑的所有"裂缝"（认得、愧疚、心软）**只准用动作演**（手顿、目光钉、压回去、不收钱、嚼苦叶堵话），一句她的内心独白都不要给。
- S6（她认得构造/问编号/不肯说怎么认得）按硬红线8：先把"逃兵军医见多识广、修过这类东西"写成读者会直接接受的表面事实，伏笔本体是顺带藏进去的，不要写得像"这里埋了个伏笔"。
