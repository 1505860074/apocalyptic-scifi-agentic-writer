# 场面调度卡 · 第11章「添东西」

> 焦点卡定"每拍发生什么事 + 读者该有什么感觉（L/N/情绪温度）"；这张卡把每拍在浮渊这座平台的物理空间里，一步一步排成可演的调度。正文照这张卡演，篇幅由具体动作/对话撑，不靠悬浮描写凑。
> **本章性质**：喘息 + 命题情感支点 + 钩爷的灰，不是动作章。密度靠"手感修机器的工序""流民潮的具体挤压""一家人数碎晶渣""钩爷货钩划人时的停顿""征收舰压来"这几组具体行为撑，不靠打斗。
> **贯穿脊**：章题「添东西」＝钩爷第9章的规矩"进了浮渊就得给浮渊添东西，不添东西的白吃饭的养不起"。械子的手＝添得起东西→被留下；那家流民＝添不起→被划到外圈。这一对照就是本章命题（被当人 vs 被当没用的白吃饭的），别喊出来，靠两组人的具体遭遇顶出来。

> **浮渊空间底图（全章通用，各拍承接）**：一整座战前废弃采矿平台。**腹地**＝晶核黑市（摊子、灯忽明忽暗）、钩爷的料堆、水站（供水口）、朝外的舷窗；**外圈泊环**＝交不起税的人被挡在这（漏风、B区、废弃舱管里塞着人）；**泊位**＝犬牙交错，耗子驾小艇在这穿梭送货。腹地与外圈之间是几条挤满人的通道/舱道，收税的在通道口设卡。

> **械子当前状态（钉死，别写错）**：靠**手感**（徒手感机器哪里还活着）修东西立足，**这一章绝不用同调**。原因＝第10章桑说破"用一次少一次"（每超限同调一次就永久烧掉自己一截神经/义体），他不敢用。可视锚点：他修机器时**左肩接口不亮**（接口只在同调/情绪战斗时渗幽蓝光）。左半身还带着锈港那场的旧损，虚，但这章不发作到栽倒。左手思考时会无意识磕金属面（标志动作）。话少、先陈述事实再表态。

## 节拍 1：械子只凭手感修活报废机件，成黑市抢手修理工，一行立住脚（L2 / N2 / 喘息 · 闲笔授权点轻开：读机器的手艺）

**① 站位/空间**
- 腹地黑市一条侧巷尽头，一台战前老货梯：两人多高的铁笼子，卡在半层高上三个月，笼门锈开一道缝。侧壁一块检修盖，里头油泥糊住的齿轮组和传动轴。
- 械子蹲在检修口正前；耗子蹲他左手边，递工具、举灯。货主（囤货的黑市贩子）背着手站三步外，怀疑地看；旁边两三个闲黑户凑热闹。
- 头顶一盏歪脖子灯管，忽明。底噪：叫卖、远处机件哐当、水管滴水。

**② 动作链**（★本拍篇幅主体，可放缓、可展开手艺，但一步不省）
1. 货主叉手，说这梯子卡三个月了，早该拆了当废铁称斤卖，问一个改造货能有什么门道。
2. 械子不接话。把检修盖再往上抬，撬棍横着卡住撑住，露出整个传动舱。
3. 他先不上工具。把右手（普通皮肉那只）手掌平贴上传动轴外壳。**（点明：他没同调。左肩接口是暗的。为什么不同调——桑那句"用一次少一次"，进④）**
4. 【闲笔·手艺展开】手掌顺着轴慢慢挪，感金属的凉、涩；哪一段推一下能传回一点点活的震，哪一段推下去闷、死。挪到某一处，指腹底下的金属发闷、不回震——卡死的点在这，一颗咬死的偏心轮。
5. 他让耗子把灯凑近那处，拿一根细撬棍探进齿隙，抵住偏心轮往外别。
6. 别不动。退出来，换角度，从料里捡块碎铁垫进去当支点，再别。
7. 手上加力，撬棍打滑，棍头蹭过他右手虎口，划开一道，渗血。他没停，抹一下继续。
8. 别到后半夜（正文可"一宿"带过一次时间跳，但工序不省）。偏心轮"咯"地松了半分。他就着松出的缝拿油浇进齿口，手来回盘，让油吃进去。
9. 合上刀闸。货梯"哐当"一声，铁笼子晃着往上升了半层，停稳。
10. 货主愣住；围观的黑户起哄叫好。货主改了脸色，摸出几粒晶核渣要给。
11. 收束（narration + 钩爷一个动作/一句带过）：这种"不烧晶核、光凭手就把死机件盘活"的名声传开，钩爷划给他一个角落、管一船人半饱口粮，条件是手归浮渊用。耗子这头也没闲着，驾小艇在泊位间穿梭送货，跑一趟挣一趟；半船黑户干最脏的活（刮锈、通淤水管、扛货箱）。一船锈港人，在死地边上勉强扎下根。

**③ 对话交锋**
- 货主（开场，潜台词：不信改造货、想看笑话/压价）："这破烂三个月了，拆了当废铁不比你瞎鼓捣强？改造货还会修梯子？"
- 械子（全程话少，只在成了之后淡淡一句，贴口吻·先陈述事实）："偏心轮咬死了，不是电路。轴没坏。"（潜台词：我修的是我摸得到的东西，不玄乎，也不是靠你们怕的那身本事。）
- 钩爷（收编，拿捏，扣章题·可放收束处）："能添东西的，浮渊留。你这手，归我使。"

**④ 内心微动**（N2，填细一点，命题轻回响）
- 手掌贴上轴那一下，先是本能想同调（那样快，一下就"看"透里头哪儿死了）。
- 紧接着桑的话顶上来：用一次，少一次；烧掉的长不回来。他把那股冲动按住。
- 落回手感：笨，慢，得一寸一寸摸。可这双手是他的，不烧他的命。
- 更底下一层（别写满，一两句）：这一路他被当危险品、当晦气、当改造货躲着，这是头一回一群人围着、等他这双手把一台死机器盘活。被当有用的人，和被当危险的货，是两回事。

**⑤ 感官锚点**
- 指腹贴在传动轴上那段发闷、推下去不回震的金属。
- 撬棍打滑蹭破右手虎口渗的那道血。
- 货梯"哐当"升起半层时，铁笼子晃的那一下。

## 节拍 2：流民潮涌入，浮渊挤爆，晶核/水/舱位全线告急，钩爷收紧规矩抬价拒人（L1-2 / N2 / 压抑）

**① 站位/空间**（承接：从黑市侧巷出来，进腹地通道、水站、望向外圈泊环）
- 变了什么：泊环外圈贴满新到的破船，泊位占满，后到的只能挂在泊环外沿。通道里人贴人，得侧身过。水站（供水口）前排长队。通道口新设了卡，钩爷的收税的在验人。

**② 动作链**（压抑·N2，montage 但每一笔都落到具体人具体动作，不概述"苦难"）
1. 从第三天起，流民的破船一批批贴上浮渊外圈；泊位满了，后来的挂在外沿，舷梯搭不上就用绳。
2. 械子和耗子从黑市往自己船上走，通道比前几天挤得多，两人得侧身、贴着舱壁蹭过去。
3. 水站前：一块刻价的铁牌被换成新的，水按滴算，比昨天又贵一截。耗子想打点水回船，摸兜，凑不够，被打水的往后一推，空手退回来，低声骂了句。
4. 通道口的卡：收税的拦下刚到的一批流民，一个个验碎晶，不够的，抬手往外圈方向一指，就有人押着往外走。
5. 械子看着这一路，没吭声。

**③ 对话交锋**（日常带坑，别写成信息播报）
- 耗子（在水站被坑退回来，少年抱怨，贴他口吻）："一滴水都要抢……昨天还不是这价。"
- 收税的（通道口，冷硬程式化，一句）："交不起的，外圈。别堵道。"

**④ 内心微动**（N1-2，浅，一句带过）
- 械子：他们这一船刚扎下的那点根，眼看要被这潮水泡松。

**⑤ 感官锚点**
- 水站铁价牌上被人划改、又贵一截的新价。
- 通道里人贴人蹭过去时贴到的体温、汗味。
- 外圈泊环外沿挂着、挤成一片的破船。

## 节拍 3：一家交不起税、孩子病着的流民登场；械子耗子动恻隐，自己却泥菩萨过江（L2 / N3 / 钝痛 · 命题）

**① 站位/空间**（外圈泊环）
- 械子刚在外圈一截舱段修完一台水循环泵，出来往回走。路过一截废弃舱管（管径够人钻进去缩着）。
- 那家人：一男一女，护着一个约五六岁的孩子，缩在舱管里。孩子在女人怀里；男人蹲在管口。
- 外圈：漏风，光更暗，能听见泊环金属被外头星海的力拉扯的轻响。

**② 动作链**（N3，放缓，挑锚点，别铺排）
1. 械子路过，脚步先慢下来，看进舱管。
2. 具体看到：孩子脸烧得通红，一声一声地哼；女人拿一块脏湿布搭在孩子额头上，搭一下，拿下来，再搭。
3. 男人蹲在管口，摊开手心，几粒成色极差的碎晶渣，一粒一粒数；数完，拢一拢，再数一遍。数着的手一直抖。
4. 械子停住了。（内心进④：他兜里也空，一船人自己半饱，泥菩萨过江。他站着，一句话说不出来。）
5. 男人抬头看见他停下，像抓住根稻草，摊着那点渣子问他进浮渊要几粒、还差多少。
6. 械子答不上（他不收税，也没钱），只能陈述一句事实，没别的。
7. 耗子不知什么时候凑到械子身边，也不说话，闷头把自己跑船挣的、半块干粮，塞进那孩子怀里。
8. 塞完转身就跑，跑得飞快，像做了什么亏心事。
9. 男人愣着，想还、想道谢，耗子已经跑没了影。
10. 械子看着耗子的背影，又看那家人，左手在身边舱壁上磕了两下（标志动作），没磕出个办法来。

**③ 对话交锋**（N3 但克制，靠潜台词，不喊苦难）
- 男人（对械子，卑微、抓稻草，数着渣子）："大兄弟……进去，要几粒？我这……还差多少？"（潜台词：求你给句准话，我好知道还有没有指望。）
- 械子（答不上，只给事实，贴口吻）："我不收税。"（潜台词：我帮不了你，我也是被数着值几个晶核过来的。）
- 耗子：全程不说话，动作代替（塞干粮就跑）。

**④ 内心微动**（N3，填细，一步步长）
- 脚先顿住（本能，看见孩子那声哼）。
- 看那男人数渣子的手抖，械子想起自己——当年在锈港，也是这样被人摊在灯下、数着"这改造货值几个晶核"。
- 他摸自己的兜，空的；这一船人自己都还半饱。
- 一层层压下来：想帮 → 帮不起 → 那种太熟的无力翻上来。跟锈港那时候比，什么都没变，只是这回数渣子的不是他，是别人的孩子。
- 命题落点（藏进感觉里，别旁白）：他添得起东西，被留下了；这家人添不起，就被挡在这漏风的管子里。

**⑤ 感官锚点**
- 孩子烧得通红的脸，加那一声一声的哼。
- 男人手心里那几粒成色极差的碎晶渣（数来数去就那么几粒，凑不成一整粒）。
- 耗子塞进孩子怀里那半块干粮（跑船揣化了角、边上有牙印的硬干粮）。

## 节拍 4：钩爷底线微显——压价拒人，却没把人打出去等死、成批卖掉；械子开始看懂这灰色老头（L2 / N2 / 灰）

**① 站位/空间**（那天晚上，腹地钩爷处）
- 钩爷坐在他那堆缴上来的机件（料堆）中间，右手那副能开合的金属货钩。
- 一队交不起税的流民（另一户户，含一户拖家带口的）被钩爷的人押着排在料堆前。
- 械子拿着一块刻了修好机件清单的板，来交差，站在料堆一侧的阴影里等。灯昏。

**② 动作链**（灰·N2，中等展开；情绪全压在货钩这几个动作上，是本拍第二吃"演得实"的地方）
1. 械子来交清单。钩爷正在处理这批流民，抬了下货钩，示意他等着。
2. 械子站阴影里看：钩爷一户户点过去，验碎晶，不够的，货钩往外一划（一个动作，指外圈方向），他的人就把那户带走。
3. 划得慢。慢得不像个心狠的军阀——每划一下之间，货钩都在半空停一停。
4. 划到那户拖家带口的，货钩停在半空，比前几下停得久。（★底线微显的关键可视动作，别解释，就让它停在那。）
5. 械子在阴影里，几不可察地动了一下，开了口（见③第一句）。
6. 钩爷没看他，货钩一开一合，把话噎回去（③第二句）。
7. 械子闭嘴。（内心进④）
8. 钩爷最后还是把货钩往外一划——那户人被带走。规矩没破。
9. 但他从料堆里摸出两块最次的碎晶，不轻不重地丢在那户人脚边（丢，不是递）。
10. 说那句打发的话（③第三句）。
11. 械子上前交清单。钩爷接过、扫一眼，点回"添东西"的规矩收尾（③第四句），扣章题、跟那家人"添不起"对照。

**③ 对话交锋**（多轮，钩爷话里有秤、绝不解释自己的道德，靠动作露底线）
- 械子（看那户被划出去，忍不住，先陈述事实——他刚从外圈来，带着那家人的画面）："外圈B区有个孩子，在发烧。"（潜台词：你能不能……他没说出口，只摆了个事实。）
- 钩爷（不看他，货钩一开一合，慢）："浮渊今天，发烧的孩子有一百个。我这儿是买卖，不是善堂。"（潜台词：别拿一个孩子来压我，我担得起一个，担不起一百个。）
- 钩爷（划出去、丢下那两块碎晶之后，对那户人）："外圈泊环B区，漏风，但饿不死。别让我看见你们往腹地钻。"
- 钩爷（接过械子的清单，扫一眼，拿捏）："手不错。能添东西的留下……记着，添不动了，就没这待遇。"（扣章题；也点破械子自己被留下的理由，跟那家人对照。）

**④ 内心微动**（N2，中等；从械子眼里"看出来"，不是全知旁白替钩爷下定义）
- 械子看这一幕，一层层往下看懂：钩爷收着最狠的税，划着最冷的线。
- 可他没像外头那些军阀——没把交不起的人直接打出去等死，也没成批捆了卖给要"劳力"的势力。
- 那半空多停的一下、那两块最次的碎晶、那句"饿不死"，是这老头给自己留的一条线，连他自己都不肯说破，嘴上还得硬着（"别往腹地钻"）。
- 械子想到自己：也是"添得动东西"才被留下的。钩爷收了他的手，也没把那家人往死里整。这灰，他开始看懂了。

**⑤ 感官锚点**
- 钩爷货钩在半空停住、比前几下停得久的那一下。
- 两块最次的碎晶丢在那户人脚边、落在金属地上弹了一下的位置。
- 械子手里那块刻着修好机件清单的板。

## 节拍 5：钩子——浮渊外缘驶来星联的舰，不是清源，是征收队（借战时之名征晶核和"劳力"，把人当耗材充前线）（L2-3 / N1 / 压顶）

**① 站位/空间**（紧接节拍4，腹地。舷窗在腹地朝外一侧）
- 械子刚交完清单。忽然警报。人群从摊子、通道各处往一个方向涌——腹地朝外的舷窗。

**② 动作链**（压顶·N1，短促，逐动作，别糊）
1. 警报响。不是流民骚动那种嘈杂人声，是外缘探测阵列被什么触响的、又急又沉的那种鸣。
2. 黑市的灯齐齐灭了一瞬，又亮起来（供电被警报抢了一下的可视终态）。
3. 人群先顿住，然后往舷窗涌。
4. 械子被人流裹着挤过去，扒住舷窗边框往外看。
5. 浮渊外缘的星海里，几艘漆着星联徽记的舰，正缓缓压来。
6. 械子先认出徽记（星联的），再认船型：不是清源那种小巧的特勤舰。是大家伙，肚子敞着（货舱门大开），一看就是用来装东西、装人的。
7. 耗子挤到他身边，盯着舰身上刷的字，念出来，声音发颤。
8. 收在耗子那句上。

**③ 对话交锋**（N1，动作/画面为主，不堆对话）
- 耗子（念舰身的字，发颤）："征收队。"
