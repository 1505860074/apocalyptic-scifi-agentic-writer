## 空间总底图（本章一次钉死，各拍承接只写"变了什么"）

- **停泊环**：锈港外圈的一条弧形通道。一侧是一排泊位，停满等拆的报废舰船/机甲残骸；另一侧内壁上开着两个口——一个是通拆船厂的卷帘门（老秦地盘），一个是通居住舱的通道口，两口相隔约二十步。
- **第七泊位**：械子干活处。一台报废战争机械（趴了快十年、登记"战前制式·不可修复·待拆解"）侧趴在泊位地面、半嵌进泊位隔板与内壁的夹角里，机身三吨多，一条液压臂压在身下。**它旁边、机身与内壁之间就是个死角**（拍3械子被逼进来的地方，也是拍4他伸手就能按上的机器——空间闭环，钉死）。
- **最外圈封闭门**：通港外对接口，在械子这段通道往外约三四十步处。拍2被海盗从外撞塌。
- **光/声底噪**：顶上一排老灯管，昏黄、发嗡、时不时晃；锈港重力场没修好，隔一阵抽一下（脚底一沉、灯管跟着晃）；金属锈味、机油味。

## 节拍 1：械子徒手贴报废战争机械"感"它——火控还热、里头有残存数据（L1-2 / N2 / 平静·专注 · 闲笔轻开）

**① 站位/空间**
- 械子半蹲在第七泊位那台报废战争机械边上，左手掌贴在它的胸甲上。周围没别人，黑户在通道别处各干各的活，离得远。灯管昏，重力场稳着（还没抽）。

**② 动作链**（骨架为主，重点在"感"的过程=本事展示，别跳）
1. 械子左手掌压在冰凉胸甲上 → 重力场"抽"了一下，脚底一沉、灯管晃 → 他没动，任那半秒失重过去，手不挪。
2. 金属底下有东西在响，不是耳朵听的响 → 是从他左半边身子外露的接口顺着骨头传上来的，一下，一下，闷闷的。
3. 他闭眼，顺这一下一下往里"摸"（万机通感 Lv.1：徒手贴、感状态）→ 摸到那台死铁最底下还剩一丝电，正一下一下顶他的接口，顶不动、又不肯灭。
4. 再往里 → 火控模块还残着温度（"还热"）→ 里头卡着一段没打完的开火指令，走到一半停了，一遍遍往前撞、过不去。
5. 械子睁眼，收手 → 左臂接口顺着他这个动作，极轻渗出一线幽蓝，又暗下去（Lv.1 现象，轻）。

**③ 对话**（一句自言自语，话少短句）
- 械子："火控还热。"→（顿）"老秦得知道这个。"——潜台词：这台"不可修复"的废铁里还封着能卖钱的东西，老秦准骂骂咧咧然后眼睛发亮。不是抒情，是干活的人算账。

**④ 内心微动**（N2，轻，一两句）
- 他"读"机器时的专注：这台趴了十年的死铁，最底下那一丝电还在顶、那道开火指令还没走完——在他这儿它不是"不可修复"，是还有一口气没咽。**别写成"他把机器当同类"这种旁白定性**（焦点卡红线：性格靠行动，不旁白宣告）；就让他对这一口没咽的气多停一下手。

**⑤ 感官锚点**（确定实体，禁伪具体比喻）
- 胸甲冰凉（触）；接口顺骨头传上来的"一下、一下"闷响（那丝电顶接口，触/体感，非声）；接口渗出的一线幽蓝（视）。
- **闲笔轻开**（挂在"火控还热"这个由头上）：可放一两句械子对"怎么徒手感一台死机器还活没活"的门道私货（哪儿还有电、哪根线还在动），是这个锈港拆船野孩子真会有的实感，不是文绉绉比喻。

## 节拍 2：他要去报老秦，海盗破外门涌入抢货（L2 / N2 / 紧张骤起）

**① 站位/空间**（承接拍1，变了什么）
- 械子起身、转向卷帘门（拆船厂）方向，要去报老秦。→ 变化：最外圈封闭门（外侧三四十步）被从外头撞塌。

**② 动作链**（不跳步）
1. 械子刚直起身、迈步 → 停泊环最外圈封闭门"轰"地塌下来（先是一声闷响+脚下震动，不是重力场那种抽）。
2. 门板砸地 → 十几道人影踩着塌下来的门板涌进来，劣质动力甲在灯下泛油光。
3. 当头一个抡起震荡棍，劈手砸翻停在通道口的一台搬运机 → 火星溅一地（立威第一下）。
4. 械子本能往最近的阴影退半步，后背贴上冰凉残骸 → 他认出那身油光甲：废土海盗，专挑锈港这种没星联管的边角下嘴。
5. 停泊环里干活的黑户呼啦往居住舱通道口那头跑，没人回头看械子一眼，跑时还绕开他半步。
6. 械子也想跟着往居住舱口挪 → 但他站的位置（第七泊位）正卡在海盗涌入方向和残骸堆之间，往居住舱口那条道，得从海盗眼皮底下横穿。他停住了。

**③ 对话**（海盗头目喊话，播报式立威，允许）
- 头目（嗓门劈开金属回声）："废土的规矩！老秦昨天吃进来那批机甲残骸，搬出来，少一件崩一个！"——潜台词：宣示来干嘛（抢老秦刚吃进的货）+ 立威给全场黑户看。

**④ 内心微动**（N2，轻）
- 认出海盗那一下的凉（他见过这种场面）；想跑是本能；发现自己被夹在中间、那条活路要横穿海盗眼皮，心里"往下沉"的那一下。**不写"他这辈子怂惯了"式自传体总结**（焦点卡红线）——只写他停住脚、没往那条道上迈。

**⑤ 感官锚点**
- 塌门的闷响+脚下震动（区别于重力场的"抽"）；动力甲的油光；砸搬运机溅的火星；后背贴上的残骸冰凉。

## 节拍 3：老秦迎出交涉、被打伤；械子被逼进第七泊位死角（L2-3 / N3 / 危急）

> 本拍两条线交叉：A线 老秦门口交涉→被打（参 场面调度卡-模板 老秦示例，并加一轮"市侩交涉"多轮交锋）；B线 械子被散开的海盗堵回死角（解释他为何正好按上那台机器）。
> **给正文生成的提示：本章动作链最吃"演得实"的是本拍A线老秦挨打的逐格 + 拍4械子笨拙同调的逐格，最不能糊。**

**① 站位/空间**（承接，变了什么）
- 拆船厂那侧卷帘门升到一半（半人高，得低头钻）。老秦拄自改义肢金属臂，从半开门下钻出/横在门口。头目在门外三四步、震荡棍此刻扛在肩上。其余海盗散开，往泊位这排铺，往里搬货、也堵路。械子还在第七泊位边缘。

**② 动作链**（N3·危急，拆细、不跳步）

A线（老秦交涉→挨打）：
1. 老秦拄义肢横在半开卷帘门口，堵住往拆船厂里的路，骂："哪来的野狗，这港是有主的！"——先摆"有主"唬人。
2. 头目嗤笑，把震荡棍从肩上卸下来、横到身前（亮家伙、警告，不是马上打）："主？"
3. 老秦不退，改市侩那套：往下压价、拿"规矩"拖时间、报个数想把这事谈成一笔买卖（他本能想少动手、把货保下一半）。
4. 头目不吃这套，往前突进一步——谈崩。
5. 老秦拄着义肢往前挪半步、挡在门口不让过（护货也护里头的人）。
6. 头目震荡棍自下往上撩。
7. 老秦想抬那条断臂改的义肢去挡——那条慢半拍、抬不利索。
8. 没挡住，棍头扫中他左肩 → 半个身子被带得侧撞门框，义肢磕在金属门框上迸一串火花，单膝跪下去，半边脸磕出血。
9. 头目抬脚、震荡棍棍尖往老秦门面上招呼（第二下将至，未落）。

B线（械子被逼回死角，与A线交叉进行）：
1. 海盗散开往泊位搬货时，一个海盗踩过第七泊位、朝居住舱口那边堵 → 械子想溜去居住舱口的那条道被堵死。
2. 械子往回缩，退进第七泊位那台报废战争机械与内壁之间的死角 → 后背/一只手抵上那台机械冰凉的胸甲（正是拍1那台，钉死空间闭环）。
3. 他从死角看得见门口老秦挨打的全过程（视线不挡）。

**③ 对话**（老秦交涉的多轮交锋，潜台词标）
- 老秦"哪来的野狗，这港是有主的！"——唬（亮靠山）。
- 头目"主？"（嗤笑反问）——不把老秦当回事，立威打给围观黑户看：谁再挡就是这下场。
- 老秦压价/报数那两句（市侩谈钱、拖）——潜台词：能不动手就把货保一半，别把命搭进去。
- 头目一句碾过去（懒得谈/嫌他啰嗦）——潜台词：谈崩，动手。

**④ 内心微动**（N3，填细，一步步——为拍4出手蓄）
- 械子的怕/急一层层涨：先是呼吸停一下（看老秦被撩中）→ 看老秦单膝跪、义肢迸火花，那股"想冲又不敢、腿像钉住"的东西顶上来 → 头目抬脚、棍尖冲老秦脸去，他心里那根线绷到断口（"老秦要被打死"）→ 但他没想清楚要干嘛（留给拍4接）。
- 别下"怂人本能"这种旁白标签（焦点卡红线）；写他攥紧的手、抵在胸甲上的那只手指头动没动。

**⑤ 感官锚点**
- 棍头扫中肩膀的那声闷响；义肢磕门框迸的一串火花；老秦半边脸的血；（械子侧）后背/手掌抵着的报废机械胸甲冰凉。

## 节拍 4：械子接口骤亮，本能"裸同调"脚边报废机械，机械抬臂砸翻海盗（L3 / N3 / 爆发·狠 · 爽点·笨拙但惊人）

> 高潮投放拍。细度旋钮：慢镜头逐格；投放瞬间零内心（内心留给拍5余韵）；感官对准动作与威胁。金手指卡 Lv.1 限制必须落地：**笨拙、只这一台、强读数据头痛**——不是干净利落一击，是笨拙地、痛着、试第二次才成。

**① 站位/空间**（承接，变了什么）
- 械子在死角，一只手已抵在报废战争机械胸甲上。头目在门口老秦跟前（离械子约十步），此刻背/侧对械子，棍尖正往老秦脸落。头目身后跟着两个海盗。那台机械的液压臂压在机身下（要抬得先挣开自重）。

**② 动作链**（逐格慢镜，不跳步，笨拙落地）
1. 械子没想清楚要干什么——只是把那只抵着胸甲的手，整个按实了（本能，不是决定）。
2. 左臂所有接口"唰"地亮，幽蓝顺他半边身子的合金纹路一路窜上来，亮得刺眼。
3. 脑子里"哗"地灌进来一种他从没学过的东西：哪根线是控制臂、哪条回路是驱动、力矩往哪压、多少度、多快——不是想出来的，是像早就长在他身子里、这会儿被人猛地拽出来。
4. 他没有接口线，没有同调舱，什么都没有，只有一只按在胸甲上的左手 → 就凭这只手，什么都没接，把那股操控数据硬按进报废机械的残骸里（裸同调现象，不点术语名）。
5. **笨拙首现**：十年没动的液压臂先是一阵抽搐、发出干涩的卡顿嘶鸣，只从机身下挣起半尺，又"哐"地砸回去（第一下不受控、Lv.1 笨拙）→ 同一瞬械子太阳穴猛地一跳、剧痛（强读数据的反噬）。
6. 械子咬住，把那股劲再往里按一次、更狠（更用力=更痛，眼前开始发花）。
7. 这次液压臂发出一声撕裂般的长嘶，猛地把整条臂从机身下抬起来。
8. 头目察觉身后异响，半侧过脸，只来得及"嗯？"了一声。
9. 三吨重的合金臂横扫过去 → 把头目和他身后两个连人带甲砸翻出去，撞在停泊环内壁上，动力甲瘪成一团废铁。
10. 停泊环里所有人都僵住：海盗僵住，躲在角落的黑户也僵住。
11. 那台"不可修复"的战争机械又"咔"地抬了半寸，幽蓝的光顺着它的关节一路爬回械子亮着的接口。

**③ 对话**：极限动作段，基本沉默留白。只有头目那声"嗯？"、金属的卡顿/撕裂嘶鸣、砸中内壁的闷响。别硬凑对话。

**④ 内心微动**（N3 但投放瞬间几乎空——照细度旋钮"投放时零内心"）
- 只保留第1格那半下"没想清楚要干什么"的空白感（本能先于想法），其余全靠身体（太阳穴的痛、咬住、发花）外化。真正的惊惧余悸留到拍5开。

**⑤ 感官锚点**
- 接口幽蓝亮得刺眼（视）；液压臂干涩卡顿→撕裂长嘶（听）；太阳穴那一跳剧痛（体感）；动力甲瘪成废铁撞内壁的闷响（听）；手掌下胸甲的震动（触）。

## 节拍 5：覆写退潮，陌生冷硬战斗记忆灌入；他盯着还亮的接口往后缩一下（L3→L2 / N3→N2 / 惊惧·余悸 · 埋S1+QS-01）

> 高潮余韵拍，内心此拍开细（拍4憋住的在这儿放）。S1（陌生战斗记忆）写成"怪现象/像应激幻觉/后遗症"，**不点破是伏笔**（焦点卡红线 + 伏笔DAG：首先服务表面功能）。QS-01 轻信号（往后缩一下），别写成引爆。

**① 站位/空间**（承接，变了什么）
- 光灭。械子从死角单膝跪到报废机械旁，手还残着微光。头目那伙瘪在内壁边。老秦在门口扶着门框往起爬。

**② 动作链**（不跳步）
1. 幽蓝的光灭 → 械子晃一下，一股钝痛从太阳穴炸开、眼前发黑 → 单膝跪在残骸旁，喘。
2. 刚才灌进来那股操控数据，退潮似的退走 → 退走时擦下来一片碎渣，黏在他脑子里。
3. **S1灌入**（写成怪画面，不解释）：一段冷硬的、不属于他的画面——有人在一个狭窄驾驶舱里，用和他刚才一模一样的手法压下一台机甲的力矩、朝什么东西开了火；那双手很稳。那不是他的手，他从没进过那种舱。可那手法，是他刚才用出来的手法。
4. 械子盯着自己那只还残微光的左手 → 极轻地、下意识往后缩了一下，像怕那只手（**QS-01**，轻）。
5. 老秦扶门框爬起来，半边脸都是血 → 盯着那台重新趴死的战争机械，又盯着械子。
6. 剩下的海盗骂了句什么，架起瘪成一团的头目，连滚带爬退出塌掉的门。

**③ 对话**（潜台词标）
- 老秦："……械子？"——潜台词：他做了半辈子买卖、什么都敢估价，这一刻头一回估不出价来；这声"械子？"不是往常喊他干活那声，是"你到底是个什么东西"没敢问出口。

**④ 内心微动**（N3→N2，此拍开细，一步步）
- 先是那段陌生画面的冷（不属于他、却又是他刚用出的手法）一层层压上来 → 再是盯着自己手时那点发毛（这手法哪来的？他从没学过）→ 收在往后缩那一下的"怕自己"（QS-01 的底：像怕那只手是别人的）。
- **可极轻带一笔"编号音节"**（S2另一半，钉焦点卡L4"接口异光+编号音节"）：记忆退走、脑子最底下剩一个说不上是什么的音节，一直在那，像个没头没尾的编号——一句带过，不解释、不点破。

**⑤ 感官锚点**
- 太阳穴炸开的钝痛（体感）；还残微光的左手（视）；陌生画面里那双很稳的手/一次开火（视，S1）；老秦半边脸的血（视）。
