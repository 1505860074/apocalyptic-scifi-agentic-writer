## 节拍 1：老秦亮身份一角 + 一个筹码，逼戚凛暂缓强攻、退到外围封锁（L2 / N2 / 压迫缓一口）

**① 站位/空间**（承接 ch3 停泊环）
- 械子：单膝跪在铁地上，左手撑地还残着一线幽蓝微光；面前一摊他刚吐的血。
- 老秦：在械子身前半步，独臂 + 那截自改义肢一起张开，把械子挡在身后，正对戚凛；他半跪着把械子从血里拢起来时，义肢金属指蹭到了血。
- 戚凛：正面三四步外，右眼战术单片镜亮着冷刻度光；身后两三个清源组特勤。
- 天顶：清源无人机几十架，悬成一张网封着停泊环天顶（ch3 的封顶还在）。
- 地上：三架被覆写坠毁的无人机残骸散在开阔地；老吴的尸体在残骸堆掩体边缘，眼还睁着。
- 远处居住舱口：黑户缩着头远远看，没人过来。
- 底噪：昏黄老灯管；几十架无人机的低频嗡鸣；一股没散的硝烟味。

**② 动作链**（★多轮交锋，别缩成"老秦一句话她就退了"）
1. 戚凛的单片镜光，停在老秦脸上不动（承接 ch3：档案跳出来了）。她本已抬手要下令回收，这会儿抬到一半停住。
2. 她没先动手，先核对——报出老秦的旧档案（试探、逼他认）。
3. 老秦不接她的核对，不否认，市侩硬话顶回去，人挡着不退。抛第一记：死人回不了你的话，我能。
4. 戚凛不吃这套，重新拿条例把场面压回去——手一抬，示意一架无人机压下来（**阻力：她没退，反而往前逼一步**）。一架无人机降低高度，红扫描线重新落到械子半边义体上。
5. 械子在血里被那道红线罩住，后背合金发凉；他伸手要去够老秦后襟（本能，想把老秦拽回来别挡），攥住了没松。
6. 老秦不看那架无人机，只盯着戚凛，把真正的筹码拍出来：问她上头给"清源"派活时，说没说过第七军械序列当年拆的是什么"货"。
7. 戚凛的单片镜光跳了一下，反复校准了一下（她的不安 tell）——这条她上头没交代过，眼前这断臂老头可能是个知道内情、又该"殉职"了的人。
8. 她权衡：拿不准老秦手里有什么，不能就这么把目标清了。她把伸出去的那步收回，改口——转外围警戒、目标暂列待核、要调档。
9. 无人机齐刷刷升高一截，退出停泊环正上方，收缩成外围一道封锁圈。
10. 戚凛最后扫械子一眼（半边义体 + 那张脸来回），转身，军靴踩过满地无人机残骸，走了。
11. 械子直到那道封锁圈稳住，才发现自己攥着老秦后襟的手一直没松开。

**③ 对话交锋**
- 戚凛报老秦旧档案（"秦河。星联同调技师，第七军械序列。十一年前坠舰，殉职，存疑。"）——潜台词：我认得你，我在逼你自己认，也在给自己争取核对的时间。
- 老秦"存疑就对了。死人回不了你的话，我能。"——潜台词：我没死，我手里有你想不到的东西，别急着动手。
- 戚凛"退开。这不改变目标的性质。"——潜台词：她动摇了但死抠规矩，用条例把自己按回猎人的位置。
- 老秦（真筹码）"中尉，你上头给'清源'派活的时候，跟你说过第七军械序列当年拆的是什么货吗？"——潜台词：我知道清源这活的脏底，你查不清我，就不敢清我。
- 戚凛"清源组转入外围警戒。目标暂列待核。调阅第七军械序列封存档案。"——潜台词：撤，但没放；她要先弄清老秦知道什么。

**④ 内心微动**（N2，轻，一两句，别抢对话戏）
- 械子：先是不懂老秦亮出来的那串身份是什么（"星联""第七军械序列"和眼前这个拆船厂老头对不上）；再是意识到老秦在替他把自己也搭进去——攥后襟那只手是这一层的外化，不写"他很感动"。

**⑤ 感官锚点**
- 单片镜那格冷刻度光（对准威胁源）。
- 红扫描线重新落在械子半边义体上。
- 军靴踩过无人机残骸的声（戚凛退场）。

## 节拍 2：拆船厂堆料间，老秦压反噬 + 第一次半坦白（前星联同调技师军官，拒绝把人当耗材而断臂除名）（L2-3 / N3 / 沉）

**① 站位/空间**
- 场景切到拆船厂堆料间（＊　＊　＊ 后）。四下：料箱、料架上一堆待拆零件、钢板地（★订正20260822：原"铁地"违命名法"现实事物不自造词"，堆料间地面照命名表用"钢板地"）。
- 老秦半拖半架着械子进来，把他按坐在一只料箱上。
- 械子：反噬余波还没过（接 ch3 过载吐血），半边义体的接口一明一暗地渗蓝光、发烫，太阳穴那根筋一跳一跳地钝痛、发胀（★订正：原"像被撬着"是比喻、本章配额0，改纯体感），身子一阵阵抽。
- 底噪：远处重力锚补偿模组偶尔丢一拍的闷响（★订正：原"重力场抽一下"拟人，机制化）；管子里镇定剂走动的细声（打进去之后）。

**② 动作链**
1. 老秦把械子按在料箱上，一只手压住他还在抽的肩。
2. 老秦从料架/怀里摸出一管星联制式镇定剂，磕开封。
3. 往械子颈侧外露接口那儿打进去。
4. 那东西凉得刺骨，顺着械子半边义体往里爬。
5. 械子那阵抽搐一点点压下去，太阳穴那根发胀的筋慢慢松开。
6. 械子缓过一口气，哑着嗓子把戚凛那句话捡起来问老秦（第七军械序列、你当年拆的什么货）。
7. 老秦不接。转身，从腰上摸出酒，灌半口，剩半口照例往地上泼——但这回没说那句"敬熄了灯的星域"（信号：这不是平常那口酒）。
8. 老秦盯着那摊酒渗进铁地缝里，很久。义肢在膝盖上收紧。
9. 才开口，声音又干又慢，像每个字都得先从锈里抠出来。先讲他拆过什么（舰、炮、报废机甲），再落到那一批"货"。
10. 讲：那批货装在同调维生舱里，一舱一个，编号，没名字；他以为是坏了的同调造物。
11. 讲：打开维生舱那天才知道，里头是人，活的；半边身子换成接口，脑子里塞了不是自己的东西，就为了不用舱、不用线，空手同调。（**MX1 维持：档案上只一行字"实验体"；不说"活体接口"这个后来才有的名字，不碰晶核钥匙**）
12. 讲命令：拆解回收有效模块，其余按报废处理。老秦顿在"报废处理"这四个字上——把还喘气的东西当报废件。
13. 讲他没干：漏了维生舱坐标出去，让人趁乱把还活着的几个弄走。
14. 老秦抬了抬那截义肢——代价：这条胳膊、一个"殉职存疑"的档案、半辈子躲在这鬼地方。

**③ 对话交锋**
- 械子（哑）"第七军械序列。她说的。你当年……拆的是什么货。"——潜台词：他要的不是八卦，是想搞清自己身上这东西从哪来。
- 老秦这一段基本是他一个人往外抠字，断续、别扭、句子短（人物卡：越难说越绕，越心软越硬着来）。他不是在讲故事给械子听，是在把埋了十一年的东西一寸寸挖出来，中间有停、有跳、有不肯细说的地方。

**④ 内心微动**（N3，但这拍重心在老秦的"别扭外化"，不在械子内心独白）
- 械子这拍不大进内心，主要是听、是被镇定剂压着缓过来；他的震动靠"呼吸慢下来""没敢插话"外化。老秦的心理不用旁白讲，全靠他泼酒不说那句、义肢收紧、从锈里抠字这些动作带。

**⑤ 感官锚点**
- 镇定剂打进接口时那股刺骨的凉，顺半边义体往里爬。
- 半口酒渗进铁地缝。
- 老秦义肢在膝盖上收紧（金属指抠住膝盖）。

## 节拍 3：老秦讲"实验体计划"，把话点到械子身上——"你不是天生的怪物，你是被造的"（L2-3 / N3 / 悬疑·钝痛）

**① 站位/空间**
- 同堆料间，承接节拍 2，只写变化：老秦讲完自己那段后，抬眼看向械子此刻暗着的半边义体。
- 堆料间静，能听见管子里镇定剂走完最后一点的细声。

**② 动作链**
1. 老秦把话从"当年那批货"往外推一层：不是一次、不是一个地方——有人在成规模地造这种东西（实验体计划，传闻级，他也只拼出一角）。
2. 老秦抬眼，目光落在械子半边亮过、此刻暗着的义体上，停住。
3. 老秦把话头第一次正面对准械子：我不知道你是不是当年那批里的；但你那手"裸同调"，我这辈子只在维生舱里见过一次。
4. 老秦顿——像这句比断胳膊还难说出口。
5. 落定："械子，你不是天生的怪物。你是被造出来的。"
6. （**投放拍：这一句砸下去时不进械子内心，余韵留到节拍 4**）

**③ 对话交锋**
- 老秦"我不知道你是不是当年那批里的。但你那手'裸同调'，我这辈子只在维生舱里见过一次。"——潜台词：我几乎肯定你就是，但我不忍心把话钉死，给你也给我自己留一线。
- 老秦"械子，你不是天生的怪物。"——潜台词：他知道这孩子最怕的是"我是不是个怪物/机器"，先把这一条摘掉。
- 老秦"你是被造出来的。"——潜台词：摘掉"天生的怪物"，却递上更冷的一个"你是被造的"；他自己都知道这不是安慰。

**④ 内心微动**（投放拍，空——留给节拍 4 的余韵）

**⑤ 感官锚点**
- 械子半边亮过、此刻暗着的义体（老秦的目光落点，也是"被造"二字的实物落点）。

## 节拍 4：械子没爆发，久久没说话，手指停在金属面上没敲；只反问一句"被造的……那还算不算人"（L2 / N2 / 压抑 · QS-03）

**① 站位/空间**
- 械子坐在料箱上，左手一直搭在冰凉的料箱金属边沿。
- 老秦在他对面/侧面，说完那句就没再出声。

**② 动作链**（放缓，核心动作只一个，别铺满）
1. 械子没动。没跳起来，没吼，没哭。
2. 械子低头看自己那只左手——半边义体、外露的接口，那些不知道由谁、为了什么，一寸寸嵌进他身体里的东西。
3. 械子平时一紧张、一想事，左手手指就会无意识去敲最近的金属面（人物卡标志动作）；这会儿手指搭在料箱边沿上，停在那儿，一下没敲。（★ QS-03 核心外化动作，全章最不能糊的一处）
4. 械子的话是从自己身上一件件往外数：所以这本事、这段不属于我的记忆、这个我自己都指挥不动的东西……都是被人塞进来的。
5. 械子想起老吴那双还睁着的眼睛（ch3 callback），想起那束穿过自己救的人的光（ch3 callback）。
6. 很久，械子才问出那一句，声音很轻，喉咙发紧。
7. 老秦答不上来，没答。

**③ 对话交锋**
- 械子"所以我这本事。这段不属于我的记忆。这个我自己都指挥不动的东西。都是……被人塞进来的。"——潜台词：他在把老秦的话往自己身上一条条对，越对越凉。
- 械子"被造的东西……那还算不算人？"——潜台词：这是他核心恐惧的正面提问（人物卡：被质疑是不是人时习惯反问"那你说，人该是什么样"，这次问得更钝、更直）。不是要老秦答，是问给自己、问给这一屋子的沉默。
- 老秦的"没答"本身是回答：他这个把人从耗材堆里捞出来的人，也答不上。

**④ 内心微动**（N2，填细，一步步——这是全章的情绪落点）
- 不是爆发。是一层钝的下沉：先是把老秦的话往自己身上套（记忆不是我的、力量不听我的）→ 再是那股"我到底是不是台机器"的老怕，这次有了实锤（被造的），压上来→ 最后收成那一句问，问完更空。全程压着，不许写成"他终于明白了/泪水夺眶"这类总结腔。

**⑤ 感官锚点**
- 手指停在料箱金属边沿上，没敲（冰凉的触觉 + 停住的动作）。
- 左手半边义体外露的接口（他低头看的落点）。
