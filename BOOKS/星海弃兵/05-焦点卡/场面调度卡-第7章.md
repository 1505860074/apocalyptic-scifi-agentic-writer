## 节拍 1：械子主动同调特勤机甲，撞上同调防火墙，与戚凛隔机第一次交手（L3 / N3 / 对抗·屏息）

**① 站位/空间**（本章底图，承第6章末）
- 场地：拆船厂停泊环。顶上一排劣质灯管，昏黄、发闷；满场硝烟；机械足和重炮把泊位炸得到处是塌下来的支架、飞溅的残骸。
- 特勤机甲：立在残骸堆前十来步，三层楼高，装甲上"清源"两个字，机械足陷进铁地，**主炮口平端着、正对老秦他们退守的那道残骸堆**。
- 械子：残骸堆掩体后、半跪，左臂接口暴出幽蓝，一只手朝特勤机甲的方向伸着（承上章末）。离机甲约十来步。
- 老秦：残骸堆另一头，独臂张开挡在七八个走不掉的黑户身前，那截自改义肢横着。
- 耗子：残骸堆最里侧的死角，蹲着，两手攥着巴掌大的导航芯片。
- 无人机：十几架清源无人机，悬在特勤机甲上方和四周，机腹红线全亮，把这片停泊环罩死。
- 出口：停泊环最里头，B7泊位一条被杂物半堵的私道口，是眼下唯一没被清源封死的路。
- 戚凛：几百米外，停泊环外沿她的机甲舱里，隔着硝烟看不见人；右眼单片镜亮着刻度冷光，一只手搭在操控杆上，同调链锁着这台前出的特勤机甲（她远端同调这台机甲，所以是"她的清源机械"）。

**② 动作链**（★逐动作，不许跳步）
1. 械子的同调顺着那只伸出的手，够上特勤机甲最外层的回路。前两次（报废机械、低配无人机）回路是敞的、烂的，他那股力量一漫就进。这台不一样：火控外头裹着一层东西，冰、密、活，像另一只手，死死攥着这台机甲的每一根线，不许外人碰。
2. 他的同调刚碰到那层"手"，那层东西立刻收紧，顺着他伸进去的路反压回来，要把他这只擅自伸进来的手斩断、弹开。
3. 械子头里"炸"了一下（读高级目标数据的头痛，金手指卡Lv.1限制：读数据剧烈头痛）。他闷哼，左臂接口的幽蓝抖了一抖，手没缩回来。
4. 他"感"到墙那头有人：每一道封锁都下得齐整、一层严丝合缝地压着一层，除了那个报编号的女人，不会是别人。
5. （戚凛那端，几百米外）单片镜刻度光"跳"了一下——有人在夺她锁着的清源机械。她搭在操控杆上的手一紧，顺着同调链把封锁又加一层。
6. 两股同调，在同一台机甲的神经里，顶上了。谁也没进去，谁也没退。

**③ 对话**：无。屏息交锋，全靠动作和体感。械子顶多从牙缝里挤出一声闷哼。

**④ 内心微动**（N3，但走体感不走反思）：械子认出墙那头是谁——"是她"这个级别的判断即可，不展开。主体是接口和头里那下疼的实感，不是"他意识到自己面对的是顶尖同调者"这类总结。

**⑤ 感官锚点**：① 左臂接口暴出的那道幽蓝光（可视）；② 头里"炸"开的那下疼（触觉实感，不是比喻）；③ 特勤机甲主炮口仍死死平端着、对准残骸堆没动（可视终态）。

## 节拍 2：镜像瞬间——她苦练封顶 vs 他天生超限；械子笨拙却凭决意一寸寸夺权，调转炮口、策反机群（L3 / N3 / 爆发·掌控爽）

**① 站位/空间**：承上，焦点收到三样东西上——这台特勤机甲的炮口/机械臂、械子半边身子、上方无人机的红线。别的都在硝烟里虚掉。

**② 动作链**（★本章最吃"演得实"的一处，多轮交锋，不许缩成"他扑了进去"）
1. 械子往里挤。笨拙、生涩，像一个从没握过刀的人硬要去夺对方手里的刀。戚凛的封锁精准、老练，一层一层地封他、切他，每一下都正中他伸进去的那条线。
2. 械子先去够那条控制炮塔转向的线，使劲"推"。特勤机甲的主炮口，偏开了一寸。
3. 戚凛立刻把它拽回来。炮口"哐"地又端正，重新对准残骸堆。反压顺着同调链撞进械子的接口，他被顶得单膝往下一沉，鼻子里渗出血。
4. 【交锋波折·戚凛主动反击】戚凛反手一记：令特勤机甲后退半步、机械足碾碎一片残骸挣同调（想甩开械子那只手），同时同调链一分，令上方一半无人机红线齐齐转向，罩向正要起身往路口走的耗子那一片——逼械子分神来救。
5. 械子眼角瞥见红线扫向耗子那头。他不能松。他咬住牙，把那股汹涌、滚烫、不讲道理的力量，一股脑地、不要命地往里灌。
6. 灌到某一处，戚凛那端"顿"了一下——那是常人同调率的天花板，她练了半辈子逼到的极限，再也上不去的地方。而械子不知道自己的顶在哪。
7. 他接着往里灌，灌过她精心织起的每一道封锁，硬生生从那只攥紧的手底下，抠开了一道缝。
8. 特勤机甲僵了一瞬。就这一瞬，械子顺着那道缝，挤了进去。
9. "调转。"他从牙缝里挤出这个念头。那条对准老秦的主炮，机械臂猛地一横，炮口调开了方向。
10. 它周围那十几架清源无人机，机腹红线齐齐熄灭，掉转过来，朝自己人组成的封锁圈冲撞过去。火光在停泊环里连成一片，硝烟里裂开一条路，一条直通B7泊位的路。

**③ 对话**：
- 械子（咬牙，一个词）："调转。"
- 械子（嘶吼）："上船！耗子，带他们走私道！"——潜台词：他撑不了多久，要人趁这条路还在赶紧走。

**④ 内心微动**（N3）：一句他此刻的实感——她压到某处上不去了，他还能往上灌，他不知道自己有没有顶。落在"他没有上限"这个身体层面的体感上，不是作者旁白总结他的天赋。短。

**⑤ 感官锚点**：① 鼻子里渗出、滴到接口上的血（触觉+可视）；② 机械臂猛地一横、把炮口甩开那下的动静（可视+听觉）；③ 十几架无人机红线齐齐熄灭、掉头（可视终态，不写"不再瞄准"这种否定式，写红线灭了、机头掉转）。

## 节拍 3：清出一条路，但械子没赶尽杀绝——留了活口，也没朝戚凛下手，只求带人上船（L2 / N3 / 克制）

**① 站位/空间**：一条清出来的路，从残骸堆通向B7泊位私道口。黑户开始往路上涌。被无人机和机甲掀翻的清源士兵，散在路两侧的铁地上，仰面朝天、枪和震荡棍甩在一边。械子夺来的特勤机甲，横在路口挡火力。戚凛本体机甲仍在几百米外。

**② 动作链**
1. 黑户回过神，连滚带爬地朝那条被清出的路涌去。耗子攥着芯片冲在最前头。
2. 械子撑着那台夺来的机甲，把机甲的身子横过来挡在路口，替人挡后头的火。他额上青筋、鼻血、单膝还跪着，同调全咬在机甲上。
3. 那些被掀翻在地的清源士兵，就在机甲脚边、炮口正下方。械子大可以让机械足一脚碾过去，让那股力量把整个清源先遣绞碎。
4. 械子没有。机械足悬在那几个士兵上方，没落下去。他只让机甲的身子撑着这条路，让路上的人先走。
5. 也没有把炮口、把那股力量，朝几百米外那个女人所在的方向，偏过去哪怕一寸。

**③ 对话**：少。械子对着往路口跑的黑户催一声——短促、就一两个字（如"快"）。

**④ 内心微动**（N3，但短、当下、不长篇闪回）：他为什么没下杀手——一句他自己的理由。上一次这股力量涌上来，杀了一个他想救的人（老吴，第3章）；这一次他要它只做撑路这一件事，别的什么都不做。轻轻带过，不铺成回忆段。

**⑤ 感官锚点**：① 脚边清源士兵仰面朝天、枪甩在一边（可视）；② 机械足悬在半空、没落下（可视终态）；③ 鼻血从械子下巴滴到机甲内壁/接口上（实感）。

## 节拍 4：戚凛怔住——这个"资产"在拼命护人、还放了她的人一条生路；文书官低声那句，被她厉声打断（L3 / N2 / 裂缝·S5）

**① 站位/空间**：几百米外，戚凛的机甲舱内，光暗。她被弹开的同调反噬得单膝一沉，扶着操控台。右眼单片镜刻度光剧烈闪烁。身旁一个清源文书官，盯着面前的监控屏——屏上正是那台被夺机甲横着撑路、谁也没杀的画面。

**② 动作链**
1. 戚凛被从机甲里弹开的同调反噬，单膝一沉，一只手撑住操控台。单片镜刻度光乱跳。
2. 她死死盯着监控里那台被夺走的机甲，盯着硝烟里那个撑着一条生路、却谁也没杀的半机械身影。
3. 她"感"里还残着刚才那股同调的味道：不走标准接口，是裸同调，野、乱、没章法，却硬得没上限。她心里给它归档：逃逸实验体，裸同调异常，危险级上调。（MX1维持：她只把这当违禁实验体的异常，不往晶核真相那一层想）
4. 文书官盯着屏，声音发飘，几乎是自言自语，说出那句话。
5. 戚凛厉声打断他。
6. 可她握着操控杆的手，没有立刻下达下一道清剿令。（动摇全落在这个"手没动"上，不写进内心）

**③ 对话**：
- 文书官（发飘、像自言自语）："中尉……它在护着那些人。它……刚才明明能杀我们的。它会痛，会不会……其实" ——潜台词：他第一次把"它"往"人"上想，话没敢说完。（S5埋点；表面功能=下属一句多嘴，正文要先把"多嘴"写像，别写成专门安排的伏笔）
- 戚凛："闭嘴。" ——潜台词：她自己也被那句话戳到了，越被戳到越要用规矩把它压回去，不许人替她把后半句说出口。

**④ 内心微动**（N2，职业化，不反思"他是不是人"）：顶多一句她的判断口径——逃逸实验体、裸同调异常、上报重评。她的动摇不进内心，进"手没下令"那个动作。

**⑤ 感官锚点**：① 单片镜刻度光剧烈闪烁（可视）；② 监控屏里那台机甲横着撑路、脚边士兵还在地上爬（活口，可视终态）；③ 她按在操控杆上、没动的那只手（可视终态，不写"她犹豫了"）。

## 节拍 5：老秦独臂驾着老旧杂牌残机断后，被特勤火力重创、机甲被打穿（L3 / N3 / 惨烈·痛）

**① 站位/空间**：清出的那条路上出了岔子。一台被械子策反的无人机撞塌了泊位一根支架，支架崩断、往下砸，底下还有三四个没撤完的黑户。械子在路口撑着特勤机甲，所有同调都咬在上头，分不出神。老秦已不在原地——他早前趁乱退回拆船厂那一侧，爬进了那台没人要的、缺件的杂牌残机。

**② 动作链**（★第二处最吃"演得实"的地方，不许缩成"老秦冲上去挡住又被打倒"）
1. 一台策反的无人机失控撞上泊位支架，支架"咔"地崩断，整根往下砸。底下三四个黑户还没跑出去。
2. 械子想分神去够那根支架、那台无人机——可他所有同调都咬在特勤机甲上，一松，炮口就回、路就断。他动不了。
3. 拆船厂那一侧，一道身影冲出来：老秦那台老旧杂牌残机，就是没人要的、缺件的那台，关节异响、涂装剥落，歪歪扭扭地冲过来。
4. 老机甲把一条机械臂顶上去，硬生生接住塌下来的支架，用机身替那几个黑户顶出一道缝。黑户从缝底下钻过去，逃上路。
5. 老机甲太旧了。它顶住了支架，两条机械足陷在铁地里、动不了，却挡不住戚凛那边缓过神来的特勤火力。
6. 一发重炮，正中老秦那台机甲的胸口驾驶舱。
7. 装甲被打穿，火光从驾驶舱的缝里喷出来。老机甲歪倒下去，砸在铁地上，冒着黑烟。

**③ 对话**：无。惨烈处沉默留白。械子的一声"老秦"留到节拍6（或压根不喊，只在心里）。

**④ 内心微动**（N3，但极短，靠身体外化）：械子的急和痛，全落在"他动不了"这个身体状态上——所有力量咬在机甲上，眼看着救不了。不写长段悲。

**⑤ 感官锚点**：① 支架崩断、往下砸的金属爆响（听觉）；② 重炮正中驾驶舱、火光从缝里喷出来（可视终态）；③ 老机甲歪倒砸地、冒黑烟（可视）。

## 节拍 6：钩子——路已通向泊位，老秦却倒在火线里，冲械子吼"上船"（L2→L3 / N3 / 揪心·引爆前奏）

**① 站位/空间**：老机甲歪倒、冒烟处。驾驶舱盖被从里头顶开一条缝。老秦半个身子挂在外头，独臂死死抓着舱沿，满脸是血。械子在路口，还咬着那台特勤机甲、动弹不得。B7泊位那条路已经通了，耗子和黑户正往船那头去。

**② 动作链**
1. 老机甲的驾驶舱盖，从里头被艰难地顶开一条缝。
2. 老秦半个身子挂出来，独臂死死抓着舱沿，满脸是血。
3. 他没有喊疼。他偏过头，找到还咬着那台特勤机甲、动弹不得的械子那个方向。
4. 用尽全身力气，冲械子吼了两个字。

**③ 对话**：
- 老秦（用尽全力吼）："上船！！" ——潜台词：别管我，快走，这条路是我给你的。（钩子，直接接第8章老秦最后的话与牺牲）

**④ 内心微动**（N3，只落在动作上）：不总结、不抒情。落在老秦独臂抓舱沿这一个动作，和械子还咬着机甲动不了的状态上。

**⑤ 感官锚点**：① 驾驶舱盖顶开的那条缝（可视）；② 老秦独臂抓舱沿、满脸血（可视终态）；③ "上船！！"两个字的吼声（听觉）。
