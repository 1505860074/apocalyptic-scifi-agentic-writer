# 场面调度卡 · 第6章「墙角」

> 焦点卡校验通过后、正文生成之前的施工图。管"焦点卡每一拍在物理空间里一步步怎么演"。
> 五栏：①站位/空间 ②动作链（不跳步）③对话交锋 ④内心微动（N2/N3才重点填）⑤感官锚点。
> 本章焦点卡节拍全是 N3，但按细度旋钮：①②③拍是动作拍（压顶/惨烈/危急），内心靠生理动作外化、内心栏留轻；④⑤拍是内心拍（恐惧·挣扎/决意），内心填细；⑥拍是投放·钩子，慢镜头逐格、内心屏息（余韵留到第7章开）。
> **红线**：本章是 QS-04 蓄力拍（差一点抗拒、最终没有），**不是引爆**（引爆在第8章）。章末停在"主动伸手去够、幽蓝光暴涨"，手还没够上（第7章开头才撞上同调防火墙）。不写覆写成功、不写调转、不写戚凛反击、不写引爆。

## 本章底图（全章共用的空间，后续各拍只写"变了什么"）

- **锈港**：废弃军用中转站改的自由港。头顶一排老灯管，劣质、发昏、时明时暗。
- **停泊环**：环形泊位区，在锈港外缘。地是锈蚀的铁地，一踩闷响。散布泊位、支架（固定船体的金属立架）、排废口。清源从停泊环外侧（开阔的封锁圈那边）往里压。
- **拆船厂**：老秦的地盘，在停泊环内侧。厂门、料架、成堆待拆的机甲残骸。黑户往这边退。
- **残骸堆**：停泊环与拆船厂之间成山的废铁，唯一的掩体。
- **进攻方（清源）**：一台星联制式特勤机甲（装甲上"清源"二字）+ 十几架清源无人机（侧舷驱离弹口）。
- **防守方（黑户）**：几十个走不掉/不肯走的黑户，抄切割光弧、震荡棍、拆船用的液压钳。老秦拄义肢在人堆里指挥。
- **械子**：徒步，在混乱正中央（无机甲，本章不驾机甲）。左半身义体+外露同调接口，情绪/战斗时接口渗幽蓝。**能力此刻是 Lv.1 本能触发、不受控**——此前两次都是力量推着他，本章是"第一次主动去够"的前一秒。
- **耗子**：怯懦少年，缩在残骸堆后头，两手攥着那片导航芯片（第5章塞给械子、又是他自己那份念想）。
- 光/声底噪：老灯管晃、硝烟、驱离弹的"啾"、重炮的闷雷、机械足落地震铁地。

## 节拍 1：通牒时限到，戚凛下令清场；清源无人机+一台特勤机甲碾进停泊环（L2 / N3 / 压顶·战火）

**① 站位/空间**：夜里最冷那一刻。停泊环外侧那圈红点（悬了两天的封锁无人机）原本静止，此刻同时压下高度。械子、老秦、几十个黑户在停泊环内侧到拆船厂之间，面朝外侧的开阔封锁线。

**② 动作链**：
1. 没有第二次广播。悬着的红点同时降高度，向内收拢一圈。
2. 领头的不再是无人机——一台特勤机甲从封锁线那侧落进停泊环，机械足砸下，把一整排泊位的支架压塌，铁地凹下去。
3. 它站直，装甲上"清源"二字冲着黑户这边。
4. 它抬起机械臂，往下一压（下令的手势）。
5. 十几架无人机跟着它的动作，一齐扑向拆船厂方向。
6. 黑户人群一乱，往后缩、又被前排堵住，挤成一团。

**③ 对话交锋**：无（这一拍不设对话，清源全程沉默执行，压迫感来自"不跟你废话"）。可给老秦一句短喝，招呼人退（"退！往残骸堆后头退！"——潜台词：别在开阔地送死，用废铁挡）。

**④ 内心微动**：轻。械子只做一个动作级判断：领头的换成机甲了，这次不是驱离，是清场。不展开抒情。

**⑤ 感官锚点**：机械足落地那一下、脚底铁地跟着震；装甲上"清源"二字在昏灯下泛冷；十几条红色扫描线一齐扫过人群。

## 节拍 2：老秦带留下的黑户用拆船厂的家伙硬顶，节节败退（L2 / N3 / 惨烈）

> ★ 本章加的"多轮交锋/合理波折"就在这一拍（见文末说明）：先一轮被冲散→老秦组织一次反扑、几个黑户合力放倒一架无人机（小胜、证明是在拼命不是待宰）→机甲重炮一炮把掩体连人轰塌（碾压式回答）→继续往拆船厂退。让"节节败退"是打出来的，不是一句话交代的。

**① 站位/空间**：承上。战线从停泊环外侧退向内侧的残骸堆。老秦在人堆中段，拄义肢。切割光弧的蓝白火线、无人机的红线在硝烟里交错。

**② 动作链**：
1. 第一排黑户举切割光弧、震荡棍迎上去。
2. 无人机侧舷的口张开，驱离弹成片扫下来，第一排大半栽倒（不是死，是被打翻、焦黑、爬不起来）。
3. 老秦拄义肢在人堆里嘶吼，用义肢往残骸堆方向劈，指挥活着的往废铁后头退。
4. 退到残骸堆后，老秦不甘心，招呼三四个黑户合围一架压得最低的无人机。
5. 一个黑户用液压钳死死夹住无人机一条起落臂，另两个抡切割光弧往它侧舷的接缝里割。
6. 火线割断那架无人机的一条推进，它一歪、栽下来，砸在铁地上冒烟——黑户里爆出一声短促的吼（唯一的一点胜）。
7. 特勤机甲侧过身，主炮口对准那堆刚放倒无人机的黑户所在的残骸堆。
8. 一发重炮轰过去，整座残骸堆连着后头没退开的两三个黑户，被掀成飞溅的碎铁和火。
9. 老秦被气浪掀得一个趔趄，义肢磕在地上撑住，继续吼着让剩下的人往拆船厂厂门退。

**③ 对话交锋**：老秦的指挥吼声（短、脏、带命令）："往后退！别跟它对轰！""夹住它！割接缝！"——潜台词：他知道这仗赢不了，只想尽量多拖回去几条命。不设完整对白，都是战场里被硝烟切碎的短句。

**④ 内心微动**：轻/不进械子内心（此拍主要外部战况）。若给一线，只落在械子眼里"那点小胜转眼被一炮抹平"的事实感，不抒情。

**⑤ 感官锚点**：驱离弹扫过的一排焦黑；液压钳夹住起落臂时金属的挤压尖响；那架无人机栽地冒的烟；重炮过后残骸堆炸开的碎铁扑面。

## 节拍 3：械子被卷进火线，身后是老秦、耗子和几个走不掉的黑户（L2 / N3 / 危急）

**① 站位/空间**：械子在残骸堆与拆船厂厂门之间的混乱正中。身后（拆船厂那侧）：老秦、抱成团的几个黑户、缩在一堆废铁后的耗子。身前（停泊环那侧）：碾过来的特勤机甲。

**② 动作链**：
1. 一个黑户被气浪掀翻，摔在械子脚边的开阔地上，爬不起来。
2. 械子俯身，双手抓住那人腋下，往后拖，拖进最近的残骸堆掩体。
3. 拖进去的一瞬他抬头。
4. 那台特勤机甲正一步一步碾过来，机械足每落一下，脚底铁地就震一下，震得掩体上的碎铁往下掉。
5. 械子的视线顺着机甲的主炮口看过去——炮口正对着老秦他们退守的那堆残骸。

**③ 对话交锋**：无（这一拍是察觉危险，沉默更紧）。

**④ 内心微动**：轻。械子只有一个念头级的确认：炮口对着老秦。不展开。

**⑤ 感官锚点**：被拖那人腋下衣料的湿冷/沉；机械足每落一下掩体上簌簌掉的碎铁；主炮口那个黑洞洞的圆，正对老秦的方向。

## 节拍 4：那股力量又涌上来——这一次械子怕了（老吴的死），下意识要把它压回去（QS-04）（L3 / N3 / 恐惧·挣扎）★内心拍

**① 站位/空间**：承上，械子半蹲在残骸堆掩体里，一手还搭在刚拖进来那人身上，脸朝着碾过来的机甲。

**② 动作链**（放缓、几笔带过，主体交给④）：
1. 那股东西顺着他半边身子的接口涌上来，比前两次都急。
2. 左臂接口"唰"地亮起幽蓝。
3. 械子的手猛地一缩（本能要把它按回去）。
4. 手缩到胸口的义体前，停住，攥成拳（差一点就把它压回那个他自己都不知道在哪的地方）。

**③ 对话交锋**：无（恐惧拍沉默）。

**④ 内心微动**（★填细，一步步）：
- 力量来时他先认出这感觉——就是这股汹涌、滚烫、不听招呼的东西。
- 认出的下一瞬，怕跟上来了：上一次它也是这么涌上来的。
- 老吴那双还睁着的眼睛。那束穿过他刚救下的人的光。
- 是这股力量杀了那个他想救的人。
- 于是他第一反应不是用它，是缩手：宁可什么都不做，也别再让它出去害人。
- （这一步是 QS-04 的核心：差一点又要抗拒这份力量。到"攥成拳、要压回去"为止，还没松开——转折留给下一拍。）

**⑤ 感官锚点**：力量顺接口涌上来时那股顶着接口的滚烫（触觉实感，不是"一种震颤"）；左臂幽蓝的光；缩手时指关节抵在胸口义体上的硬。

## 节拍 5：他回头看见身后的人，看见耗子攥着导航芯片发抖——他停住了那个"压回去"的动作（L3 / N3 / 决意萌芽·转）★内心拍

**① 站位/空间**：械子人朝前（机甲方向），头回转向后（拆船厂方向）。视线扫过：老秦在开阔处独臂张开挡在黑户身前、义肢在机甲阴影里显得很小；几个黑户抱成一团；耗子缩在残骸后。

**② 动作链**（放缓）：
1. 械子回头（因为他攥成拳、要压回去的那只手，先顿住了，人跟着回头）。
2. 视线落到老秦：独臂张开，横挡在那群黑户身前，那截义肢在机甲的阴影里小得可笑。
3. 移到抱成团的几个黑户。
4. 落到耗子：缩在残骸后，两手死死攥着那片导航芯片，攥得指节发白，隔着硝烟望过来，望着械子。
5. 械子那只要把力量压回去的手，停在半空。
6. 手指一寸一寸，重新张开（从拳到张开——决意从生理动作里长出来，不写"他明白了"）。

**③ 对话交锋**：无（这一拍靠眼神和手，不靠话）。

**④ 内心微动**（★填细，但短、贴动作）：
- 耗子那眼神里没有嫌他晦气，没有当他是货。
- 那是在等他。
- （不写"他终于懂了力量的意义"这种总结。决意就落在"手从拳到张开"这一个动作上。）

**⑤ 感官锚点**：老秦那截独臂义肢在机甲阴影里的小；耗子攥芯片攥得发白的指节；那双隔着硝烟望过来的眼。

## 节拍 6（钩子）：械子第一次不等力量自己来，而是主动伸手，去够那台碾过来的特勤机甲（L3 / N3 / 屏息·投放）★慢镜头逐格·内心屏息

**① 站位/空间**：承上。械子面朝碾过来的特勤机甲（炮口仍对着老秦）。手已张开。

**② 动作链**（慢镜头逐格，一格一格）：
1. 械子不再等那股力量自己去扑向什么（前两次都是被动）。
2. 他盯住那台碾过来的、正把炮口对准老秦的特勤机甲。
3. 抬起左臂，把张开的手朝机甲伸出去。
4. 朝着那台庞然大物冰冷的回路，主动够过去（裸同调：隔着距离、隔着装甲去够对方系统）。
5. 幽蓝的光顺着他的手臂，暴涨成一道刺目的弧。
6. **停在这里**（手还没够上；够上撞墙是第7章开头）。

**③ 对话交锋**：无。

**④ 内心微动**：屏息、空（投放拍不进内心，把余韵留给第7章）。至多一句最短的定性：这一次是他去够它，不是它来找他。

**⑤ 感官锚点**：机甲冰冷的回路（他要够的那个目标）；幽蓝暴涨成弧的刺目；手臂伸出去时义体关节的绷紧。

## 给正文生成的提示

- **最吃"演得实"、最不能糊的两拍**：
  1. **节拍 2**（老秦带黑户硬顶、节节败退）——这一拍撑起本章大半篇幅的动作密度，多轮交锋（冲散→合力放倒一架无人机的小胜→重炮把掩体连人轰塌）必须一步步打出来，不许缩成"黑户拿废铁挡不住清源"一句。液压钳夹起落臂、切割光弧割接缝、无人机栽地、重炮回答——每一步都要有空间和先后。
  2. **节拍 6**（主动伸手）——本章钩子、L3 投放，慢镜头逐格：盯住机甲→抬臂→伸手→够过去→光暴涨，一格一格演，别一句带过。停在光暴涨、手未够上。
- **节拍 4、5 是内心拍**：恐惧和决意都要从生理动作里长（手缩成拳/手从拳一寸寸张开），不许写"他终于明白""力量的意义"这类总结。老吴闪回只给一两笔（睁着的眼、那束穿过救下的人的光），不铺陈。
- **禁**：写覆写成功、同调防火墙、戚凛反击、机甲调转、引爆——那些全是第7、8章的事。本章到"手伸出去、光暴涨"为止。
- 全程禁破折号；描写只挂在上面⑤的感官锚点和②的具体动作上；对话都是战场里被硝烟切碎的短句，不设长对白。
