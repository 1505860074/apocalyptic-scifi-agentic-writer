# 场面调度卡 · 第9章「浮渊」

> 依据：焦点卡-第9章（4 拍 + L/N/情绪温度）。本卡只做物理调度（站位/动作链/对话/内心/感官），不写文采。正文照此演。
> 空间锚点：破舰驾驶舱 → 舷梯/舱口 → 浮渊腹地钩爷的料堆。全程零破折号。

---

## 节拍 1：破舰漂到浮渊外围，晶核告罄、引擎将熄；耗子把船靠稳（成长小步）；浮渊全景（L1-2 / N2 / 困顿·压抑）

**① 站位/空间**
- 破舰驾驶舱：耗子在主控台/舵位，械子站他侧后方半步。晶核舱读数屏在视野里（格子一格一格往下掉，最后一格闪红）。
- 舷窗外：浮渊＝一整座战前废弃采矿平台，泊满各式凑合能动的破船；舱壁焊满后来人加盖的居住格，层层叠叠。平台腹地晶核黑市的灯忽明忽暗。四周是熄了灯的死地，黑暗里就这一片还亮。
- 声底噪：引擎声从轰鸣变成一顿一顿、快断的喘。

**② 动作链**（docking under power loss，一步步顶正靠稳，别缩成"靠稳了"）
1. 引擎声一顿一顿，晶核读数掉到最后一格，开始闪红。
2. 耗子盯读数，手在配比阀上切（连切三次），把那点残晶匀着烧 → 引擎又续上一口气。
3. 船头对不准泊位、偏了；耗子推姿态推进器，一点点把船头顶正。
4. 距离近了、速度还偏快 → 耗子反推一下，船头一沉，贴向泊位。
5. 舰腹蹭上泊位边的金属，一声闷响，船身晃了晃，停稳。
6. 读数最后一格灭，引擎彻底熄。舱里静下来。
7. 耗子愣了一下，回头看械子，眼里有讨赏的意思。械子冲他点头。

**③ 对话**：极少（困顿·压抑，多留白）。耗子最多半句嘀咕（配比/靠上了）；械子无言或"稳"一个字。收税的马上就到，别在这拖对话。

**④ 内心微动**（N2，填细一步）
- 械子看耗子把带伤破舰喂着残晶顶进泊位 → 想到这半个月这孩子从只敢缩舱角、到现在能干这活 → 长得比谁都快（成长小步从械子眼里看出来，不旁白夸）。
- 械子扫浮渊：比想象的大、还要破；死地里唯一还亮的就这片黑市 → 一点点"总算有个能停脚的地方"压着的松，垫底是压抑（这地方也不是善地）。

**⑤ 感官锚点**：① 晶核读数最后一格闪红→灭（可视终态）；② 舰腹蹭泊位的那声闷响；③ 舷窗外黑市那片忽明忽暗的灯。

## 节拍 2：钩爷的人登船收过路税，一行几乎一无所有被拿捏；械子护人，此刻后遗损伤发作、咬牙瞒下（L2 / N3 / 憋·隐痛·QS-05）

**① 站位/空间**（承接：船已靠泊，舷梯放下）
- 舱口内侧：械子横身挡在舱口，身后十几个黑户挤在舱里。
- 舱口外/舷梯：四个收税的，穿杂七杂八动力甲，当头一个甩一截电棒；另两个已越过械子往舱里走、熟门熟路翻。
- 距离：头目在械子正对面一两步；翻东西的两个在舱内货堆边。

**② 动作链**（★憋+N3，动作拆细，把"痛发作却瞒下"演满）
1. 舷梯刚落，四个收税的上来。头目甩着电棒，懒洋洋报"浮渊的规矩，过路税"。
2. 身后两个直接往舱里走，翻货舱、扒黑户身上。
3. 械子往舱口一横，身体挡在头目和舱里的人中间，堵住往里的路。
4. 头目扫一眼械子半边发微光的义体，起了兴致，抬手要去掀/碰那义体看成色（把械子当货估）。
5. 头目的手快够到时，械子左半身接口深处扎下一阵痛：顺骨头往上蹿，灼烧、紊乱（自锈港把力用到底后就时不时回来，一次比一次凶）。
6. 械子左手几不可察抖一下 → 他把手背到身后、攥紧，咬后槽牙，把那口痛硬咽下去（正被人盯着看成色，更不能露）。
7. 械子把声音压平：“他不抵。” 平得头目愣一下。
8. 头目盯他两眼，没占到便宜，啐一口：“带他去见钩爷。”（掀义体没掀成，把人往上交）

**③ 对话+潜台词**
- 头目“浮渊的规矩。过路税。晶核、能动的机件、值钱的人，挑着抵。”→ 例行盘剥、居高临下、你们没得挑。
- 头目“哟，这还是个改造货。这个值钱。”→ 把械子当货估价（物化他）。
- 械子“他不抵。”（压平的短句）→ 划线：我不是货；也是护自己别被当筹码、别暴露身体。
- 头目啐“带他去见钩爷。”→ 拿不定/懒得跟他掰扯，上交钩爷定夺（把立威权让上去）。

**④ 内心微动**（N3，两条线各一步步）
- 痛怎么涨：先接口深处一点扎 → 顺骨头往上蹿、灼烧 → 左手不受控抖。
- 决定瞒的一步步：这船人已经够难了 → 他这身子要再被看出毛病、被当会失控的危险品 → 他们连浮渊都待不下去 → 所以背手、攥紧、咽下，脸上一丝不露。

**⑤ 感官锚点**：① 接口深处顺骨头往上蹿的灼痛（体感落地：那几个外露接口里像哪根线烧着了；这是械子——一个靠"感机器"活的人——真会有的联想，钉在实感上，不作者腔）；② 后槽牙咬着的那一下；③ 背在身后攥紧的指节。

## 节拍 3：见钩爷，货钩义肢开合估价，灰色军阀拿捏 + 底线微露；械子被逼下抵押/接活计（L2 / N2 / 灰色博弈）

**① 站位/空间**（换到浮渊腹地）
- 钩爷坐在一堆缴上来的机件（料堆）中间，五十上下，粗壮，右手一副能开合的金属货钩义肢。
- 械子一行被押到料堆前站定；收税头目在侧。
- 料堆阴影里：一个女人靠着（后面的桑），一直没作声、冷眼看，嘴里嚼着片苦叶（beat4 埋点，此拍只在场、静默）。
- 光：黑市的灯忽明忽暗，机件堆金属反光。

**② 动作链**（放缓，博弈为主体；多轮交锋撑篇幅）
1. 械子一行被带到料堆前站定。
2. 钩爷没抬头，货钩先动，一开一合，对着这一行人（无形地掂量值几个晶核）。
3. 钩爷把一枚成色好的碎晶在钩尖上转圈，慢腔开口（锈港来的……）。
4. 抬眼，目光在械子义体上停一停，又移开。
5. 说规矩：进浮渊得添东西，白吃饭的养不起；船破成这样，晶核别想赊；想留下，拿手艺换、拿力气换。
6. 货钩又一开一合，钩尖指向械子：“拿那身‘手艺’换。”
7. 【波折】耗子急了，往前半步，脱口“他能……” → 械子侧头一个眼神/一只手按住耗子肩，把话截住 → 耗子把后半句咽回去。
8. 钩爷把碎晶弹回料堆，底线微露：“什么都能卖，就别卖我的规矩。”
9. 钩爷落条件：船押在泊位当抵，人留下，拿手艺力气换晶核换口粮，想走先清账。
10. 械子没得反驳，一个动作认下（或钩爷把沉默当成交，抬手让人给船挂标记/收了芯片）。

**③ 对话+潜台词**（本拍核心）
- 钩爷“锈港来的。锈港上个月熄了灯，星联的清源亲自动的手。你们能从那儿爬出来，不简单。”→ 我知道你们底细、你们无处可去（拿捏）；也带一分真的估量。
- 钩爷“在浮渊，什么都能卖。就是别卖我的规矩。”→ 底线微露：我盘剥有度、有条不碰的线（非纯恶的伏笔，但此刻读者只当他立威，别旁白点破）。
- 钩爷“进了浮渊，就得给浮渊添东西……晶核是别想赊的。想留下，拿手艺换，拿力气换。”→ 逼迫、你没得选。
- 钩爷“拿那身‘手艺’换。你那种改造货能干的活，浮渊多得是。”→ 试探械子的能力：我看出你不一般、你值这个价。
- 耗子（急）“他能……” / 械子（低）压住 → 耗子想拿械子的能力当筹码换活路；械子不许（不暴露、不当工具，且他现在根本使不出）。
- 械子几乎不接话 → 认了这被拿捏的局。

**④ 内心微动**（N2，比 beat2 轻，一步步）
- 械子听“那身手艺” → 知道钩爷指的是什么 → 也知道自己现在连一次都不敢用（承接 QS-05：用一次啃自己一次）→ 所以这筹码亮不得，亮了就是把自己卖成钩爷手里一件会失控的工具，何况他根本使不出来。

**⑤ 感官锚点**：① 货钩一开一合（金属开合的动作/那点声）；② 碎晶在钩尖上转的那个圈；③ 钩尖指过来时指向自己的那一下。

## 节拍 4（钩子）：械子后遗损伤加重、险些当众栽倒，被嚼苦叶的冷面军医（桑）瞥见，撂下“你这身子，撑不过三天”（L2 / N2 / 不祥）

**① 站位/空间**（承接：还在钩爷料堆前，交易刚定）
- 械子站着，正要转身带人走。附近一面金属墙（撑手用）。
- 料堆阴影里的女人（桑）此刻从静默里动起来。

**② 动作链**（近身崩溃 + 钩子，逐动作）
1. 交易定下，械子转身/正要带人走。
2. 那口一直咽着的痛猛翻上来，比方才凶得多（加重）。
3. 械子眼前一花，身子晃了一下，一只手不受控地按向最近的金属墙。
4. 险些栽下去：左手死死撑住墙，半跪的姿势没跪下去，义体接口渗出乱光。
5. 料堆阴影里，桑把嘴里嚼的苦叶吐掉（她一直在看）。
6. 桑开口（冷、糙）：劝钩爷别指望他干活。
7. 桑瞥着械子那只死撑墙、还发着乱光的左手。
8. 桑撂下最后一句：“他这身子，撑不过三天。”（章末钩子，收在这一句）

**③ 对话+潜台词**
- 桑“钩爷，你留不留他是你的事。不过我劝你别指望他干活了。”→ 表面：凉薄、只陈述事实、跟我无关；底层（此章只藏、不露）：她看得出他这身子不对（专业眼光）。
- 桑“他这身子，撑不过三天。”→ 表面：一句判死刑的冷话；顺带藏一点（她盯的是那只发乱光的左手，看得比别人细）。**S6（她认得这构造）留到第10章揭，本章只写表面的冷面军医断言，别提前露她懂实验体。**

**④ 内心微动**（N2，轻；投放拍，情绪主要靠身体外化）
- 械子最怕的事（身子被当众看穿、被当会失控的危险品）正在发生 → 一下僵/慌，撑着墙没敢动。别展开成大段独白。

**⑤ 感官锚点**：① 痛猛翻上来那一下（体感）；② 手按上去的金属墙冰凉；③ 桑吐在地上的那片苦叶；④ 械子左手接口渗的乱光。
