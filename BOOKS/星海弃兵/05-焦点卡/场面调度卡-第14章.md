## 空间底图（本章通用，先钉死一次）

- **浮渊**：一整座废弃采矿platform，几公里长。结构从外到内：**外缘泊环**（泊各式破船、舱壁焊满层叠居住格）→ 连接各段的**舱桥/通道** → **腹地**（晶核黑市、钩爷料堆、桑医铺，还亮着灯的活结点）→ **内层还完好的大船泊位**。
- 崩解顺序：异族造物先削外缘 → platform整体倾斜 → 结构一段段断裂、脱离主体、飘向星海。
- 械子本章起点：ch13结尾戚凛把他带到的**内层一间无人舱室**（屏退左右、审他到一半警报炸响）。他戴着戚凛的枷（清源制式，反同调，他自己够不开）。
- 本章路线：无人舱室（脱困）→ 一条直通腹地的通道塌了 → 被迫改走一段**断裂舱桥**（撞见异族造物）→ 桥另一头的一段舱室（他那船人被困在这里，正脱离主体下沉）。

## 节拍 1：异族袭外缘，platform开始解体，交火溃逃，浮渊大乱、流民黑户被困（L2-3 / N3 / 末日混乱）

**② 动作链**：
1. 探测阵列长鸣不停（接ch13）；顶灯从狂闪抽成频闪，暗一下亮一下。
2. 舷窗外第一下巨响：异族造物贴近外壳，一道切割强光顺着外壳犁过去，外缘一整圈泊环连船带焊死的居住格被削掉、卷进黑里。械子隔窗看见那圈灯（居住格的灯）成排地灭、碎、被吸走。
3. platform发出金属被生生撕开的长鸣（结构级、几公里长）；地板一侧猛地抬高，械子被枷拽着往低处滑、拿肩膀撑住舱壁。
4. 戚凛单片镜的刻度光一格格刷过监控数据；她频道里进来一串呼叫（清源要她归建/她那艘舰要撤）。她转身看向械子（引出节拍2的抉择）。

**④ 内心**：近空。只给一个闪念、且挂在动作上：械子的头先偏向舱门（他那一船人在外头）。不写成"他担心他们"的总结句。

**⑤ 感官锚点**：(a) 外缘泊环那排居住格的灯成排灭掉、连船带格被光犁走、卷进黑；(b) 金属被撕开的、几公里长的长鸣；(c) 脚下地板一寸寸抬起、他被枷拽着往下滑、肩膀磕上舱壁。

## 节拍 2：戚凛被战况牵制（走，留他戴枷·默许的种子）＋ 桑与耗子冒险冲进来找他（桑越线）（L2 / N3 / 紧·暖）

> 焦点卡node2＝"戚凛被战况牵制＋桑耗子冲进来"。拆成 2a戚凛离场（**这一拍是重排新增/续接ch13的交锋**，见文末说明）＋ 2b桑到。桑越线靠"冲进来"这个动作，不靠内心独白（焦点卡去AI味要求）。

### 2a · 戚凛离场（她本可带走/处置他，没有）

**① 站位**：同上舱室，倾斜加剧。戚凛在舱门内侧，单片镜接着频道。械子在低处、双腕戴枷。

**② 动作链**：
1. 频道催第二遍（撤离令/她那舰要跃走）。戚凛低头看械子腕上那副枷，又看他脸。
2. 抉择那一下：她接管他本是为查证（ch13"唯一活着的证人"），可这会儿她没法拖着一个囚犯穿过正在塌的platform；也没有当场处置他。
3. 她没开枷、没拖他、没报编号（她开火/处置前必报目标编号的习惯，这一次没报，留白，动作即默许）。她伸手把单片镜的刻度冷光关掉（callback ch13那次她关刻度光＝不再把他当"待回收资产"看的手势）。
4. 撂一句条例壳的话，转身出舱门。门在歪掉的门框里合上、卡住。
5. 械子被单独留在倾斜的舱室里、双腕还戴着枷。他试着用裸同调够那副枷的锁扣，枷是清源反同调制式，够上去像撞在一堵没有回应的死墙上，接口一阵头痛被弹回来。他开不了。（抬高桑的必要性。）

**③ 对话**：戚凛一句，条例壳、底下是默许，例：她报的不是编号，是一行她待会儿要正式补进记录的话，"违禁实验体，浮渊事变……脱离监管权限。"说完就走。潜台词：她在给"没带走他"提前铺一个说得过去的理由（接ch15她假报"确认损毁"）。别把潜台词写破。

**④ 内心**：N3、极短。械子做好了她重念"你是待回收资产"、或把他一起拖走的准备（callback ch13他等的那句）。她没有。他没懂她为什么。给一个"没懂"的闪念即可，不分析。

**⑤ 感官锚点**：(a) 单片镜那格刻度冷光灭下去；(b) 舱门在歪门框里合上的闷响、然后卡死；(c) 枷冰凉、勒着腕骨，他随倾斜往下滑时枷链绷紧。

### 2b · 桑与耗子冲进来

**① 站位**：械子单独在倾斜舱室、戴枷。卡死的舱门是障碍。门外通道里是桑和耗子。

**② 动作链**：
1. 门外撞击声＋人声。械子听见桑的骂声/耗子的喊从门缝挤进来。
2. 撬门：耗子把一截断管/撬棍塞进门缝，桑搭手一起撬；歪掉的门框死咬着门（波折：撬一下不动，卸力，换个角度，再来第二下第三下）。
3. 门在歪框里只让开半人高的缝、卡住不动了。两人侧身挤进来。
4. 械子看清他们的样子：桑左手那片旧烫疤上添了道新口子、正渗血、喘得厉害；耗子半个吓懵、手里还攥着那截撬门的断管。
5. （越线不明说，靠状态外化：她本可带着耗子上任何一艘还能跑的船逃，她逆着往外溃逃的人潮、把手都磨破了，冲进了最乱的这里。）

**③ 对话**：桑，冷糙骂人壳、底下是在乎（保留原正文那两句好台词、可微调）："你他妈还愣着？""我说过我只管修，没说过管埋。"潜台词：她回来救他，却把这事框成"你欠我的/交易"，不肯认自己心软。耗子急，一两个字。

**④ 内心**：N3的"暖"，但克制。械子只落在一个具体上：她冲进最乱的地方、把手磨破了、来找他。给一下就够，不铺排感慨。

**⑤ 感官锚点**：(a) 门在歪框里刮出的尖利金属声＋只让开半人高的那道缝；(b) 桑左手烫疤上那道新口子在渗血；(c) 耗子手里攥着的那截撬门的断管。

## 节拍 3：脱困（桑开枷）＋ 冲去找一船人（L1-2 / N2 / 转）

**① 站位**：三人在倾斜舱室。桑就着械子的手腕干活。

**② 动作链**：
1. 桑一把扯过械子腕上的枷，从身上摸出探针（她医铺那套调律工具）。
2. 探针捅进锁扣。她手稳得反常（老本行）。波折：清源枷不是标准锁扣，第一下没对上、她低声骂一句、换个角度，第二下才"咔"地弹开。（动作分解，不写成一下就开。）
3. 枷弹开、掉在抬起的地板上滑走。械子活动被勒麻的手腕、腕上一圈红痕。
4. 出舱：从卡死的门缝挤出去，到通道。耗子指原路（通腹地那条），那头已经塌下来、堵死（波折：直路断了，逼出节拍4的绕行）。
5. 械子问他那船人。耗子报：钩爷在腹地嘶着嗓子指挥人往内层大船撤，但那家流民、那半船黑户被冲散、困在外圈一段舱室里（setup节拍5）。械子当即决定：绕过去找他们。

**③ 对话**：桑开枷时糙话催一句。耗子报人的位置，不是干巴巴的信息播报，是吓坏了在带哭腔求救那种。桑撂一句（保留原正文，潜台词是关心装成讨债）："去找你那船人，别死在这儿欠我医药费。"

**④ 内心**：N2、短。一船人是他往外冲的唯一驱动，一句带过。

**⑤ 感官锚点**：(a) 探针捅进锁扣、第二下才响的那声"咔"；(b) 枷弹开后腕上一圈红勒痕、手发麻；(c) 通道原路那头塌下来的舱壁、堵得严严实实。

## 节拍 4：异族造物共鸣，身世伏线 S7（L3 / N3 / 惊悚·悬疑）★本章最吃"演得实"的一拍

> 高潮·揭示型（旋钮）：动作慢镜头逐格、投放共鸣时零内心、余韵再开内心。**⑤感官是本章防悬浮的重灾区**：碎片涌入必须写成他接口/身体真正读到的实感＋钉死终态，禁伪具体比喻（禁"像谁在很远的地方敲还没断干净的电路"这类角色不会有的作者腔联想）。表面＝实验体对异族科技的剧烈排异/敏感；本体（编码照着他身体的规格写、它认得他）藏进"他每一处接口都能对上那段编码"这个细节里，不点破。

**① 站位/空间**：一段断裂舱桥（连着两段platform，桥面已裂、一侧翘起、桥下是裂开的缝和星海的黑）。械子上桥往另一头去（腹地/找人方向）。桥另一头三四步处，一台异族的造物半嵌在扭曲的platform残骸里。应急灯频闪。造物的钉死特征：见⑤（给一个确定视觉，不用"陌生得违背直觉"糊）。

**② 动作链**：
1. 械子踏上翘起的断桥，手扶桥沿、往另一头挪（要过桥去找人）。
2. 挪到离那台造物约三四步。他没打算去够它，他甚至看不出那是台什么、哪儿是它的接口。
3. 不是他去够它。是它顺着他左半边那些外露接口，主动挤进来。
4. 械子整个人僵在桥上（身体先于脑子停住）。左半身接口对着那台造物剧烈起来、幽蓝暴涨。
5. 一段碎片顺着这股共鸣灌进来。比锈港那次强、也陌生：全是冷编码，一层压一层，望不到头。**怪象（S7本体，藏）**：那些编码是照着他这具身子的规格写的，密密麻麻里，每一段他都能对上自己身上一处接口，像它涌进来找的，就是他这样一具身体。里头没有一丝人味。
6. 余韵起：械子踉跄后退一步、脚跟磕在翘起的桥棱上；他一把在心里掐断那股共鸣（主动切断的动作）。冷汗一下浸透后背。
7. （余韵内心N3开）：那台从没见过的东西，为什么认得他的身体。他是被谁、用什么造出来的。这念头比脚下正在垮的platform更让他心慌。**不解说、不点破、不给答案。**
8. 他把这股寒意死死压下去，继续过桥（platform在崩，停不得）。

**③ 对话**：无（独自、惊悚、沉默）。若桑/耗子落在桥后喊他一声，他只从牙缝挤一个字"走"，不解释方才发生了什么。

**④ 内心**：共鸣投放时ZERO（纯感官灌入）。仅余韵开N3（上第7步的两句dread，具体、短、不点破真相）。

**⑤ 感官锚点**：(a) 那台异族造物，一整块光溜的东西、他找不到一条焊缝、一个他认得的接口或型号，可他左半身的接口偏偏够上了它；(b) 碎片涌入的实感，顺着接口/骨头灌进来的冷、密密麻麻的编码、每一段都能对上他身上一处接口（钉死：编码照着他身体的规格写）；(c) 冷汗一下浸透后背、脚跟磕在翘起的桥棱上。

## 节拍 5：钩子，一船人被困在脱离下沉的一段、逃生通道封死；只有他能救、救＝付代价；用一次少一次；引爆前屏息（L3 / N3 / 临界）

> 临界拍：动作慢、沉默重。桑的"用一次少一次"是ch10那句在耳里回响，不是这里新说的对话。章末收在"械子轻轻抽回被桑攥着的手"，直接续ch15开头"械子这一次，没有犹豫。他把两只手都按在了裂开的舱壁上"。代价（义体烧毁/濒昏）落在ch15，不在本章兑现。

**① 站位/空间**：械子（耗子随到）过桥到另一段，找到他那船人。这段舱室已经和主结构断开、连接舱桥塌了，唯一逃生通道被垮下来的一堵舱壁死死封住。整段舱室正缓缓脱离platform、往下沉、飘向星海和那片黑。械子在裂开的缝这一侧，隔缝能看见里头：那家流民、那半船从锈港跟来的黑户、几十个没撤走的浮渊人。桑随后追上来。

**② 动作链**：
1. 械子（耗子在前）冲到裂缝前。缝那头那段舱室正一寸寸往下脱、缝一点点变宽。
2. 隔缝看见里头人：发烧的孩子在他母亲怀里、那些从锈港一路活下来的熟脸、他们拍着舱壁喊。
3. 耗子冲上去徒手扒那堵封死通道的垮塌舱壁，纹丝不动（几吨的东西，人力完全无效）。械子也上手推了一把，一样死沉。人力这条路，堵死。
4. 械子看清：唯一能挪动那堵舱壁、能托住这整段正在下坠的舱室的，只有他那双手。可救这么多人、挪这么大一块东西，是引爆级，他得把自己烧掉一大截（用一次少一次，烧掉的长不回来）。
5. 械子低头看自己那只左手（他的标志动作）。接口开始渗出一线幽蓝（情绪外化，不受控）。
6. 桑追上来，一把攥住他左手腕、死死攥着、一个字不说。她那双一直不肯看人脸的眼睛，这会儿直直盯着他那只已经渗蓝的手。
7. 那眼神里没有阻止、也没有允许。只有ch10她说过的那句"用一次，少一次"，此刻响在两个人耳朵里。
8. 械子看着舱室里那些等着他的人，很久。
9. 他轻轻抽回被桑攥着的手。（章末钩子，续ch15。）

**③ 对话**：极少。耗子扒不动时的急喊/骂（沉默里唯一的声）。桑全程一字不说（她的沉默就是这一拍的分量，保留原正文的处理）。"用一次少一次"是耳里回声，不作对白写。

**④ 内心**：N3临界，但挂在动作上。械子的dread＝要烧掉自己多大一截、不敢想；护住这些人 vs 保住自己。别写成长独白，靠"低头看左手""抽回手"两个动作外化。

**⑤ 感官锚点**：(a) 隔缝看见发烧那孩子的脸、里头一双双拍着舱壁的手；(b) 耗子（和他）徒手扒垮塌舱壁、纹丝不动的那股死沉；(c) 桑攥他手腕的力道＋他左手接口渗出的那线幽蓝；(d) 那段舱室脱离主体的缝一寸寸变宽、里头人一点点飘远（钉死终态，不写成"眼看要坠了"）。
