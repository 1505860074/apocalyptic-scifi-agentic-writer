# 场面调度卡 · 第5章「交出去」

> 施工图。焦点卡定了每拍"发生什么事 + 读者该有什么感觉"；这张卡把每拍在物理空间里怎么一步步演排出来，交给正文照演。只做物理调度，不写文采。
> 本章 械子 全程 POV。械子能力此刻仍是本能/不受控（首次主动覆写在第7章），**本章不许出现覆写**，接口至多情绪性微渗幽蓝。
> 时间线：白天（节拍1撕裂）→ 通牒广播定"今夜最冷时到点"（节拍2）→ 夜里（节拍3-6）。接第6章"通牒时限卡在锈港的夜里最冷那刻到点"。

## 节拍 1：锈港内部撕裂（L2 / N3 / 撕裂·压抑）

**① 站位/空间**
- 白天。拆船厂门口那片空地，就是第1章卷帘门那道口子外头。卷帘门升到一半（半人高）。
- 老秦拄义肢横堵在半开的卷帘门口，背对厂里，脸朝人堆。
- 人堆二三十个黑户，散成一个半圆围在门口空地上；抱孩子的女人在半圆靠前、离老秦四五步；三瓣嘴在人堆边缘阴影里、不往中间站。
- 械子在人堆最外围、贴着一堆待拆残骸的死角，离老秦约十步，没人把他圈进半圆里。
- 头顶老灯管昏黄、时明时暗。停泊环外缘那圈红点（清源封锁）在远处悬着，隔着门口空地能望见几颗。
- 承接第4章：老吴昨天从排废口推出去了，人堆里的争吵是从昨夜压到今天的。

**② 动作链**（本拍主体：多轮口头交锋 + 一次差点动手的物理波折 → 老秦弹压）
1. 三瓣嘴先起头。他不进圈，缩在人堆边，漏风的嗓子从后头往中间怼，抛"值当吗"这种账。
2. 抱孩子的女人被顶上来，往前挪半步，冲老秦开口，声音发抖，把孩子往怀里紧了紧。她要的是"我娃活着"，不是"害械子"。
3. 老秦不退，义肢横着，拿"清源回收资产是什么下场我见过"顶回去。
4. 人堆里分出声音：几个附和女人的往前凑了半步；旁边一个满手油污的老拆工（跟老秦拆了多年船）扭头骂附和的人"你们信三瓣嘴的漏风话"。半圆肉眼可见裂成两拨。
5. 三瓣嘴趁乱把话头往械子身上引——"老吴就是他招来的"，一句点着,人堆里几张脸齐刷刷转向外围死角里的械子。
6. 靠前一个黑户（不是女人，是个红了眼的精壮汉子，家里也有人怕清源清场）没忍住，越过半圆朝械子走两步，一把攥住械子小臂，要往门口方向拽——"交出去不就完了"。
7. 老秦动作比嘴快。义肢金属臂横扫过来，"当"一声磕开那只手（磕在汉子手腕上，不是打脸，是拨开），把人逼退半步。老秦这才把嗓门压到最低、最狠地撂一句，全场静下来。
8. 静场。没人再上前。汉子攥过的地方还留着痛。人堆没散，也没人再动——港就这么明摆着裂成了两半，谁也说服不了谁。

**③ 对话交锋**
- 三瓣嘴："老秦，你拿全港几百口，给一个来路不明、还害死了老吴的实验体陪葬。值当吗？"｜潜台词：他不关心械子死活，他在给"交人"找一个听着仗义的账本，把责任摊给老秦。
- 抱孩子女人："清源说了，把那东西交出去，他们就撤。我娃还小……锈港这半熄的灯，经不起一场清场。"｜潜台词：不是恨械子，是一个母亲把命算到了骨头里；她自己也不敢看械子。
- 老秦："交？交出去他就是死。清源回收'资产'是什么下场，你们不知道，我知道。"｜潜台词：他拿自己见过的旧事压场，但不能明说来历（S3/S4已在ch4半揭，这里只露"我知道"）。
- 老拆工（帮老秦那半拨）："三瓣嘴一张漏风嘴，他卖过几回人了你们忘了？"｜潜台词：把"交人"这主意的出处钉在三瓣嘴身上，动摇它的正当性。
- 三瓣嘴："老吴的死,就是他招来的。"｜潜台词：不接反驳,直接换靶子,把港里对清源的怕转成对械子的恨——这是他最省力的煽法。
- 攥手汉子："交出去不就完了。"｜潜台词：不是坏,是怕到极点想抓根稻草。
- 老秦（磕开手后，压到最低那句）："谁再当着我的面，伸手抓我的人……"（话不说完，义肢金属指往门框上一叩，"当"一声）｜潜台词：不讲道理，只亮姿态和力气——这是"弹压"，不是说服。

**④ 内心微动**（N3，械子在外围看，一步步）
- 先是"这场争吵没人拉我进去，可句句都是我"——他被架在场外，像块被议价的货，不是参与的人。
- 再看那个抱孩子的女人眼里的怕：不是躲晦气那种怕（他被躲惯了），是一个母亲实打实、算得清清楚楚的怕。这种怕他反驳不了。
- 最后那只手攥上他小臂时，他没挣（他习惯不主动碰别人的手，也没料到别人会来抓他）；被老秦磕开后，他盯着那汉子退回去的背影，心里冒出来的不是委屈，是"她没说错"。念头就在这一拍扎下根——为后面他决定走做地基。

**⑤ 感官锚点**
- 抱孩子女人红着的眼、怀里往里缩的孩子。
- 攥住小臂那只手的力道 + 义肢金属臂磕开它的那声"当"。
- 门口空地望出去、停泊环外缘悬着的那几颗红点。

## 节拍 2：戚凛最后通牒（L1-2 / N2 / 冷·倒计时）

**① 站位/空间**
- 承接节拍1：人还没散，就在拆船厂门口空地。天色更暗了些（傍晚往夜里走）。
- 声音来源：锈港的公共频道（停泊环那圈旧喇叭），全港都听得见。
- 停泊环边那块还亮着的旧公告屏（平时滚播泊位费、拆解令），此刻被清源接管，跳出一行倒计时。
- 械子仍在外围死角。老秦仍横在门口。

**② 动作链**
1. 门口那圈旧喇叭先"滋啦"一声底噪炸开，人堆的争吵被这声压下去，所有人抬头。
2. 戚凛的声音进来。不是喊话，是照条例念，一字一顿、平得像在给一件货记账。她念清源的处置令：限本港今夜到点前交出违禁实验体，逾期按窝藏违禁资产、全港清场。
3. 念完条例，停泊环那块公告屏上的数字开始往下走（倒计时启动）。人堆里有人下意识去看屏，脸色变了。
4. 广播没马上断。戚凛顿了半秒，加了一句不在条例里的话，是冲老秦（报了他的旧序列号/第七军械序列），意思是"档案我看过了，上头只要结果"。
5. 说完广播才断，喇叭余下一串电流噪，停泊环公告屏上那行倒计时安静地往下跳。

**③ 对话交锋**（广播单向，交锋在"条例 vs 那一句off-script"）
- 戚凛（条例腔）："星联特勤清源组通告。按《同调管制条例》，本港窝藏违禁实验体一名。限今夜港区温控最低点前，交出该资产。逾期，本港列窝藏违禁资产处置，清场。"｜潜台词：把械子彻底非人化成"该资产"，好让所有人（也让她自己）扣得下这个扳机。
- 戚凛（顿半秒，off-script那句，声音比条例低一点）："秦河。第七军械序列的封存档案，我调过了。上头，只要结果。"｜潜台词：这一句是节拍2的核心——她试过用档案给械子争"待核"（ch4她说要调档案），试过了，没保下；她在告诉老秦"我尽过力了，别怪我"，也是她那套条例话术上的第一道裂缝（敌我暧昧）。写的时候不许把这层挑明，就让她冷冷丢下这句、广播就断。

**④ 内心微动**（N2，一句到两句，别展开）
- 械子听见"该资产""清场"，第一反应不是怕自己死，是往那个抱孩子女人和她怀里的孩子那边看了一眼——倒计时是给全港的，不是给他一个人的。这一眼把节拍1"她没说错"又压实一层。

**⑤ 感官锚点**
- 喇叭炸开的那声"滋啦"底噪。
- 停泊环公告屏上往下跳的倒计时数字。
- 戚凛报"第七军械序列"时，老秦脸上那一下（横着的义肢，指节收紧）。

## 节拍 3：械子决定不连累众人，趁夜自己走（L2 / N3 / 沉·两难）

**① 站位/空间**
- 夜里。拆船厂内，堆料间/料架那一片，只留一两盏值夜的老灯管，昏。
- 白天老秦硬塞给械子的那把机甲启动钥匙（拆船厂那台老旧杂牌机甲的），此刻在械子手里。料架靠墙，上头堆着待拆零件。
- 厂里静，能听见远处停泊环喇叭偶尔的电流余噪。老秦不在这屋（在别处）。

**② 动作链**
1. 械子站在料架前，手里捏着那把启动钥匙。他没揣走。
2. 他伸手，把钥匙轻轻放回料架原来那格（放回去＝他拒绝老秦要他"留下拼一场/开机甲跑"的安排）。放的时候手指在钥匙金属面上停了一下，没敲。
3. 他转身，摸黑往厂外走。不走卷帘门正口（那儿老秦盯着），贴着残骸堆的阴影往停泊环那边挪。
4. 一路上他把想清楚的那笔账在心里过一遍（见④）：他一个人走到封锁圈前，戚凛就没理由清场全港；一个"待回收资产"，回收了就是了。
5. 走到停泊环边沿的通道口，还没到泊位。

**③ 对话交锋**：无（独行、静默，别硬塞独白式对话）。

**④ 内心微动**（N3，两难，一步步）
- 起点是节拍1/2扎下的"她没说错"。他不是想通了要牺牲，是算账算到只剩这一条：留下，老秦得拿命顶，那女人和一港人得跟着他一起被清场；走，就他一个。
- 中间卡一下：他想到老秦白天塞钥匙时那副凶样（"你他妈给我留下"那种）。他把钥匙放回去，就是不接这份安排——这是他这辈子第一次替一群人做一个"我来担"的决定，别扭，也踏实。
- 落点：他没觉得自己高尚，就是觉得"至少那个抱孩子的女人，不用怕了"。走的脚步是轻的，不是悲壮的。

**⑤ 感官锚点**
- 启动钥匙放回料架那格的轻响 + 他手指在钥匙金属面停住、没敲。
- 残骸堆阴影里、贴着后背的金属冰凉（第1章同一个死角的触感callback）。

## 节拍 4：老秦拦下他（L2-3 / N3 / 硬·暖）★本章情绪高点

**① 站位/空间**
- 停泊环边沿的通道口。械子刚要往泊位走。
- 老秦从残骸堆的阴影里出来（已经等了不知多久），一截冰冷的义肢横过来，拦在械子胸前那片义体上。两人正面对着，隔一步。
- 头顶灯管昏。停泊环外那圈红点在两人身后远处悬着。

**② 动作链**（多轮：拦 → 械子要绕 → 再拦 → 推 → 塞钥匙 → 撂话）
1. 义肢横拦。老秦不知等了多久，靠在残骸堆阴影里，这会儿一截义肢横过来，正挡在械子胸口义体上。
2. 械子没回头（也没必要回头，他知道是谁），说"你都听见了，我走出去锈港就没事"。要侧身从义肢底下绕过去。
3. 老秦不讲道理，一个字"放屁"，义肢跟着械子的侧身移，继续横挡；械子绕左，他挡左。
4. 械子还要往前，老秦把那截义肢重重按在械子胸口的义体上，力气大得不像个断臂老头，硬生生把械子往回顶了一步。
5. 顶回来的同时，老秦另一只手（好的那只）从怀里掏出那把启动钥匙——就是械子刚放回料架那把（老秦发现钥匙被放回、跟出来时抓在手里），一把塞进械子手里，攥着他的手往回按，逼他攥住。
6. 械子想把钥匙再推回去，老秦攥得死紧不松。
7. 老秦借着这个攥着手的姿势，把那段"当年漏坐标/这条胳膊为什么断"的话，低声、发闷地说出来（见③）。说到最后一句，他松开手，退半步。
8. 械子攥着那把被硬塞回来的钥匙，说不出话。（节拍在此停在两人对峙、钥匙回到械子手里——为节拍5耗子出现让位。）

**③ 对话交锋**
- 械子："你都听见了。我走出去，锈港就没事。"｜潜台词：他已经算完账，语气是陈述不是求，反而更堵人。
- 老秦："放屁。"｜潜台词：他不接械子那套逻辑，越心软骂得越凶（人物卡）。
- 老秦（按住胸口义体、塞钥匙时）："当年我漏那个坐标的时候，就想过会有这么一天。有人会站在我面前，说'交出去，大家就都好了'。"｜潜台词：他把械子此刻这套"我走大家就好"的话，认成了当年那条"把人当耗材"的命令——他这辈子就为了不点头这句话，断的胳膊。
- 老秦（最后，松手退半步）："我这条胳膊，就是为了不说那句话断的。械子，我他妈拆了半辈子货……我不会再把一个活人，当货交出去。"｜潜台词：这是他第一次当面把械子从"货/资产"里摘出来、认成"活人"。别写成抒情，写成他别扭、发狠地往外撂。
- 钥匙的潜台词：塞钥匙＝"要走也开着机甲走，别空手去送死"＋"这是给你的，你是能开机甲的人，不是一件货"。

**④ 内心微动**（N3，本章暖峰，一步步）
- 械子先是被顶回来那一步，身体上的（老秦力气大得反常，他没想到断臂老头能顶住他）。
- 再是钥匙被硬塞进手心：他刚把它放回料架，现在它又回来了，还带着老秦掌心的温度——他一时没懂老秦要干嘛。
- 听到"不会再把一个活人当货交出去"，他懂了：老秦不是在留一个劳力，是认了他是个人。这句他等了很久（承接ch4他问"被造的东西还算不算人")，被造的东西、够格被这么护着吗——他没问出口，喉咙发紧，说不出话。别写"他很感动"，就写他攥钥匙的手、和说不出话。

**⑤ 感官锚点**
- 义肢横按在胸口义体上那股冰冷的分量（老秦那截自改义肢的金属触感）。
- 塞进手心那把启动钥匙，还带着老秦掌心的温度。
- 老秦声音在黑暗里发闷（不是清亮的，是从锈里抠出来的那种，ch4同款嗓子）。

## 节拍 5：耗子偷偷示好（L2 / N2 / 微暖）｜埋耗子线、E-03起点强化

**① 站位/空间**
- 承接节拍4：停泊环边沿，老秦刚退半步（老秦还在场，或正转身往厂里走——让位给耗子这个更小的影子）。
- 黑暗里，一道更小的影子从旁边残骸堆的缝里怯生生凑过来：耗子。他跟械子隔两三步，不敢近。
- 械子手里攥着那把启动钥匙。

**② 动作链**
1. 耗子凑过来，不敢看械子的眼睛，眼神往地上/往械子的义体接口那边瞟，又躲开。
2. 他飞快地把东西往械子手里（空着的那只手）塞——半块口粮 + 一小片刻着旧航道数据的导航芯片——塞完手立刻缩回去，像怕烫。
3. 塞的同时，他压着抖的嗓子，把B7泊位那条私道的事说出来（清源封锁没堵严实的那条缝，芯片里有）。话说得断断续续，但到底说完了。
4. 说完他转身要走。关键动作：他没像以前那样绕开械子（全港的人经过械子都绕，像绕一摊晦气，ch1立过）——这一回，他是从械子身边直直穿过去的。走之前极快地、几乎看不见地抬眼看了械子一下。
5. 影子钻回黑暗里没了。

**③ 对话交锋**
- 耗子（抖，断续）："停泊环……B7泊位那条私道，芯片里有。清源的封锁……没堵严实那条。你要是……要是真得走，别走正门。"｜潜台词：他崇拜械子（想学开船、想跟这个"能听懂机器"的人一伙）又怕他（怕他晦气、怕他那半边机器身子）；这块芯片是他偷学开船攒下的私货，掏出来＝把自己最宝贝的东西给了械子。他不敢明说"我信你不是害老吴的人"，就用一条活路替他说。

**④ 内心微动**（N2，一到两句）
