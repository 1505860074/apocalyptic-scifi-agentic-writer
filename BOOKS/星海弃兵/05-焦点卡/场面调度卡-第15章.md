# 场面调度卡 · 第15章「弃兵的船」

> 照焦点卡6拍逐拍展开五栏（①站位空间 ②动作链不跳步 ③对话潜台词 ④内心微动 ⑤感官锚点）。
> 本章全是 N2/N3（收尾章、情绪重），但节拍1是 QM-02 引爆投放拍：动作链慢镜头逐格、投放时内心几乎空、余韵那一下再开。
> **接章头**：第14章结尾械子刚从桑手里抽回被攥着的手（＝决意动手，不是退缩）。本章开场承接这个动作。
> **金手指硬约束（贯穿节拍1）**：万机通感只能同调「有系统的机械」，不能徒手挪一整块死结构。所以他挪不动坠落舱段本身，只能同调平台上现成的重机械（系泊绞盘/锚爪牵引缆、采矿平台留下的货运吊臂/绞车/轨道机）去咬、去拽、去撬。目标越大反噬越重，代价必须见血见伤，别写成无敌。
> **术语**：地点用中文「平台」（照第9章登场章，不用英文 platform）；同调/覆写/裸同调/接口/晶核/清源/自由港/争议星域照命名表。
> **加了波折（见节拍1）**：原正文引爆是"一发力→舱段停住→墙开缝→人逃出"一步到位。本卡把节拍1拆成六段阶梯（先够近处小机械只够拖住一半→再够重机械上撬门、代价开始见血→舱段猛沉的回挫、被迫同时撑两头、代价烧到最狠→最后几个人险些没钻出、他多撑三秒加倍烧自己），并让第14章埋的异族造物共鸣在他够宽时来拉他一把、被他强行挡开（S7背景重量，不揭示、接QM-03）。剧情结果不变（人全救出、他濒昏），密度和阻力上来。

## 节拍 1：械子主动同调，拖住坠落舱段、撬开逃生通道、护撤离；代价当场落实（悲壮·燃·QM-02引爆投放拍·N3）

**① 站位/空间**（承接第14章）
- 场地：正在沉没的浮渊平台腹地，一段已经和主结构断开的舱室（下称"断舱"），正缓缓下沉、往平台外壳的破口和外头那片黑漂。
- 断舱与主结构之间：塌了的舱桥（断的）；原来的逃生通道被一堵垮下来的舱壁死死封住，只裂着一道够看不够钻的缝。
- 械子：站在主结构这侧、封死通道的缝前，左半身接口已经在渗微光。桑：就在他侧后半步（刚被他抽回手）。耗子：在缝这侧，之前一直扒缝扒不开。断舱里：那家流民、半船黑户、几十个没撤的浮渊人，挤在缝那头往外看；发烧的孩子在他母亲怀里。
- 可同调的机械（他的抓手，钉死）：缝两侧泊位上的系泊绞盘＋锚爪＋牵引缆（原来拴船用的，有电机）；再远处采矿平台留下的一排货运吊臂、装卸绞车、矿料轨道机（重家伙）。远端舱桥另一头，第14章那台嵌进残骸的异族造物——冷、强、认得他的身体。
- 底噪：几公里长的金属倾斜呻吟、警报、外壳被切割光犁过的闷响。光：断续的应急红灯，一亮一灭。

**② 动作链**（★本章最吃"演得实"、最不能糊。逐格拆成六段阶梯，不许缩成"一发力就停住"）
1. 械子抽回手，转过身，不看桑，两只手按上封死通道的那堵冷舱壁。他把一直死死压着的那道闸，松开。左半身接口的蓝光顺着他这半边身子往外淌。
2. **第一段（够近处小机械·只够拖住一半）**：他先够最近的——缝两侧泊位的系泊绞盘和锚爪。绞盘电机被他一台台唤醒，尖啸着倒转，牵引缆绷直，锚爪咬住断舱边缘往回收。断舱下沉的势头被硬拽住，慢了。但断舱太沉，几台绞盘的电机就开始过载冒烟，锚爪在金属上打滑、崩开一只。光靠这些拴船的家伙，拉不住。
3. **第二段（够远处重机械·代价开始见血）**：他把够的范围往外推，够上采矿平台那排货运吊臂和绞车。这一下要接的系统又多又大，接口猛地过载。他闻到自己左半身神经束烧焦的味；渗出的蓝光烧成了惨白；第一根嵌在骨头里的合金接线烧断，剧痛顺半边身子炸开，口鼻里涌出血。他单膝跪下去，手没离开舱壁。吊臂群转过来，一半添到牵引上、拖住断舱，一半探向那堵封死的舱壁，液压钳咬住扭曲的门框，往两边撑。缝，从够看，被生生撑到够钻。
4. **第三段（异族造物来拉·被他强行挡开）**：他够得太宽，远端那台异族造物的系统撞进他接口——冷，没有一丝人味，像认得他，要把一整片解不开的编码往他脑子里灌。它比这里所有机械都强，够到它也许就够了。可那股寒意一漫上来，他"自己"就开始被冲淡。他咬着牙，把伸过去的那一缕同调硬生生掐断，把它挡在外头。这一挡，又烧掉他一截力气。（S7 背景重量，不点破）
5. **第四段（回挫·被迫同时撑两头，代价烧到最狠）**：外壳又被切割光犁中一记，断舱猛地往下一沉、往外一挣，绷紧的缆几乎要断。械子只能同时撑住两头：绞盘吊臂拽住下坠的断舱，液压钳撑住撬开的缝，一样都不能松。这已经远超他能扛的。更多接线接连烧断，惨白的光烧得他半边身子发抖，血顺着下巴往下滴，他从单膝跪变成双膝跪，额头几乎抵到冰凉的舱壁——没松手。
6. **第五段（护撤离·最后几个险些没钻出，他多撑三秒加倍烧）**：缝稳住够钻的宽度，耗子扒着缝，把断舱里的人一个一个往外拽。流民、黑户、浮渊人，从这道用械子的命撑开的缝里钻出来。最后是那对母子，孩子发着烧、腿软，卡在缝里挣了两下没过来。械子把已经在往回缩的那点力气，又往缝上压了三秒，缝多撑开一指。母亲连人带孩子被拽出来。
7. **第六段（力竭）**：最后一个人过来了。械子撑着的所有机械，绞盘、吊臂、锚爪，一台接一台熄下去。惨白的光从他身上退，比锈港那次凶狠百倍。他眼前一黑，双手从舱壁上滑下来，整个人往前栽。（栽进节拍2）

**③ 对话**（节拍1基本沉默留白，只留极短的）
- 耗子扒着缝喊撤离的人："走！快走！"（嗓子喊劈了。不是交代信息，是把动作喊出来）——潜台词：他现在只会做这一件事，替械子把人一个个接出来。
- 械子全程不说话（引爆投放拍，沉默是对的，别硬凑对话）。

**④ 内心微动**（投放拍：投放时几乎空，靠身体反应外化；只在第六段力竭那一下裂开半句余韵）
- 第1到第五段：空。他的恐惧、决心，全部走身体（渗光、烧焦味、跪、血、没松手），不进内心独白。
- 第六段栽倒前，可裂开极短一线（不超一句）：这一次他没有像锈港那样先怕，也没有像征收章那样把手缩回来——他只是没松。（＝焦点卡要的"这次没犹豫"对照，一笔带过，不总结成"他终于成为了英雄"）

**⑤ 感官锚点**（确定实体，禁伪具体比喻）
- 绞盘电机倒转的尖啸 + 牵引缆绷直的震颤；锚爪在金属上打滑、崩开一只的脆响。
- 接口渗出的蓝光烧成惨白；左半身神经束烧焦的气味；合金接线烧断的那一下剧痛 + 口鼻涌出的血、顺下巴滴。
- 异族造物撞进接口那股"冷"（没有人味的冷，钉在触觉/接口感上，不比喻成远处敲电路那种作者腔）。
- 他额头抵上去的、冰凉的舱壁。

## 节拍 2：械子力竭濒昏，桑冲上去用她的技术把他从过载里抢回来，越线加入（揪心·暖·N3）

**① 站位/空间**（承接：械子往前栽）
- 就在断舱缝前的主结构地面。械子往前栽，桑在他侧后半步，一把接住。周围是刚被拽出来、瘫作一团喘气的人，警报还在响，地板还在倾斜。

**② 动作链**（情感锚点拍：动作放缓，几笔到位，重点在她的手艺"这次真救了命"）
1. 桑接住栽倒的械子，半跪下去，把他焦黑的左半身翻过来朝上。
2. 她一眼扫过烧穿的接口、还在冒白烟的接线——脸色铁青。先把嘴里那片苦叶吐掉（她干活前的习惯动作）。
3. 手上开始快、准，没有一下多余：镇定剂、抑制针打下去；探针捅进烧穿的回路，一段一段封断，掐掉还在过载、还在往深处烧的那几路。她那身在星联练出来、又用来赎了半辈子罪的手艺，这一次全压在这半条命上。
4. 她的眼睛盯着他的接口和自己的手，不看他的脸（她一贯的习惯）——可这次骂出了声。
5. 械子这半边身子已经没知觉，意识在往下沉，最后还能听见的，是她这句骂。他往黑里沉下去。

**③ 对话**（有潜台词的交锋——嘴上最难听，底下是"给我活着"）
- 桑（咬着牙，声音发抖，一边下针一边骂）："你个蠢货……谁准你烧这么狠的……给我活着。"——潜台词：她越在乎越难听；"给我活着"是她整个人设里最软的一句，从牙缝里挤出来。（照人物卡：桑越在乎越难听、救人像还债）

**④ 内心微动**（N3，填细，但走械子将昏的一线意识，不写桑的内心独白——她的越线靠动作和那句骂外化）
- 械子沉下去前那一线：原来被一个人这样骂着、逼着活下去，也是一种被当成人的方式。（一句，落在"被当人"这个他核心欲望上，不铺排）

**⑤ 感官锚点**
- 她吐掉的那片苦叶。
- 探针捅进烧穿回路的触感/那点封断时的焦味。
- 她发抖的声音（对照她一贯的冷、糙）。

## 节拍 3：钩爷没跑，指挥浮渊的人上他压箱底的大船，自己留下断后，把"不让人被当耗材"的底线走到底（悲·敬·E-07·N3）

> 焦点卡去AI味note：钩爷牺牲靠一个动作/一句别扭的话收，不煽情长独白。POV 移到船坞口（钩爷这条线，械子已昏迷不在场）。

**① 站位/空间**
- 平台内层还完好的一处船坞口。钩爷压箱底的大船（他这辈子的本钱）停在坞里，舷梯放着。钩爷站在坞口，用那副能开合的金属货钩义肢。撤下来的人潮（黑户、浮渊流民、被救出来的那批）往舷梯涌。警报、坍塌的闷响一阵近过一阵。

**② 动作链**（动作为主，钩爷的选择靠"一件货都不往外划"这个对照动作落地）
1. 钩爷站在坞口，货钩一开一合，把一个又一个人钩上舷梯——动作还是他一贯清点货物那一套，稳、准、像在算账。
2. 只是这一次，他钩上来的每一件"货"都是一条命，一件都没往外划（对照他登场时"值钱的人挑着抵"——他现在一个都不抵、不卖）。
3. 他钩住那个还发着烧的孩子，连人带那床裹着的破被子，塞进他母亲怀里，一把推上舷梯。
4. 大船的舱门开始合拢。钩爷停在坞口，没跟着上船。
5. 他回头看了一眼正在崩塌的、他从流民一路杀上来挣下的整个浮渊。那副货钩，最后一次，一开，一合。
6. 然后他转身，迎着压下来的那片黑，走回去，替这艘满载着人的船断后。

**③ 对话**（潜台词——他把"活下去"当命令吼出来，不抒情）
- 钩爷（嗓门压过警报，一边钩人一边吼）："上船！都给我上船！"（推那对母子时）"浮渊养不起你们了。滚去别的地方，活下去！"——潜台词：他守了一辈子的浮渊守不住了，他能做的最后一件事，是把人从这口棺材里钩出去；"滚去活下去"是他这种人能说出的最深的一句托付。（照人物卡：他自己就是当年的流民、太懂被当耗材、这是他给自己留的最后体面）

**④ 内心微动**（N3 但焦点卡明令不长独白：留空，全靠动作。最多货钩最后一开一合那下带一丝，不写"他知道自己要死了"这种旁白总结）

**⑤ 感官锚点**
- 货钩义肢一开一合的咔哒声（贯穿他这一场，最后一次开合是收束）。
- 发烧孩子裹着的那床破被子。
- 舱门合拢的机械声 + 他回头看到的、正在崩塌的浮渊。

## 节拍 4：撤离中戚凛最后照面，她没回收械子，留一句意味深长的话，各自散入战火（暧昧·余味·E-02·N2）

> POV 移到戚凛（照第8章戚凛尾声的写法）。N2：内心一步微动，靠"手按上又收回"这个动作落地，不写她大段挣扎独白。

**① 站位/空间**
- 另一艘正在撤离的星联舰的舱口/舰桥。戚凛站在那儿，右眼战术同调单片镜亮着冷光。隔着两船之间飞溅的火光，她看得见那艘满载流民、正拼命逃向暗航道的大船，也看得见被抬到舷窗边、半边身子焦黑、还昏着的械子。她一只手边上就是舰载武器的操控台。副手在旁。

**② 动作链**（N2，简。她的选择＝一个按上又收回的动作）
1. 戚凛看见那艘慢吞吞的大船和船上昏迷的械子。
2. 她的手按在舰载武器的操控台上。（一炮就能追上那艘船。那是她的职责。那个人是待回收的资产、违禁实验体。）
3. 她按着，很久，没有下令。
4. 然后她把手收回来，转身对副手下令，声音平稳一如既往（她越动摇越死抠规矩的习惯——这次用平稳的公事腔，替械子铺一条生路）。
5. 说完最后半句，望着那艘船消失进暗航道的方向。

**③ 对话**（两层：一句给记录/给制度看，一句极轻、给自己/给他）
- 戚凛（对副手，平稳公事腔）："记录：目标实验体，浮渊事变中确认损毁，无法回收。"——潜台词：她在用条例的话术，亲手把他从通缉名单上抹掉、放他走。（照人物卡：她越动摇越抠规矩、开火前报编号记账——这次反过来用记账的话放人）
- 戚凛（极轻，像只说给自己听，补一句）："活着，把当年的事，查清楚。"——潜台词：E-02 那一问她没正面答，但这句话是她的回答——她把他当"唯一活着的证人/人"，放他去把真相活成证据。

**④ 内心微动**（N2，一步：从"这是我的职责/他是资产"到手收回来。不铺长挣扎，靠②的动作和③第一句的话术裂缝外化）

**⑤ 感官锚点**
- 单片镜的冷光。
- 她按在操控台上的那只手（按上→收回，钉死的动作终态）。
- 两船之间飞溅的火光；大船没进暗航道的方向。

## 节拍 5：大船载着黑户、流民、桑逃出沉没的浮渊；桑给出自由港坐标（脱出·定向·N2）

**① 站位/空间**
- 大船内。船正撞进一条暗航道、跃离浮渊。舱里挤着几百口人。械子被安置在舷窗边，正从昏迷里往上浮（节拍2之后，桑守着他）。桑在他身旁。

**② 动作链**（N2）
1. 大船脱离浮渊、跃进暗航道，舷窗外星海拉成流光，警报声和坍塌的闷响被甩在后头，舱里第一次静下来。
2. 械子从黑里往上浮，能感到左半身一阵迟钝、空落落的痛。
3. 桑坐在旁边，头也不抬地按住他不让他乱动。
4. 她从怀里摸出一小片东西，塞进他手里——一枚导航芯片。她别开脸（不看他，一贯的习惯）。

**③ 对话**（桑给坐标，嘴硬底软，潜台词）
- 桑（头不抬，按住他）："别乱动。你那条命，我从过载里抢回来的时候，就没剩多少了。"
