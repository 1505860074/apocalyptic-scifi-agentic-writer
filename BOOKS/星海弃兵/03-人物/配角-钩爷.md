# 人物卡 · 配角「钩爷」（双层）

> 双层 = 表层 + 底层。只记短期不变的设定。第2弧阶段性配角（浮渊军阀），灰色势力，非纯恶。

## 基本信息
- **姓名 / 代号**：钩爷（本名无人再提，因早年惯用一柄货钩得名）
- **角色定位**：浮渊补给platform的军阀/话事人；第2弧的灰色势力、收尾抉择点
- **登场卷章**：第2弧前段
- **一句话人设**：把整座浮渊当自家买卖盘剥的军阀，也是唯一还肯让这口"死地里最后一盏灯"续着的人。

## 表层
- **外貌特征**：五十上下，粗壮，右手是一副能开合的金属货钩义肢（早年落下的）；说话慢，笑起来眼睛不笑。
- **身份 / 职业 / 技能**：浮渊的实际掌控者，收过路税、管晶核黑市、庇护也压榨逃亡者；老江湖，识人、算账、拿捏分寸是一绝。
- **说话方式 / 口头禅**：慢条斯理、话里有秤："在浮渊，什么都能卖，就是别卖我的规矩。""这世道，能让人喘口气的地方，得有人收钱看着。"
- **习惯动作 / 标志性小动作**：那副货钩义肢一开一合，像在无形地估量对面值几个晶核。
- **表面性格**：唯利是图、盘剥成性的地头蛇军阀。

## 底层
- **核心欲望**：守住浮渊这口气——它是死地交界里仅存的活结点，也是他从流民一路挣上来的整个世界。
- **核心恐惧**：怕浮渊被外头那几头巨兽（星联征收、战火、更大的军阀）一口吞了，怕自己护不住这最后一块地。
- **创伤 / 来历**：他自己就是当年的流民，靠一柄货钩从底层杀上来，太懂"被当耗材"是什么滋味——所以他盘剥，却有一条不碰的线。
- **价值观 / 底线**：可以收重税、可以见死放手，但不把浮渊的人成批卖给星联当征收的耗材——这是他跟外头那些"抽血"的势力唯一的区别，也是他给自己留的最后体面。
- **表里冲突**：唯利是图的军阀 vs 死守最后一块活地的"守夜人"；他的盘剥，某种意义上正是让这盏灯不灭的方式。

## 功能位
- **剧情作用**：浮渊秩序的化身；第2弧的灰色势力（非好即坏原则的落地——他既压榨械子一行，也可能在最后关头因那条底线而帮一把）；收尾清场时的抉择点（帮/不帮）。
- **与主角的关系弧**：盘剥者/雇主 → 收尾一场基于"底线"的短暂共情或交易。
- **结局去向**：未定（可能随浮渊沦陷而牺牲/离散，留白）。
