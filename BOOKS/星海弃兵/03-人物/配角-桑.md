# 人物卡 · 配角「桑」（双层）

> 双层 = 表层 + 底层。只记短期不变的设定。第2弧登场，核心配角，后续升为船队医师/调律师。

## 基本信息
- **姓名 / 代号**：桑（逃兵，弃了原军籍姓名，只留一个"桑"字）
- **角色定位**：前星联同调军医/调律师，逃兵；第2弧新船员（船队医疗+机体维护）
- **登场卷章**：第2弧前段（浮渊）
- **一句话人设**：一个嘴上只认交易、下手却下不去"看人烂死"的逃兵军医，救人像还债，还了又怕再欠。

## 表层
- **外貌特征**：约三十出头，眼下常年青黑，左手手背一片旧烫疤（调律事故留的）；总嚼一种苦味的提神叶片，说话含混。
- **身份 / 职业 / 技能**：前星联战地同调军医兼"调律师"（专修同调驾驶员的神经接口/义体），逃兵；一手顶尖的接口维护与机体调律技术，能修械子这类实验体的身体。
- **说话方式 / 口头禅**：冷、糙、爱泼冷水，句句先谈代价："修可以，晶核先付""死不死是你的事，别指望我心软。"越在乎越难听。
- **习惯动作 / 标志性小动作**：干活前先把那片苦叶吐掉；给人处理伤口时手极稳，眼睛却不看对方的脸。
- **表面性格**：凉薄、市侩、谁的账都不认的逃兵。

## 底层
- **核心欲望**：不再对任何人负责、不再有牵挂，好让自己别再经历一次"眼睁睁看着救不了"。
- **核心恐惧**：怕重演当年——她在星联时，实验体在她手上被当"资产"处置，她修好过、也签字报废过；这笔账她一直背着。
- **创伤 / 来历**：前星联同调军医，接触过"实验体计划"的医疗/调律侧，认得实验体接口的构造。她逃，是因为再签不下第二张"报废单"；但逃兵不等于赎清，她清楚。
- **价值观 / 底线**：可以要价、可以见死不救地嘴硬，但真到手底下有条命，她下不去手不管——这条她恨自己也改不掉。
- **表里冲突**：嘴上"只认交易不管死活"，底层是个被愧疚追着跑、拼命不让自己再心软的人。（与老秦对照：老秦漏走坐标救了人、赎了半生；桑逃了，还在赎，且更硬更刺）

## 功能位
- **剧情作用**：救治械子的引爆后遗损伤，成为他身体的"读得懂的人"；身世线的新信息源（认得实验体接口/知道医疗侧一角，埋 S6）；船队第一个有专业技术的成员。
- **与主角的关系弧**：猜忌/交易 → 勉强的信任（她把他身体当人来修，而不是当资产核对）→ 加入。
- **结局去向**：未定（长线船员，留白）。
