# 命名与术语表 ·《星海弃兵》

> ① 定死本书**命名调性**（统一风格 + 命名哪些类别 + 克制原则）；② 增量登记所有专有名词，当"唯一真相源"，防止同一个东西全书名字漂移。
> 命名调性 P1 定，术语表随写作**增量登记**（每章写完把本章新造的专有名词登记进来，像伏笔DAG那样是活文件）。

---

## 零、最高原则：克制，专有名词是点缀不是堆砌

**默认不造新词。** 只有同时满足"会反复出现 / 值得读者记住 / 能被传播或喊出来有爽感"才值得起专有名词。宁可少，不可滥——本书真正让读者记住的核心专有名词就那么十几个，其余用大白话讲清。

---

## 一、命名调性（开书时定，之后基本不变）

- **本书整体命名风格**：**硬核科技·冷峻功能向**。
  - 听起来像军事/科技术语——冷硬、功能性、可信，不玩中二不堆意象。
  - 示例名："晶核""同调率""覆写""星联"。
- **本书重点命名哪些类别**（勾选）：
  - [x] 能力/技能/机制术语（同调相关）
  - [x] 组织/势力/群体代号
  - [x] 物品/资源/黑话术语（晶核、机甲型号等）
  - [ ] 地点/域/空间名（除关键星域外，默认大白话）
  - [x] 其他：实验体/身世线相关的**计划代号/编号**（冷硬、带阴谋感，扣悬疑）
  - > 没勾选的类别，默认用大白话描述，不刻意起专有名词。
- **命名禁忌**：不要生僻字堆砌；不要中英混搭；不要中二意象词；核心术语尽量 ≤4 字、喊得出口。

## 二之二、常用名物对照（现实已有、反复出现的场景名物——不造词，挑一个现实通用名，全书统一）

| 名物 | 全书统一叫它 | 别写成（防混用/生造） |
|---|---|---|
| 泊环 / 浮渊的平台地面 | **甲板** | 铁地 / 金属地 / 地板 |
| 拆船厂堆料间等室内地面 | **钢板地** | 铁地 |

> 由"铁地"违和引出（现实已有的地面被硬造成生造词、还混用"地板/金属地"三种），已按此把第 3–14 章相关处统一为 甲板 / 钢板地。机制见《命名与术语表-模板》二之二 + 全局命名原则（现实已有的沿用现实通用名、不造词）。
