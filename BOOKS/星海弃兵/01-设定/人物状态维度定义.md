# 人物状态维度定义 ·《星海弃兵》

> 一次性定死本书追踪哪些"人物状态"（会随故事弧频繁变的东西）。定完之后，所有人物状态账本（T18）只能用这里勾选的维度，不许自己加。
> 与人物卡（T4/T5）分工：卡记短期不变的设定，账本记这里勾选的、频繁变的状态。

---

## 本书追踪的维度（✅追踪 / ❌不追踪）

| 维度 | 是否追踪 | 说明 |
|---|---|---|
| **能力·同调阶位** | ✅ | 本书有明确升级机制（万机通感 Lv.1→舰船级）。同调能同调的目标量级、并行数、维持时长、反噬阈值，是核心成长线。 |
| **社会地位·身份** | ✅ | 主角从"边缘星带黑户/械子"一路变动（逃犯→杂牌头领→……）。星籍有无、被官方如何定性（人/资产/通缉）都算。 |
| **装备·机甲与舰队** | ✅ | 从一台老旧杂牌机甲 → 杂牌小队 → 破舰 → 舰队。这是"扛起舰队"的量化主线，必须追踪。 |
| **健康·机体损耗** | ✅ | 半机械之躯：义体状态、同调过载造成的损伤、恢复情况。反噬有代价，需记账防止忽伤忽好。 |
| **资源·晶核** | ✅ | 晶核=硬通货+能源。持有量直接决定能不能折跃、能不能供机甲，是资源紧张感来源。 |
| **自定义·身世线索碎片** | ✅ | 暗线进度条：主角通过读机器记忆/际遇积累的"关于自己是什么"的线索碎片数与内容。驱动悬疑内核。 |
| 金钱/资产（独立于晶核） | ❌ | 本书经济以晶核计价，不单列货币维度，并入"资源·晶核"。 |
| 职务/军衔（独立维度） | ❌ | 并入"社会地位·身份"。 |
| 角色关系身份 | ❌ | 关系进展走《关系情感状态卡》(T13)，不在状态账本里重复。 |

> **说明**：主角械子六个维度全追踪；配角按其身上"有意义"的维度选列（如老秦不追踪"身世线索碎片"）。
