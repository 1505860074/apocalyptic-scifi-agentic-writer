> 由 `人物种子` 步产出。服从《立项书》#5「主角大方向」与《世界观设定卡》《金手指卡》。
> 本卡只写**短期不变的设定**（性格/价值观/说话方式/外貌/模糊弧光）；会随弧频繁变的（同调等级/军中身份/机械化程度/锁区进度等）归 `03-人物/状态账本-R-09(老九).md`。
> ★本卡是"披着人皮但不确定是不是人"的存在——设计时启用了模板「非人/非常人视角塑造工具箱」（见文末标注哪几样落地）。

## 基本信息
- **姓名 / 代号**：**R-09**（渊火计划给的实验体物件编号，冷、非人）／军中蔑称"**弃兵**"／一线部队后来给的人名"**老九**"（从编号 R-09 的"九"顺口叫出来的——把一个物件编号软化成一个人的称呼，这声"老九"本身就是他"被当人"的第一步）。
- **角色定位**：主角（失忆半机械战士 / 从填线耗材长成舰队脊梁）。
- **一句话人设**：一具想不起自己是谁、却比谁都会打仗的身体；越强，越不像人。
- **贯穿全书的核心标签**：**"编号还是名字"**——读者提起他就想到那个在"武器 R-09"和"人·老九"之间反复被撕扯的存在。

## 第一层 · 表层（外在 / 读者一眼可见）
- **外貌特征**：清瘦、精壮，一张过于平静、几乎不带表情的脸——不是酷，是"表情这东西对他还很陌生"。后颈到脊椎沿线一排**神经同调接口**（冷金属接驳点，接入机甲时亮起冷光；深同调过载时这一带过热发红、渗出焦味）——这排接口是他"不是纯粹的人"的最直观标记，正文反复据此写。眼睛在寻常时候很静，进驾驶舱、进入同调的一瞬会亮起接口的冷光反色。
- **身份 / 职业 / 核心技能**：渊火计划报废批次的半机械实验体，被填进联合舰队一线部队当机甲驾驶员（耗材）。核心技能＝**异常高的裸同调 + 身体本能级的战斗操作**（不懂教科书战术，身体却像"打过很多仗"）。〔注：同调**等级/机械化程度/军中身份**是会变的状态，见状态账本，此处不写具体数值。〕
- **说话方式 / 口头禅**：**极省话、军令式短句**，能用一个字不用两个字；被问私事只会答不上来（没有记忆可答）。★内容域——**只在"战术/机甲参数/威胁评估"这类话题上他才突然利索、精准、成句**（身体记得的东西），一落到"你是谁/你想要什么/家在哪"这类情感与身世话题就卡壳、沉默或反问式的一句"……不知道"。正文只在内容落进"打仗/机器/活下来"这个域时让他显出专业与利索，别在无关场景硬给他台词。
- **习惯动作 / 标志性细节**：进任何空间先无意识扫出入口、掩体、威胁方位（把活人当"威胁度"读的异质本能）；紧张/过载前会**无意识去摸后颈的接口**；对旁人递来的善意（一块口粮、一句关心）有半秒的"读不懂、要先解析"的停顿，再照着别人的样子笨拙回应（社会脚本照本宣科）。
- **表面性格 / 外界评价**：麻木、冷、没脾气的工具人；军中都当他是"用完即弃的一件东西"，连名字都懒得给——直到一线部队开始叫他"老九"。

## 第二层 · 底层（内核 / 行动的真实驱动力）
- **核心欲望**：**活下去，并且——弄明白自己到底是个东西还是个人。**（表层是纯粹的生存本能；越往后，"想被当人看、想有个能回去的地方"这层欲望越浮上来，驱动他从护自己→护身边人→扛起更多人。绝不喊成口号。）
- **核心恐惧**：**怕那个答案是"不是人"。**——每一次深同调让他更强、也更机械化，他既依赖这份力量、又怕它把自己身上"人"的部分一点点换走；怕有一天想起来的真相，会证明他本就不该被当人。
- **创伤 / 出身**：**留白的空洞**——他没有可回忆的创伤，因为记忆被抹空了；这份"空"本身就是他最大的创伤（别人有过去可依靠，他连自己是谁都要靠身体的肌肉记忆去反推）。真正的出身＝渊火计划，方向留白（见命运层）。
- **价值观 / 底线**：**务实到近乎非人**——一切按"能不能活下来 / 威胁度 / 成本-风险-收益"计算（贴文风"机制精算显算化"）。但这套冷坐标里有一条他自己都没察觉的裂缝：**对"救人这件事"，他会做出不划算的选择**——身体会先于计算冲上去。这条裂缝＝他"是人"的第一个证据，也是弧光的种子。
- **表里冲突**：★**表＝麻木冷面的工具人/耗材，里＝"我是不是人"的隐痛 + 压不住的求生与护人本能。**外界越把他当"一件武器 R-09"，他里子里那个"想当人"的东西就越疼——但他不会说，只会用行动漏出来。
- **能力成长线**：（只写心智方向）从"被力量支配、被绝境逼着觉醒、事后害怕"→逐步"主动、可控地驾驭这份力量，并在变强与'守住人'之间学会自己踩刹车"。〔具体同调等级台阶 Lv.1→Lv.5+ 见《金手指卡》与状态账本，此处不重复数值。〕

## 第三层 · 命运层（秘密 / 弧光 / 宿命 · 长线大伏笔）
- **隐藏秘密**：**他的身体"打过很多仗"，但他一场都想不起来。**这具身体的战斗肌肉记忆、异常高的裸同调、体内层层封着的"锁区"，到底是他"前身"本就有的、被渊火计划封起来抹了记忆的（本我封印方向），还是渊火用异族技术/样本"造"出来的（异族产物方向），还是他本人被设计成一把"钥匙"——**他自己也不知道为什么**。只给方向，不定死（同步《金手指卡》【待揭示】、《世界观设定卡》【待揭示】B 组）。
- **成长弧光**：从"一件被造出来、用完即弃的武器（R-09/弃兵）"→"一个被人叫出名字、值得追随的人（老九）"→"一支舰队的脊梁"。（只定方向，转变节点不锁死。）
- **与主线的宿命联系**：他体内的锁区**逐层解锁＝记忆逐步归位＝逼近这场"存亡之战另有真相"的那一层**——变强引擎与身世解谜引擎是同一台。他越强，就越接近"敌我暧昧"真相的核心，也越接近"我是不是人"的答案。他很可能本身就是这场战争真相的一部分。
- **关键抉择点**（价值观级，1–3 个，对应弧光章，方向不锁死）：
  1. 第一次在"划算地丢下某人保命"与"不划算地回头救人"之间，身体替他选了后者——他第一次撞见自己"像个人"。
  2. 某次面对"再深同调一层就能赢、但会更不像人"的取舍——变强的代价第一次被他自己看清并主动承担/拒绝。
  3. 后期当身世/敌我真相摊开，面对"他到底站哪一边、算哪一边的人"的抉择（留白，与真相合流）。
- **模糊命运方向**：走向"成长/接纳"为主——被当人接纳、也接纳自己是不是人这个答案本身；不排除"牺牲式的重生"色彩。给两个可能：①最终认定"是不是人由怎么活来定义，不由怎么造出来定义"，扛起舰队；②真相揭开他确非纯粹的人，但仍选择像人一样活/战。写作中自然收束。

## ★本卡用到的"非人/非常人视角塑造工具箱"（对照模板落地清单）
1. **双名标记**：R-09（物件编号，冷/非人）↔ 老九（战友给的人名，暖/被当人）；本质外泄/深同调过载时旁人会切回叫"那东西/编号"。
2. **恐怖谷＝该有的人类反应缺席 + 不该有的非人反应出现**：对本该恐惧的杀戮/绝境反应麻木（该有的恐惧缺席），身体却做出不该有的、非人般精准冷静的杀法；错位微动作——别人手抖他不抖、过载时瞳孔映接口冷光。
3. **社会脚本照本宣科**：对递来的善意先"解析半秒"再笨拙照做，把人类日常互动当说明书执行。
4. **概念缺席即塑造**：失忆到没有"我是谁/家/名字"的概念，被问只能报编号；被叫"老九"时的陌生感——用空缺定义他与人的鸿沟。
5. **一以贯之的异质价值坐标系**：以"威胁度/成本-风险-收益/能不能活"评估一切人和事，务实到非人（同时落地文风"机制精算显算化"）。
6. **反差立人（祛魅再镀金的反向用法）**：先被当废料/填线料狼狈落地，再一场场露出"深不见底"的獠牙。
